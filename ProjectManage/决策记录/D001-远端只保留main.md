# D001 远端只保留 main，所有版本走“冲突检测 → 冲突处理 → 合并到 main”

- 日期：2026-11-02
- 决定人：用户
- 状态：有效
- 来源：项目记忆（回溯补记）；规范正文见 [GitHub 协同规范](../../炼厂车间设备员/文档/规范/GitHub协同规范.md)

## 决定

远端仓库只保留 `main`。任何人的改动在本地工作分支完成，按协同规范第三节的 5 步（冲突检测、冲突处理、验证、快进合并并推送、清理）进入 `main`。不推送工作分支，不强制推送。

## 备选方案

- 分支加 PR 评审：用户否决。

## 影响

- 工作分支只在本地，最长不超过 2 天。
- 发现远端出现其他分支时，按同样流程合并后删除；未完成或无法判断取舍的先联系提交人。
