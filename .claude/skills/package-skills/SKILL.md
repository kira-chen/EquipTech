# 设备员技能打包

所有打包都通过 `炼厂车间设备员/tools/package.sh` 完成。产物在 `炼厂车间设备员/dist/`，该目录不入库，不要提交或上传 zip。

## 选择命令

在仓库根目录执行，按用户要求选一条：

| 用户要求 | 命令 |
|---|---|
| 打全部发布包，或更新技能清单 | `bash 炼厂车间设备员/tools/package.sh` |
| 打一个或几个技能 | `bash 炼厂车间设备员/tools/package.sh --skill <英文名> --skill <英文名>` |
| 打开发包（含 `演示case/` 样例） | `bash 炼厂车间设备员/tools/package.sh --with-examples` |

用户只给中文名时，先在技能目录的 `上架信息.md` 中找到对应的英文目录名。全量打包约需数分钟，命令超时时间设为 10 分钟。

`--skip-test` 只在用户明确要求时使用，并在结果里说明没有跑自测。

## 处理结果

- **全部成功：** 告诉用户成功数量、自测断言数、技能清单状态和产物目录。
- **有技能失败：** 脚本不会打包自测失败的技能，退出码为 1。列出失败技能和原因，不要修改自测来让它通过，也不要用 `--skip-test` 绕过。
- **缺少命令：** 脚本需要 node、zip、unzip。缺少时告诉用户，不要自行安装。

## 产物说明

- `dist/设备员-发布包/`：每个技能一个 zip，只含运行所需文件，另有 `技能清单.xlsx` 和 `技能清单.md`。上传平台时用这里的包。
- `dist/设备员-开发包/`：全部文件，含回归样例和自测脚本，仅内部使用。
- 技能清单只在发布包齐全时生成。只打单个技能时，脚本会用现有发布包刷新清单。

## 依赖提醒

`permit-precheck-bridge` 和 `overhaul-process-check-bridge` 运行时依赖【炼化】技能，这两个依赖不在本仓库内。打包不受影响，部署时要同时安装对应的依赖技能。
