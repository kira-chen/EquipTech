# EquipTech · 设备检维修技能包

面向中石化体系炼化厂设备员的技能包，同时适配 WorkBuddy 和豆包办公两个平台。

## 目录

```
炼厂车间设备员/
├── 设备员skill/            # 设备员 50 个技能，按 8 个业务域分目录
├── 演示case/              # 各技能的演示与回归样例
├── 文档/                  # 规范与历史过程记录
├── 素材/                  # 技能图标（图标/）与图标生成脚本（脚本/）
├── tools/                 # 打包脚本
└── dist/                  # 打包产物，不入库

ProjectManage/             # 项目推进管理：时间线、任务记录、决策、待办与阶段总结
.claude/skills/package-skills/  # 打包技能，运行 /package-skills
```

详细说明见 [炼厂车间设备员/README.md](炼厂车间设备员/README.md)。
