# 巡检点检任务清单生成（inspection-task-dispatch）· 演示与回归样例

> 本目录为技能 `inspection-task-dispatch` 的演示与回归样例，不进发布包；开发包（`build.sh --with-examples`）中位于技能目录 `examples/`。
> 全部样例由 `node scripts/make-sample.js` 再生（默认 seed=1），上次巡检日期/时间随 seed 变化但结论不变。

## 关键验证点

1. **周期待确认不默认日检**：M-1501「电机接线盒检查」周期为空、I-1601「变送器取压管检查」周期填「视情况」，两项都进 `unscheduled`，**不进任务清单**，warning 明确写「未按日检默认处理」，行号可追溯到巡检标准表。运行小时周期（「运行 2000 小时」）同样进待确认并提示转 runtime-hours-tracker。
2. **特护强制最高优先级**：K-1801 富气压缩机台账「特护=是」，任务为 P1，概览【注意】行点名；逾期项（P2）排在其后。
3. **无巡检标准不造占位项**：A-1701 常压塔顶空冷器按位号与设备类型「空冷器」都匹配不到标准，进 `noStandard` 单列，不生成任何任务项。
4. **标「否」的设备排除**：V-1302 备用储罐台账标「否」，进 `excluded` 并附原因，不出现在任务清单与 `noStandard` 中。
5. **优先级六级**：特护 P1 > 逾期 P2 > 关键设备 A P3 > 上次异常 P4 > 临期 P5 > 常规/未检 P6；`priorityReason` 写明定级理由。
6. **临期阈值随周期比例**：默认周期的 10%，E-1201 法兰泄漏检查（30 天周期，距到期 2 天 ≤ 3 天）临期；P-1101A 的 7 天周期项未到期不进清单。`--due-soon 2` 或 `--due-soon 20%` 可改。
7. **上次记录缺失全按未检**：`sample-no-history.xlsx` 无「上次巡检记录」表，全部设备 `dueStatus` 为 `never`，`meta.lastRecordProvided` 为 `false`，不假设已检过。
8. **`--shift` 可选**：给了按标准表「适用班次」过滤（未填/每班/全部任何班次都排）；不给按全天排不过滤。
9. **班次级周期按小时**：每班=8 小时、每 2 小时；上次记录带时间且给 `--time` 才按小时判逾期，否则「本班到期」并 warning，不捏造逾期小时数。
10. **系统列名与一行一检查项**：SAP 样例的「功能位置/设备/设备描述/工厂区段/ABC标识/对象类型」、智能巡检「检查内容/巡检时间/测值/是否报警」直接识别；同一位号多条明细按位号聚合取最近一次，任一检查项报警即记上次异常。
11. **路线仅为建议**：区域按一区 → 二区聚类、区内按位号升序编号；`meta.routeNote` 与报告末尾均保留「实际巡检路线由车间确定」。
12. **车间范围核对（D007）**：本目录样例都不含车间列，各对照行结果与加核对前一致（2026-11-05 逐行复跑核对）；报告口径处多一行「车间范围：输入未含车间列，车间范围以取数条件为准。」，输出 JSON 的 `meta.workshopScope` 各表 `status` 为 `noColumn`。

## 再生样例

```bash
node scripts/make-sample.js            # 默认 seed=1
node scripts/make-sample.js --seed 7   # 上次巡检日期变化，结论不变
```

## MCP 取数对照

平台接入业务系统 MCP 时不用附件：按 SKILL.md「数据获取（MCP）」调用三个工具，csv 全部放进同一个空目录作 `--input`，`--date` 用当天。演示数据每天按剧本刷新，预期结果只列每天稳定的结论。

| # | 示例问题 | MCP 调用 | 运行参数 | 预期结果 |
|---|---|---|---|---|
| M1 | 常减压车间今天白班巡检任务，特护放前面，标出漏检 | 设备资产管理 `get_equipment_ledger`（workshop=常减压车间，for_skill=inspection-task-dispatch）+ 点检巡检App `get_inspection_standards` + `get_last_inspection`（workshop=常减压车间）→ 同一目录 | `--input <目录> --workshop 常减压车间 --date <今天> --shift 白班` | 特护设备（P-2105A/B、P-2106A/B、C-3101A/B、T-1201、T-1301 等）全部 P1；逾期含漏检的 P-3102B（振动、润滑油位）和 E-3201（法兰泄漏、进出口温度），P2；不需巡检的 W-1101、W-1201、W-3201、Q-2101 进 `excluded`；无周期待确认、无无标准设备；warning 提示每班周期项未给 `--time` 按本班到期。逢周检、月检项到期而上次未检的日子（如 T-3201、V-3101、V-3201、E-3101、P-2108），逾期清单另有这些设备，如有则照列，不写死“只有” |
| M2 | 同上，8 点接班，每班项按小时判逾期 | 同 M1 | 同 M1 加 `--time 08:00` | 今早已检的每班项不再进清单；P-3102B 的轴承温度、密封泄漏按小时判逾期，`overdueHours` 有值；无班次级周期 warning；特护设备仍为 P1。特护 T-1201、T-1301 的每班项（外观及保温、安全附件）如今早未检则也按小时判逾期，有的日子今早已检就不进清单；周检项到期的日子同 M1 另有逾期设备 |
| M3 | 加氢车间今天白班要检什么，有没有逾期 | 设备资产管理 `get_equipment_ledger`（workshop=加氢车间，for_skill=inspection-task-dispatch）+ `get_inspection_standards` + `get_last_inspection`（workshop=加氢车间）→ 同一目录 | `--input <目录> --workshop 加氢车间 --date <今天> --shift 白班` | 无逾期项；特护 C-5302A/B、P-5101A/B、R-5101、E-5101 等为 P1；W-5101、Q-5301 进 `excluded` |
