> 命令在技能目录 `设备员skill/01-日常运行监控与巡检/lubrication-manager/` 下运行，`$CASE` 指本技能的演示目录：`CASE=../../../演示case/01-日常运行监控与巡检/lubrication-manager`。

## 关键验证点

1. **周期缺失不默认**：P-1103A 台账未填润滑周期，进「无法判定」并 warning，**未按一月一次之类的常见周期推算**；既不计入逾期也不计入正常。
2. **上次日期缺失不倒推**：E-1201 上次加换油日期为空，同样进「无法判定」，**未从加换油记录中取最后一条日期倒推**。
3. **运行小时周期不折算日历天**：K-1402「运行2000小时」按 累计 18650 − 上次加换油时 16400 = 2250h 判逾期 250h；P-1104 直接给「自上次加换油运行小时」1900h 判临期；P-1105「运行4000小时」缺累计小时进无法判定，配 `--run-hours` 后可判。
4. **五定齐备率**：定点/定质/定量 100%，定期 13/14、定人 13/14（E-1202 责任人空）；台账无责任人列时定人齐备率为「—」并 warning，不按齐备处理。
5. **油液无限值只列数值**：K-1401 闪点、V-1301 铁含量均未给厂内限值，进 `oilAnalysis.noLimit`，**不判异常、不引用任何通用限值**；`counts.oaAbnormal` 不因此增减。仅 `--ref-standard` 显式提供时才进参考比对，且不计入异常。
6. **单位混用不换算**：K-1401 的透平油记录中 L 与桶并存，按单位分列，warning 明示未做换算，**未按标准桶容积折合**。
7. **数量缺失不按 0**：P-1101A 有一条补油记录数量为空，计入「数量缺失条数」，消耗量显示「—」，未并入合计。
8. **油品牌号品牌词归一**：「L-TSA46 透平油」「L-TSA46透平油」「长城 L-TSA46 透平油」归为同一疑似组列入「附一」，统计按原写法分列，**未自动合并**；单价匹配同样忽略品牌词。
9. **无单价不折算**：不加 `--price` 时不出现任何金额，报告写「未使用任何估计单价」。
10. **SAP/EM 列名**：导出样例「功能位置→位号、设备描述→设备名称、润滑点名称→润滑部位、油品牌号→油品名称、换油周期→润滑周期、最近加换油日期→上次加换油日期、润滑责任人→责任人」全部按合并别名识别；8 位「设备编号」单独展示，不当位号。
11. **带单位数值**：加油量「12L」「0.2L」剥离单位取数值并 warning 提示核对单位。
12. **声明行与提示风格**：报告开头带声明行；醒目提示用【注意】【未判定】，无 emoji。
13. **车间范围核对（D007）**：本目录样例都不含车间列，各对照行结果与加核对前一致（2026-11-05 逐行复跑核对）；报告口径处多一行「车间范围：输入未含车间列，车间范围以取数条件为准。」，输出 JSON 的 `meta.workshopScope` 各表 `status` 为 `noColumn`。

## 再生样例

```bash
node scripts/make-sample.js            # 默认 seed=1
node scripts/make-sample.js --seed 7   # 数值变化，结论不变
```

seed 变化后仍恒定：4 逾期、3 临期、4 周期内、3 无法判定（含 1 项运行小时周期）、2 油液超厂内限值、2 无限值项、1 组油品牌号写法不一致（3 种写法）。

## MCP 取数对照

平台接入业务系统 MCP 时不用附件：按 SKILL.md「数据获取（MCP）」调用工具，润滑台账、加换油记录、油液分析放目录 A（`get_oil_analysis` 先取台账、再用台账位号作 `tag` 取，避免混入外车间油样），油品单价单独放目录 B，`get_run_events` 的累计运行小时放目录 C，`--date` 用当天。演示数据每天按剧本刷新，预期结果只列每天稳定的结论。

| # | 示例问题 | MCP 调用 | 运行参数 | 预期结果 |
|---|---|---|---|---|
| M1 | 常减压车间润滑到期、用油量与金额、油样超标 | 点检巡检App `get_lubrication_ledger`（workshop=常减压车间）+ `get_lubrication_records`（workshop=常减压车间）+ `get_oil_analysis`（tag=润滑台账里的位号）→ A；`get_oil_prices` → B | `--input A --price B --oil-analysis --workshop 常减压车间 --date <今天>` | 无法判定 0；五定齐备率 100%；油品全部匹配到单价；油液分析 P-2101A 水分、铁含量超厂内限值（剧本油样），无「无限值项」、无台账外油样；临期含 M-3101A。逾期、临期的其余位号随剧本日变化（如有 P-3102A、P-2106A、M-2106A 逾期，或 C-3101B 运行 2000h 周期剩余不足 168h，则按清单列出），不写死 |
