# 巡检点检数据汇总（inspection-data-digest）· 演示与回归样例

> 本目录为技能 `inspection-data-digest` 的演示与回归样例，不进发布包；开发包（`build.sh --with-examples`）中位于技能目录 `examples/`。
> 全部样例由 `node scripts/make-sample.js` 再生，数值随 seed 变化但结论不变。
> 列名采用中石化炼化厂常用系统导出写法：智能巡检 APP（功能位置/检查项/测值/是否报警，一行一检查项）、点检仪（设备位号/点检项目/实测值/报警标志/ABC标识）、状态监测（测点/测量值/上限/下限，无结果列）、SAP PM 技术对象清单台账（功能位置/设备/技术对象描述/工厂区段/ABC标识）。

## 关键验证点

1. **一行一检查项聚合**：主样例巡检明细 10 行检查项聚合为 8 台设备；P-1101A 两项（机封泄漏、轴承温度）均未报警为正常。
2. **是否报警判定**：P-1101B 巡检"机封泄漏"报警标志为"是"，点检振动报警 → 异常；两项都是异常不算冲突。
3. **测值对限值**：状态监测表无检查结果列，C-1401 壁温在 300~380 内为正常；P-1102A 轴承温度 71 < 上限 85 为正常。
4. **就严冲突定位到检查项**：P-1102A "轴承温度" 点检异常（报警）、状态监测未超限，同一检查项正常/异常并存 → 冲突，整机判异常；两条原始记录及行号列出。
5. **未判定不静默**：M-1501 结果为「待查」且报警标志空，既不计正常也不计异常，单列并注明原因。
6. **六档状态**：P-1102B 运行状态"备用"显示为备用；无运行状态列的表报告加【注意】。
7. **特护**：点检数据 ABC标识"特护"、台账 ABC标识"特护" 或「特护/特护标记」列为「是」都能标记；重要度 A/关键 不等于特护；台账才有的特护标记补到异常清单；异常清单与漏检清单特护置顶并有【注意】上报提示。
8. **带单位测值**：`54.45℃`、`2.74mm/s` 剥离单位取数值，每列 warning 一次。
9. **无台账不倒推**：不加 `--ledger` 时 `counts.missed` 为 `null`，报告写「未提供设备台账」。
10. **跨日 / 班次日**：系统导出样例 P-2103 记录为前一日被跳过；夜班样例次日 02:10 在 `--shift-window 08:00` 下归入本班次日。
11. **合计行**：系统导出样例末行「合计」被跳过并 warning。
12. **车间范围核对（D007）**：本目录样例都不含车间列，各对照行结果与加核对前一致（2026-11-05 逐行复跑核对）；报告口径处多一行「车间范围：输入未含车间列，车间范围以取数条件为准。」，输出 JSON 的 `meta.workshopScope` 各表 `status` 为 `noColumn`。


## MCP 取数对照

平台接入业务系统 MCP 时不用附件：按 SKILL.md「数据获取（MCP）」调用工具，巡检记录放目录 A、台账放目录 B。两个工具都传 `workshop`，`--date` 用当天。演示数据每天按剧本刷新，预期结果只列每天稳定的结论。

| # | 示例问题 | MCP 调用 | 运行参数 | 预期结果 |
|---|---|---|---|---|
| M1 | 常减压车间今天巡检汇总，对照台账看漏检 | 点检巡检App `get_inspection_records`（workshop=常减压车间，for_skill=inspection-data-digest）→ A；设备资产管理 `get_equipment_ledger`（workshop=常减压车间，for_skill=inspection-task-dispatch）→ B | `--input A --ledger B --workshop 常减压车间 --date <今天>` | 异常含 P-2101A（振动、轴承温度、轴承箱声音三项报警）、E-1201；漏检清单含 P-3102B、E-3201；无冲突；E-3101 法兰泄漏如为「待查」（剧本日的脏数据），E-3101 判未判定单列、不计正常，warning 点名，除此之外无未判定；报告提示记录表无「运行状态」列。其余异常设备（如 FV-2101、LT-1101）、特护异常与漏检置顶的特护设备随剧本日变化，如有则按清单列出，不写死 |
