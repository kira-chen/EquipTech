## 关键验证点

1. **周期缺失不默认**：P-1401 台账未填切换周期，进「无法判定」并 warning，**未按一月一次之类的默认周期替用户设定**；既不计入逾期也不计入正常。
2. **上次日期缺失不倒推**：P-1402 上次盘车日期为空，同样进「无法判定」，**未从切换盘车记录中取最后一条日期倒推**。
3. **周期写法无法解析**：P-1403 切换周期写作「随机组检修」，无法解析进「无法判定」，未按 90 天猜测；运行小时周期（「运行 2000 小时」）同样不按日历判定并指向 runtime-hours-tracker。
4. **主备无法配对不猜测**（关键）：P-1501 备用位号为空、P-1502 主用位号为空，均进 `pairingIssues` 单列并 warning，**未按位号尾字母 A/B 规律或名称相似度猜测配对**；这两行不参与到期判定、执行率与备机完好。导出样例中 P-2103 主备同位号同理。
5. **当前主用可变、不按奇偶猜**：P-1101、P-1102 的最近一次切换记录「切至位号」为 B 泵，当前主用推导为 B（`roleSource: 切换记录`），与台账相反；P-1201 记录未填切换方向、无记录表时按台账展示并 warning。
6. **以机组为键**：到期清单、长期未切换、执行率、备机完好都按「机组号」统计；无机组列时以主备位号组合作键并 warning。
7. **备机检修中单列**：P-1601 备机状态「检修中」，切换虽已逾期 150 天但**不进逾期/长期未切换清单**，单列第五节并提示验收后更新台账；不计入备机完好分子。无备机状态列（导出样例）时备机完好率为 null 并 warning，不按备用默认。
8. **长期未切换按 N 倍切换周期**：默认 2 倍，P-1101（周期 30 天，阈值 60 天，未切换 13X 天）与 P-1102（周期 60 天，阈值 120 天，未切换 20X 天）进 `longIdle`，注明阈值依据；`--overdue-factor` / `--long-idle-days` 可改。
9. **每班盘车按班次级到期**：P-1302 盘车周期「每班」，上次盘车为当日 → 临期并备注「班次级周期，本日内按班次到期」（`shiftLevel:true`）；执行率不折算计划次数显示「—」。
10. **执行率分母为 0 显示「—」**：K-1401 切换周期 1 年，默认 180 天统计区间内计划次数为 0，执行率为 `null`，报告显示「—」，**未写 0%**；而 P-1102 切换计划 3、实际 0，才显示 `0.0%` —— 两者含义不同，不可混淆。
11. **记录归属不猜测**：记录表中 P-9999 在台账中查无对应机组、P-1302B 的「检查」无法归入切换/盘车/试运，两条均不计入执行率并 warning。
12. **系统列名与别名口径**：导出样例「机组编号/主用/备用/设备描述/装置名称/倒泵周期/盘车间隔/功能位置/切换后主用」全部按别名识别；SAP「设备」（8 位流水号）不当位号；「项目」不作作业类型别名。
13. **说明行保留**：报告头部与管理说明段之后各出现一次「切换实施前需由工艺确认具备切换条件并按操作票执行，本清单仅为周期提醒」，末尾另有通用声明行。
14. **车间范围核对（D007）**：本目录样例都不含车间列，各对照行结果与加核对前一致（2026-11-05 逐行复跑核对）；报告口径处多一行「车间范围：输入未含车间列，车间范围以取数条件为准。」，输出 JSON 的 `meta.workshopScope` 各表 `status` 为 `noColumn`。

## 再生样例

```bash
node scripts/make-sample.js            # 默认 seed=1
node scripts/make-sample.js --seed 7   # 数值变化，结论不变
```

seed 变化后仍恒定：2 切换逾期、1 切换临期、2 盘车逾期、2 盘车临期、3 无法判定、2 主备配对异常、2 长期未切换、1 备机检修中、5 个机组当前主用由记录推导。
