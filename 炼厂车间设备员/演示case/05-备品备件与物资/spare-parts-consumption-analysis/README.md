## 关键验证点

1. **单位不换算**：样例含套、片、L、台、个五种单位。同一设备的多单位消耗分行显示为 `12 套 / 38 L`，绝不合成一个数。
2. **未归属不平摊**：3 条无位号记录单列。平摊会凭空制造某台设备的消耗，排除会让总量小于实际领用量，两者都是失真。
3. **异常增长按区间归一**：用 3 个月基线与 1 个月基线分别跑，归一后倍数明显不同。不归一会把「统计区间更长」误报成「消耗异常」。
4. **无单价不折算**：样例中球阀、螺栓、部分轴承故意无单价，这些项金额为「—」，不按同类单价估算。
5. **不断言原因**：异常增长节固定带「建议核实是否与某次检修、重复故障或统计口径变化相关；本技能不断言原因」。
6. **MB51 冲销与收货**：262 冲销按负数抵减数量与金额，101 收货不计入消耗，warnings 各提示一次，`counts.reversals` 记录条数。
7. **金额来源优先级**：本位币金额列 > 单价表 > 不折算；有金额列时单价表不覆盖（selftest K17），只补空值（K18）。
8. **基期三种取法**：上期 JSON / 上期出库表 + 起止 / 同一导出切基期；基期与本期重叠、倒置、缺起止均报错；基期无记录只 warning。
9. **「设备编号」不作位号**：SAP 设备编号是流水号，这一列不会被当作位号归属消耗。
