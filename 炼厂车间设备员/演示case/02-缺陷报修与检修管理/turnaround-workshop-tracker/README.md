# 大检修车间侧跟踪（turnaround-workshop-tracker）· 演示与回归样例

> 本目录为技能 `turnaround-workshop-tracker` 的演示与回归样例，不进发布包；开发包（`build.sh --with-examples`）中位于技能目录 `examples/`。
> 全部样例由 `node scripts/make-sample.js` 再生，承修单位、班组与人名随 seed 变化但结论不变。
> 样例中的日期按 `--date`（默认 2026-09-21）相对生成，跑脚本时 `--date`、`--start`、`--end` 须与下表一致，否则预期结果不成立。

统一参数：`--workshop 常减压车间 --project "2026年装置大检修" --date 2026-09-21 --start 2026-09-10 --end 2026-10-10`

## 关键验证点

1. **完成比例与状态矛盾不自行修正**（最关键）：主样例 T-09 状态「未开工」但比例 50%、T-10 状态「已完工」但比例 30% → warning + `inconsistent` 单列，**两个字段均按原值保留**。
2. **已中交 / 已开工独立状态**：T-20「已中交」、T-21「已开工」分列计数，不归已完工；总体表与进度表.xlsx 摘要行分列；T-21 触发"已开工语义" warning。
3. **类型③默认不判**：T-01 完成比例 35% 明显落后，默认不判滞后，加 `--linear-check` 后判为「完成比例落后应有进度」。
4. **三查四定单独一节**：Q-02 超期 2 天、Q-03 四定不全（中交留项）、Q-06「已上报」未判定（不按已关闭）；进度表.xlsx 另附「三查四定问题」工作表。
5. **完成比例为空不按 0、不线性推算**：T-12、T-13 显示「—」并给定性进度。
6. **完成比例超界不截断**：T-11 填 150 → 置空，`rawPercent` 保留。
7. **滞后影响工期必带免责声明**：md 头部、关键路径滞后节、滞后节末尾与 `进度表.xlsx` 第三行均出现。
8. **计划完工早于计划开工单列**：T-15 进 `planIssues`，不对调。
9. **开工条件与材料缺口分别单列**：T-13 两处未判定均不按已具备 / 已到货。
10. **SAP 列名**：案例 7 的功能位置 / 订单号 / 基本开始日期 / 主工作中心 / 用户状态经共享别名识别，SAP「设备」编号不当位号。
11. **无 emoji**：关键路径滞后节标题用【注意】。

## 再生样例

```bash
node scripts/make-sample.js            # 默认 seed=1，date=2026-09-21
node scripts/make-sample.js --seed 7   # 承修单位与人名变化，上述结论不变
```
