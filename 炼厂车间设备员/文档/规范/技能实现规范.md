## 九条硬约束（违反即返工）
1. **脚本出数**：所有数字、判定、计数在脚本里算完写进 JSON，md 里的数字全部来自 JSON。
2. **缺数据不补齐**：无法解析的数值 → warning + null（显示"—"），**绝不按 0**。缺表缺列 → warning + 该节写"未提供 XX 数据"。
3. **未判定单列**：判定依赖的字段为空 → 该项 `undetermined` 并在 JSON 与 md 里单列一节，说明缺哪个字段。**绝不按最宽松或最严格默认**。
4. **出错格式**：末行 `{"ok":false,"error":...,"warnings":[...]}` 且 `process.exit(1)`。成功末行 `{"ok":true,...}` 且同时写 `<out>/summary.json`。
5. **时间**：显示用北京时间；ISO 8601 带时区的入参强校验；Excel 序列号按墙钟。
6. **分析段占位**：报告里模型要写的段落用 `<!-- ANALYSIS_START -->` / `<!-- ANALYSIS_END -->` 包起来。
7. **声明行**：SKILL.md 里写了"必须保留声明行"的，脚本要把那句话直接写进 md 产出。
8. **样例可再生**：make-sample.js 支持 `--seed`，seed 变数值变、但预期结论（几项超期/几项异常/几项未判定）不变。
9. **仅 Node 内置模块**，禁止 npm，Node ≥18。

## selftest.js 必须覆盖
- 正常路径产出与计数正确
- 每一类 `undetermined` 的触发与"不被默认处理"
- 缺列/缺表 → warning 且不中断（除非该表是唯一数据源）
- 数值无法解析 → null 不是 0
- 参数校验：缺值、未知参数、非法日期、输入不存在 → ok:false + exit 1
- 合计行跳过、别名列头、标题行表头识别
- summary.json 落盘、md 各章节齐全、分析段占位符存在

结尾打印 `<技能名> 自测：N 通过，M 失败`，有失败则列出并 exit 1。

## SKILL.md 的「数据获取（MCP）」一节
每个技能的 SKILL.md 在「操作步骤」之前都有这一节，写明平台接入业务系统 MCP 时怎样取数：调哪个服务的哪个工具、`for_skill` 等参数、下载文件交给脚本的哪个参数、分几个目录、需要的改名或补列。依据是 `MCPServer/test/e2e-skills.js` 与 `e2e-knowledge.js` 里实测通过的用法，工具名与参数名以 [MCP服务清单](../MCP服务清单.md) 和工具定义为准。

- 新增技能、改了脚本的输入参数或可识别的表名列名时，同步改这一节，并告知 MCP 维护方。
- 服务名写平台上的显示名，但不写「EAM」，按口径对照写「设备资产管理」。
- 不用 MCP 的技能也保留这一节，写明数据来自哪里（上游技能 JSON、平台知识库或用户输入）。
