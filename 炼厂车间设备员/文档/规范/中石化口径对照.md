# 中石化体系炼化厂 · 设备员技能包口径对照

> 本文件是 50 个技能统一改造的**唯一依据**。所有 SKILL.md、references、scripts 中涉及系统列名、术语、分级、组织层级、指标定义的写法，以本文件为准。不绑定具体企业；凡厂与厂之间有差异的项，标注「厂内可配置」，技能用 `--rules`/`--spec` 等参数接厂内口径，默认不替用户选。
>
> 本文件只记口径与术语，不转述法规数值。需要法规数值的地方写"依据 XX 规定，数值以用户提供的制度文件为准"。

## 一、对象与岗位边界

- 对象：中石化体系炼化厂（炼油、乙烯、芳烃、化工等装置）**车间（运行部）设备员**。常白班，不倒班；交接的是值班、休假、调岗的工作交接，不是操作班组的交接班。
- 组织层级（由下至上）：班组 → 车间/运行部 → 分厂/作业部（有的厂无此层）→ 公司机动/设备部门 → 公司领导。技能参数统一用 `车间 | 分厂 | 公司` 三档，允许用户自定义名称。旧称"机动处"一律不用，统一写"公司设备管理部门（机动部/设备部）"。
- 设备员**可做**：台账、缺陷登记（维修通知单）、工单跟踪催办、巡检点检数据汇总、检修需求申报、属地监督记录、隐患台账、日报周报月报、迎检材料整理、设备专业培训与指引建议稿。
- 设备员**不做**（技能须声明"由 XX 归口"）：创建维修工单与定工时（维修单位/计划员）、工艺参数与联锁定值变更（工艺/仪表）、压力表温度计检定与 SIS 功能测试（计量/仪表）、承包商考核分档定性（安全环保部门归口）、事故定性与责任认定、作业票审批签发、检修方案批准、验收签字。

## 五、作业许可与检修分级术语

- 作业许可八大类（《中国石化作业许可管理规定》）：**用火作业**（不写"动火"）、受限空间作业、高处作业、吊装作业、临时用电作业、动土作业、断路作业、**盲板抽堵作业**。拆装盲板必须提示办理盲板抽堵作业许可。用火按特级/一级/二级，高处一~四级，吊装一~三级（级别以作业票为准，技能不自判）。
- 监护：**双监护**（属地监护人 + 作业单位监护人），作业前 JSA/风险分析交底，属地确认人在场。
- 检修分级：**装置大检修（停工检修）/ 日常维修 / 抢修 / 专项（技改技措）**。"大修/中修/小修"口径废止，但别名表保留映射：大修→大检修、中修/小修→日常维修。
- 大检修关键节点：开工前条件确认（设备交出、盲板、作业票）→ 施工 → **三查四定** → **中交（中间交接）** → 试压/试运/投料前条件确认 → 开工。"中交"是独立状态，≠检修完工。
- 验收：**三级验收**（班组 / 车间 / 公司设备部门），工艺（操作）方参与；日常维修无监理。应附资料：检修记录卡、质量验收记录（H/W 点见证）、试车记录、备件领用单、更换部件质量证明。
- 设备交出：按介质与作业类型给条件清单，带压/高温与否由用户确认，脚本不按阈值推断；推断值一律标"推断，待确认"。

| 指标 | 定义口径 | 数据来源 | 备注 |

| 主要设备完好率 | 同上，分子分母限 A/B 类 | 台账重要度 | |

## 七、制度与法规引用方式

- 可引用名称（不转述数值）：《中国石化设备管理规定》《炼化企业设备管理技术规定》《中国石化作业许可管理规定》《中国石化承包商安全管理规定》《中国石化安全隐患管理规定》《中国石化变更管理规定》《中国石化设备事故管理规定》《炼化企业非计划停工管理规定》、设备润滑"五定三过滤"、设备完整性管理体系（GB/T 44692 系列）、GB 30871-2022、TSG 21、TSG D7005、TSG ZF001、TSG Z6001-2019、GB 31570、ISO 10816 / GB/T 6075（振动分区，只引分区概念不引数值）。
- 隐患管理：**五定**（定整改方案、定资金、定责任人、定期限、定应急措施）。"三定四不推"旧口号废止。一般隐患无统一天数，期限以整改方案为准，台账无期限 → undetermined。
- 变更管理：分**工艺技术变更 / 设备设施变更 / 管理变更**，级别**重大 / 一般**，"临时"是属性；**同类替换**不属于变更，材料代用走代用单。涉及压力容器/管道结构改动须附"改造告知、监督检验、使用登记变更"三项提示。
- 特种设备：压力容器/管道周期由**安全状况等级**决定，不由 GC 级别决定；使用单位每年**年度检查**是设备员主责；安全阀校验周期以厂内规定与校验报告为准。常压储罐不是特种设备。
- 承包商：准入必查入厂安全教育、人员三级教育、安全协议；特种作业证看**复审**（3 年复审逾期即无效）；司索工已无取证项目，只核培训记录；一般高处检修不需高处作业操作证；维保/技术服务类承包商不要求安全生产许可证（按承包商类别决定必备项）。TSG Z6001：Q1 起重机指挥、Q2 起重机司机。
- 事故事件：内部通报须衔接《设备事故管理规定》分级与非计划停工事件；报送时限以厂内规定为准，技能不判定。
- 润滑：五定（定点、定质、定量、定期、**定人**）三过滤（领油、转桶、加油）；油液分析允许 `--ref-standard` 显式启用国标换油指标作参考并标注"非厂内标准"。

## 八、数据来源形态（输入设计必须覆盖）

- 巡检三条线：操作工巡检（每班 / 每 2 小时，智能巡检 APP 导出一行一检查项）、专职点检（点检仪导出，含测值与是否报警）、状态监测（测振/测温/油液，无"结果"列，只有参数与限值）、**特护设备日巡检**。
- 周期写法：每班、每 2 小时、每天、每周、每月、每季、半年、每年、运行 2000 小时（运行小时与日历周期是两个维度，分开解析）。
- 表格形态：多文件（按装置分文件）、宽表（一列一期）、带单位数值（78℃、4.5mm/s、0.35MPa）、GBK CSV、Word 方案、PDF 规程与检查通知（PDF 统一前置转 txt/docx，SKILL.md 写标准衔接步骤）。
- 夜班跨 0 点记录按"班次日"归属，不按自然日丢弃。

## 九、写作与声明规范

- 技能产出一律写"车间设备员"视角，交付对象写"车间设备主任 / 公司设备管理部门"。
- 声明行模板：
  - 通用："本材料由脚本汇总、模型成文，仅供设备员复核参考，不替代审批、定性、验收与签字；厂内制度与系统数据为准。"
  - 读图/读 PDF 类（nameplate-ocr-intake、technical-document-finder）："识别值 / 摘录由模型读取产生，未经脚本验证，须人工核对原件。"
  - 培训/指引类："仅供参考，不替代操作规程与检修规程；设备专业建议稿，由车间工艺/安全审核后使用。"
- node 不可用一律终止，不允许手工成文（硬约束 2）。
- 产出 md 不用 emoji，醒目提示用「【注意】」「【未判定】」。
- 虚构示例的标准号写 `Q/XX-虚构-001`，不得形似真实企标。
