# 备件库存查询 · 样例问题

> 附件均在 `examples/`（可用 `node scripts/make-sample.js --out examples --seed <n>` 重新生成，默认 seed=1）。库存数随 seed 变化，但每题的预期结论——低于安全库存项、无法判定项、候选置顶——不变；预期计数与验证要点见 `examples/README.md` 对照表（仅开发库含，发布包不含）。样例中物料号、库位、数量均为虚构。

1. BJ-MS-0021 这个机封库里还有几套？低不低于安全库存？　　**附件：** `examples/sample-inventory.xlsx`
2. 这个机封快没了，在途的什么时候到？　　**附件：** `examples/sample-inventory.xlsx + examples/sample-intransit.xlsx`
3. 这是 SAP 导出的 MB52，物料号 30020046 的轴承还有没有货？没有的话有没有同类的能先顶上？　　**附件：** `examples/sample-sap-mb52.xlsx`（`--alternatives`）
4. SAP 表里没有位号，这是我们的备件设备对应表，帮我查 P-1101A 这台泵的备件库存。　　**附件：** `examples/sample-sap-mb52.xlsx + examples/sample-mapping.xlsx`（`--tag P-1101A --mapping`）
5. 机封没货了，目录里有没有能代的？材质和压力等级差在哪？　　**附件：** `examples/sample-inventory.xlsx + examples/sample-catalog.xlsx`（`--query BJ-MS-0021 --catalog --alternatives`）
6. P-1101A 这台泵有哪些备件在库？　　**附件：** `examples/sample-inventory.xlsx`（`--tag P-1101A`）
7. 库存表里安全库存那列没填，还能看出缺不缺吗？　　**附件：** `examples/sample-no-safety.xlsx`（预期：无法判定，不按满足处理）
8. 查"机械密封"怎么出来三个编码？能不能合起来算一共几套？　　**附件：** `examples/sample-inventory.xlsx`（预期：规格不同，不合并，按编码确认）
9. 这台泵是什么型号、哪年投用的？　　**附件：** 无（预期：转 equipment-ledger-query）
