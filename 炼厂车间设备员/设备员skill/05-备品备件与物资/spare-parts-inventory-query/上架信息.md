# 备件库存查询
**技能名称**：备件库存查询

**技能简介**：按物料号、名称、规格或设备位号查备件库存、库位、在途和是否低于再订货点，没货时列出同规格候选和代用前要确认的技术要点。读 SAP MM 或 EM 导出表，代用可不可以由技术人员定。

**技能描述**

面向炼化厂车间（运行部）设备员，报修或检修前想知道备件有没有货时用。上传库存表（SAP MB52/MMBE 导出的物料、物料描述、非限制使用库存、库存地点、再订货点等列名可直接识别），告诉技能要查的物料号、名称、规格或设备位号，技能给出库存量、库位、是否低于安全库存和在途情况。SAP 导出一般没有位号，按位号查时再给一张备件设备对应表即可。查不到就明说，不拿近似型号糊弄；同名多物料号分开列不合并；库存量空着的按无法判定，不按零。没货时可开代用候选检索，列出同类备件及材质、压力等级、温度范围的差异和代用前必须确认的技术要点，有货的候选排前面，但不下"可以代用"的结论。

**示例问题**
1. BJ-MS-0021 这个机封库里还有几套？低不低于安全库存？　　**附件：** `examples/sample-inventory.xlsx`
2. 这个机封快没了，在途的什么时候到？　　**附件：** `examples/sample-inventory.xlsx + examples/sample-intransit.xlsx`
3. 这是 SAP 导出的 MB52，物料号 30020046 的轴承还有没有货？没有的话有没有同类的能先顶上？　　**附件：** `examples/sample-sap-mb52.xlsx`
4. SAP 表里没有位号，这是我们的备件设备对应表，帮我查 P-1101A 这台泵的备件库存。　　**附件：** `examples/sample-sap-mb52.xlsx + examples/sample-mapping.xlsx`
5. 机封没货了，目录里有没有能代的？材质和压力等级差在哪？　　**附件：** `examples/sample-inventory.xlsx + examples/sample-catalog.xlsx`
