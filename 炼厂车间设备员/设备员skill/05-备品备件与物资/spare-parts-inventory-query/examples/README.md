## 关键验证点

1. **代用不下结论**：案例 3/8 是本技能最关键的行为。报告列出候选与差异，但全文不出现「可以代用」「建议代用」「应该能用」。selftest 有专门断言锁死。
2. **查不到不放宽**：查一个不存在的编码时明确回答未查到，不返回近似编码。模糊匹配必须用户显式开启。
3. **同名不合并**：样例中「机械密封」有 3 个编码、「轴承」有 3 个编码，规格各不相同。合并库存会给出错误的可用量。只提示与查询相关的那一组，避免全表报警。
4. **空库存量不按 0**：BJ-LX-0301 库存量为空，显示「—」并判为无法判定，不显示为 0。
5. **负库存保留**：BJ-LX-0302 库存 -2，原样保留并 warning 提示核实台账，不清零。
6. **SAP 列名与「数量」收窄**：MB52 样例的「非限制使用库存」是库存量，「数量」列（批次计数）不会被读作库存；「再订货点」作安全库存；「库存地点」作库位。
7. **按位号查归口与对应表**：SAP 导出无位号列时按位号查为 0 并提示提供 `--mapping`；给了对应表后按位号命中，并说明匹配依据；对应表里有、库存表里没有的物料不按 0。
8. **无库存候选置顶**：所查件库存为 0/空时，有库存候选排前面，md 标「【注意】所查件当前无库存…置顶」；有库存时只按相似度。
9. **互指**：md 末尾固定指引 equipment-ledger-query（台账参数）、spare-parts-demand、spare-parts-consumption-analysis。
