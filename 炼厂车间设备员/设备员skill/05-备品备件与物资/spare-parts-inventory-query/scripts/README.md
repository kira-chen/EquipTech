# scripts 使用说明

## inventory.js —— 主脚本

```bash
node "<技能目录>/scripts/inventory.js" \
  --input "<库存xlsx>" \
  --query "<编码/名称/规格>" \
  --out "<输出目录>"
```

### 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| `--input` | 是 | 库存表 xlsx 或 CSV 目录（SAP MB52/MMBE 导出或 EM 备件台账，列名按局部别名 + 共享 `SYSTEM_ALIASES` 识别） |
| `--query` | 与 `--tag` 二选一 | 按编码、名称或规格查，默认精确匹配 |
| `--tag` | 与 `--query` 二选一 | 按适用设备位号（功能位置）查；「按位号查备件」归口本技能 |
| `--mapping` | 否 | 备件设备对应表（位号 ↔ 物料号），SAP 导出无位号列时配合 `--tag`；命中结果与库存表位号列合并去重，报告写明匹配依据 |
| `--out` | 否 | 输出目录，默认输入文件同目录下 `spi-out/`；**建议始终传 `--out`** |
| `--intransit` | 否 | 在途采购表，关联到货数量与预计到货 |
| `--catalog` | 否 | 备件目录，扩大代用候选检索范围 |
| `--alternatives` | 否 | 开启代用候选检索；所查件无库存（0 或空）时有库存候选置顶 |
| `--fuzzy` | 否 | 开启包含匹配（默认精确匹配） |
| `--limit` | 否 | 最大返回条数，默认 50 |

### 产出

| 文件 | 内容 |
|---|---|
| `inventory.json` | 命中、低于安全库存、无法判定、在途、代用候选（含 `queriedNoStock`/`stockedFirst`）、同名多编码、`meta.tagSource` |
| `inventory.md` | 五节报告 |
| `inventory.xlsx` | 多条结果时导出 |
| `summary.json` | 末行摘要落盘 |

### 退出码
- `0`：成功（含「未查到」，这是正常结果不是错误）
- `1`：失败（输入不存在、无库存表、非法参数）

### 关键行为

1. **查不到不放宽**。精确匹配无结果时明确回答未查到，需要模糊匹配必须显式加 `--fuzzy`。
2. **代用不下结论**。只列候选、参数差异与技术确认要点，不输出「可以代用」。
3. **同名不合并**。同名不同编码的库存分别列出，只对与查询相关的给出提示。
4. **缺数据不补零**。库存量为空显示「—」，安全库存缺失时判为「无法判定」。
5. **SAP 列名**：物料 / 物料描述 / 基本计量单位 / 非限制使用库存 / 库存地点 / 再订货点 直接识别；**「数量」不作库存量别名**（在途表的「数量」仍按到货数量读）；**「设备编号」不作位号别名**。
6. **无库存候选置顶**：所查件库存为 0 或空时，候选先按有无库存再按相似度排序，md 标注；置顶不等于推荐。
7. **互指**：md 末尾固定指引设备台账参数用 equipment-ledger-query、需求提报用 spare-parts-demand、消耗分析用 spare-parts-consumption-analysis。
8. **位号边界比对**：在位号列/对应表单元格里找位号，字符间允许空白、`-`、`_`；位号前面紧挨字母或数字时不算（`SP-101A` 不中 `P-101A`），`#`、`/`、中文等算边界（「1#P-101A」可中）。查询以数字结尾（`--tag P-2101`）时后面不能紧跟数字（不误中 P-21011A），可跟任意个字母后缀（P-2101A、P-2101AB、「P-2101A泵」）；查询以字母结尾（`--tag P-2101B`）时完全相同，或「P-2101AB」「P-2101A/B」「P-2101A、C」里的同组字母含该字母才中（`--tag P-2101C` 不中 P-2101A/B）；同组字母后面紧跟「-数字」的是另一个位号，不算同组字母（「P-2101A、C-101」查 P-2101C 不中，「P-2101A, B-202」查 P-2101B 不中，「P-2101A/B 2台」仍中 B）。
9. **在途带采购订单号**：在途表有「采购订单」列（别名 采购订单号、采购凭证、采购单号、PO号、PO）时，`inTransit[].arrivals[].po` 带订单号（空为 null），md 在途表多一列「采购订单」；无此列时不出该列。
9. **候选按编码合并**：同一物料既在库存表又在备件目录里时只列一条，库存量取库存表，来源写「库存表 + 备件目录」，库存表缺的规格/材质/压力/温度由目录补齐；只在目录里的候选库存量为「—」。

## lib/substitution.js —— 代用检索库

```js
const SUB = require('./lib/substitution');
SUB.categoryOf('104-45机械密封');   // '机械密封'
SUB.checkPoints('6310轴承');         // ['内径/外径/宽度', '游隙等级', ...]
SUB.specSimilarity('DN100 PN40', 'DN100 PN16');   // 排序用，非判定依据
SUB.diffFields(target, cand, ['spec','material']); // 参数差异
```

口径见 `references/substitution-rules.md`。

## make-sample.js

```bash
node scripts/make-sample.js [--seed <n>]
```

生成 6 份样例：主库存（恒 14 条：2 条低于安全库存、1 条库存量为空、1 条负库存、多组同名多编码）、在途采购、备件目录、缺安全库存列变体、SAP MB52 导出变体（标题行 + 物料/物料描述/非限制使用库存/库存地点/再订货点列名 + 迷惑性「数量」列 + 合计行，无位号列，两条零库存轴承）、备件设备对应表（功能位置 ↔ 物料，含 1 个库存表中没有的物料）。

## selftest.js

```bash
node scripts/selftest.js
```

138 条断言，覆盖代用库单元测试、精确与模糊查询、查不到不放宽、安全库存判定、同名不合并、在途、代用不下结论、按位号查、参数校验、别名列头、产出完整性，以及中石化口径：SAP MB52 列名命中、「数量」不作库存量（在途表仍可读）、无位号列提示 `--mapping`、对应表按位号命中与合并去重、对应表物料无库存记录不按 0、「设备编号」不作位号、无库存候选置顶与有库存不置顶、互指与无 emoji、模板文件存在；位号按分隔符逐个比对（P-101 不误中 P-1011A）、位号常见写法 P-101AB / 1#P-101A / P-101A/B 与同组字母（P-101B 中 P-101AB，P-101C 不中）、目录与库存表同编码候选合并（带库存量、不重复列）、同组字母后紧跟「-数字」不算同组（C-101、B-202 是另一位号）、在途带采购订单号。
