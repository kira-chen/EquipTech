# 代用候选检索口径与技术确认要点

> **本技能不判定代用是否可行。** 只列同类候选、参数差异与须确认的技术要点，可否代用由设备工程师或技术人员确认。

## 一、为什么不给结论

备件代用涉及材质相容性、压力温度等级、安装尺寸、介质适应性等多个维度，其中若干维度（如介质相容性、实际工况波动）不在台账字段里。**脚本能看到的只是台账上的几列参数，据此下"可以代用"的结论是危险的。**

炼化厂常见的代用事故模式：压力等级够但材质不耐介质腐蚀、尺寸对得上但温度范围不够、参数全对但旋向相反。这些都不是比对台账字段能发现的。

因此本技能的定位是**把差异摆出来，让懂的人快速判断**，而不是替人判断。

## 二、候选检索方式

1. **限定同类别**：按备件名称推断类别（机械密封、轴承、垫片、阀门、电机、仪表、叶轮、联轴器、滤芯、紧固件、通用），只在同类别内检索。
2. **相似度排序**：`0.6 × 规格型号 token 重合 + 0.4 × 名称 token 重合`，仅用于排序，**不作判定依据**。
3. **来源**：库存表 + 备件目录（`--catalog`）。库存表内的候选带库存量，只在目录里的候选库存量为 `—`（目录不含库存信息）。同一编码两边都有时合并为一条（来源「库存表 + 备件目录」），库存量取库存表，库存表缺的参数由目录补齐，不重复列出。
4. 每个所查备件最多返回 5 个候选。
5. **所查件无库存（库存量为 0 或空）时，有库存的候选置顶**（先按有无库存，再按相似度）；所查件有库存时只按相似度。置顶只是便于先看能立刻拿到的件，**仍不是代用结论**。

## 三、参数差异比对

逐字段比对并列出差异，字段为：规格型号、材质、压力等级、温度范围。

- 两边都为空的字段不列为差异
- 一边有值一边为空，列为差异（显示 `值 → —`）
- **所列字段无差异不等于可以代用**，报告中会注明「其余参数未比对」

## 四、按类别的技术确认要点

| 类别 | 须确认 |
|---|---|
| 机械密封 | 材质组合（动环/静环/辅助密封）、介质相容性、工作压力等级、工作温度范围、轴径与安装尺寸、旋转方向、API 682 分类 |
| 轴承 | 内径/外径/宽度、游隙等级、精度等级、润滑方式、额定转速、额定动载荷 |
| 密封垫片 | 材质与介质相容性、压力等级、温度范围、公称通径、密封面形式（RF/FF/RTJ） |
| 阀门 | 公称通径 DN、公称压力 PN、阀体材质、密封面材质、连接形式、驱动方式、泄漏等级 |
| 电机 | 额定功率、额定电压、额定转速、防爆等级、防护等级 IP、绝缘等级、安装方式、接线方式 |
| 仪表 | 量程、精度等级、输出信号、过程连接、防爆等级、防护等级、介质相容性 |
| 叶轮 | 材质、外径与叶片数、平衡等级、轴孔尺寸与键槽、水力性能曲线 |
| 联轴器 | 扭矩容量、轴径与键槽、许用不对中量、转速上限、材质 |
| 滤芯 | 过滤精度、材质与介质相容性、压差承受能力、尺寸与密封形式、流通能力 |
| 螺栓紧固件 | 材质与强度等级、规格与螺距、表面处理、使用温度范围 |
| 通用 | 规格型号一致性、材质与介质相容性、压力等级、温度范围、安装接口尺寸 |

## 五、回答时的措辞

| 场景 | 应写 | 不得写 |
|---|---|---|
| 候选 | 「同类候选 3 个，参数差异如下」 | 「可以用 BJ-XX 代替」 |
| 差异 | 「压力等级 PN25 → PN16」 | 「压力等级低一档，问题不大」 |
| 结论 | 「代用是否可行须由设备工程师确认」 | 「应该能用」「建议代用」 |
| 无候选 | 「未检索到同类候选」 | 「没有可代用的」 |

## 六、其他硬规则

- **查不到时明确回答「未查到」**，不放宽条件返回近似结果。需要模糊匹配须由用户显式加 `--fuzzy`，且结果会带「需人工核对」提示。
- **同名不同编码不合并库存**。备件同名不同规格是常态，合并会给出错误的可用量。只对与本次查询相关的名称给出提示，避免全表报警淹没真正的问题。
- **库存量或安全库存缺失 → 无法判定是否低于安全库存**，单列说明，不按满足处理。
- **负库存原样保留并 warning**，不清零。
- **实物数量以仓库实盘为准**，报告固定带该声明。
