# 输入规格：备件库存查询

## 库存表（必需）

sheet 名匹配「库存表」「库存」「备件库存」（SAP MB52/MMBE 导出常以「库存」「Sheet1」命名，后者请改名或指定）。列名按局部别名 + 共享 `SYSTEM_ALIASES`（SAP MM / EM 列名）识别。

| 列名 | 必需 | 说明 |
|---|---|---|
| 备件编码 | 是 | SAP 物料号（通常 8 位数字）或厂内备件编码；为空的行跳过并 warning |
| 备件名称 | 否 | 用于类别推断与同名检查 |
| 规格型号 | 否 | 用于代用候选比对 |
| 单位 | 否 | |
| 库存量 | 否 | SAP「非限制使用库存」；为空或无法解析 → null（显示「—」），**绝不按 0**。**「数量」不作库存量别名**（MB51 等表的「数量」是业务量，过宽） |
| 安全库存 | 否 | SAP MRP「再订货点」/ 储备定额；缺失时无法判定是否低于安全库存 |
| 库位 | 否 | |
| 状态 | 否 | |
| 位号 | 否 | 适用设备（功能位置），用于 `--tag` 查询。一格多台时用 `/`、`、`、逗号或分号分隔（如 `P-2101A/P-2101B`），也认「P-2101AB」「P-2101A/B」「1#P-2101A」写法：位号前面是非字母数字字符（`#`、`/`、中文等）就算边界；`--tag P-2101` 后面可跟任意个字母后缀（命中 P-2101A、P-2101AB），`--tag P-2101B` 认「P-2101AB」「P-2101A/B」里的同组字母（同组字母后面紧跟「-数字」的是另一个位号，如「P-2101A、C-101」里的 C-101，不算同组）；不做子串包含（P-101 不命中 P-1011A，SV-101 不命中 PSV-101）。**SAP MM 库存导出通常没有此列**，按位号查请另给备件设备对应表（`--mapping`）。「设备编号」不作位号别名（SAP 设备编号是 8 位流水号，不是位号） |
| 材质 / 压力等级 / 温度范围 | 否 | 用于代用候选的参数差异比对 |

|---|---|

| 备件名称 | 备件名称、名称、物料名称、物料描述、物资名称、备件 |
| 规格型号 | 规格型号、型号、规格、型号编号 |
| 单位 | 单位、计量单位、基本计量单位 |
| 库存量 | 库存量、库存、非限制使用库存、非限制库存、可用库存、现有量、现有库存、结存（**不含「数量」**） |
| 安全库存 | 安全库存、最低库存、警戒库存、再订货点、储备定额 |

## 在途采购表（可选，`--intransit`）

sheet 名匹配「在途采购」「在途」「采购在途」「采购」。

| 列名 | 必需 |
|---|---|
| 备件编码 | 是 |
| 到货数量 | 否（别名：在途数量、采购数量、订单数量、数量——在途表的「数量」按到货数量读） |
| 预计到货 | 否（别名：到货日期、交期、交货日期；无法解析时 warning） |
| 采购订单 | 否（别名：采购订单号、采购凭证、采购单号、PO号、PO）；有此列时在途清单与报告带订单号 |
| 单位 | 否 |

同一编码多批到货会分别列出。未提供此表时在途情况为 `null`，报告写「未提供在途采购表」。

## 备件设备对应表（可选，`--mapping`）

sheet 名匹配「备件设备对应」「对应」「设备备件」「BOM」「备件清单」。SAP MM 库存导出没有位号列时，用它把位号（功能位置）对到物料号，`--tag` 查询按「库存表位号列 + 对应表」合并去重命中，报告写明匹配依据。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 功能位置 / 设备位号 |
| 备件编码 | 是 | 物料号 |

对应表里有、库存表里没有的物料：warning 提示「无库存记录」，**不按 0 处理**。

## 备件目录（可选，`--catalog`）

sheet 名匹配「备件目录」「目录」「备件清单」。用于扩大代用候选的检索范围（目录内的备件不一定有库存）。

| 列名 | 必需 |
|---|---|
| 备件编码 | 是 |
| 备件名称 / 规格型号 / 材质 / 压力等级 / 温度范围 | 否 |

## 查询方式

| 参数 | 说明 |
|---|---|
| `--query` | 按编码、名称或规格查。默认**精确匹配**（去空格与大小写后相等） |
| `--tag` | 按适用设备位号（功能位置）查；「按位号查备件」归口本技能（equipment-ledger-query 的 `--spare` 已停用并指向本技能） |
| `--mapping` | 备件设备对应表，SAP 导出无位号列时配合 `--tag` 使用 |
| `--fuzzy` | 开启包含匹配。**必须显式开启**，结果带「需人工核对」提示 |
| `--alternatives` | 开启代用候选检索；所查件无库存（0 或空）时有库存候选置顶 |
| `--limit` | 最大返回条数，默认 50 |

`--query` 与 `--tag` 至少提供一个。

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 等开头的行（warning）
- 备件编码为空的行（warning）

## 产出

| 文件 | 内容 |
|---|---|
| `inventory.json` | 命中记录、低于安全库存、无法判定、在途、代用候选、同名多编码 |
| `inventory.md` | 五节报告，含实盘与代用确认声明 |
| `inventory.xlsx` | 多条结果时导出 |
| `summary.json` | 末行摘要落盘 |
