# 备件消耗分析
**技能名称**：备件消耗分析

**技能简介**：从出库记录或 SAP MB51 物料凭证统计备件消耗，按设备、备件、月份分布和排行，按本位币金额或单价表折算金额，与基期对比找出消耗明显增长的备件。只给统计结果和核实方向，不断言原因。

**技能描述**

面向炼化厂车间（运行部）设备员，做季度备件消耗分析时用。上传出库记录（SAP MB51 导出的物料、过账日期、数量、移动类型、本位币金额等列名可直接识别），告知车间和统计区间，技能按设备、按备件、按月统计消耗并列出排行。MB51 的 262 冲销按负数抵减，101 收货不算消耗；有本位币金额列直接取用，没有就按单价表折算，两者都没有就不折算。不同单位分开统计不换算，没填领用设备的单列为未归属，不平摊也不排除。基期可取上期分析结果、上期出库表，或在同一份导出里指定基期起止，两期天数不同按日均归一后比倍数，超阈值的列为异常增长项，只提示"建议核实是否与检修或重复故障相关"，不下原因结论。

**示例问题**
1. 三季度常减压车间的备件消耗统计一下，哪台设备最费备件？　　**附件：** `examples/sample-consumption.xlsx`
2. 这是 SAP 导出的 MB51，三季度的消耗和金额帮我统计，里面有一条冲销和一条收货。　　**附件：** `examples/sample-sap-mb51.xlsx`
3. 没有上期的分析结果，就这一份半年的 MB51，4 到 6 月当基期，和 7 到 9 月比一下哪些备件用得明显多了。　　**附件：** `examples/sample-sap-mb51.xlsx`
4. 带上单价表看看花了多少钱，再按设备类型分一下。　　**附件：** `examples/sample-consumption.xlsx + examples/sample-price.xlsx + examples/sample-equipment-ledger.xlsx`
5. 上期的出库表还在，直接拿它当基期跟本期比。　　**附件：** `examples/sample-consumption.xlsx + examples/sample-prev-consumption.xlsx`
