# 备件消耗分析 · 样例问题

> 附件均在 `演示case/05-备品备件与物资/spare-parts-consumption-analysis/`（可用 `node scripts/make-sample.js --seed <n>` 重新生成，默认 seed=1）。出库日期随 seed 变化，但每题的预期结论——条数、未归属数、异常项——不变；预期计数与验证要点见 `演示case/05-备品备件与物资/spare-parts-consumption-analysis/README.md` 对照表（不进发布包）。样例中物料号、订单号、数量、金额均为虚构。

1. 三季度常减压车间的备件消耗统计一下，哪台设备最费备件？　　**附件：** `sample-consumption.xlsx`
2. 这是 SAP 导出的 MB51，三季度的消耗和金额帮我统计，里面有一条冲销和一条收货。　　**附件：** `sample-sap-mb51.xlsx`
3. 没有上期的分析结果，就这一份半年的 MB51，4 到 6 月当基期，和 7 到 9 月比一下哪些备件用得明显多了。　　**附件：** `sample-sap-mb51.xlsx`（`--prev-from 2026-04-01 --prev-to 2026-06-30`）
4. 带上单价表看看花了多少钱，再按设备类型分一下。　　**附件：** `sample-consumption.xlsx + sample-price.xlsx + sample-equipment-ledger.xlsx`
5. 上期的出库表还在，直接拿它当基期跟本期比。　　**附件：** `sample-consumption.xlsx + sample-prev-consumption.xlsx`（`--prev <上期表> --prev-from 2026-04-01 --prev-to 2026-06-30`）
6. 有几条出库单没填领用设备，会不会影响统计？　　**附件：** `sample-consumption.xlsx`（预期：单列未归属，不平摊不排除）
7. 机封这个季度用得比上个季度多三倍，是不是机封质量有问题？　　**附件：** `sample-consumption.xlsx`（预期：只给倍数与核实方向，不断言原因，建议接 repeat-failure-detector）
8. 螺栓单价表里没有，金额怎么算？　　**附件：** `sample-consumption.xlsx + sample-price.xlsx`（预期：金额「—」，不用估计单价）

## 平台接入业务系统 MCP 时

不上传附件，数据由 MCP 工具获取，演示数据每天按剧本刷新。

M1. 常减压车间近 90 天的备件消耗统计一下，哪几台设备最费备件？花了多少钱？　　**数据：** MCP 备件库存MRO `get_material_movements`（`workshop`：常减压车间，`start_date`：今天前 89 天），`--from` 今天前 89 天、`--to` 今天

M2. 常减压车间近 90 天和再往前 90 天比，哪些备件用得明显多了？　　**数据：** MCP 备件库存MRO `get_material_movements`（`workshop`：常减压车间，`start_date`：今天前 179 天），`--from` 今天前 89 天、`--to` 今天，`--prev-from` 今天前 179 天、`--prev-to` 今天前 90 天

M3. 加氢车间这三个月的备件消耗按设备排一下。　　**数据：** MCP 备件库存MRO `get_material_movements`（`workshop`：加氢车间，`start_date`：今天前 89 天），`--workshop 加氢车间`
