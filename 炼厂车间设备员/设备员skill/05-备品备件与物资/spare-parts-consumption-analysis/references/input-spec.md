# 输入规格：备件消耗分析

## 出库记录（必需）

sheet 名匹配「出库记录」「消耗记录」「出库」「领用记录」「物料凭证」「MB51」「发料」。SAP MM MB51 物料凭证导出可直接读（列名见下方别名表）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 备件编码 | 是 | 为空的行跳过并 warning |
| 数量 | 是 | 为空或无法解析 → null（不计入合计），**绝不按 0** |
| 出库日期 | 否 | 不在统计区间的记录被排除并 warning |
| 备件名称 | 否 | 用于报告标签 |
| 单位 | 否 | 为空归入「（未填单位）」；**不同单位分别统计，不换算** |
| 位号 | 否 | 为空归入「未归属消耗」，**不平摊** |
| 领用单位 | 否 | |
| 用途 | 否 | |
| 工单号 | 否 | SAP「订单」列 |
| 移动类型 | 否 | SAP MB51：261/201 等发料计正；262/202 等冲销按负数抵减；101 收货、311 转储等不计入消耗。无此列时全部按消耗计 |
| 金额 | 否 | SAP「本位币金额」。有此列直接取用（优先于单价表，冲销计负）；为空的记录再按单价表折算；两者都无 → null |

### 列名别名

| 标准列名 | 可识别写法 |
|---|---|
| 出库日期 | 出库日期、日期、领用日期、消耗日期、出库时间、过账日期、凭证日期、输入日期 |
| 备件编码 | 备件编码、编码、物料编码、物料、物料号、物料编号、物资编码、备件编号、料号 |
| 备件名称 | 备件名称、名称、物料名称、物料描述、物资名称、备件、短文本 |
| 数量 | 数量、出库数量、领用数量、消耗数量、以录入单位计的数量 |
| 单位 | 单位、计量单位、基本计量单位、录入单位 |
| 位号 | 位号、设备位号、领用设备、使用设备、功能位置、技术对象、适用设备（**不含「设备编号」**，SAP 设备编号是流水号） |
| 领用单位 | 领用单位、领用部门、使用单位、班组、成本中心、工作中心、收货方 |
| 工单号 | 工单号、关联工单、单号、工单编号、订单、订单号、PM订单、维修订单号 |
| 移动类型 | 移动类型、业务类型、移动类型代码 |
| 金额 | 金额、本位币金额、本币金额、金额(本位币)、出库金额 |

## 单价表（可选，`--price`）

sheet 名匹配「单价表」「单价」「价格表」。

| 列名 | 必需 |
|---|---|
| 备件编码 | 是 |
| 单价 | 否（无法解析的不入表） |
| 单位 | 否 |

出库记录有「本位币金额」列时该列优先，单价表只用于金额为空的记录。两者都未提供时全部金额为 `null`，**不使用任何估计单价**。

## 设备台账（可选，`--ledger`）

sheet 名匹配「设备台账」「台账」「设备清单」。用于设备名称标注与按设备类型归类。

| 列名 | 必需 |
|---|---|
| 位号 | 是 |
| 设备名称 / 设备类型 / 专业 | 否 |

## 基期数据（可选，`--prev` / `--prev-from` / `--prev-to`）

三种取法，任选其一：

| 取法 | 参数 | 说明 |
|---|---|---|
| 上期产出 | `--prev 上期/consumption.json` | 本脚本上期产出；基期区间取其 `meta.from/to` |
| 上期出库表 | `--prev 上期出库.xlsx --prev-from <起> --prev-to <止>` | 按同样列名规则读上期表，只取基期区间内的记录 |
| 同一导出切基期 | 仅 `--prev-from <起> --prev-to <止>` | 首次使用没有上期 JSON 时，直接在本次 `--input` 里切出基期（如 MB51 导出半年，4~6 月为基期、7~9 月为本期） |

基期不得与本期重叠；`--prev` 为 xlsx 时必须给基期起止。两期区间长度不同时自动按日均归一。基期内无记录只 warning，不中断。

## 其他参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--by` | equipment | 排行维度：equipment / part / month |
| `--top` | 10 | 排行条数 |
| `--anomaly-ratio` | 2 | 异常增长倍数阈值，须大于 1 |

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 等开头的行（warning）
- 备件编码为空的行（warning）
- 出库日期不在统计区间的行（warning）

## 产出

| 文件 | 内容 |
|---|---|
| `consumption.json` | 各维度分组、排行、异常增长、未归属、counts |
| `consumption.md` | 八到九节报告，分析段留占位符 |
| `消耗统计表.xlsx` | 四张表：按设备、按备件、按月份、未归属 |
| `summary.json` | 末行摘要落盘 |
