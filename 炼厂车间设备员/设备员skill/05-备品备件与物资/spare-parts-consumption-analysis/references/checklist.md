# 交付自检清单

- [ ] 末行 JSON 的 `ok` 为 `true`；为 `false` 时已告知 `error` 并终止，未手工统计
- [ ] `warnings` 已逐条告知用户

## 统计口径
- [ ] 所有数量、金额、倍数引用 `consumption.json`，未自行统计
- [ ] **不同单位分别呈现，未相加换算**

- [ ] 未提供单价表时金额显示「—」，**未使用估计单价**

- [ ] 已向用户说明金额来源（本位币金额列 / 单价表折算 / 未折算）

## 未归属消耗
- [ ] 单列一节并说明「未平摊到其他设备，也未排除后当作完整统计」

## 异常增长
- [ ] 两期区间长度不同时已按日均归一，报告中注明
- [ ] 已说明基期来源（上期 JSON / 上期出库表 / 同一导出切基期）与基期区间
- [ ] **只提示需核实的方向，未断言原因**
- [ ] 未出现「说明可靠性下降」「原因是……」这类表述
- [ ] 未提供上期数据时显示「未做异常增长识别」，未显示为 0
- [ ] 基期无消耗、本期新出现的备件（`newInPeriod`）已列出，未写成异常增长倍数，也未漏掉
- [ ] 两期单位不同的备件（`unitMismatch`）写成「两期单位不同、不可比」，未当作本期新出现

## 分析段
- [ ] 已替换占位文字，字数 250~400
- [ ] 五段结构齐全
