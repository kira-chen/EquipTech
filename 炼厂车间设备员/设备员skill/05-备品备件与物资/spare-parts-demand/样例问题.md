## 平台接入业务系统 MCP 时

不上传附件，数据由 MCP 工具获取，演示数据每天按剧本刷新。

M1. 常减压车间这个月的备件需求帮我报一下，工单预留和历史领用都算上，扣掉库存和在途。　　**数据：** MCP 备件库存MRO `get_reservations`（`workshop`：常减压车间）、`get_material_movements`（`workshop`：常减压车间）分放两个目录逗号拼接作 `--input`，`get_inventory`（无参数）作 `--stock` 和 `--intransit`，`--period` 本月

M2. P-2101A 要换驱动端轴承，机封也没货了，这个季度 6314 轴承和 P-2101 机封各要报多少？在途的扣了没有？　　**数据：** 同 M1，`--period` 本季度（如 2026-Q4），看 30020052、30020049 两行

M3. 这个月只按检修工单的预留报，历史消耗先不算。　　**数据：** MCP 备件库存MRO `get_reservations`（`workshop`：常减压车间）、`get_material_movements`（`workshop`：常减压车间）、`get_inventory`（无参数），`--method plan`
