# 输入规格：备件需求提报

输入可以是一个或多个 `.xlsx`（或同结构 CSV 目录，UTF-8 或 GBK），用 `--input` 以逗号分隔。脚本在所有输入文件中按 sheet 名查找各表，**多个文件含同名表时全部合并读取**（同编码同月数量累加）并 warning 提示确认不是重复导出。列名按局部别名 + 共享 `SYSTEM_ALIASES`（SAP PM/MM 列名）识别。

## 检修计划表（`--method plan/both` 时需要）

sheet 名匹配「检修计划」「检修计划表」「计划」「检修项目」「工单备件」「预留」。一行 = 一个检修项目（PM 工单 / 预留）对应的一种备件。SAP PM 工单组件/预留导出可直接读：订单号 → 项目编号、订单描述 → 项目名称、基本开始日期 → 计划开工、物料 → 备件编码、预留数量 → 需求数量、功能位置 → 位号。

| 列名 | 必需 | 说明 |
|---|---|---|
| 备件编码 | 是 | 为空的行跳过并 warning |
| 项目编号 | 否 | **需求依据的来源**。为空 → 该项无依据，只进 `noHistory`，不入正式清单 |
| 项目名称 | 否 | 写进依据说明 |
| 计划开工 | 否 | 用于推算建议到货时间（开工前 `--lead-days` 天，默认 15）；无法解析时建议到货为 null |
| 需求数量 | 否 | 为空或无法解析 → null（显示「—」），**绝不按 0**；该项转入 `noHistory` |
| 备件名称 / 规格型号 / 单位 / 位号 | 否 | |

## 历史消耗表（`--method history/both` 时需要）

sheet 名匹配「历史消耗」「消耗记录」「消耗」「领用记录」「出库记录」「物料凭证」「MB51」。一行 = 一个备件在一个月份的消耗，或 MB51 的一条物料凭证（按过账日期归并到月）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 备件编码 | 是 | 为空的行跳过并 warning |
| 消耗月份 | 是 | `2026-08` / `2026年8月` / `2026-08月` 均可；也可给「过账日期 / 凭证日期 / 出库日期」（整日期按月归并）；为空的行不计入期数并 warning |
| 消耗数量 | 是 | MB51 的「数量」列按此读；无法解析 → 该条不计入，**不按 0 摊薄月均** |
| 移动类型 | 否 | 有此列时：261/201 等发料计正；262/202 等冲销按负数抵减当月；101 收货、311 转储等不计入（各 warning 一次）。无此列时全部按消耗计 |
| 备件名称 / 规格型号 / 单位 / 位号 | 否 | 单位参与分组：同编码不同单位分别统计 |

同一编码同一月份的多行会先合并为该月合计，再算期数与月均。

## 库存现状表（可选，`--stock`）

sheet 名匹配「库存表」「库存」「备件库存」。列名口径与 `spare-parts-inventory-query` 完全一致（SAP MB52：非限制使用库存 → 库存量、再订货点 → 安全库存、库存地点 → 库位；**「数量」不作库存量别名**）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 备件编码 | 是 | |
| 库存量 | 否 | 为空或无法解析 → null，该项净需求为 null，**绝不按库存为 0 计算** |
| 安全库存 | 否 | 未单独提供 `--safety` 时，从此列取 |
| 单位 | 否 | 与需求单位不一致时不扣减、不换算 |
| 库位 / 规格型号 / 备件名称 | 否 | |

**不提供此表时输出为毛需求，脚本全程标注「未扣减在库量」，不得直接作为采购量。**

## 安全库存标准表（可选，`--safety`）

sheet 名匹配「安全库存」「安全库存标准」「定额」「库存标准」。

| 列名 | 必需 |
|---|---|
| 备件编码 | 是 |
| 安全库存 | 否 |
| 备件名称 / 单位 | 否 |

未提供时历史消耗推算不加安全库存，并在口径说明中写明。

## 在途采购表（可选，`--intransit`）

sheet 名匹配「在途采购」「在途」「采购在途」「采购」。

| 列名 | 必需 |
|---|---|
| 备件编码 | 是 |
| 到货数量 | 否 |
| 预计到货 | 否（无法解析时 warning） |
| 单位 | 否 |

同一编码多批到货会累加为在途总量并分别记录。未提供时在途为 null，净需求不扣减在途。

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| `--input` | 是 | 一个或多个 xlsx / CSV 目录，逗号分隔 |
| `--workshop` | 是 | 车间名称 |
| `--period` | 是 | 需求周期，如 `2026-Q4`、`2026-10`、`2026-10~2026-12`、`2026` |
| `--out` | 否 | 输出目录，默认 `spd-out/` |
| `--method` | 否 | `plan` / `history` / `both`，默认 `both` |
| `--lookback` | 否 | 历史回溯月数，默认 12（只取最近 N 期算月均） |
| `--months` | 否 | 显式指定需求周期月数，覆盖 `--period` 的自动解析 |
| `--stock` | 否 | 库存现状表，用于扣减在库量 |
| `--safety` | 否 | 安全库存标准表 |
| `--intransit` | 否 | 在途采购表，用于扣减在途量 |
| `--lead-days` | 否 | 建议到货提前天数，默认 15（未显式给出时产出标「默认值」） |
| `--min-periods` | 否 | 历史期数下限，默认 6（未显式给出时产出标「默认值」） |

需求周期自动解析：`2026-Q4`→3、`2026-10`→1、`2026-10~2026-12`→3、`2026`→12、`2026-H1`→6。无法识别时按 1 个月并 warning，建议显式给 `--months`。

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 开头的行（warning）
- 备件编码为空的行（warning）
- 历史消耗中消耗月份为空、或消耗数量无法解析的行（warning，不计入期数）

## 产出

| 文件 | 内容 |
|---|---|
| `demand.json` | items / netDemand / lowConfidence / codeAmbiguity / noHistory / unitConflicts / counts / meta |
| `demand.md` | 七节申报稿（净需求表分列计划/历史毛需求），含申报说明行与分析段占位符 |
| `备件需求表.xlsx` | 五个工作表：备件需求表、需求明细、低置信度项、编码待确认、无依据待核实 |
| `summary.json` | 末行摘要落盘 |
