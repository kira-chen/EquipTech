- 推算方式：检修计划驱动按项目备件清单直接取用量；历史消耗驱动按「月均消耗 × 3 个月 + 安全库存」。

- 净需求 = 毛需求 − 在库量 − 在途量；结果为负时置 0 并注明「库存充足，本期无需采购」。
- 单位不一致的备件按单位分别统计，**未做任何换算**。

## 措辞对照

| 场景 | 应写 | 不应写 |
|---|---|---|
| 无库存表 | 「毛需求 24 片，未扣减在库量」 | 「需采购 24 片」 |
| 期数不足 | 「仅 3 期，推算量仅供参考，建议人工核定」 | 「月均 2.33，本季需 7 组」 |
| 多编码 | 「编码不同，未合并，请确认是否同一物料」 | 把两个编码的量加起来报 |
| 单位不一 | 「个：6.24；套：7.14，未换算」 | 「合计 13.38」 |
| 库存充足 | 「库存充足，本期无需采购」 | 直接不列这一项 |
| 无依据 | 「缺项目编号，列入建议核实」 | 按经验补个项目编号报上去 |
| 库存量为空 | 「库存量未填，无法算净需求」 | 「库存 0，全额采购」 |
