# 验收项规则表与表述规范（中石化炼化厂口径）

规则实现见 `scripts/lib/rules.js`，每条规则带规则号（写入 `acceptance.json` 的 `items[].ruleId`），可逐条追溯。

## 一、验收组织：三级验收 + 工艺

按《中国石化设备管理规定》《炼化企业设备管理技术规定》的检修验收口径（层级与签字人以厂内制度为准，本技能不转述数值）：

| 级别 | 验收方 | 车间设备员的角色 |
|---|---|---|
| 一级 | 班组 | 组织班组按清单逐项核对 |
| 二级 | 车间（车间设备员 / 设备主任） | 汇总验收记录、核对应附资料、组织车间级验收 |
| 三级 | 公司设备管理部门（机动部 / 设备部） | 大检修必须参加；日常维修 / 抢修 / 专项是否参加按厂内规定 |
| 参与 | 工艺（操作）方 | 人孔封闭前确认、投用前置换与升压 |
| 签认 | 承修单位 | 施工记录、质量验收记录签认 |

**日常维修无监理**，签字栏不设监理；大检修若厂内另设监理，由用户在签字栏自行增补，脚本不预置。

检修分级（`--repair-type`）：装置大检修（停工检修）/ 日常维修 / 抢修 / 专项（技改技措）；旧称大修 → 大检修、中修 / 小修 → 日常维修，脚本映射并 warning。分级只写入概况表与签字栏说明，**不改变验收项**。

## 二、验收项分五大类别

| 类别 | key | 管什么 |
|---|---|---|
| 外观与清洁 | `appearance` | 现场清洁、工完料尽、本体外观、标识、保温防腐恢复 |
| 装配质量 | `assembly` | 间隙、对中、紧固力矩、部件一致性、附件复位 |
| 密封与试压 | `sealing` | 试压/气密试验、静密封、动密封 |
| 试运 | `trial` | 空负荷、负荷、振动、温度、电流、转向、联锁 |
| 资料记录完整性 | `records` | 检修记录卡、质量验收记录、试压试运记录、无损检测、隐蔽工程、特种设备资料 |

md 报告的「二、验收项逐项结果」按这个顺序分小节，序号连续编号。

## 三、验收项的来源：通用 + 设备类型

```
验收项 = 通用规则（GEN-*，对所有设备生效）
       + 设备类型专用规则（CMP/FUR/ACC/PMP/HEX/VES/VLV/MOT-*）
       + 条件命中（解体/换件/焊接/清洗/防腐 × 试压/试运/特种设备）
```

### 各设备类型的验收要点（八类，识别优先级从上到下）

| 设备类型 | 规则前缀 | 必验要点 | 备注 |
|---|---|---|---|
| 压缩机/机组 | `CMP-` | 轴承间隙与轴向窜量（H 点）、机组对中、盘车与动平衡、油/密封系统复位、干气密封泄漏、联锁保护试验、振动与轴位移、轴承温度 | 多属特护设备，验收由公司设备部门牵头，联锁试验由仪表/电气执行 |
| 加热炉 | `FUR-` | 炉衬与钢结构、炉管材质与吊挂、燃烧器与风门、烟道挡板、热电偶与防爆门复位、炉管试压、燃料线严密性、烘炉曲线、点火工况、熄火保护联锁 | 烘炉项在防腐/炉衬修补且试运时生成 |
| 空冷器 | `ACC-` | 翅片与管箱外观、管束清洗、回装与膨胀间隙、丝堵与堵管、风机叶片角度/皮带/百叶窗、管程水压试验、风机试运 | 空冷器优先于换热器识别，不套用 HEX 规则 |
| 离心泵 | `PMP-` | 对中偏差、机封无泄漏、振动值、轴承温度、盘车灵活、试运合格 | |
| 换热器 | `HEX-` | 管束清洗、管程/壳程水压试验、法兰无泄漏 | 保温恢复由通用项 GEN-AP-03 覆盖，不另设类型项 |
| 塔器/容器 | `VES-` | 内件安装、人孔封闭（封闭前确认为 H 点，工艺参与）、气密试验、防腐层 | |
| 阀门 | `VLV-` | 启闭灵活、密封（强度/严密性）试验、填料无泄漏、限位与开度指示正确 | 安全阀校验证书在特种设备开关下生成 |
| 电机 | `MOT-` | 绝缘电阻、接地、转向正确、空载电流、负荷电流与温升 | |

### 设备类型不覆盖时（硬约束）

`--equip-type` 归不到上述八类时：

1. 只输出**通用验收框架**（GEN-* 全部）+ 三条占位项（装配/密封/试运专用指标）。
2. 占位项的验收标准与验收方式一律写 **「待技术人员补充」**。
3. 脚本 warning，md 开头【注意】提示。
4. **模型不得据经验把「待技术人员补充」改写成具体数值**（间隙、力矩、振动、试压压力、温升……一律不许填）。交付时明确告知用户：这份清单要先经技术人员补充技术指标才能用。

## 四、验收标准的写法（口径）

验收标准一律写成**「按…执行 / 符合…规定 / 有…记录」**，**不写具体数值**。

| 应写 | 不得写 |
|---|---|
| 「紧固力矩按设备技术文件或检修方案执行」 | 「螺栓力矩 120 N·m」 |
| 「振动值不超过设备技术文件或相应标准规定的合格值，有实测记录」 | 「振动不超过 4.5 mm/s」 |
| 「按设计或方案规定的试验压力与保压时间执行」 | 「1.25 倍设计压力保压 30 分钟」 |
| 「径向与轴向偏差符合设备技术文件或检修方案规定值」 | 「径向偏差 ≤0.05mm」 |
| 「绝缘电阻实测值符合相应电压等级的规定值」 | 「绝缘电阻 ≥0.5MΩ」 |
| 「干气密封泄漏量在技术文件规定范围内」 | 「一级泄漏 ≤X Nm³/h」 |

原因：同一类设备在不同厂家、不同规格、不同工况下的合格值不同，数值只能来自设备技术文件、制造厂说明书或经审批的检修方案。**脚本与模型都不是技术标准的出处。** 振动可引 ISO 10816 / GB/T 6075 的分区概念，不引数值。

## 五、验收结论的填写（硬约束）

1. `items[].result` 由脚本恒置 `null`。只有 `--records` 里明确填了的项才会被回填。
2. `conclusion.result`、`signatures[].name/date` 同样恒为 `null`。
3. md 中未填的验收结果、验收结论栏、签字栏一律留空格。
4. **模型不得在任何一栏写「合格」「同意投用」「符合要求」**，哪怕用户说「应该没问题」。

回填时的结果归一（写不明白的一律未判定，不按最宽松处理）：

| 归类 | 可识别写法 |
|---|---|
| 合格 | 合格、通过、符合、OK、√、是、已完成 |
| 不合格 | 不合格、未通过、不通过、不符合、整改、返工、NG、不达标 |
| **未判定** | 其他文字（如「待复测」「基本可以」）→ 单列一节并 warning |
| 保持 `null` | 空单元格 → 视为尚未验收，计入 `pending` |

## 六、不合格项的处理

存在不合格项时：

1. md **开头**出现「【注意】**存在 N 项不合格，整改并复验合格前设备不得投用。**」（不用 emoji）。
2. 「四、不合格项与整改要求」逐条列出：序号、类别、验收内容、不合格情况、整改要求（留空）、复验人（留空）、复验日期（留空）。
3. 验收项表中该项的结果栏加粗为 **不合格**。
4. **整改要求、复验结论不由模型填写**，留给验收组与承修单位商定。
5. 不合格项需跟踪整改的，转 `defect-intake-grading` 登记维修通知单。

不存在不合格项时**不得出现**该提示——空喊狼来了会让真正的提示失效。

## 七、应附资料清单（按检修内容确定，不按设备类型一刀切）

按中石化口径，检修验收应附：检修记录卡、质量验收记录（H/W 点见证）、试车记录、备件领用单、更换部件质量证明。

| 资料 | 规则号 | 什么情况下必附 |
|---|---|---|
| 检修记录卡（施工记录） | REC-01 | 所有检修 |
| 质量验收记录（H/W 点见证） | REC-17 | 所有检修；H 点（停止点）须见证签字后方可进入下道工序 |
| 施工方案与技术交底记录 | REC-15 | 所有检修 |
| 完工验收签证（本清单签字页） | REC-16 | 所有检修 |
| 更换部件质量证明（备件清单及合格证） | REC-02 | 更换主要部件 |
| 备件领用单 | REC-18 | 更换主要部件 |
| 材质证明书（材料代用审批） | REC-03 | 更换受压元件或涉及焊接 |
| 焊接记录及焊工资质证明 | REC-04 | 涉及焊接 |
| 无损检测报告（RT/UT/PT/MT） | REC-05 | 涉及受压焊缝或方案要求检测 |
| 试压（气密）记录 | REC-06 | `--pressure-test` |
| 试运（试车）记录（空负荷/负荷） | REC-07 | `--trial-run` |
| 联锁保护试验记录 | REC-19 | 压缩机/机组、加热炉且 `--trial-run` |
| 隐蔽工程记录（封闭前检查确认） | REC-08 | 解体或有封闭作业 |
| 对中（找正）记录 | REC-09 | 涉及对中，或设备为离心泵/电机/压缩机 |
| 清洗记录 | REC-10 | 涉及清洗 |
| 防腐/保温施工记录 | REC-11 | 涉及防腐保温 |
| 电气试验报告（绝缘、接地） | REC-12 | 涉及电气作业，或设备为电机 |
| 特种设备检验报告及使用登记变更资料 | REC-13 | `--special-equipment` |
| 安全阀（安全附件）校验证书 | REC-14 | `--special-equipment` |

「是否提供」栏同样留空，由验收组核对后填写，**脚本与模型不预填**。资料归档交 `maintenance-record-archive`。

## 八、与检修方案质量控制点的比对（硬约束）

提供 `--plan` 时（支持 `.docx` / `.txt` / `.md` / `.xlsx` / CSV 目录；PDF 先前置转换）：

1. 从方案中抽取质量控制点条目（识别「质量控制点 / 控制点 / QC 点 / 见证点 / 停止点 / H 点 / W 点」关键词，以及「质量控制点」小节下的编号条目；docx 的表格行拆成文本后同样识别）。
2. 每个控制点与全部验收项做文本相似度匹配（bigram Dice，阈值 0.34）。
3. **`qcMatched` 与 `qcGap` 之和恒等于 `qcPoints`**——每个控制点都有归宿。
4. 缺口逐条进 `warnings`，md 开头【注意】提示，「六、与检修方案质量控制点对应情况」列出控制点原文、方案出处行号、最接近的验收项及相似度。

**禁止**：
- 把匹配不上的控制点当成「方案写得太细，不用管」而删掉。
- 把相似度低的强行算作已对应。
- 方案读不出控制点时（无关键词），当作「方案没有控制点」而不提示——脚本会 warning，要向用户说明需人工核对。此时 `qcPoints` 为 0（`[]`），`qcMatched`、`qcGap` 为 `null`（没做比对，缺口未知），不得报成「0 缺口」。
- 未提供方案时把 `qcGap` 当 0 报给用户——此时三项均为 `null`，报告写「未做质量控制点比对」。

## 九、遗留问题段表述规范

`<!-- ANALYSIS_START -->` / `<!-- ANALYSIS_END -->` 之间由模型撰写，只写用户说明或记录中**写明**的内容：

- 本次未处理、留待下次检修解决的事项
- 需投用后持续观察的部位
- 备件、材料、图纸方面的欠账

**不得**：替验收组判定是否影响投用、不得推测未记录的问题、不得写「整体运行良好」这类结论性评价。无遗留问题就写「无」。

## 十、制度引用（只引名称，不转述数值）

- 《中国石化设备管理规定》《炼化企业设备管理技术规定》：检修验收三级组织、应附资料。
- 设备完整性管理体系（GB/T 44692 系列）：检修质量记录与 H/W 点见证的管理要求。
- TSG 21 / TSG D7005：特种设备（压力容器 / 压力管道）检修后的检验与使用登记变更（由特种设备管理归口）。
- ISO 10816 / GB/T 6075：试运振动按分区概念评价，数值以设备技术文件为准。
- 厂内检修验收制度（虚构示例编号写 `Q/XX-虚构-001`）：三级验收签字人、公司设备部门参加范围以厂内制度为准。

## 十一、下游衔接

- 验收发现的不合格项需转缺陷跟踪 → `defect-intake-grading`
- 验收合格后的检修记录归档 → `maintenance-record-archive`
- 大检修项目完工后的中交与开工跟踪 → `turnaround-workshop-tracker`
- 承包商施工质量与表现记录 → `contractor-performance-log`（分档定性由安全环保部门归口）
