## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 验收标准 | 「径向与轴向偏差符合设备技术文件规定值」 | 「径向偏差 ≤0.05mm」 |
| 结果栏 | 留空，由验收组填 | 预填「合格」 |
| 验收结论 | 留空 | 「经验收，该泵检修质量合格，同意投用」 |
| 签字栏 | 班组 / 车间 / 公司设备管理部门 / 工艺（操作）/ 承修单位 | 车间 / 设备部 / 施工单位 / 监理 |
| 不合格项 | 「径向偏差实测超出方案规定值」 | 「对中做得不行，需返工」 |
| 未判定 | 「待复测 → 无法归类为合格/不合格」 | 按合格计入，或直接删掉该行 |
| 控制点缺口 | 「需由验收组确认是否补充该验收项」 | 「方案要求过细，可不单列」 |
| 遗留问题 | 「备件未到未予更换，需下次停机补做」 | 「整体检修质量良好，无影响投用的问题」 |
| 类型不覆盖 | 「待技术人员补充」 | 按相近设备类型套用技术指标 |
| 醒目提示 | 「【注意】存在 2 项不合格」 | 用 emoji 符号 |
