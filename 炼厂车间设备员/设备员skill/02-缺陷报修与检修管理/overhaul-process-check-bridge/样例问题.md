# 车间检修方案安全措施核查入口 · 样例问题

> 附件均在 `演示case/02-缺陷报修与检修管理/overhaul-process-check-bridge/`（可用 `node scripts/make-sample.js --seed <n>` 重新生成，默认 seed=1）。`sample-overhaul-plan.json` 是虚构的检修方案数据，`sample-overhaul-result.json` 是依赖技能对它跑出的真实结果，其余 `*.json` 是车间侧 `notes.json` 与计数不一致变体，方案编号、工期与人名随 seed 变化，但每题的预期结论——缺失 / 建议完善 / 未判定 / 已有的**数量**与 warning 类型——不变；预期计数与验证要点见 `演示case/02-缺陷报修与检修管理/overhaul-process-check-bridge/README.md` 对照表（不进发布包）。`sample-overhaul-plan.docx` 为依赖技能 overhaul-safety-check 的泵检修方案样例副本，题 1 需先按源技能流程跑出 result.json。

1. 附件是 P-102 泵解体检修方案，日常维修，帮我核一下安全措施章节有没有漏的，设备交出条件我已经核实了。　　**附件：** `sample-overhaul-plan.docx`
2. 方案的核查结果已经跑出来了，车间这边交出、交叉作业、承包商、备件四项我核实的情况在附件里，帮我合成一份车间自查报告。　　**附件：** `sample-overhaul-result.json + sample-workshop-notes.json`
3. 这份是按老叫法报的"大修"方案，报告抬头按中石化口径该写什么，会不会影响核查结果？　　**附件：** `sample-overhaul-result.json`
4. 源技能摘要说缺失 5 项，可明细里只有 3 条，转达的时候按哪个算？　　**附件：** `sample-overhaul-result-summary-mismatch.json`
5. 班长说设备交出"应该够了"，我把它填进了车间侧提示，这样合并出来会怎么标？　　**附件：** `sample-overhaul-result.json + sample-workshop-notes-bad.json`
6. 方案我只有扫描 PDF，这个技能读不读 PDF？该先做什么。　　**附件：** `sample-overhaul-plan.docx`（扫描 PDF 请先转成 docx 或 txt 再上传）
7. 核查结果里"高处"专项是未判定，说是有一项作业没标类型，这能当作方案没问题吗？　　**附件：** `sample-overhaul-result.json`
8. 只发核查结果，车间那几项我还没来得及核，先出报告，提示里怎么写？　　**附件：** `sample-overhaul-result.json`
9. 平台上没装检修方案安全措施核查技能，这个入口还能帮我核方案吗？　　**附件：** 无
10. 方案安全措施核查都通过了，是不是开工时就不用再预检作业票了？　　**附件：** `sample-overhaul-result.json`

## 平台接入业务系统 MCP 时

本技能不调用业务系统 MCP，不上传附件：检修方案取自平台知识库，先按外部技能 overhaul-safety-check 的流程抽取 plan.json 并核查，再由本技能合并转达。

M1. 平台知识库里有 P-2101A 机械密封更换检修方案，日常维修，帮我核一下安全措施章节有没有漏项；设备交出已经核实，备件已经领了，交叉作业和承包商资质还没核。　　**数据：** 平台知识库 `01-设备资料/P-2101A_机械密封更换检修方案.docx`；先运行外部技能 overhaul-safety-check（docx2text → plan.json → check.js）
M2. 知识库里的 T-1201 塔盘检修方案，按老叫法是"大修"，安全措施缺哪些，方案里该怎么补？车间那几项我还没核。　　**数据：** 平台知识库 `01-设备资料/T-1201_塔盘检修方案.docx`；先运行外部技能 overhaul-safety-check（docx2text → plan.json → check.js）
