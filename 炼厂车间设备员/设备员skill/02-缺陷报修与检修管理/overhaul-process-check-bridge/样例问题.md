# 车间检修方案安全措施核查 · 样例问题

> 附件均在 `演示case/02-缺陷报修与检修管理/overhaul-process-check-bridge/`（可用 `node scripts/make-sample.js --seed <n>` 重新生成，不传 seed 为入库的基准版本）。`sample-overhaul-plan.docx` 与 `pump-repair.docx` 是同一份机泵检修方案，`cdu-overhaul.docx` 是常减压装置停工大检修方案，两份 Word 都附有抽取好的 `*.json` 与期望报告；`sample-overhaul-plan.json` 是 E-1201 换热器检修方案的抽取结果，`sample-overhaul-result.json` 是本技能规则引擎对它跑出的真实结果，其余 `*.json` 是车间侧 `notes.json` 与计数不一致变体。方案编号、工期、承修单位与人名随 seed 变化，但每题的预期结论——缺失 / 建议完善 / 未判定 / 已有的**数量**与 warning 类型——不变；预期计数与验证要点见 `演示case/02-缺陷报修与检修管理/overhaul-process-check-bridge/README.md` 对照表（不进发布包）。

1. 附件是 P-102 泵解体检修方案，日常维修，帮我核一下安全措施章节有没有漏的，设备交出条件我已经核实了。　　**附件：** `sample-overhaul-plan.docx`
2. 附件是常减压装置停工大检修方案，塔内和炉膛里都要用火，帮我把安全措施整体核一遍，重点看受限空间和用火相关的措施写全没有，缺什么、怎么补列个清单。　　**附件：** `cdu-overhaul.docx`
3. 方案的核查结果已经跑出来了，车间这边交出、交叉作业、承包商、备件四项我核实的情况在附件里，帮我合成一份车间自查报告。　　**附件：** `sample-overhaul-result.json + sample-workshop-notes.json`
4. 这份是按老叫法报的"大修"方案，报告抬头按中石化口径该写什么，会不会影响核查结果？　　**附件：** `sample-overhaul-result.json`
5. 班长说设备交出"应该够了"，我把它填进了车间侧提示，这样合并出来会怎么标？　　**附件：** `sample-overhaul-result.json + sample-workshop-notes-bad.json`
6. 核查结果摘要说缺失 5 项，可明细里只有 3 条，转达的时候按哪个算？　　**附件：** `sample-overhaul-result-summary-mismatch.json`
7. 我们这次大检修工期超过一个月，方案里除了常规措施，像阶段性安全检查、应急演练这类长周期安排有没有漏？帮我核一下并给出补充措辞。　　**附件：** `cdu-overhaul.docx`
8. 方案文档还在编，我先口头说要点：加氢换热器抽芯检修，涉及吊装和管线加盲板，工期 10 天，外委队伍干活。按这些信息列一下方案里必须写进去的安全措施，标出哪些是必须、哪些是建议。　　**附件：** 无（文字描述）
9. 核查结果里"高处"专项是未判定，说是有一项作业没标类型，这能当作方案没问题吗？　　**附件：** `sample-overhaul-result.json`
10. 只要核方案安全措施，车间那几项我还没来得及核，先出报告，提示里怎么写？　　**附件：** `sample-overhaul-result.json`
11. 方案我只有扫描 PDF，这个技能读不读 PDF？该先做什么。　　**附件：** `sample-overhaul-plan.docx`（扫描 PDF 请先转成 docx 或 txt 再上传）
12. 方案安全措施核查都通过了，是不是开工时就不用再预检作业票了？　　**附件：** `pump-repair.docx`

## 平台接入业务系统 MCP 时

本技能不调用业务系统 MCP，不上传附件：检修方案取自平台知识库，本技能用 docx2text 读取、抽取 plan.json 并向用户复述确认，再跑规则引擎 check.js 与 merge-report.js。

M1. 平台知识库里有 P-2101A 机械密封更换检修方案，日常维修，帮我核一下安全措施章节有没有漏项；设备交出已经核实，备件已经领了，交叉作业和承包商资质还没核。　　**数据：** 平台知识库 `01-设备资料/P-2101A_机械密封更换检修方案.docx`；本技能 docx2text → plan.json → check.js → merge-report.js
M2. 知识库里的 T-1201 塔盘检修方案，按老叫法是"大修"，安全措施缺哪些，方案里该怎么补？车间那几项我还没核。　　**数据：** 平台知识库 `01-设备资料/T-1201_塔盘检修方案.docx`；本技能 docx2text → plan.json → check.js → merge-report.js
