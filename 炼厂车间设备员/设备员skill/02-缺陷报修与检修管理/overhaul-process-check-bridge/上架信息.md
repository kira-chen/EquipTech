# 车间检修方案安全措施核查入口
**技能名称**：车间检修方案安全措施核查入口

**技能简介**：车间设备员把检修方案上报前，调用已有的检修方案安全措施核查技能对方案安全措施章节做一次自查，再把缺失、建议完善、未判定项连同"方案里怎么补"逐条原样转达，并单独附上设备交出、交叉作业、承包商资质、备件工机具等车间侧核实情况；不审技术内容，不替代审批。

**技能描述**

面向炼化厂车间设备员，检修方案上报前先把安全措施章节自查一遍。对接已有的"检修方案安全措施核查"技能，查通用措施和用火、受限空间、高处、吊装、临时用电、盲板抽堵等专项措施有没有写进方案。上传 Word 方案（PDF 先转成 txt/docx），先探测依赖技能装没装，没装就终止，不自己判；装了就按源技能流程读方案、跑规则，再把缺失、建议完善、未判定项连同"方案里怎么补"逐条原样转达，规则编号、依据一字不改。设备交出、交叉作业、承包商资质、备件工机具四项车间侧情况单独成节，状态只认已核实、未核实、不适用。结果由脚本出，模型只写转达；不审方案技术内容，专项措施以开工时办的作业票为准，不替代审批。

**示例问题**
1. 附件是 P-102 泵解体检修方案，日常维修，帮我核一下安全措施章节有没有漏的，设备交出条件我已经核实了。　　**附件：** `examples/sample-overhaul-plan.docx`
2. 方案的核查结果已经跑出来了，车间这边交出、交叉作业、承包商、备件四项我核实的情况在附件里，帮我合成一份车间自查报告。　　**附件：** `examples/sample-overhaul-result.json + examples/sample-workshop-notes.json`
3. 这份是按老叫法报的"大修"方案，报告抬头按中石化口径该写什么，会不会影响核查结果？　　**附件：** `examples/sample-overhaul-result.json`
4. 源技能摘要说缺失 5 项，可明细里只有 3 条，转达的时候按哪个算？　　**附件：** `examples/sample-overhaul-result-summary-mismatch.json`
5. 班长说设备交出"应该够了"，我把它填进了车间侧提示，这样合并出来会怎么标？　　**附件：** `examples/sample-overhaul-result.json + examples/sample-workshop-notes-bad.json`
