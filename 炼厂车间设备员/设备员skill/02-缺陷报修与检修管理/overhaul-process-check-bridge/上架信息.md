# 车间检修方案安全措施核查
**技能名称**：车间检修方案安全措施核查

**技能简介**：车间设备员把检修方案上报前，读取方案安全措施章节，按 70 条规则逐项对照通用措施和用火、受限空间、高处、吊装等专项措施，输出缺失、建议完善、未判定、已有四类结果和"方案里怎么补"，可另附设备交出、交叉作业、承包商资质、备件工机具等车间侧核实情况；不审技术内容，不替代审批。

**技能描述**

面向炼化厂车间设备员，检修方案上报前先把安全措施章节自查一遍。上传 Word 方案（PDF 先转成 txt/docx）或口述方案要点，技能读出作业内容表和安全措施，抽取后先向你复述作业项、作业类型、工期和没写的措施，确认后再按 70 条规则对照：风险辨识、交底、应急、承包商管理等通用措施，用火、受限空间、高处、吊装、临时用电、盲板抽堵等专项措施，以及受限空间内用火双票联办、工期超 30 天阶段性检查等组合情形。缺失、建议完善、已有逐条列出并附"方案里怎么补"和依据，信息不足的单列未判定，不猜测。设备交出、交叉作业、承包商资质、备件工机具四项车间侧情况可选填，单独成节，状态只认已核实、未核实、不适用。检修分级按装置大检修、日常维修、抢修、专项写入抬头。结果由脚本出，模型只写说明；不审方案技术内容，专项措施以开工时办的作业票为准，不替代审批。

**示例问题**
1. 附件是 P-102 泵解体检修方案，日常维修，帮我核一下安全措施章节有没有漏的，设备交出条件我已经核实了。　　**附件：** `sample-overhaul-plan.docx`
2. 附件是常减压装置停工大检修方案，塔内和炉膛里都要用火，帮我把安全措施整体核一遍，重点看受限空间和用火相关的措施写全没有，缺什么、怎么补列个清单。　　**附件：** `cdu-overhaul.docx`
3. 方案的核查结果已经跑出来了，车间这边交出、交叉作业、承包商、备件四项我核实的情况在附件里，帮我合成一份车间自查报告。　　**附件：** `sample-overhaul-result.json + sample-workshop-notes.json`
4. 这份是按老叫法报的"大修"方案，报告抬头按中石化口径该写什么，会不会影响核查结果？　　**附件：** `sample-overhaul-result.json`
5. 班长说设备交出"应该够了"，我把它填进了车间侧提示，这样合并出来会怎么标？　　**附件：** `sample-overhaul-result.json + sample-workshop-notes-bad.json`
