# 泵类（离心泵 / 往复泵）检修口径

> **本文件不提供任何具体数值。** 凡涉及力矩、间隙、公差、试压值、对中偏差、动平衡等级、振动与温度限值处，一律写「**须查厂内规程，本文件不提供数值**」。
> 规则实现见 `scripts/lib/rules.js` 的 `TYPE_STEPS.pump`，每条步骤带步骤号（PU 系列）可对照复核。
> 厂内有正式《离心泵检修规程》时以厂内为准；本文件与厂内规程冲突时，**一律以厂内规程为准**。

## 一、标准作业步骤（PU 系列）

| 步骤号 | 阶段 | 作业步骤 | 涉及数值 |
|---|---|---|---|
| PU1 | 施工准备 | 查上次检修记录、运行状态与缺陷记录，明确本次针对性内容 | 无 |
| PU2 | 隔离交出确认 | 拆护罩，测量记录检修前对中数据、轴窜量与径向跳动原始值 | 对中偏差：须查厂内规程，本文件不提供数值 |
| PU3 | 解体拆卸 | 拆联轴器（用拉马，禁敲击禁火焰加热），断开附属管线并标记封堵 | 无 |
| PU4 | 解体拆卸 | 按顺序拆泵盖、叶轮、机械密封与轴承箱，记录调整垫片厚度与口环位置 | 无 |
| PU5 | 检查测量 | 测口环配合间隙、叶轮与泵体间隙 | 配合间隙：须查厂内规程，本文件不提供数值 |
| PU6 | 检查测量 | 检查泵轴弯曲度、轴颈磨损与轴套配合，测径向跳动 | 公差与跳动：须查厂内规程，本文件不提供数值 |
| PU7 | 检查测量 | 检查滚动轴承游隙与滚道；滑动轴承检查合金层、轴瓦间隙与接触角 | 游隙与间隙：须查厂内规程，本文件不提供数值 |
| PU8 | 检查测量 | 检查叶轮汽蚀冲刷、口环磨损、平衡盘（鼓）磨损、泵体腐蚀结垢 | 判废标准：须查厂内规程，本文件不提供数值 |
| PU9 | 修复更换 | 更换机封、轴承、O 形圈与垫片；叶轮修复或更换后做动平衡 | 动平衡等级：须查厂内规程，本文件不提供数值 |
| PU10 | 回装装配 | 装配转子，调整叶轮轴向位置与转子窜量，装机封并调压缩量 | 窜量与压缩量：须查厂内规程，本文件不提供数值 |
| PU11 | 回装装配 | 回装联轴器，泵与电机对中，热态膨胀量按规程预留 | 对中偏差与热膨胀量：须查厂内规程，本文件不提供数值 |
| PU12 | 试验试运 | 泵体与附属管线严密性试验 | 试验压力与保压时间：须查厂内规程，本文件不提供数值 |
| PU13 | 试验试运 | 盘车无卡涩后单机试运，记录振动、轴承温度、电流、出口压力、机封泄漏 | 振动与温度限值：须查厂内规程，本文件不提供数值 |

通用步骤（G1~G10：方案审批交底、工机具到场、交出条件确认、作业许可、解体原始记录、检查测量、修复方案、力矩紧固、试验试运、收尾交付）对所有设备类型一律生成，见 `procedure-generic.md`。

| QC-PU2 | 检查测量 | 泵轴弯曲度与径向跳动 | 百分表测量 | 须查厂内规程，本文件不提供数值 | 否 |

| QC-PU6 | 试验试运 | 严密性试验 | 按规定压力保压检查渗漏 | 须查厂内规程，本文件不提供数值 | **是** |

## 三、常见失效模式与针对性检查

| 现象 | 重点检查 | 说明 |
|---|---|---|
| 机封频繁泄漏 | 对中、转子窜量、机封冲洗管路、介质结晶 | 只换机封不查对中，修完还漏 |
| 振动偏高 | 对中、基础与地脚、管线应力、叶轮不平衡、轴承 | 检修前的原始对中数据是判断依据 |
| 出口压力下降 | 口环间隙、叶轮汽蚀与磨损、入口滤网 | 间隙判废值须查规程 |
| 轴承温度高 | 润滑油品与油位、轴承游隙、对中、轴承安装方式 | 加热装轴承的温度须查规程 |
| 电流偏高 | 介质密度黏度变化、叶轮摩擦、轴承卡涩 | 与工艺核对操作工况 |

## 四、表述规范

1. 数值处一律写「按厂内规程执行（出处：<文件名> 第 N 行）」或「**待查规程确认**」，**不得写「一般为」「通常取」加一个数**。
2. 往复泵与离心泵共用本口径的通用部分；往复泵的柱塞、填料、阀组、曲轴箱专项步骤须由技术人员按厂内规程补充。
3. 屏蔽泵、磁力泵、高速泵等特种泵型的专项要求不在本口径内，须专门编制。
