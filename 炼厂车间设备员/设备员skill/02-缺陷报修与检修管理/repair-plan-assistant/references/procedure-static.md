# 静设备（塔器 / 容器 / 换热器 / 管道）检修口径

> **本文件不提供任何具体数值。** 凡涉及最小允许壁厚、腐蚀速率判据、无损检测合格级别、紧固力矩、试验压力与保压时间、内件安装公差处，一律写「**须查厂内规程，本文件不提供数值**」。
> 规则实现见 `scripts/lib/rules.js` 的 `TYPE_STEPS.static`（ST 系列）。
> **属特种设备（压力容器）的，检验与修理须符合定期检验与使用登记要求**；到期情况接 `special-equipment-inspection-due` 核对。本文件与厂内规程、设计文件冲突时**一律以厂内规程与设计文件为准**。

## 一、标准作业步骤（ST 系列）

| 步骤号 | 阶段 | 作业步骤 | 涉及数值 |
|---|---|---|---|
| ST1 | 施工准备 | 调阅设备档案：制造资料、设计参数、上次检验与检修报告、腐蚀监测数据，确认是否特种设备 | 设计参数以设计文件为准 |
| ST2 | 隔离交出确认 | 确认置换分析合格、盲板到位；需进人的确认受限空间条件（氧含量、有毒气体、通风、监护） | 分析合格判据由安全部门确定 |
| ST3 | 解体拆卸 | 打开人孔（或拆管箱、封头），自然通风后强制通风，进人前再次分析合格 | 无 |
| ST4 | 解体拆卸 | 换热器按抽芯方案抽出管束并支撑；塔器按顺序拆塔盘（填料），逐层标记编号 | 无 |
| ST5 | 检查测量 | 清理内壁、管束与内件的结垢、聚合物与腐蚀产物 | 清洗压力与药剂浓度：另行编制清洗方案 |
| ST6 | 检查测量 | 壁厚测定（重点部位与历次测点对照）、腐蚀形貌检查、焊缝与接管角焊缝无损检测 | 最小允许壁厚、腐蚀速率判据、检测合格级别：须查厂内规程与设计文件，本文件不提供数值 |
| ST7 | 检查测量 | 检查内件：塔盘变形腐蚀、降液板与堰板、填料与支撑、分布器；换热器查管板、胀口、折流板 | 变形允许值：须查厂内规程，本文件不提供数值 |
| ST8 | 检查测量 | 检查防腐衬里、隔热层与基础、支座、地脚螺栓 | 无 |
| ST9 | 修复更换 | 堵管或换管、补焊、内件更换、衬里修补；承压部件补焊须有焊接工艺与焊工资质 | 堵管比例上限：须查厂内规程，本文件不提供数值 |
| ST10 | 回装装配 | 内件回装并复查位置与水平度，清点工机具与杂物、确认无遗留后封人孔 | 安装公差：须查图纸与厂内规程 |
| ST11 | 回装装配 | 更换人孔与法兰垫片，按对角顺序分次紧固螺栓 | 紧固力矩与分次比例：须查厂内规程，本文件不提供数值 |
| ST12 | 试验试运 | 按规定做水压（或气密）试验，升压分段保压，检查焊缝与法兰渗漏 | 试验压力、介质温度、升压速率、保压时间：须查厂内规程与设计文件，**严禁自行折算** |

## 二、质量控制点（QC-ST 系列）

| 控制点号 | 阶段 | 控制内容 | 检查方法 | 合格标准 | 停工待检 |
|---|---|---|---|---|---|
| QC-ST1 | 检查测量 | 壁厚测定 | 超声测厚，测点与历次对照 | 须查厂内规程与设计文件，本文件不提供数值 | **是** |
| QC-ST2 | 检查测量 | 焊缝与接管无损检测 | 有资质单位检测出报告 | 合格级别须查厂内规程，本文件不提供 | **是** |
| QC-ST3 | 修复更换 | 承压部件焊接修复 | 查焊接工艺评定、焊工资质与焊后检测 | 按厂内规程与特种设备要求 | **是** |
| QC-ST4 | 回装装配 | 封闭前设备内清理确认 | **双人进入确认无遗留并签字** | 无遗留物 | **是** |
| QC-ST5 | 回装装配 | 法兰与人孔螺栓紧固 | 对角分次紧固，力矩扳手复核 | 须查厂内规程，本文件不提供数值 | 否 |
| QC-ST6 | 试验试运 | 水压（气密）试验 | 按规定压力与保压时间执行，全程旁站 | 须查厂内规程与设计文件，本文件不提供数值 | **是** |

## 三、静设备检修的特别提示

1. **试验压力绝不允许现场折算**。设计压力、试验压力、试验温度都在设计文件与铭牌上；没查到就标「待查规程确认」，不得按「设计压力乘个系数」自行算。
2. **封人孔前的清点是红线**。工机具、破布、垫片边角料遗留在塔器容器内，开车后会堵塔盘、堵管束、打坏机泵。双人确认签字不可省。
3. **壁厚测点要与历次一致**，否则算不出腐蚀速率。测点编号与位置以腐蚀监测台账为准。
4. **承压部件补焊属重大修理**，须履行审批与检验手续；属特种设备的还须符合定期检验要求，不得作为一般检修处理。
5. 塔器进人属受限空间作业，作业条件由安全部门确认（接 `overhaul-process-check-bridge` 核查），本方案不替代分析与许可。

## 四、表述规范

数值处一律写「按厂内规程/设计文件执行（出处：<文件名> 第 N 行）」或「**待查规程确认**」。壁厚与试压值尤其不得凭经验——最小允许壁厚判错，设备可能带缺陷开车。
