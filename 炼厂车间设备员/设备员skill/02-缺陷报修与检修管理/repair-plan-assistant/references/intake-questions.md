# 检修范围确认清单与追问话术

> 范围不清时必须追问，**不得按最常见情形假定**。写检修方案跟写交出单不一样：范围猜错，整份方案的步骤、备件、工期全错。

## 一、必需信息

| 字段 | 参数 | 为什么必需 | 缺失时的追问 |
|---|---|---|---|
| 设备类型 | `--equip-type` | 决定作业步骤、工机具、质量控制点；不在覆盖范围只能出通用框架 | 「这台是什么设备？泵、机组、塔器容器换热器、阀门、电机、加热炉、空冷器还是仪表回路？」 |
| 检修分级 | `--level` | 大检修（停工检修）/ 日常维修 / 抢修 / 专项（技改技措）；旧口径 大修/中修/小修 自动归并并 warning | 「这次是大检修项目、日常维修、抢修还是专项？」 |
| 位号 | `--tag` | 方案必须挂到具体设备 | 「位号是多少？」 |
| 检修内容 | `--scope` | 决定是否解体、哪些步骤要出 | 「这次做什么？是解体大修、抽芯清洗，还是只紧固消漏？」 |
| 计划工期 | `--duration` | 施工准备与人员安排的依据 | 「计划几天完？」（不给就留「—」，**不按经验估**） |

## 二、强烈建议提供

| 字段 | 参数 | 不提供的后果 |
|---|---|---|
| **厂内规程 / 设备说明书**（PDF 先用平台 pdf 技能转 txt/docx，扫描件需 OCR） | `--spec` | **方案中全部力矩、间隙、公差、试压值、对中偏差一律只能写「待查规程确认」**，方案无法直接用于施工 |
| 规格型号 | `--model` | 备件选型与工机具规格无法确定 |
| 上次检修记录 | `--last` | 无法判断本次的针对性内容，易重复修同一部位 |
| 是否解体 | `--dismantle 是/否` | 检修内容说不清时该项未判定，解体类步骤全部单列未判定 |
| 作业许可与 HSE | （方案第三节占位） | 用火/受限空间/高处/吊装/盲板抽堵等八大类是否涉及、JSA/风险分析编号、双监护人由谁担任——脚本只给占位，须向安全员/属地单位与作业单位确认 |

## 三、追问原则

1. **一次性列出所有缺项**，不要挤牙膏式逐个追问。
2. **规程缺失时要明确告知后果**：「没有厂内规程的话，力矩、间隙这些数值我只能写『待查规程确认』，方案不能直接拿去施工。厂里有这台设备的检修规程或说明书吗？」
3. **设备类型不在覆盖范围时要直说**：「这类设备我这边没有标准步骤，只能给个通用框架，具体拆装步骤和数值得请技术人员补。」**不得用通用知识硬凑。**
4. **不得用假设值填补**。「大概 200 N·m 吧」不能写进方案。
5. 检修内容说不清时按未判定处理，**不要替用户猜是不是解体**。

## 四、常见口语化表述与结构化对应

| 用户可能这样说 | 结构化字段 |
|---|---|
| 「P-101A 泵要拆机封」 | 设备类型 离心泵、检修内容 机械密封解体更换（涉及解体） |
| 「换热器要抽芯清洗」 | 设备类型 管壳式换热器、涉及解体 |
| 「压缩机要揭缸大修」 | 设备类型 压缩机、检修等级 大修、涉及解体 |
| 「安全阀要校验」 | 设备类型 安全阀、检修内容 整定与密封试验 |
| 「电机换个轴承」 | 设备类型 电机、涉及解体 |
| 「例行处理一下」 | 是否解体 **未判定**，需追问 |
| 「烧嘴换一下」 | 设备类型 加热炉、检修内容 烧嘴更换（涉及解体） |
| 「空冷风机轴承响」 | 设备类型 空冷器、涉及解体 |
| 「变送器要校一下，带联锁的」 | 设备类型 仪表回路；联锁摘除须审批，定值变更不在方案内 |
| 「承包商报了份大修方案，帮我看看」 | 用本技能生成同类设备的步骤与质控点作**审查要点**对照，不替代审批 |
| 「离心机转鼓换一下」 | **不在覆盖范围**，只出通用框架 |

## 五、不要问的

- 不要问「力矩一般是多少」然后按回答写进方案。数值只能来自厂内规程或说明书原文。
- 不要问「按常规来就行吧」。没有规程出处的数值，一律标「待查规程确认」。
- 不要问「这个方案可以直接用吗」。方案是否可实施由技术负责人审核批准决定。
- 不要替用户判用火级别、高处等级或风险等级。级别以作业票为准，风险等级按厂内风险分级，方案第三节只留占位。
