# 通用检修框架与「待补充」标注规范

> 用于**设备类型不在覆盖范围**（不是泵类 / 机组类 / 静设备 / 阀门 / 电气 / 加热炉 / 空冷器 / 仪表回路）的场合。
> **本文件不提供任何具体数值**，凡涉及数值处一律写「**须查厂内规程，本文件不提供数值**」。
> 规则实现见 `scripts/lib/rules.js` 的 `GENERIC_STEPS`（G 系列）。

## 一、覆盖范围判定

脚本按 `--equip-type`（其次 `--name`）归类，命中以下八类之一即为覆盖范围内（仪表回路先于阀门判，调节阀归仪表回路；空冷器先于静设备判）：

| 归类 | 命中关键词（节选） | 口径文件 |
|---|---|---|
| 仪表回路 | 仪表、变送器、调节阀、控制阀、回路、联锁、SIS、DCS、热电偶、流量计、液位计、定位器 | `procedure-furnace-aircooler-instrument.md` |
| 泵类 | 泵、柱塞、隔膜、螺杆 | `procedure-pump.md` |
| 机组类 | 压缩机、机组、汽轮机、透平、膨胀机、风机、鼓风机 | `procedure-rotating.md` |
| 加热炉 | 加热炉、工业炉、管式炉、烧嘴、燃烧器、炉管、余热锅炉、转化炉、裂解炉 | `procedure-furnace-aircooler-instrument.md` |
| 空冷器 | 空冷、空冷器、空气冷却器 | `procedure-furnace-aircooler-instrument.md` |
| 静设备 | 塔、容器、罐、槽、换热器、冷却器、再沸器、冷凝器、分离器、反应器、过滤器、管道 | `procedure-static.md` |
| 阀门 | 阀 | `procedure-valve.md` |
| 电气 | 电机、马达、电动机、变频、配电、开关柜、变压器 | `procedure-electrical.md` |

都不命中 → 归类 `generic`，脚本 `covered: false`，**只输出 G 系列通用框架**，并在 `warnings` 中说明。

## 二、通用框架（G 系列）

| 步骤号 | 阶段 | 作业步骤 | 涉及数值 |
|---|---|---|---|
| G1 | 施工准备 | 编制并审批方案、技术交底与安全交底，作业人员资质与人数确认到位 | 无 |
| G2 | 施工准备 | 工机具、量具、备件、材料到场清点，量具在检定有效期内 | 无 |
| G3 | 隔离交出确认 | 确认已完成停车、隔离、泄压、降温、置换与断电挂牌，交出单四方签字齐全 | 无 |
| G4 | 隔离交出确认 | 按《中国石化作业许可管理规定》办理作业许可（用火、受限空间、高处、吊装、临时用电、动土、断路、盲板抽堵八大类），票证到现场悬挂；拆装盲板须单办盲板抽堵作业许可 | 无 |
| G11 | 隔离交出确认 | 作业前完成 JSA/风险分析并交底，落实 HSE 措施：属地监护人与作业单位监护人双监护、应急措施与撤离路线、个体防护 | 无（方案第三节占位，由安全员/属地单位与作业单位填写） |
| G5 | 解体拆卸 | 解体前做原始记录：部件相对位置打标记、垫片记厚度、拆下件分类摆放登记 | 无 |
| G6 | 检查测量 | 对检修部位做外观检查与尺寸测量，数据逐项记入检修记录 | 判废标准：须查厂内规程，本文件不提供数值 |
| G7 | 修复更换 | 按检查结论确定修复或更换方案，更换件核对型号、材质与合格证明 | 无 |
| G8 | 回装装配 | 按拆卸逆序回装，紧固件按规定顺序与力矩对称紧固 | 紧固力矩：须查厂内规程，本文件不提供数值 |
| G9 | 试验试运 | 按厂内规定完成检修后试验与试运，记录运行参数 | 合格判据：须查厂内规程，本文件不提供数值 |
| G10 | 收尾交付 | 现场清理、工机具回收、盲板拆除登记、联锁恢复，办竣工验收与交付运行手续 | 无 |

G 系列对**所有**设备类型一律生成；覆盖范围内的设备在此基础上追加对应的专业步骤。

## 三、「待补充」标注规范（硬约束）

设备类型不在覆盖范围时：

1. **脚本只出 G 系列**，`plan.json` 的 `steps` 中不会出现任何 PU / RO / ST / VA / EL 系列步骤。
2. **每条步骤的 `note` 末尾追加「待技术人员补充」**，`qcPoints[].item` 追加「（待技术人员补充）」。
3. **`plan.md` 开头写醒目提示**：「【注意】设备类型「XXX」不在本技能覆盖范围内，以下仅为通用检修框架……」。
4. **第八节单列「8.4 待技术人员补充的内容」**，逐项列出：解体与回装的具体步骤、力矩值与间隙标准、专业质量控制点与验收判据、专用工机具与备件。
5. **模型不得凭通用知识填充**。不得因为「这类设备大概也是这么修的」就补写拆装步骤或数值——不在覆盖范围就是不在覆盖范围，交给技术人员。

## 四、常见的覆盖范围外设备

烟机、空分冷箱、膜组件、离心机、造粒机组、包装线、起重机械、在线分析仪（分析小屋）、消防设施……这些都须由对应专业的技术人员按厂内规程编制方案。

## 五、通用口径与厂内规程冲突时

**一律以厂内规程为准。** 冲突点由脚本列入 `plan.json` 的 `conflicts`，在 `plan.md` 第八节「8.2 厂内规程与通用口径冲突点」单列，注明两侧原文与行号，供技术人员确认采用哪一条。冲突未确认前，相关步骤按「待查规程确认」处理，**不得任选其一**。

冲突只在**同一参数**取值不同时才报：条款编号（「1.1」「1.2」）不算数值，「1.1 口环间隙 0.30~0.45 mm」与「1.2 轴承游隙 0.30 mm」是两个参数，不算冲突；「试运轴承振动烈度不大于 2.8 mm/s」与「一般情况下振动烈度按 4.5 mm/s 控制」是同一参数，报冲突。名称分不清是否同一参数时按同一参数报，交技术人员确认。

## 六、检修分级与作业许可口径（中石化）

- 检修分级：**装置大检修（停工检修）/ 日常维修 / 抢修 / 专项（技改技措）**。旧口径「大修/中修/小修」废止，脚本保留别名：大修→大检修、中修/小修→日常维修，并 warning 提示。
- 作业许可八大类：**用火作业**（不写「动火」）、受限空间作业、高处作业、吊装作业、临时用电作业、动土作业、断路作业、**盲板抽堵作业**。级别（用火特级/一级/二级、高处一~四级、吊装一~三级）以作业票为准，**方案不自判**。
- 监护：**双监护**（属地监护人 + 作业单位监护人），作业前 JSA/风险分析交底，属地确认人在场。方案第三节为占位，由车间安全员/属地单位与作业单位共同填写，合规性接 `overhaul-process-check-bridge` 核查。
- 验收：**三级验收**（班组 / 车间 / 公司设备管理部门），工艺参与；质量控制点与验收标准供 `completion-acceptance` 比对。
