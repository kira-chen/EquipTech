# 机组类（压缩机 / 风机 / 汽轮机）检修口径

> **本文件不提供任何具体数值。** 凡涉及间隙、力矩与热紧伸长量、对中偏差、动平衡、振动轴位移瓦温限值、试验压力、油品清洁度处，一律写「**须查厂内规程，本文件不提供数值**」。
> 规则实现见 `scripts/lib/rules.js` 的 `TYPE_STEPS.rotating`（RO 系列）。
> **机组检修属重大作业**：方案须经技术负责人审核批准，必要时报厂级审批；本文件与厂内规程冲突时**一律以厂内规程为准**。

## 一、标准作业步骤（RO 系列）

| 步骤号 | 阶段 | 作业步骤 | 涉及数值 |
|---|---|---|---|
| RO1 | 施工准备 | 调阅运行历史、在线监测（振动/位移/温度）趋势与上次大修记录，明确解体范围 | 无 |
| RO2 | 施工准备 | 确认起重方案与吊装机具，起重作业单独办许可 | 吊具载荷：按起吊重量核算 |
| RO3 | 隔离交出确认 | 确认润滑油、密封油、干气密封气源隔离泄压，盘车断电锁定，进汽/进气阀加盲板 | 无 |
| RO4 | 隔离交出确认 | 记录检修前冷态对中数据、缸体标高与轴承箱位移原始值 | 对中与标高允许偏差：须查厂内规程，本文件不提供数值 |
| RO5 | 解体拆卸 | 揭缸：按规定顺序松扣缸体螺栓、拆销子与管口，按标记吊出上缸 | 松扣顺序与热拆方式：须查厂内规程，本文件不提供数值 |
| RO6 | 解体拆卸 | **解体前**测量记录通流间隙、轴瓦间隙、推力间隙原始值，再吊出转子入专用支架 | 各项间隙：须查厂内规程，本文件不提供数值 |
| RO7 | 检查测量 | 测径向轴瓦间隙、推力瓦间隙与轴向总窜量 | 间隙标准：须查厂内规程，本文件不提供数值 |
| RO8 | 检查测量 | 检查叶片（叶轮）结垢腐蚀裂纹冲蚀，测轴颈圆度锥度与转子弯曲 | 判废标准与允许值：须查厂内规程，本文件不提供数值 |
| RO9 | 检查测量 | 检查迷宫密封齿磨损与间隙、干气密封件、联轴器膜片或齿套 | 密封齿间隙：须查厂内规程，本文件不提供数值 |
| RO10 | 修复更换 | 转子清洗除垢、换密封件与轴瓦；修复或换叶片后送专业机构做高速动平衡 | 平衡转速与等级：须查厂内规程，本文件不提供数值 |
| RO11 | 回装装配 | 回装转子，复测调整通流、轴瓦、推力与密封间隙并记录 | 调整目标值：须查厂内规程，本文件不提供数值 |
| RO12 | 回装装配 | 扣缸：清理结合面、涂密封胶，按顺序与力矩（必要时热紧）紧固缸体螺栓 | 力矩、热紧温度与伸长量：须查厂内规程，本文件不提供数值 |
| RO13 | 回装装配 | 机组整体对中（驱动机、增速箱、被驱动机），预留热态位移量 | 对中允许偏差与热膨胀量：须查厂内规程，本文件不提供数值 |
| RO14 | 试验试运 | 本体与油系统、气密系统做气密性与严密性试验 | 试验压力与保压时间：须查厂内规程，本文件不提供数值 |
| RO15 | 试验试运 | 油系统冲洗至清洁度合格；超速、轴位移、振动、低油压等联锁校验并传动 | 清洁度等级与联锁定值：须查厂内规程与联锁定值表 |
| RO16 | 试验试运 | 盘车、空负荷、升速试验与带负荷试运，逐档记录振动、轴位移、瓦温、油温 | 各转速限值与升速禁区：须查厂内规程，本文件不提供数值 |

## 三、机组检修的特别提示

1. **解体前原始数据是不可再生的**。通流间隙、轴瓦间隙、推力间隙、对中与标高必须在解体前测完记完，事后无法补测，补不出就只能按规程重新设定。
2. **转子是重大备件**。吊装必须用专用吊具，严禁钢丝绳兜吊轴颈与密封部位；存放必须用支架，不得直接落地。
3. **联锁不得擅自改定值**。检修后校验按联锁定值表执行，定值变更须走变更手续（接 `moc-change-assistant`）。
4. **汽轮机、膨胀机的专项要求**（如汽封调整、危急遮断试验、胀差与轴向位移保护）须由技术人员按厂内规程补充，本口径未覆盖其全部细节。
5. 往复式压缩机的气阀、活塞环、十字头、填料函等专项步骤须按厂内往复机规程补充。

## 四、表述规范

数值处一律写「按厂内规程执行（出处：<文件名> 第 N 行）」或「**待查规程确认**」。机组的间隙与热紧值尤其**不得凭经验估**——扣缸力矩写错，轻则结合面泄漏，重则缸体变形。
