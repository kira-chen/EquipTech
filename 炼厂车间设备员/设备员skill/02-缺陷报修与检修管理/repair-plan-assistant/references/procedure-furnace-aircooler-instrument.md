# 加热炉 / 空冷器 / 仪表回路检修口径（FU / AC / IN 系列）

> **本文件不提供任何具体数值。** 凡涉及炉管壁厚与胀粗判废值、烘炉升温曲线、叶尖间隙、平衡等级、试验压力、校验精度与回差处，一律写「**须查厂内规程，本文件不提供数值**」。
> 规则实现见 `scripts/lib/rules.js` 的 `TYPE_STEPS.furnace / aircooler / instrument`。本文件与厂内规程、制造厂文件冲突时**一律以厂内规程与制造厂文件为准**。
> 依据《炼化企业设备管理技术规定》中加热炉、空冷器与仪表设备维护检修的要求整理，不转述具体数值。

## 一、加热炉（FU 系列）

| 步骤号 | 阶段 | 作业步骤 | 涉及数值 |
|---|---|---|---|
| FU1 | 施工准备 | 调阅运行记录（炉膛温度、壁温、排烟温度、氧含量）、上次检修与炉管测厚/蠕变报告，明确范围（炉管、烧嘴、衬里、预热器、风机） | 无；余热锅炉属特种设备接 `special-equipment-inspection-due` |
| FU2 | 隔离交出确认 | 燃料气/油管线加盲板、吹扫置换分析合格，炉膛降温，进炉膛属受限空间作业 | 分析合格判据由安全部门确定 |
| FU3 | 解体拆卸 | 拆烧嘴（记编号与角度）、开看火门与人孔、拆需更换炉管段与衬里 | 无 |
| FU4 | 检查测量 | 炉管外观（鼓包、弯曲、氧化皮、结焦）、壁厚测定与蠕变/胀粗测量 | 壁厚、胀粗率、蠕变判据：须查厂内规程与设计文件 |
| FU5 | 检查测量 | 吊架、管卡、弯头箱、回弯头、耐火衬里与炉体钢结构 | 无 |
| FU6 | 检查测量 | 烧嘴配风器、火嘴头、点火器与火检，空气预热器与引风机 | 喷嘴孔径按制造厂文件 |
| FU7 | 修复更换 | 更换判废炉管段（受监焊口，须焊接工艺评定与焊工资质）、烧嘴部件、衬里修补 | 无 |
| FU8 | 回装装配 | 回装烧嘴（原编号与角度）、看火门与人孔，螺栓按规定力矩紧固 | 紧固力矩：须查厂内规程 |
| FU9 | 试验试运 | 炉管系统水压（气密）试验，燃料气管线气密试验 | 试验压力与保压时间：须查厂内规程与设计文件 |
| FU10 | 试验试运 | 烘炉（新衬里）、按升温曲线点火升温，记录炉膛温度、壁温与氧含量 | 升温曲线、壁温与氧含量限值：须查厂内规程 |

质量控制点：QC-FU1 燃料气盲板与炉膛分析（停工待检）、QC-FU2 炉管壁厚与胀粗（停工待检）、QC-FU3 炉管焊口无损检测（停工待检）、QC-FU4 水压试验（停工待检）、QC-FU5 烘炉/升温曲线执行（停工待检）。
验收：AC-FU1~AC-FU5（壁厚胀粗、焊口检测、试压、火焰与壁温氧含量、衬里）。

**特别提示**：炉管为受监部件，判废与焊接修复须按厂内规程与特种设备/受监要求履行手续；进炉膛属受限空间作业，分析与许可由安全部门确认。

## 二、空冷器（AC 系列）

| 步骤号 | 阶段 | 作业步骤 | 涉及数值 |
|---|---|---|---|
| AC1 | 施工准备 | 调阅运行记录（出口温度、风机电流、振动）、上次检修与管束泄漏历史，明确范围（管束、风机、减速/皮带、百叶窗） | 无 |
| AC2 | 隔离交出确认 | 管束隔离泄压置换加盲板，风机电机断电挂牌上锁，高处作业平台与防坠措施到位 | 无；须办高处作业许可 |
| AC3 | 解体拆卸 | 拆管箱丝堵/管箱盖（记位置），拆风机叶片、皮带或联轴器，吊出管束或电机 | 无；吊装须办许可 |
| AC4 | 检查测量 | 翅片倒伏与积灰、管端胀口泄漏、管箱腐蚀；壁厚测定 | 翅片管壁厚与胀口判废：须查厂内规程 |
| AC5 | 检查测量 | 叶片角度与一致性、叶尖与风筒间隙、轮毂与轴承游隙、减速箱/皮带 | 叶尖间隙与轴承游隙：须查厂内规程或说明书 |
| AC6 | 修复更换 | 堵管/换管、翅片梳理清洗、更换轴承/皮带/叶片；叶片更换后做平衡 | 平衡等级与叶片角度：须查厂内规程或说明书 |
| AC7 | 回装装配 | 回装管箱盖与丝堵（换垫片）、叶片与护网，按规定力矩紧固 | 紧固力矩：须查厂内规程 |
| AC8 | 试验试运 | 管束水压（气密）试验，检查胀口与丝堵渗漏 | 试验压力与保压时间：须查厂内规程与设计文件 |
| AC9 | 试验试运 | 风机空载试运（转向、电流、振动、轴承温度），百叶窗与调速功能 | 振动与轴承温度限值：须查厂内规程 |

质量控制点：QC-AC1 翅片管壁厚与胀口、QC-AC2 叶尖间隙与叶片角度、QC-AC3 叶片平衡（停工待检）、QC-AC4 水压试验（停工待检）、QC-AC5 试运振动与温度（停工待检）。
验收：AC-AC1~AC-AC4。

## 三、仪表回路（IN 系列）

| 步骤号 | 阶段 | 作业步骤 | 涉及数值 |
|---|---|---|---|
| IN1 | 施工准备 | 核对位号、型号、量程、介质与联锁归属（SIS/DCS） | 无；**联锁定值变更属工艺/仪表归口，本方案不涉及** |
| IN2 | 隔离交出确认 | 引压管线隔离泄压，联锁按审批旁路/摘除，供电气源断开挂牌 | 无；旁路补偿措施由工艺与仪表确认 |
| IN3 | 解体拆卸 | 拆表/拆执行机构送校验，接线标记与回路编号 | 无 |
| IN4 | 检查测量 | 按量程校验（零点、满度、线性、回差） | 示值误差与回差允许值：须查厂内仪表校验规程或说明书；**压力表温度计检定属计量归口** |
| IN5 | 检查测量 | 引压管线堵塞泄漏伴热，调节阀阀芯阀座、填料、定位器、气源 | 调节阀本体解体接 VA 系列 |
| IN6 | 修复更换 | 更换膜盒、电子件、定位器、填料，整修电缆端子 | 防爆区保持防爆等级 |
| IN7 | 回装装配 | 回装、恢复接线并核对回路编号，引压管线排气排污 | 接线双人核对 |
| IN8 | 试验试运 | 回路联校（现场→DCS/SIS）、调节阀行程与全行程时间、联锁传动试验后投用 | 联校允差与传动试验要求：须查厂内规程；联锁定值与定值表核对 |
| IN9 | 收尾交付 | 联锁恢复投用签字，校验与联校记录归档，更新校验台账 | 台账接 `valve-instrument-calibration-ledger` |

质量控制点：QC-IN1 联锁摘除/旁路审批（停工待检）、QC-IN2 校验数据、QC-IN3 接线与回路编号核对（停工待检）、QC-IN4 联校与联锁传动试验（停工待检）、QC-IN5 联锁恢复投用确认（停工待检）。
验收：AC-IN1~AC-IN4。

**特别提示**：仪表回路方案由设备员提出需求与审查要点，具体校验与联锁操作由仪表专业实施；SIS 功能测试与计量检定不在本技能范围。

## 四、表述规范

数值处一律写「按厂内规程/说明书执行（出处：<文件名> 第 N 行）」或「**待查规程确认**」。炉管判废值、试验压力与联锁定值尤其不得凭经验。
