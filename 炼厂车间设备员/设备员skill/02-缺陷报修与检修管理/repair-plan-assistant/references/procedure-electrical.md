# 电气（电机 / 变频器 / 配电设备）检修口径

> **本文件不提供任何具体数值。** 凡涉及绝缘电阻、吸收比与极化指数、直流电阻不平衡率、耐压试验电压、轴承游隙与配合公差、气隙不均匀度、润滑脂牌号与加注量、烘干温度、振动与温升限值处，一律写「**须查厂内电气试验规程，本文件不提供数值**」。
> 规则实现见 `scripts/lib/rules.js` 的 `TYPE_STEPS.electrical`（EL 系列）。
> **电气作业须由持证电工实施**，试验由持证电气试验人员执行。本文件与厂内电气试验规程冲突时**一律以厂内规程为准**。

## 一、标准作业步骤（EL 系列）

| 步骤号 | 阶段 | 作业步骤 | 涉及数值 |
|---|---|---|---|
| EL1 | 施工准备 | 核对铭牌参数（功率、电压、电流、转速、绝缘等级、防爆标志）与备件绕组、轴承型号 | 参数以铭牌为准 |
| EL2 | 隔离交出确认 | 断电、验电、放电并挂牌上锁（LOTO），高压电机装设接地线，钥匙由检修负责人保管 | 无 |
| EL3 | 隔离交出确认 | 测量检修前绕组绝缘电阻与吸收比、直流电阻，作为与检修后对比的原始值 | 合格值：须查厂内电气试验规程，本文件不提供数值 |
| EL4 | 解体拆卸 | 拆接线盒接线（做相序标记）、联轴器与地脚螺栓，吊出送检修间；抽转子防碰伤绕组 | 无 |
| EL5 | 检查测量 | 检查定子绕组绝缘老化变色、槽楔松动与端部绑扎，检查转子鼠笼条（或滑环、集电环） | 判废标准：须查厂内规程，本文件不提供数值 |
| EL6 | 检查测量 | 检查轴承磨损与游隙、轴承室配合，检查定转子气隙均匀度 | 游隙、配合公差、气隙不均匀度：须查厂内规程或说明书，本文件不提供数值 |
| EL7 | 修复更换 | 清洁绕组与通风道、绝缘处理（烘干或浸漆）、换轴承与密封；重绕由专业厂家实施 | 烘干温度与时间：须查厂内规程，本文件不提供数值 |
| EL8 | 回装装配 | 回装转子与端盖，加注规定牌号与数量的润滑脂，回装接线核对相序，恢复接地 | 润滑脂牌号与加注量：须查厂内规程或说明书，本文件不提供数值 |
| EL9 | 试验试运 | 检修后电气试验：绝缘电阻与吸收比、直流电阻、必要时耐压试验，出具试验报告 | 合格判据与耐压电压：须查厂内电气试验规程，**不得凭经验判定** |
| EL10 | 试验试运 | 空载试运转查转向、电流、振动、温度、声音；合格后对中并联轴带负荷试运 | 空载电流、振动与温升限值：须查厂内规程，本文件不提供数值 |

| 控制点号 | 阶段 | 控制内容 | 检查方法 | 合格标准 | 停工待检 |
|---|---|---|---|---|---|
| QC-EL1 | 隔离交出确认 | 断电挂牌上锁与验电放电 | 现场确认并记录挂牌编号 | 挂牌上锁到位，验电无压 | **是** |
| QC-EL2 | 隔离交出确认 | 检修前绝缘与直流电阻原始值 | 电气试验并记录 | 须查厂内试验规程，本文件不提供数值 | 否 |
| QC-EL3 | 检查测量 | 轴承游隙与定转子气隙 | 塞尺测量，气隙四点对称测量 | 须查厂内规程，本文件不提供数值 | 否 |
| QC-EL4 | 回装装配 | 接线相序与接地连接 | 相序表核对，接地电阻测量 | 须查厂内规程，本文件不提供数值 | **是** |
| QC-EL5 | 试验试运 | 检修后电气试验 | 绝缘电阻、吸收比、直流电阻、耐压，出报告 | 须查厂内试验规程，本文件不提供数值 | **是** |

## 三、电气检修的特别提示

1. **挂牌上锁的钥匙不得转交**。解锁只能由挂锁人本人完成，严禁他人代解——这是防误送电最后一道屏障。
2. **防爆电机的防爆性能不得破坏**。隔爆面加工、接线盒密封、绕组重绕都须由具备防爆维修资质的单位实施，并出具防爆性能确认记录；自行修复会使防爆认证失效。
3. **相序标记必须做**。回装接错相序电机反转，对泵、风机、压缩机都是重大隐患。
4. **绝缘电阻要看吸收比和温度**。同一台电机不同温度下的读数没有可比性，换算方法须按厂内试验规程，**不得自行按经验折算**。
5. **耐压试验有风险**。试验电压值只能来自厂内电气试验规程，由持证试验人员操作，试验区域须隔离警戒。
6. 变频器、软启动、配电柜（开关柜、继保定值）的检修与校验属电气专业专项，本口径未覆盖其细节，须由电气技术人员补充。

## 四、表述规范

数值处一律写「按厂内电气试验规程执行（出处：<文件名> 第 N 行）」或「**待查规程确认**」。绝缘电阻与耐压电压尤其不可凭经验——判据写松了带病投运，写紧了好电机被误判重绕。
