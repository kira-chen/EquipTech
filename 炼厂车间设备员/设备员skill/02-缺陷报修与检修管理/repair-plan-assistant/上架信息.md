# 检修方案辅助编制
**技能名称**：检修方案辅助编制

**技能简介**：按设备类型和检修内容生成检修方案初稿或审查要点：作业步骤、工机具、备件、质量控制点、验收标准，附 JSA/风险分析与 HSE 措施占位；力矩、间隙、试压值只引用厂内规程原文，没出处就写"待查规程确认"。初稿须经技术负责人审批。

**技能描述**

面向炼化厂车间设备员，出检修方案初稿或审查要点。告诉它设备类型、位号、检修内容和分级，最好再给厂内检修规程（Word、txt 或 md），它按泵、机组、塔器容器换热器、阀门、电机、加热炉、空冷器、仪表回路八类匹配标准作业步骤，列出工机具、备件、待检点和验收项。方案里每个数值只引用规程原文并注明出处，规程没有的写"待查规程确认"并单列，不凭经验填；规程前后不一致的列为冲突点交你确认。JSA、作业许可、双监护和 HSE 措施只留占位，由安全员和作业单位填，作业级别和风险等级不自判。适合自编日常维修初稿或对照审承修单位方案。步骤由脚本出，模型只写说明；不判安全措施合规，不办作业票，初稿须经技术负责人审批。

**示例问题**
1. P-3101A 进料泵要拆机封，这是我们厂的离心泵检修规程，帮我写个日常维修方案，3 天工期，9 月 25 日开工。　　**附件：** `sample-procedure-pump.md`
2. 加热炉 F-3501 大检修要换炉管、检修烧嘴，规程给你，出个方案，重点把停工待检点和受限空间的要求列清楚。　　**附件：** `sample-procedure-furnace.md`
3. E-3401 换热器例行处理一下，只有一份通用紧固规定，看看能出到什么程度，说不清的别替我定。　　**附件：** `sample-procedure-partial.md`
4. 规程是 Word 版的，能不能直接读？还是按 P-3101A 拆机封出方案。　　**附件：** `sample-procedure-pump.docx`
5. 承修单位报了份压缩机揭缸大检修方案，我没有规程，先给我一份标准步骤和质控点，我拿来对照审他们的方案。　　**附件：** 无
