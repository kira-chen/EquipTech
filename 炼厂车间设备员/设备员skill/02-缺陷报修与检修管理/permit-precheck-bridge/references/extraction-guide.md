# 作业票抽取手册：Word / 图片 / 文字 → permit.json

本手册是 SKILL.md 操作步骤第 1~2 步的操作依据。目标：把票面内容**如实**搬进 `permit.json`，不判断对错（判断交给规则引擎 `scripts/precheck.js`）。

> **type 枚举沿用 GB 30871 的「动火」，即中石化的「用火作业」。** 票面标题是"用火作业许可证 / 用火安全作业证 / 用火票"或"动火安全作业证"时，`type` 一律填「动火」；规则库原文、票面栏目名（如"动火级别""是否受限空间内动火"）里的「动火」照原样理解为用火。下文说明性文字统一写"用火"，引用票面原文、JSON 取值与规则原文时保留"动火"。

## 0. 总原则（违反任何一条都会让预检结果失真）
1. **只抄不猜**：票面空白、看不清、被遮挡 → 填 `null`，并在 `extraction_notes[]` 记一条。不得用常识补全（不能因为"一般都有监护人"就填名字；不能因为地点是塔就填 `in_confined_space=true`）。
2. **票面没有该栏目 ≠ 未勾选**：措施项票面根本没印 → `null`；印了但没勾 → `false`；勾了 → `true`。
3. **签字栏**：手写签字/电子签 → 填姓名；只有打印姓名无签字 → 仍填姓名，但记备注"无签字仅打印名"；完全空白 → `null`。
4. **时间统一 ISO 8601 + 时区 `+08:00`**；数值去单位；`"合格"` 不是数值，填 `null` 并记备注。
5. **每一次"填 null / 推断 / 换算 / 取检出限"都要在 `extraction_notes[]` 留痕**，格式：`字段路径：票面情况 → 填了什么`。
6. 抽取完成后先做第 5 节自检，再向用户复述关键字段并请其确认，最后才运行脚本。

## 1. 三步流程

### 第 1 步：把票面变成可读文本
| 输入 | 做法 |
|---|---|
| `.docx` | `node "<技能根目录>/scripts/docx2text.js" --input <docx> --out ./precheck/permit.txt`，读输出的 txt。表格每行以 `\|` 分隔，`[x]`/`[ ]` 即勾选状态，`[×]` 为叉选（可能是"选中"也可能是"否定"，结合上下文判断并记备注），`〃` 表示与上一行纵向合并，`‹›` 为横向合并占位（不是留白），空单元格 = 票面留白；`~~文字~~` 为删除线（视为作废内容）；`【文本框】…` 为文本框内容；末尾 `### 页眉/页脚` 块里可能有票号、单位名 |
| 图片 / 扫描 PDF | 直接看图。先整体看清票面结构（几个表格、各在哪），再逐栏读取；每页都要看，缺页记备注 |
| 文字描述 | 用户口述内容按第 2 步对照表映射；未提到的字段全部 `null` |
| `.doc` / `.wps` / 加密 docx | docx2text 不支持，提示用户另存为 `.docx` 或截图 |

docx2text 末行的 JSON 摘要 `{"paragraphs","tables","checked","unchecked","crossed","textboxes","header_footer"}` 可用来核对：作业票通常 5～8 个表格、勾选框 10～25 个；表格数为 0 且 `textboxes` 也为 0 多半是整票用图片排版，需让用户转成图片再看图；`textboxes` > 0 时文本框内容已内联输出，但其在版面上的位置无法还原，对应字段要谨慎并记备注。

### 第 2 步：按字段对照表逐项映射
复制 `assets/templates/permit.json`，按下面 2.1～2.6 逐项填写。填不到的保持 `null`（数组类字段用 `[]`）。

#### 2.1 顶层信息
| 票面栏目（含常见别名） | permit.json 字段 | 取值规则 |
|---|---|---|
| 作业证标题 / 作业类别 / 作业类型 | `type` | 映射为八类之一（取值）：动火、受限空间、高处、吊装、临时用电、盲板抽堵、动土、断路。"用火作业许可证 / 用火安全作业证 / 用火票 / 用火作业"→动火；"动火安全作业证"→动火；"进入受限空间/有限空间作业证"→受限空间；"登高作业票"→高处；"起重吊装"→吊装；"临时用电作业证"→临时用电；"盲板抽堵/抽堵盲板"→盲板抽堵；"动土/破土"→动土；"断路/道路断开"→断路 |
| 编号 / 票号 / 作业证编号 / No. | `permit_no` | 含前缀原样抄，如 `DH-2026-0828-017` |
| 用火级别 / 动火级别 / 作业级别 / 高处作业级别 / 吊装级别 | `level` | 勾选组 `[ ]特级 [x]一级 [ ]二级` 取被勾的那个；"Ⅰ级/I级/1级"→"一级"，"Ⅱ级"→"二级"，"Ⅲ级"→"三级"；无级别的类型填 `null` |
| 作业地点 / 作业部位 / 装置 / 设备位号 / 受限空间名称 | `location` | 多栏拼成一句，以空格连接，如 `常减压装置 加热炉 F-101 北侧 转油线管廊` |
| 申请单位 / 属地单位 / 作业单位 / 施工单位 | `unit` | `属地单位 / 作业单位`，用 ` / ` 连接；只有一个就填一个 |
| 介质 / 物料 / 设备（管线）内介质 / 空间内介质 | `medium.name` | 原文抄录，含括号说明（如"已置换"） |
| 介质爆炸下限 / LEL / 爆炸极限下限 | `medium.lel_pct` | 数值（体积%），`1%`→`1.0`；票面无此栏→`null`（脚本会提示"无法按体积分数判定"），可在交付说明里提示常见值，**不要填进 JSON** |
| 介质性质 / 易燃 / 有毒（勾选或介质性质栏） | `medium.flammable` / `medium.toxic` | 勾选→布尔（`[x]易燃 [ ]有毒` → `flammable=true, toxic=false`）；票面无→`null`。`toxic=false` 时有毒气体栏留空可通过 |
| 作业时间 自…至… / 有效期 / 作业起止时间 | `start_time` / `end_time` | 见 2.5 时间格式 |
| 申请人 / 作业负责人 / 作业申请人签字 | `applicant` | 姓名；见签字栏规则 |
| 监护人 / 监护人签字 | `guardian` | 姓名；空白→`null` |
| 监护人证书编号 / 监护人证号 / 监护证 | `guardian_cert` | 原样抄；空白→`null` |
| 安全交底签字 / 交底确认（整体一栏，签字或勾选） / 作业人员已交底签字 | `briefing_signed` | 有签字/勾选→`true`；栏目存在但空白→`false`；票面无此栏→`null`（逐人签字的填 `workers[].briefing_signed`，两者任一即可） |
| 审批 / 审核 / 批准 / 属地车间主任 / 安全环保部 / 完工验收 各签字栏 | `approvers[]` | 每个**已签字**的审批环节一项，格式 `姓名（职务/环节）`，如 `王建国（属地车间主任）`；空白环节不写入数组，但记备注"XX 栏空白"；"申请人"和"完工验收人"不算审批人 |
| 作业内容 / 备注 / 特殊情形 栏 | `notes` | 票面备注栏原文；无则 `null`（作业内容可并入 `location` 后面或写到 notes） |

#### 2.2 作业人员（`workers[]`，一人一项）
| 票面栏目 | 字段 | 规则 |
|---|---|---|
| 姓名 | `workers[].name` | 空白行不生成对象 |
| 工种 / 角色 / 岗位 | `workers[].role` | 原文；吊装票的"指挥 / 司索 / 起重机司机"、临时用电的"电工"、用火票的"焊工"必须保留这些关键词（脚本按关键词匹配证书要求） |
| 特种作业证 / 资质证书编号 / 证号 | `workers[].cert` | 原样抄；空白→`null`（脚本会提示"未填写证书"）；票面明确写"非特种作业"→`"N/A-非特种作业"`（焊工/电工/指挥/司索/司机等特种工种填 N/A 会被判无证） |
| 安全交底签字 / 交底签字 / 作业人员签字（逐人一列） | `workers[].briefing_signed` | 该行有签字→`true`；栏目存在但空白→`false`；票面无此列→`null` |

#### 2.3 气体分析记录（`gas_tests[]`，一行一项）
| 票面列名（别名） | 字段 | 规则 |
|---|---|---|
| 分析时间 / 检测时间 / 取样时间 | `gas_tests[].time` | ISO 时间；只写 `08:05` 时日期取作业开始日，记备注"日期由作业日期补全" |
| 分析部位 / 取样点 / 检测位置 | `gas_tests[].location` | 原文 |
| O₂ / 氧含量 / 氧气 % | `gas_tests[].o2` | 数值，`20.9%`→`20.9` |
| 可燃气 / 可燃气体 %LEL / 爆炸下限百分比 | `gas_tests[].lel` | 数值（%LEL），`0%LEL`→`0` |
| 可燃气 %(V) / 体积分数 / 可燃气体浓度 % | `gas_tests[].combustible_vol` | 数值（体积%）；票面只给 %LEL 不给体积% → `null`（不要自行换算） |
| 有毒气体 / H₂S / CO / 苯 … | `gas_tests[].toxic[]` | 每种一项 `{name, value, unit}`；`unit` 抄票面单位（`mg/m3` 或 `ppm`），ppm **不换算**，脚本会提示人工比对；`"<1"`→`value=1` 并记备注"检出限以下"；票面写"无/—"→`toxic: []` |
| 分析人 / 检测人 / 分析人签字 | `gas_tests[].analyst` | 姓名；空白→`null` |
| 仪器校验有效 / 检测仪校验有效期内 / 仪器编号及校验日期 / 检测仪器在有效期 | `gas_tests[].instrument_ok` | 勾选或写"是/有效"→`true`；写"否/过期"→`false`；只写仪器编号或校验日期→`null` 并把编号/日期记备注；票面无此栏→`null` |

表格里整行空白的不生成对象；一次分析都没有 → `gas_tests: []`。多行时按票面顺序填即可，脚本会按时间排序、以时间最新的一次判定；开工后的复检也照填，脚本不会把它当成超时。

#### 2.5 时间格式
| 票面写法 | 填法 | 备注 |
|---|---|---|
| `2026年8月28日 09:00` / `2026-08-28 9:00` / `8.28 9时` | `2026-08-28T09:00:00+08:00` | 时分补两位，秒填 00 |
| 只有日期 `2026年8月28日` | 起：`2026-08-28T00:00:00+08:00`；止：`2026-08-28T23:59:00+08:00` | 记备注"票面只有日期，时刻按 00:00/23:59 补" |
| 只有时刻 `08:05`（气体分析） | 日期取 `start_time` 的日期 | 记备注"日期由作业日期补全" |
| 跨天 `28日 20:00 至 29日 6:00` | 分别填两天 | 同时 `night_or_holiday=true`，记备注"由时间推断" |
| 空白 | `null` | 记备注 |

#### 2.6 其他布尔 / 数值 / 关联项
| 票面栏目 | 字段 | 规则 |
|---|---|---|
| 关联作业票 / 同时办理的其他作业票 / 相关作业证编号 | `cross_jobs[]` | 只填票面**明确写出票号**的，`{type, permit_no}`；`type` 用八类名称（"盲板抽堵"而非"盲板"），按票号前缀或栏目名判断；无→`[]` |
| 附件：作业方案 / 盲板图 / 地下管线图 / 绕行方案 | `attachments.scheme / blind_plate_map / underground_map / detour_plan` | 填附件名或编号；"已附"→`"已附"`；空白→`null` |
| 是否受限空间内用火 / 是否受限空间内动火 | `in_confined_space` | 勾选→布尔；票面无此栏→`null`，**不要从地点名推断** |
| 是否含用火 / 是否含动火 / 交叉动火 | `hot_work_inside` | 同上 |
| 露天 / 室外 | `outdoor` | 同上 |
| 夜间 / 节假日 | `night_or_holiday` | 勾选→布尔；无此栏可由时间推断（18:00～次日 06:00），推断要记备注 |
| 作业高度 / 坠落高度 | `height_m` | 数值 m；`约 12.5m`→`12.5` |
| 吊装质量 / 吊物重量 | `load_mass_t` | 数值 t；`8000kg`→`8` 并记备注"由 kg 换算" |
| 动土深度 | `depth_m` | 数值 m |
| 电压 / 接电点 | `voltage` / `power_source` | `380V`→`380`（数字；字符串 "380" 脚本也能识别）；接电点原文 |
| 爆炸危险区域 | `hazardous_area` | 布尔 |
| 照明电压 | `lighting_voltage` | `12V`→`12` |
| 潮湿 / 狭小金属容器 | `wet_or_metal_container` | 布尔 |
| 盲板清单：编号 / 位置 / 抽或堵 / 规格 | `blind_plates[]` | `action` 写 `堵-1`、`抽-2`（含顺序号） |
| 天气：风力 / 雷雨 / 降雨 | `weather.wind_level` / `thunderstorm` / `rain` | `风力 6 级`→`6`；票面通常无天气栏→`null`；用户口头告知可填并记备注"来源：用户口述" |
| 作业中断时长 | `interrupted_minutes` | 审批前预检通常 `null` |

### 第 3 步：自检（见第 5 节），然后向用户复述并保存
保存到工作目录（如 `./precheck/permit.json`），用一句话向用户复述：作业类型与级别、起止时间、气体分析（次数、最近一次时间与 O₂/LEL）、监护人、已勾选措施数 / 总数、`extraction_notes` 条数，**请用户确认后**再运行 `scripts/precheck.js`。

## 2. 完整抽取示例（用火案例）

### docx2text 输出片段（演示样例 `hotwork-level1-with-issues.docx2text.txt`，节选；样例票面按 GB 30871 版式印"动火安全作业证"）

## 3. 图片 / 扫描件专项
- 先数表格、找标题与编号，再逐表逐行读；手写姓名/数字不确定 → `null` + 备注（如"监护人栏似为'吴X'，无法确认"）。
- 勾选框：✓、√、×、圈选、涂黑都可能表示"选中"；划掉/留白为未选；模糊 → `null` + 备注。
- 多页票只拿到部分页面：缺页涉及的字段全部 `null`，明确告知用户缺哪页。
- 复印件上盖章/涂改覆盖的内容 → `null` + 备注。

## 4. 纯文字描述专项
- "一级用火，早上 8 点分析合格，9 点开工" → `level=一级`，`gas_tests[0].time=…T08:00:00+08:00`，`o2/lel=null`（"合格"不是数值，备注），`start_time=…T09:00:00+08:00`，`end_time=null`。
- 用户没提到的字段一律 `null`。抽取完成后**复述已抽取字段与 null 清单，请用户确认（或补充）后再跑预检**；对 null 较多的票，预检报告会有大量"缺失"和"未判定"，先确认再跑可避免无意义的整改项。

## 5. 抽取后自检清单（10 项，逐项打勾后才复述给用户）
1. **类型与标题一致**：`type` 与票面标题/类别栏一致；多类作业混合时主票类型正确，其余进 `cross_jobs`。
2. **级别与作业内容一致**：`level` 取自勾选组的被勾项；高处票 `height_m`、吊装票 `load_mass_t`、用火票"受限空间内/夜间"等分级依据已抽取（脚本会校核级别是否匹配）。
3. **时间起止顺序与时区**：`start_time < end_time`，都带 `+08:00`（无时区会被脚本当作缺失），跨天已分别写日期；气体分析时间通常早于 `start_time`（开工后的复检除外）。
4. **编号与关联票号无错字**：前缀、年月日、序号逐字符核对；`cross_jobs` 只含票面明确写出的票号。
5. **勾选项没有漏读、错读**：docx2text 摘要的 `checked+unchecked` 数量 ≈ 票面勾选框总数；`measures` 中 true/false 的数量与票面一致；票面没有的措施保持 `null`。
6. **签字栏空白已如实为 null**：申请人、监护人、各审批环节、分析人逐一核对；空白的都写进 `extraction_notes`。
7. **人员逐人核对**：`workers` 条数 = 票面非空行数；证书空白 → `null`，未编造；角色关键词（焊工/电工/指挥/司索/司机）保留；交底签字列逐人填 `briefing_signed`。
8. **气体分析逐行核对**：每行 O₂/LEL/体积%/有毒气体/分析人/仪器校验分列正确，单位保留在 `unit`，未做 ppm↔mg/m³ 换算；`medium.lel_pct` 已填（否则脚本无法按体积分数判定）。
9. **数值无单位、无中文**：`lel_pct`、`height_m`、`lighting_voltage`、`wind_level` 等都是纯数字或 `null`。
10. **extraction_notes 完整**：每个 `null`、每次推断/换算/补全都有对应一条，格式为"字段：票面情况 → 填了什么"；JSON 能被 `node -e "JSON.parse(require('fs').readFileSync('permit.json','utf8'))"` 解析。
