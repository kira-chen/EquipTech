# 特殊作业票预检规则（人读版）

> 依据 GB 30871-2022《危险化学品企业特殊作业安全规范》及中石化特殊作业管理通行做法，**按记忆整理**。章节号（第4~12章）可信度较高，细分条款号不确定处以"参考 GB 30871-2022 相应条款"表述，最终以正式文本与企业制度为准。机器版见 `rules.json`（规则 ID 一致）。
>
> 用词：GB 30871-2022 称「动火作业」，《中国石化作业许可管理规定》称「用火作业」，二者指同一类作业。本文的规则检查项、`type` 取值与 `rules.json` 的规则原文一致，保留「动火」一词，报告照搬原文；车间口径行文写「用火」。
>
> 严重度：**must_fix** 必须整改 / **should_improve** 建议完善 / **undetermined** 未判定（规则的 when 条件依赖的票面字段为空，无法判断是否适用，报告单列一节）/ **pass** 通过。标注"待核实"的规则为审查新增、尚未逐条核对正式文本，清单见 §9。

## 2. 用火作业（GB 30871 第5章「动火作业」，HW-xxx）
### 分级与升级
| 级别 | 适用情形（摘要） |
|---|---|
| 特级 | 运行状态的易燃易爆生产装置、储罐区等重点部位动火 |
| 一级 | 易燃易爆场所动火（生产装置区、罐区等） |
| 二级 | 一级/特级以外的禁火区动火 |
| 升级 | 节假日、夜间、受限空间内动火等情形应升级管理（HW-002 节假日/夜间二级→must_fix；HW-030 节假日/夜间其他级别→should_improve"请确认级别已上调"，升级范围待核实；HW-003 受限空间内二级→should_improve，通行做法） |

## 9. 不确定 / 待核实条款清单（需人工核对正式文本与企业制度）
1. HW-008 / CS-020：介质爆炸下限 <4% 时可燃气体体积分数上限 0.2%。
2. HW-006 / CS-003：10%LEL 合格线为通行做法（企业制度），GB 5.3 只规定体积分数，两者并存时以体积分数判定为准。
3. HW-005：>30 min 建议完善、>60 min 必须整改的分档——GB 只规定 30 min，分档为通行做法。
4. HW-002 / HW-030：节假日、夜间动火"升级管理"的适用范围（是否所有级别均需上调）。
5. HW-003：受限空间内动火按一级管理——中石化通行做法，国标条文表述待核。
6. HW-009 / CS-002：氧含量上限 21%（2022 版是否由 23.5% 收紧为 21%）。
7. HW-025：特级动火"作业期间随时监测"的表述；HW-028 全程视频监控为通行做法。
8. HW-027：特级动火审批层级（≥2 级、含公司/厂级）。
9. HW-029：气瓶间距 ≥5 m、距火点 ≥10 m 的具体数值。
10. HW-026 / CS-021：检测仪校验有效期要求为通行做法。
11. CS-017：受限空间作业每 2 h 复测的频次。
12. CS-018：大容积空间上/中/下分层取样的判定口径（本规则以 ≥3 次或取样点含上/中/下为准）。
13. G-022：监护人不得兼任作业人员/申请人的条款位置。
14. G-023：安全交底签字的条款位置（第4章）。
15. HP-011：三级/特级高处作业须附专项方案——通行做法。
16. LF-012 / DG-004 / RB-004：吊装、动土、断路作业票有效期 7 天。
17. BP-005：盲板抽堵作业票有效期 24 h。
18. BP-009：一票一板为通行做法。
19. LF-013：“十不吊”为通行做法。
20. DG-003 / DG-006：动土深度 ≥1.5 m 须支护、须设上下通道的阈值；DG-005 / RB-005 夜间警示灯/红灯。
21. 所有 "5.3"、"第 N 章" 之下的细分条款号均未标注，仅到章级。
