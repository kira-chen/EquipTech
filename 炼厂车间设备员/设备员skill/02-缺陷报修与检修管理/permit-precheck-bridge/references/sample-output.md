## 措辞对照

| 场景 | 应写 | 不应写 |
|---|---|---|
| 作业类别 | 「一级用火票」「用火作业」 | 「一级动火票」（规则原文里的「动火」照搬除外） |
| 未判定 | 「既不代表符合也不代表不符合，需补齐信息」 | 「问题不大，应该能过」 |
| 不符合项 | 逐条照搬规则原文 | 「有几处小问题」 |
| 规则原文 | 「受限空间内动火…」（规则原文）+ 字段表加注「用火作业」 | 把原文改成「受限空间内用火」 |
| 车间提示 | 单独成节，标「非规则判定」 | 与不符合项混在一张表里 |
| 未核实 | 「同区域交叉作业未核实，建议用 cross-operation-conflict 核对」 | 「同区域应该没别的活」 |
| 票面看不清 | 「票面缺失/未识别，请核对原件」 | 按常识补一个值 |
| 无法运行规则引擎 | 告知原因并终止 | 凭经验给一个判断 |
