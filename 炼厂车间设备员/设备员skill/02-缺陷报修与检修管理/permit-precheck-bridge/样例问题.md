# 车间作业票预检 · 样例问题

> 附件均在 `演示case/02-缺陷报修与检修管理/permit-precheck-bridge/`（可用 `node scripts/make-sample.js --seed <n>` 重新生成，默认 seed=1）。`*.docx` 是虚构的 Word 作业票，与同名 `*.json`（抽取结果）、`*.expected-report.md`（期望报告）成套，预检基准时间统一用 `--now 2026-08-28T08:50:00+08:00`；`sample-*.json` 是虚构的规则引擎 `result.json` 与车间侧 `notes.json`，票号、时间与人名随 seed 变化。每题的预期结论——必须整改 / 建议完善 / 未判定 / 通过的**数量**与 warning 类型——不变；预期计数与验证要点见 `演示case/02-缺陷报修与检修管理/permit-precheck-bridge/README.md` 对照表（不进发布包）。需要票号、人名、位号都换过的演示票面时，用 `--demo <目录>` 另生成一批变体 docx，计数不变，预检基准时间改用末行 JSON 的 `demo.now`。

3. 这是夜班 22 点开始的二级用火票，帮我看看级别对不对，夜间作业是不是应该升级，还有哪些措施没勾。　　**附件：** `hotwork-level2-night.docx`
4. 这张票的预检结果已经跑出来了，车间这边交出、交叉作业、承包商资质三项我核实的情况在附件里，帮我合成一份车间自查报告。　　**附件：** `sample-permit-result.json + sample-workshop-notes.json`

6. 这张一级用火票的气体分析做得比较早，离计划开工时间已经超过半小时了，马上就要开工，你看这张票现在还能不能开工，哪些地方需要补。　　**附件：** `hotwork-level1-with-issues.docx`
7. 高处作业票，作业面 12.5 米，票上填的是一级，今天现场风力 6 级，帮我预检，重点看级别、防坠落和天气这几项。　　**附件：** `high-place-level2-issues.docx`
8. 帮我检查这张受限空间票：介质是氮气置换后的储罐，票面有毒气体那栏写的是"无"，氧含量在正常范围，作业时间从早上 8 点一直开到次日上午，这样能通过吗？　　**附件：** `confined-space-n2-tank.docx`
