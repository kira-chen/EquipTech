# 车间作业票预检入口 · 样例问题

> 附件均在 `演示case/02-缺陷报修与检修管理/permit-precheck-bridge/`（可用 `node scripts/make-sample.js --seed <n>` 重新生成，默认 seed=1）。`*.json` 是虚构的源技能 `result.json` 与车间侧 `notes.json`，票号、时间与人名随 seed 变化，但每题的预期结论——必须整改 / 建议完善 / 未判定 / 通过的**数量**与 warning 类型——不变；预期计数与验证要点见 `演示case/02-缺陷报修与检修管理/permit-precheck-bridge/README.md` 对照表（不进发布包）。`sample-hotwork-permit.docx` 为依赖技能 work-permit-precheck 的用火票样例副本，题 1 需先按源技能流程跑出 result.json。

1. 附件是 F-101 加热炉北侧转油线膨胀节焊补的一级用火票，帮我预检一下有没有漏项，设备交出单我已经核过、四方签了字。　　**附件：** `sample-hotwork-permit.docx`
2. 这张票的预检结果已经跑出来了，车间这边交出、交叉作业、承包商资质三项我核实的情况在附件里，帮我合成一份车间自查报告。　　**附件：** `sample-permit-result.json + sample-workshop-notes.json`
3. 源技能摘要说建议完善 5 项，可明细里只有 2 条，转达的时候按哪个算？　　**附件：** `sample-permit-result-summary-mismatch.json`
4. 这是射线探伤作业的预检结果，不在八大类里，还能按车间口径转达吗？　　**附件：** `sample-permit-result-unknown-type.json`
5. 班长口头说设备"大概交出了"，我把它填进了车间侧提示，这样合并出来会怎么标？　　**附件：** `sample-permit-result.json + sample-workshop-notes-bad.json`
6. 票我只有扫描 PDF，这个技能读不读 PDF？该先做什么。　　**附件：** `sample-hotwork-permit.docx`（扫描 PDF 请先转成 docx 或 txt 再上传）
7. 预检结果里有 1 项未判定，是票面"是否在受限空间内"没填，这项能不能算通过？　　**附件：** `sample-permit-result.json`
8. 只发预检结果，车间那几项我还没来得及核，先出报告，提示里怎么写？　　**附件：** `sample-permit-result.json`
9. 平台上没装特殊作业票预检技能，这个入口还能帮我看票吗？　　**附件：** 无
10. 票面上写的是"动火安全作业证"，报告里是写动火还是用火？　　**附件：** `sample-permit-result.json`

## 平台接入业务系统 MCP 时

> 不上传附件，作业票 Word 原件由作业票系统 MCP 工具获取，演示数据每天按剧本刷新（E-1201 抽芯检修当天有盲板抽堵、用火、吊装作业票）。

M1. 今天 E-1201 抽芯检修那张一级用火票，帮我从作业票系统调出来预检一下，车间这边交出、交叉作业、承包商资质我还没核。　　**数据：** MCP 作业票系统 `get_permits`（workshop=常减压车间，找当天 E-1201 用火作业票的许可证编号）、`get_permit_document`（permit_no=该编号）
M2. 下午 E-1201 管束抽芯的吊装票，提交审批前帮我自查一遍，看看人员资质那块有没有问题。　　**数据：** MCP 作业票系统 `get_permits`（workshop=常减压车间）、`get_permit_document`（permit_no=当天 E-1201 吊装作业票编号）
M3. P-3101A 今天的临时用电票，能直接从系统里调出来预检吗？　　**数据：** MCP 作业票系统 `get_permits`（workshop=常减压车间）、`get_permit_document`（permit_no=当天 P-3101A 临时用电作业票编号）
