# 车间作业票预检
**技能名称**：车间作业票预检

**技能简介**：车间设备员把作业许可票提交审批前，读票抽取字段并请你确认，按 GB 30871-2022 整理的规则逐项预检，逐条列出必须整改、建议完善、未判定项，再单独附上设备交出、交叉作业、承包商资质等车间侧核实情况；不替代审批签发。

**技能描述**

面向炼化厂车间设备员，把作业许可票交审批前先自查一遍，覆盖用火、受限空间、高处、吊装、临时用电、动土、断路、盲板抽堵八大类。上传 Word 票面（PDF 先转成 txt/docx）、照片或文字，技能读取票面并抽取字段，先复述作业类型与级别、起止时间、气体分析、监护人等关键信息请你确认，再按 130 条规则逐项核查气体分析时效、有效期、人员资质与签字、安全措施勾选、交叉作业票关联、夜间升级等，输出必须整改、建议完善、未判定、通过四级结果，每条附依据条款；看不清或留白的栏目列为未判定，不做猜测。判定由脚本出，转成车间自查报告时规则编号、原文、依据一字不改。设备交出、交叉作业、承包商资质等车间侧情况单独成节，状态只认已核实、未核实、不适用，没有就写未核实。适合票据提交前自查、退票后整改复核；不核检修方案安全措施，不判作业级别，不替代安全部门审批签发。

**示例问题**
1. 附件是 F-101 加热炉北侧转油线膨胀节焊补的一级用火票，帮我预检一下有没有漏项，设备交出单我已经核过、四方签了字。　　**附件：** `sample-hotwork-permit.docx`
2. 附件两张票：一张受限空间票、一张用火票，同一个分馏塔内部焊补，帮我分别预检，并看看两张票有没有互相关联、时间是否对得上。　　**附件：** `confined-space-t201.docx + hotwork-t201-inside.docx`
3. 这是夜班 22 点开始的二级用火票，帮我看看级别对不对，夜间作业是不是应该升级，还有哪些措施没勾。　　**附件：** `hotwork-level2-night.docx`
4. 这张票的预检结果已经跑出来了，车间这边交出、交叉作业、承包商资质三项我核实的情况在附件里，帮我合成一份车间自查报告。　　**附件：** `sample-permit-result.json + sample-workshop-notes.json`
5. 盲板抽堵票，一张票上列了 3 块盲板，编号有了但没有盲板图，材质厚度也没填，帮我看看哪些是必须补的，哪些是建议补的。　　**附件：** `blind-plate-3.docx`
