# 车间作业票预检入口
**技能名称**：车间作业票预检入口

**技能简介**：车间设备员把作业许可票提交审批前，调用已有的特殊作业票预检技能做一次自查，再把必须整改、建议完善、未判定项逐条原样转达，并单独附上设备交出、交叉作业、承包商资质等车间侧核实情况；不替代审批签发。

**技能描述**

面向炼化厂车间设备员，把作业许可票交审批前先自查一遍。本技能是入口，对接已有的"特殊作业票预检"技能，覆盖用火、受限空间、高处、吊装、临时用电、动土、断路、盲板抽堵八大类。上传 Word 票面（PDF 先转成 txt/docx），先探测依赖技能是否装了，没装就终止，不自己判票；装了就按源技能流程读票、跑规则，再把必须整改、建议完善、未判定项逐条原样转达，规则编号、原文、依据一字不改，未判定保持未判定。设备交出、交叉作业、承包商资质等车间侧情况单独成节，状态只认已核实、未核实、不适用。适合票据提交前自查、退票后整改复核。结果由脚本出，模型只写转达；不核检修方案安全措施，不替代安全部门审批签发。

**示例问题**
1. 附件是 F-101 加热炉北侧转油线膨胀节焊补的一级用火票，帮我预检一下有没有漏项，设备交出单我已经核过、四方签了字。　　**附件：** `examples/sample-hotwork-permit.docx`
2. 这张票的预检结果已经跑出来了，车间这边交出、交叉作业、承包商资质三项我核实的情况在附件里，帮我合成一份车间自查报告。　　**附件：** `examples/sample-permit-result.json + examples/sample-workshop-notes.json`
3. 源技能摘要说建议完善 5 项，可明细里只有 2 条，转达的时候按哪个算？　　**附件：** `examples/sample-permit-result-summary-mismatch.json`
4. 这是射线探伤作业的预检结果，不在八大类里，还能按车间口径转达吗？　　**附件：** `examples/sample-permit-result-unknown-type.json`
5. 班长口头说设备"大概交出了"，我把它填进了车间侧提示，这样合并出来会怎么标？　　**附件：** `examples/sample-permit-result.json + examples/sample-workshop-notes-bad.json`
