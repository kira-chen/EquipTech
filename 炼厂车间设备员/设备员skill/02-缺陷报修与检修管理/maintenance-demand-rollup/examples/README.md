## 关键验证点

1. **四处默认改未判定**：无等级工单 GD-2609-104 优先级「未判定」（不按高）；本期到期的周期项 ZQ-001、ZQ-003「未判定」（不按中）；备件需求数量未填且有库存时写「未判定（库存 N，需求数量未填）」（不按 1 件）；状态无法判断的记录不纳入正式清单。全部在「六、未判定项」单列。
2. **隐患台账来源**：YH-2609-01 重大隐患 → 紧急、检修类别「专项（隐患整改）」、整改期限作计划结束；YH-2609-02「B级」是管理层级写法 → 优先级未判定并 warning；已销号 YH-2608-03 不纳入。
3. **SAP 列名与状态**：功能位置→位号、设备描述→名称、通知单短文本→描述、系统状态按 SAP 六态归一；「已完成/TECO」为待验收，本期不重复申报（`counts.skippedDone`）。
4. **疑似重复不自动合并**：P-2101A 在缺陷台账（QX-20260903-001）与工单台账（GD-2609-101）各有一条机封处理记录，相似度约 0.73。**两条都保留在正式清单中**，只列入「疑似重复待确认」。
5. **无备件表不写「有库存」**：不加 `--spare` 时，所有有备件需求的项备件到位列一律「未核实」，`需求汇总.md` 中除「不得按有库存处理」这句禁令外不出现「有库存」三个字。
6. **备件缺口要分性质**：`spareGap` 同时收「不足」「未核实」「未判定」，交付时不能笼统说"缺 N 项备件"。
7. **无依据项不进正式清单**：缺陷台账第 7 行 P-2105 未填缺陷编号，进「建议核实区」；全部无编号时（`sample-no-basis.xlsx`）直接报错。
8. **停机未填不默认**：C-2401 的「是否需停机」为空，记「未填写」，既不计入需停机汇总，也不按不需停机处理。
9. **申报表列头**：不给模板时 `检修需求表.xlsx` 按月度检修计划申报表列头输出（序号、车间、功能位置、设备名称、检修项目名称、检修内容、检修类别、来源、依据编号、是否停工、计划开始、计划结束、工期(天)、主要备件材料、备件到位情况、建议专业、优先级、申报理由、备注）。
10. **周期项按申报周期筛到期**：加 `--include-cyclic` 时下次到期日（上次检修 + 检修周期）晚于 `--period` 月末的不申报、单列周期外（ZQ-002）；早于月初的照常纳入并标「已超期」；缺上次检修或周期无法解析的照常纳入并 warning；给了 `--due` 也按月末筛。
11. **说明行与声明行**：`需求汇总.md` 开头为通用声明行 + 「本清单为车间申报稿，最终计划以公司设备管理部门（机动部/设备部）批复为准」，不出现「机动处」。

## 再生样例

```bash
node scripts/make-sample.js --out examples            # seed=1
node scripts/make-sample.js --out examples --seed 9   # 滴数、工期天数变化，条数/重复/停机/未判定等结论不变
```

## 三步验证

```bash
node scripts/make-sample.js --out examples
node scripts/selftest.js
node scripts/rollup.js --input examples/sample-demand-sources-2026-10.xlsx \
  --workshop 加氢车间 --period 2026-10 --include-cyclic \
  --spare examples/sample-spare-stock.xlsx \
  --template examples/sample-report-template.xlsx \
  --window "10月检修窗口共5天" --out <工作目录>/检修需求
```

## MCP 取数对照

不上传附件；按 SKILL.md「数据获取（MCP）」取数，三张表各放一个目录、逗号拼接作 `--input`；`--period` 填当月。预期结果只写每天稳定的结论。

| # | 示例问题 | MCP 调用 | 运行参数 | 预期结果 |
|---|---|---|---|---|
| M1 | 常减压车间本月未闭环检修需求汇总，已转工单的通知单不重复报 | 设备资产管理 `get_notifications`（workshop=常减压车间，open_only=true）→ 目录 A；`get_work_orders`（workshop=常减压车间，open_only=true）→ 目录 B | `--input <目录A>,<目录B> --workshop 常减压车间 --period <当月>` | 剧本工单「E-1201 管束内漏，需抽芯试压」（PM01 施工中）列入，检修类别日常维修、优先级高、需停机、工期 3 天（「72小时」折算），`notifNo` 为对应通知单；该通知单不再单列，计入 `counts.linkedNotif`；E-1201 不报疑似重复；通知单表、工单表都没有备件列 → 每条需求备件到位写「未核实（来源表无备件列）」（`counts.spareNeedUnknown` 等于正式清单条数，`spareGap` 为 0），两张表各一条「无备件列」warning，md 与 json 中不出现「无备件需求」 |
