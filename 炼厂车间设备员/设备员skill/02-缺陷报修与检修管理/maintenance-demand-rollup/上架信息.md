# 检修需求汇总上报
**技能名称**：检修需求汇总上报

**技能简介**：把缺陷台账/SAP 通知单、未闭环工单、周期检修项和设备隐患台账里的检修需求汇总成一份按月度检修计划申报表口径、可报公司设备管理部门（机动部/设备部）的车间申报稿，标注检修类别、停工需求和备件到位情况。只出申报稿，不替代审批。

**技能描述**

面向炼化厂车间设备员，每月把检修需求汇总成报设备管理部门的申报稿。上传缺陷台账、工单台账（或 SAP 通知单、订单导出）、周期检修项、隐患台账（多表或多文件都行），脚本把未闭环需求逐条平铺成月度检修计划申报表（含功能位置、类别、停工需求、备件到位等列）。每条必须有缺陷编号、通知单号、工单号等依据，没有的放"建议核实区"；同一设备在缺陷和工单里各挂一条的列疑似重复，不自动合并；等级没填的优先级判未判定；没给备件库存表时备件写"未核实"；已完成未验收的不重复报。可按厂内模板出表。产出申报稿 md、xlsx 和 JSON。数字由脚本出，模型只写说明；不做跨车间平衡，不编方案，不做预算，不替代审批。

**示例问题**
1. 把下个月要修的汇总一下，出一份报给设备部的月度检修计划申报表，我是加氢车间的。　　**附件：** `examples/sample-demand-sources-2026-10.xlsx`
2. 周期性保养项和设备隐患也一起报上去，备件有没有现货一并标上。　　**附件：** `examples/sample-demand-sources-2026-10.xlsx + examples/sample-spare-stock.xlsx`
3. 按我们厂的月度检修计划申报表模板出表，列名对不上的告诉我。　　**附件：** `examples/sample-demand-sources-2026-10.xlsx + examples/sample-report-template.xlsx`
4. 这次停车窗口只有 5 天，把要停工的项目列出来看看够不够。　　**附件：** `examples/sample-demand-sources-2026-10.xlsx`
5. 这是从 SAP 导出来的通知单和订单清单，状态是 OSNO、REL、TECO 这种代码，直接按这个汇总下个月的检修需求。　　**附件：** `examples/sample-sap-export.xlsx`
