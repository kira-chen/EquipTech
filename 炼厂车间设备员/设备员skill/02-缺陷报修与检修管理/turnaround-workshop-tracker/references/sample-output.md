## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 滞后影响 | 「滞后 2 天，基于计划节点测算，最终以指挥部判定为准」 | 「大检修总工期将延后 2 天，建议指挥部批准顺延」 |
| 中交 / 开工 | 「已中交 1 项（中间交接），尚有 1 项三查四定留项」 | 「已完工 4 项」（把中交混入完工） |
| 状态-比例矛盾 | 「状态『未开工』与完成比例 50% 矛盾，脚本未作修正，需核实」 | 「实际应为施工中，进度按 50% 计」 |
| 比例未填报 | 「本日与上一日均未填报完成比例，增量显示『—』，未按 0 增量」 | 「本日进度增量 0%」／「按工期推算约 6X%」 |
| 线性核对 | 「本次未启用线性进度核对，只按①②判滞后」 | 不说明却写「TA-0X1 落后应有进度」 |
| 三查四定未判定 | 「Q-06 填『已上报』，不能视为已关闭」 | 「Q-06 基本关闭」 |
| 滞后原因 | 「备注记录为『焊口返修』」 | 「估计是承修单位窝工，建议考核」 |
| 关键路径 | 「按 --critical 指定的关键路径项目 TA-0X2、TA-0X5」 | 自行判断「炉管应该是关键路径」 |
