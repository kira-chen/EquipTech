# 输入规格：大检修车间侧跟踪

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一次一个文件：`--input 大检修项目清单.xlsx`
- 一个文件里可同时放「项目清单」「材料到货」「人员到位」「开工条件」「三查四定」五张表；后四张缺失只 warning，不中断
- 厂内自编表、指挥部导出表、SAP PM 工单导出表均可（列名别名见下）

## 一、项目清单工作表（必需）

sheet 名匹配规则：去空白与「表」字后做包含匹配，「项目清单」「检修项目表」「大修项目」「大检修项目」「工单清单」「订单清单」均可识别。**找不到该表时脚本报错终止**。

| 列名 | 必需 | 说明 |
|---|---|---|
| 项目编号 | 是 | 为空的行会被跳过并 warning；重复时两条均保留并 warning |
| 项目名称 | 是 | 缺失时报表显示 — |
| 状态 | 是 | 见下方「状态枚举」；缺此列时全部项目归入未知状态并 warning |
| 位号 | 否 | 设备位号 / 功能位置；SAP「设备」编号不当位号 |
| 专业 | 否 | 静设备 / 动设备 / 电气 / 仪表 等 |
| 计划开工 / 计划完工 | 否 | 滞后判定基准；缺失时相关判定列入未判定 |
| 实际开工 / 实际完工 | 否 | 实际完工仅记录 |
| 工期 | 否 | 天数，总体完成比例的加权权重；缺失或非正数 → 不参与加权并单列 |
| 施工单位（承修单位） | 否 | 责任方 |
| 责任人 | 否 | 责任方 |
| 完成比例 | 否 | 0~100 的数值 |
| 备注 | 否 | 滞后原因等；未填写时报表写「原因未记录」，**不推测** |
| 车间 | 否 | 车间范围核对，见下方「车间列（五张表通用）」 |

### 车间列（五张表通用，可选）

车间范围核对（D007）：项目清单、材料到货、人员到位、开工条件、三查四定各自核对，只认表头正好是「车间 / 所属车间 / 属地车间 / 运行部」（或其后加「名称」）的列；「维护工厂」等 SAP 工厂代码列、「责任单位 / 属地单位 / 使用单位」和「车间负责人」等人员列都不认。有本车间行时剔除其他车间的行并 warning（逐车间写行数），不进任何统计；车间为空的行按本车间保留并 warning；没有一行是本车间时不筛，warning 与 md 开头写【注意】（多半是传错了文件）；无车间列不筛，md 口径写「输入未含车间列，车间范围以取数条件为准」。结果写 `meta.workshopScope`（每张表一项）。

## 二、材料到货工作表（可选）

sheet 名匹配「材料到货」「材料」「物资到货」「到货」。列：项目编号（必）、材料名称（必）、需求数量、到货数量、需求日期、到货状态、备注。缺口判定：① 到货状态可判定 → 用状态；② 无状态但数量齐 → `到货 ≥ 需求`；③ 皆缺 → **未判定**，列入缺口并标注，**绝不按已到货处理**。

## 三、人员到位工作表（可选）

sheet 名匹配「人员到位」「人员」「人力到位」「队伍到位」。列：项目编号（必）、施工单位、计划人数、到位人数、备注。任一人数缺失 → 缺口 null、是否缺员「未判定」。

## 四、开工条件工作表（可选）

sheet 名匹配「开工条件」「开工」「条件确认」「条件」。列：项目编号（必）、条件项（必）、是否具备、责任单位、责任人、备注。空或无法识别 → **未判定**，**绝不按已具备处理**。

## 五、三查四定工作表（可选）

sheet 名匹配「三查四定」「三查四定问题」「问题台账」「问题清单」「三查」。

| 列名 | 必需 | 说明 |
|---|---|---|
| 问题描述 | 是 | 为空的行跳过并 warning |
| 问题编号 | 否 | 缺失时用行号 `#N` |
| 项目编号 | 否 | 关联项目清单；不存在时 warning，问题保留 |
| 位号 | 否 | 缺失时取项目清单中的位号 |
| 问题类别 | 否 | 查设计漏项 / 查未完工程 / 查工程质量（自由文本） |
| 整改措施 | 否 | 定任务 / 定措施；为空 → 四定不全 |
| 责任单位 | 否 | 缺失时取项目清单中的承修单位 |
| 责任人 | 否 | 定人员；为空 → 四定不全 |
| 整改期限 | 否 | 定时间；为空或无法解析 → 四定不全；未关闭且早于统计日 → 超期 |
| 整改状态 | 否 | 见「关闭状态」 |
| 备注 | 否 | |

## 状态枚举（七态）

| 标准状态 | 可识别的写法 | 参与进度统计 |
|---|---|---|
| 未开工 | 未开工、未开始、待开工、未启动、计划中、未施工、待施工 | 是 |
| 施工中 | 施工中、在施工、进行中、检修中、作业中、在建、实施中、已开始施工 | 是 |
| 已完工 | 已完工、完工、已完成、完成、已交付、施工完工、检修完工 | 是 |
| **已中交** | 已中交、中交、中间交接、已中间交接、已交工艺 | 是 |
| **已开工** | 已开工、已开车、已投用、已投料、开车、已复产、已投运 | 是 |
| 已中止 | 已中止、中止、暂停、已暂停、停工、搁置 | 是 |
| 取消 | 取消、已取消、作废、已作废、取消实施 | 否（如实列出） |

> 「已中交」「已开工」是大检修独立节点，**不归到已完工**。台账若用「已开工」表示"已开始施工"，请改填「施工中」；脚本见到「已开工」会 warning 提示。取值不在上表内（含空）→ warning + `unknownStatus` 单列，绝不就近映射。

## 完成比例

| 情形 | 处理 |
|---|---|
| 正常 0~100 的数值（含「45%」写法） | 取值，四舍五入到 1 位小数 |
| **为空** | `null`，显示「—」，按状态给定性进度，绝不按 0、绝不线性推算 |
| **超出 0~100** | warning + 置 `null`，不截断，保留 `rawPercent` |
| 无法解析为数字 | warning + `null` |

## 状态与完成比例的相容关系

| 状态 | 相容的完成比例 |
|---|---|
| 未开工 | 0 |
| 施工中 | 0 ≤ 比例 < 100 |
| 已完工 / 已中交 / 已开工 | 100 |
| 已中止 / 取消 | 不做相容校验 |

越出即矛盾：warning + `inconsistent` 单列，**两个字段均按原值保留，脚本不修正任一字段**。

## 是否类字段（开工条件「是否具备」、材料「到货状态」）

是：是、具备、满足、已具备、已满足、已到、已到货、齐备、Y、YES、TRUE、√、1；否：否、不具备、未具备、不满足、未满足、未到、未到货、缺、N、NO、FALSE、×、0；其余 → **未判定**。

## 关闭状态（三查四定「整改状态」）

| 判定 | 可识别的写法 |
|---|---|
| 已关闭 | 已关闭、关闭、已整改、已完成、完成、已销项、销项、已闭环、闭环、是、Y、YES、TRUE、√ |
| 未关闭 | 以 未 / 待 / 不 开头（未整改、未关闭、待复查、待确认…）、整改中、在整改、处理中、进行中、否、N、NO、FALSE、× |
| **未判定** | 其余（如「已上报」「见附件」、空）→ 标注未判定，**绝不按已关闭处理** |

## 日期与工期字段
- 日期支持：`2026-09-21`、`2026/9/21`、`2026年9月21日`、Excel 日期单元格与序列号；无法解析 → warning + 按缺失处理
- 计划完工早于计划开工 → warning，原样保留不对调，该项不测算应有进度、不判滞后，列入未判定
- 工期支持：`12`、`12天`、`2周`、`1个月`；缺失 / 无法解析 / 非正数 → `null`，不参与加权，绝不按计划跨度反推

## 会被跳过的行
- 全空行；首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning）；项目编号为空的行（warning）；三查四定表中问题描述为空的行（warning）
