# 大检修车间侧跟踪
**技能名称**：大检修车间侧跟踪

**技能简介**：装置大检修期间，用本车间的项目清单、材料到货、人员到位、开工条件、三查四定问题表，每天出一张进度表和滞后预警，分列已完工、已中交、已开工节点；进度与滞后全部由脚本测算，最终以指挥部判定为准。

**技能描述**

面向炼化厂车间设备员，装置大检修期间每天出一张本车间进度表。上传项目清单（厂内表、指挥部或 SAP 导出能认），可再给材料到货、人员到位、开工条件、三查四定四张表，脚本按工期加权算总体完成比例，按过了计划完工日没完工、过了计划开工日没开工判滞后，可选按计划节点线性推算，关键路径滞后醒目列出；已中交、已开工作为独立节点分列，不混进已完工；缺货、开工条件未具备、超期未关闭逐条单列。完成比例为空显示"—"不按零，状态和比例矛盾只单列不改；给上一日结果可做对比。产出进度报告、可上早晚会的进度一张表（Excel）和 JSON。数字由脚本算，模型只写说明；不调整计划节点，不判工期能否完成，不替代指挥部决策。

**示例问题**
1. 出今天的大修进度日报，关键路径是 T-01、T-02、T-05，看看哪些项目滞后了、三查四定还有几项没关。　　**附件：** `sample-turnaround-2026-09-21.xlsx`
2. 还是这份清单，按计划节点线性推算一下，把进度落后的项目也找出来。　　**附件：** `sample-turnaround-2026-09-21.xlsx`
3. 我只有项目清单，材料、开工条件、三查四定表都还没有，先出一版进度表行不行？　　**附件：** `sample-list-only.xlsx`
4. 这是指挥部导出的进度表，标题行和列名跟我们的不一样，底下还有合计行，能直接用吗？　　**附件：** `sample-hq-export.xlsx`
5. 这是 SAP 导出的大修订单清单，列名是订单号、功能位置、基本开始日期、用户状态，帮我出进度表并说清楚哪些已经中交、哪些已经开工。　　**附件：** `sample-sap-orders.xlsx`
