# 常见炼化介质危险特性表

> **本表为默认参考口径。** 厂内有正式 MSDS 与介质危险性清单时以厂内为准。
> 表中未列出的介质**一律按最严（高危）口径生成交出条目**，并提示核实 MSDS，**绝不按无危险处理**。

## 一、危险档位定义

| 档位 | 含义 | 对交出条目的影响 |
|---|---|---|
| 高危 | 易燃易爆、有毒、窒息性 | 必须加盲板（H3）、双阀隔离（H4）、取样分析合格（Q3）、气体检测报警（S4） |
| 中等 | 可燃液体、腐蚀性、高温烫伤 | 必须加盲板（H3）、取样分析合格（Q3） |
| 低 | 水、蒸汽、氮气以外的惰性/无害介质 | 不强制盲板与取样分析；仍须停车、关阀、清理、围栏 |
| **不在库** | 介质为空，或不在本表中 | **按高危处理**，并 warning 提示核实 MSDS |

## 二、高危介质

| 介质 | 主要危险特性 | 交出要点 |
|---|---|---|
| 硫化氢（H2S） | 剧毒、易燃 | 置换后必须做 H2S 分析，取样人佩戴正压呼吸器 |
| 氢气、循环氢、新氢、富氢 | 易燃易爆、易扩散、爆炸极限宽 | 氮气置换至氢含量合格，禁止空气直接置换 |
| 液化气（LPG） | 易燃易爆、气化膨胀比大 | 泄压须缓慢，防止低温冻伤；双阀隔离并确认无内漏 |
| 轻烃、石脑油、汽油 | 易燃易爆、静电积聚 | 蒸汽或氮气置换，接地防静电 |
| 瓦斯气、干气、燃料气、火炬气 | 易燃易爆、含 H2S | 加盲板与火炬系统彻底隔离 |
| 丙烯、乙烯、丁烯、丁二烯、丙烷、丁烷 | 易燃易爆 | 同液化气，丁二烯另注意自聚物 |
| 苯、甲苯、二甲苯、重整生成油 | 易燃、有毒致癌 | 分析须含苯系物含量，进人前加强通风 |
| 氨、液氨 | 有毒、强刺激、可燃 | 水吸收置换，人员佩戴防氨面具 |
| 一氧化碳 | 有毒、易燃、无味 | 必须用检测仪分析，不得凭气味判断 |
| 甲醇、乙醇 | 易燃、有毒 | 水置换后分析可燃气 |
| 环氧乙烷（EO）、EO/EG 混合物 | 剧毒、易燃易爆、易自聚 | 氮气置换，严禁空气直接置换；分析含 EO 浓度；交出前确认无自聚物残留 |
| 环氧化物、丙烯腈、光气、氰化物 | 剧毒 | 专项方案，安全部门全程监护 |
| 氯气、液氯 | 剧毒、强氧化 | 碱液吸收置换，佩戴防氯面具，下风向警戒 |
| 苯乙烯 | 易燃、有毒、易自聚 | 分析含苯乙烯浓度，注意阻聚剂与自聚物堵塞 |
| 碳四、混合碳四、碳五、裂解气、裂解汽油 | 易燃易爆 | 同液化气，丁二烯组分注意过氧化物与自聚物 |
| 乙苯、异丙苯、MTBE | 易燃、有毒 | 蒸汽或氮气置换后分析可燃气与苯系物 |
| **氮气** | **窒息性（无毒但致命）** | **氮气置换后进人前必须做氧含量分析，合格区间依据 GB 30871-2022、以厂内分析标准为准** |
| 原油 | 易燃、常伴生 H2S | 按含硫原油处理，分析含 H2S |

> 氮气常被误认为"无害"，实际是受限空间窒息事故的主要原因，本表按高危处理。

## 三、中等危险介质

| 介质 | 主要危险特性 | 交出要点 |
|---|---|---|
| 柴油、航煤、煤油 | 可燃 | 排净后蒸汽吹扫，用火前做可燃气分析 |
| 蜡油、渣油、油浆、重油 | 可燃、高温烫伤 | 必须先降温再交出，防止凝固堵塞与烫伤 |
| 润滑油、导热油、密封油 | 可燃 | 导热油注意高温与油雾 |
| 硫酸、盐酸、硝酸、磷酸、酸性水、含硫污水 | 腐蚀、有毒（酸性水含 H2S） | 水冲洗置换，人员穿防酸服；酸性水按含 H2S 处理 |
| 碱液、氢氧化钠 | 腐蚀、烫伤 | 水冲洗至中性，防溅防灼伤 |
| 胺液（MDEA、MEA、DEA、乙醇胺、贫胺、富胺） | 腐蚀、富胺含 H2S | 富胺液按含 H2S 处理，必须做 H2S 分析 |
| 乙二醇（EG）、二甘醇、三甘醇、丙二醇 | 可燃、高温烫伤 | 降温后排净，热水冲洗；EO/EG 混合物按 EO 高危处理 |
| 乙酸/醋酸、丙酮、乙醛、丁醇、辛醇 | 可燃、腐蚀或刺激 | 水冲洗置换后分析可燃气 |
| 催化剂、溶剂、糠醛、抽余油、抽出油 | 可燃或有毒 | 按具体 MSDS 确定，本表按中等处理 |

## 四、低危介质

| 介质 | 主要危险特性 | 交出要点 |
|---|---|---|
| 除盐水、循环水、冷却水、软化水 | 基本无害 | 排净防冻，冬季注意残水结冰 |
| 蒸汽、凝结水、伴热 | 高温烫伤 | 必须泄压降温，防止残汽喷出烫伤 |
| 仪表风、净化风、压缩空气 | 带压伤害 | 泄压后拆卸，防止余压弹出 |

## 五、不在库介质的处理

脚本判定介质不在本表时：

1. `handover.json` 的 `meta.mediumHazard` 为 `unknown`、`meta.mediumEffective` 为 `high`、`meta.mediumInLibrary` 为 `false`
2. 按高危口径生成全部条目（含盲板、双阀隔离、取样分析、气体检测报警）
3. warning 提示「介质「XX」不在危险特性库中，已按最严（高危）口径生成交出条目，请查阅该介质 MSDS 核实后复核清单」
4. 交出单「取用口径」一栏标注为「介质不在库，按最严（高危）口径生成，须核实 MSDS」

**禁止**：按低危处理、按无危险处理、或从清单中省略与介质相关的条目。

## 六、混合介质与多相物料

设备内含多种介质时，按**其中危险等级最高的一种**判定。例如含硫污水中含 H2S，按高危处理，不按"水"处理。用户只说"油"「料」「气」这类笼统说法时，按介质不在库处理并追问具体介质名称。
