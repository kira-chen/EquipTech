# 交出信息确认清单与追问话术

## 一、必需信息

| 字段 | 参数 | 为什么必需 | 缺失时的追问 |
|---|---|---|---|
| 位号 | `--tag` | 交出单必须挂到具体设备 | 「这次交出的是哪台设备？位号是多少？」 |
| 检修内容 | `--scope` | 决定是否需要拆线、拆联轴器 | 「这次做什么检修？是解体、抽芯还是只做外部检查？」 |
| **介质** | `--medium` | 决定隔离、置换、分析的严格程度 | 「设备里走的什么介质？有没有硫化氢、氢、液化气这类？」 |
| 设备类型 | `--equip-type` | 决定电气与机械隔离条目 | 「是机泵、容器、塔器、换热器还是电气设备？」 |

## 二、条件必需信息（缺失即未判定，不得默认）

| 字段 | 参数 | 什么情况下必需 | 追问 |
|---|---|---|---|
| 是否带压 | `--pressured 是/否`（`--pressure <MPa>` 只记录不推断） | 承压设备与机组 | 「设备现在还带压吗？请工艺确认一下，压力数值我只记录。」 |
| 是否高温 | `--hot 是/否`（`--temp <℃>` 只记录不推断） | 塔器、换热器、加热炉、容器，泵与压缩机等机组，或高危介质 | 「设备温度降下来了吗？是不是高温设备？请工艺确认。」 |
| 是否进受限空间 | `--entry` / `--no-entry` | 容器、塔器、加热炉 | 「这次检修要不要进设备里面？」 |
| 是否用火作业 | `--hotwork` / `--no-hotwork` | 涉及焊接、切割、打磨 | 「要不要用火？焊接、气割、砂轮打磨都算用火作业，要办用火作业票。」 |

## 三、追问原则

1. **一次性列出所有缺项**，不要挤牙膏式逐个追问。
2. **介质信息缺失时必须追问**，不得按「一般介质」或「没什么危险」处理。用户只说「油」「料」「气」时要追问具体名称。
3. **不得用假设值填补后直接给结论**。「应该不带压了吧」不能当作「不带压」。
4. 用户明确说「不清楚」时，按未判定处理并说明补齐后可确定，**不要替用户猜**。
5. 抽取结果要**回读给用户确认**，特别是介质名称与作业类型。

## 四、常见口语化表述与结构化对应

| 用户可能这样说 | 结构化字段 |
|---|---|
| 「P-101A 泵要拆机封」 | 位号 P-101A、设备类型 泵、检修内容 机械密封解体更换（涉及解体） |
| 「塔要进人清塔盘」 | 设备类型 塔器、进受限空间 = 是 |
| 「换热器要抽芯」 | 设备类型 换热器、涉及解体 |
| 「管线上要开个口焊个接管」 | 用火作业 = 是（需办用火作业许可，级别以作业票为准） |
| 「台账上压力 1.6 MPa」 | 只记录数值，形成「可能带压，待确认」提示；是否带压仍须用户/工艺回答 |
| 「SAP 导出的功能位置 P-101A」 | 位号 P-101A（功能位置即位号；「设备」列 8 位号是设备编号，不是位号） |
| 「已经泄完压了」 | 带压 = 是（曾经带压，需要 P1 条目确认泄压到位） |
| 「常压设备，不带压」 | 带压 = 否 |
| 「凉了」「温度降下来了」 | 高温 = 是（需要 P2 条目确认降温到规定温度） |
| 「就是水，没什么」 | 介质 = 循环水/除盐水，需确认具体是哪种水（含硫污水不是低危） |

注意：「已经泄完压了」「凉了」说明该条目**需要确认**，不是「不需要该条目」。判为「否」的前提是设备本来就不带压、不带温。

## 五、不要问的

- 不要问「这些条件都做完了吗」然后按回答勾选。逐项确认由现场人员在交出单上签字，脚本与模型都不代填。
- 不要问「可以交出了吗」。是否具备交出条件由逐项确认结果决定，不由任何人一句话决定。
