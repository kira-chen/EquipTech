# 交出条目规则表

> **本表为默认参考口径。** 依据《中国石化作业许可管理规定》（用火作业、受限空间作业、盲板抽堵作业等八大类）、GB 30871-2022 与《炼化企业设备管理技术规定》的做法整理，**不转述法规数值**；厂内有正式《设备交出安全确认规定》时以厂内为准，并在交付时注明口径来源。
> 规则实现见 `scripts/lib/rules.js`，每条交出条目都带规则号，可对照本表复核。

## 一、判定要素

条目由三个维度决定：

1. **介质危险特性** —— 高危 / 中等 / 低 / 不在库（按最严处理），见 `references/medium-hazards.md`
2. **设备类型** —— 泵、压缩机、容器/罐、塔器、换热器、加热炉、管线/阀门、电气设备、仪表
3. **作业类型** —— 是否解体拆卸、是否进受限空间、是否用火作业、是否带压、是否高温。**带压/高温与否由用户（工艺）确认，脚本不按压力、温度数值推断**；给了数值只形成「推断值，待确认」提示，不进入判定。

| 规则号 | 条目 | 触发条件 | 关键 | 责任岗位 |
|---|---|---|---|---|
| P1 | 泄压至常压，压力表指示为零并确认无憋压 | 带压 = 是（`--pressured 是`） | | 工艺 |
| P2 | 降温至厂内交出规定的温度（限值以厂内制度与检修方案为准，不写死数值） | 高温 = 是（`--hot 是`） | | 工艺 |

**未判定触发**：
- 承压类设备（容器、塔器、换热器、加热炉、管线）或机组**未说明是否带压** → P1 标 undetermined，**即使台账或 `--pressure` 给了压力数值也不推断**（旧版按 >0.02 MPa 推断已废止）
- 容器、塔器、换热器、加热炉，或介质按高危口径处理时**未说明是否高温** → P2 标 undetermined，**不按 `--temp` 数值推断**（旧版 ≥60 ℃ 推断已废止）

## 三、关键条目

以下三类为**关键条目**，无论是否完成都在交出单「二、关键条目」一节单列并醒目标注：

| 关键条目 | 规则号 | 为什么是关键 |
|---|---|---|
| 盲板加装 | H3 | 关阀不足以保证隔离可靠，阀门内漏是交出事故的主因之一 |
| 置换分析合格 | Q3（受限空间另有 Q4） | 置换效果只能以分析数据为准，不得凭经验判断 |
| 断电挂牌上锁 | E1 | 误送电是检修伤亡事故的主要原因 |

关键条目未落实的，**一律视为不具备交出条件**，不得以口头确认代替书面记录。

## 四、未判定的处理要求

判定依据字段缺失时，对应条目：

1. **仍然列入清单**，`status` 为 `undetermined`、`required` 为 `null`（不是 `false`）
2. 在 `handover.json` 的 `undetermined` 数组与交出单「四、未判定项」一节单列
3. 注明缺失的具体字段（如「未说明设备是否带压」）

**禁止**：按「不需要」从清单中删除、按「需要」直接生成为必做项而不标注依据缺失、或用默认值填补后出结论。

补齐信息后重新运行脚本即可确定。

## 五、确认结果的填写

- 脚本**只生成待确认清单**，`items[].confirmed` 一律输出 `null`，`confirmedBy`、`confirmedAt` 同样为 `null`
- 交出单的「完成情况 / 确认人 / 确认时间」三栏以 `☐ 已完成　☐ 未完成` 形式留白，由现场确认人填写
- 现场确认结果可整理为 JSON 后用 `--confirm` 回填，格式见 `scripts/README.md`
- **模型不得代替任何人勾选「已完成」**，也不得根据用户的口头描述推断某项已完成

## 六、交出条件判定

存在以下任一情况时，`ready` 为 `false`，交出单开头写「【注意】尚不具备交出条件」：

- 任一条目尚未确认或现场确认为未完成
- 存在未判定项

`ready` 为 `true` 仅表示清单内条目的现场确认结果均为已完成，**仍须四方签字后方可开始检修作业**。

## 七、作业许可提示（`meta.permits`）

按《中国石化作业许可管理规定》八大类命名（用火作业、受限空间作业、高处作业、吊装作业、临时用电作业、动土作业、断路作业、盲板抽堵作业），脚本只提示本次交出涉及哪些票，级别与审批以作业许可系统和作业票为准：

| 触发 | 提示的作业许可 |
|---|---|
| `--hotwork` | 用火作业 |
| `--entry` | 受限空间作业 |
| 生成 H3 盲板条目（非未判定） | 盲板抽堵作业 |

高处、吊装、临时用电等由用户在作业票预检时补充，本技能不自判。监护按**双监护**（属地监护人 + 作业单位监护人）。
