# 输入规格：检修前设备交出确认

本技能以**命令行参数驱动**为主，设备台账与确认结果为可选文件输入。

## 一、命令行参数

| 参数 | 必需 | 取值 | 说明 |
|---|---|---|---|
| `--tag` | 是 | 文本 | 设备位号 |
| `--scope` | 是 | 文本 | 检修内容；含「解体/拆卸/拆除/抽芯/更换/开盖/打开人孔/吊出/返厂」时判定为涉及解体 |
| `--equip-type` | 否（强烈建议） | 文本 | 设备类型，见下方归类表；缺失时仅生成通用条目并 warning |
| `--medium` | 否（强烈建议） | 文本 | 介质名称；**缺失或不在危险特性库时按最严（高危）口径生成并 warning** |
| `--name` | 否 | 文本 | 设备名称 |
| `--entry` / `--no-entry` | 否 | 标志 | 是否进受限空间；**都不给 → 未说明**，容器/塔器/加热炉的相关条目标未判定 |
| `--hotwork` / `--no-hotwork` | 否 | 标志 | 是否用火作业（中石化作业许可八大类命名，不写"动火"）；都不给 → 未说明，不凭空生成用火条目 |
| `--pressured` | 否 | 是/否 | 是否带压；**由用户或工艺确认**；无法识别为是/否时按未说明处理并 warning；未给 → 承压设备的泄压条目未判定 |
| `--pressure` | 否 | 数值(MPa) | 操作压力；**只记录，不据此推断是否带压**。未给 `--pressured` 时形成 `meta.pressureHint`（"可能带压 / 可能常压"，标"推断值，待确认"，不进入判定）并 warning |
| `--hot` | 否 | 是/否 | 是否高温；由用户或工艺确认；未给 → 塔器/换热器/加热炉/容器或高危介质的降温条目未判定 |
| `--temp` | 否 | 数值(℃) | 操作温度；**只记录，不据此推断是否高温**。未给 `--hot` 时形成 `meta.hotHint`（推断值，待确认，不进入判定）并 warning |
| `--workshop` | 否 | 文本 | 车间 / 运行部名称；未给时可由台账「维护工厂 / 属地单位」列补全 |
| `--requester` | 否 | 文本 | 申请人 |
| `--plan-date` | 否 | YYYY-MM-DD | 计划检修日期；非法日期报错 |
| `--ledger` | 否 | 路径 | 设备台账 xlsx，用于补全设备类型、介质、温度、压力 |
| `--confirm` | 否 | 路径 | 现场确认结果 JSON，见第四节 |
| `--out` | 否 | 路径 | 输出目录，默认系统临时目录 `<os.tmpdir()>/ehc-out`，建议始终传 `--out` |

`--entry` 与 `--no-entry` 同时给出时报错；`--hotwork` 与 `--no-hotwork` 同理。

## 二、设备类型归类

脚本按关键词把 `--equip-type` 与 `--name` 归类，归类结果决定电气与机械隔离条目：

| 归类 | 可识别的写法 | 触发的专项条目 |
|---|---|---|
| 泵 | 泵、机泵 | E1 断电挂牌、E3 联锁摘除、M1 盘车防转、M2 拆联轴器（解体时） |
| 压缩机 | 压缩机、风机、鼓风机、引风机、增压机 | 同泵 |
| 容器/罐 | 容器、罐、槽、储罐、缓冲罐、分液罐、分离器、反应器 | P1/P2 泄压降温（未说明带压/高温时未判定）、Q4/Q5 受限空间（未说明时未判定） |
| 塔器 | 塔 | 同容器 |
| 换热器 | 换热器、冷却器、再沸器、冷凝器、空冷 | P1/P2 泄压降温 |
| 加热炉 | 加热炉、锅炉、炉 | P1/P2、Q4/Q5 |
| 管线/阀门 | 管线、管道、阀门、调节阀、安全阀 | P1 泄压 |
| 电气设备 | 电机、变频、配电、开关柜、变压器、电气、马达 | E1 断电挂牌、E2 验电接地 |
| 仪表 | 仪表、变送器、分析仪、流量计、联锁 | E1、E3 |
| 其他 | 以上均不匹配 | 仅通用条目（H1、H2、S1、S3 等） |

## 三、设备台账（可选，`--ledger`）

工作表名匹配「设备台账」「台账」「设备清单」「技术对象」「功能位置」「设备主数据」「设备列表」（去空白与「表」字后包含匹配）；都没命中时取第一个工作表并 warning。支持厂内自编台账与 **SAP PM 技术对象导出**（功能位置 / 设备 / 设备描述 / 对象类型 / 维护工厂）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 与 `--tag` 精确匹配；未命中时 warning，不中断。SAP 导出的「功能位置」即位号 |
| 设备编号 | 否 | SAP 8 位流水号（「设备」列），**不是位号**；`--tag` 填设备编号时也可命中该行 |
| 设备名称 | 否 | 补全 `--name`（SAP「设备描述」） |
| 设备类型 | 否 | 补全 `--equip-type`（SAP「对象类型」） |
| 介质 | 否 | 补全 `--medium` |
| 操作温度 | 否 | 数值，带单位（78℃）可解析；无法解析时 null + warning，**绝不按 0**；只记录不推断 |
| 操作压力 | 否 | 数值(MPa)，带单位（0.35MPa）可解析；同上 |
| 车间 | 否 | 补全 `--workshop`（SAP「维护工厂」、作业票「属地单位」） |

命令行参数优先于台账；台账只补命令行没给的字段。

### 列名别名

别名表 = 局部别名 + 共享 `SYSTEM_ALIASES`（`C.mergeAliases`），局部优先；去空白后全等优先，再前缀匹配。

| 标准列名 | 局部别名 | 共享别名（SAP PM / EM） |
|---|---|---|
| 位号 | 位号、设备位号、TAG、tag | 位号编码、功能位置、功能位置编号、技术标识、技术对象、技术对象标识、Tag |
| 设备编号 | — | 设备编号、设备、设备号、设备编码、技术对象编号、EM编码 |
| 设备名称 | 设备名称、名称 | 设备描述、技术对象描述、功能位置描述、描述 |
| 设备类型 | 设备类型、类型、设备类别、类别、对象类型、设备分类、专业类别、设备品种 | — |
| 介质 | 介质、物料、工艺介质、输送介质、操作介质、流体 | — |
| 操作温度 | 操作温度、温度、工作温度、设计温度 | — |
| 操作压力 | 操作压力、压力、工作压力、设计压力 | — |
| 车间 | — | 车间、维护工厂、属地单位、使用单位、运行部、作业部 |

注意：「设备编号」已从位号别名中移出（SAP 的设备编号是 8 位流水号，不是位号）。

表头行识别：取前 10 行中命中必需列最多的一行；首列以 合计 / 小计 / 总计 开头的行跳过并 warning。

## 四、现场确认结果（可选，`--confirm`）

由**现场确认人填写后**回填，脚本自身从不产生 `confirmed: true`。

格式为 JSON 数组（或含 `items` 数组的对象）：

```json
[
  {"ruleId": "H1", "confirmed": "是", "by": "张工", "at": "2026-09-21 10:00"},
  {"ruleId": "H3", "confirmed": "否", "by": "张工", "at": "2026-09-21 10:05"}
]
```

| 字段 | 必需 | 说明 |
|---|---|---|
| `ruleId` | 是 | 规则号；不在本次清单中时 warning 并忽略 |
| `confirmed` | 是 | 是/否（或 true/false）；**无法识别时 warning 且仍按未确认（null）处理** |
| `by` | 否 | 确认人；缺失时 warning |
| `at` | 否 | 确认时间 |

未在文件中出现的条目保持 `confirmed: null`（未确认），**不按已完成处理**。

## 五、会 warning 但不中断的情况

- 未提供设备类型
- 介质未填或不在危险特性库（按最严口径处理）
- 位号不在设备台账中
- 温度/压力无法解析为数字（按 null，不按 0）
- 给了温度/压力数值但未给 `--pressured` / `--hot`（只形成推断值提示，不进入判定）
- 台账无「设备台账/技术对象」工作表，取第一个工作表
- `--pressured` / `--hot` 取值无法识别为是/否
- 确认结果中的未知规则号、无法识别的确认结果、缺确认人
- 同时涉及进受限空间与用火作业的高风险作业组合

## 六、会报错并 exit 1 的情况

- 缺 `--tag` 或 `--scope`
- 参数缺取值、未知参数
- `--plan-date` 非法
- `--entry` 与 `--no-entry`（或 `--hotwork` 与 `--no-hotwork`）同时给出
- `--ledger` 或 `--confirm` 指向的文件不存在、`--confirm` 内容不是合法 JSON 或格式错误
