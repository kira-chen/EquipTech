# 检修前设备交出确认
**技能名称**：检修前设备交出确认

**技能简介**：设备交出检修前，按介质、设备类型与作业类型生成停车、隔离、泄压、吹扫置换、盲板、停电挂牌、采样分析的交出条件清单，并提示要办的用火、受限空间、盲板抽堵作业许可；辅助核对，不替代现场确认签字。

**技能描述**

面向炼化厂车间设备员，用于机泵解体、塔器进人、管线用火、换热器抽芯等设备交出场景。说明位号、设备类型、介质、检修内容、是否进人、用火、带压、高温后，按介质危险特性（含液化气、硫化氢、EO/EG、氯气、碳四等）生成带规则号的交出条目，盲板、置换分析、断电挂牌三类关键条目单列，并按作业许可八大类提示要办的用火、受限空间、盲板抽堵作业票；台账可用 SAP 导出补全。介质不在库按最严口径并提示核实 MSDS；未说明带压、高温时对应条目列为未判定，不按台账数值推断。完成情况由现场人员确认后回填，模型不代填；有未完成或未判定项时标注"尚不具备交出条件"。不做作业票预检与完工验收，不替代签字。

**示例问题**
1. P-3101A 液化气进料泵要拆机封，工艺说现在还带压、不高温，不进人不用火，帮我出一份交出条件清单，关键条目单独列出来。　　**附件：** `examples/sample-handover-cases.xlsx`
2. E-3201 蜡油换热器要抽芯清洗，法兰还要补焊，设备信息在附件台账里，高温带压，帮我生成交出单并告诉我要办哪些作业票。　　**附件：** `examples/sample-equip-ledger.xlsx`
3. 附件是 SAP 导出的技术对象清单，P-3601A 碳四泵拆机封，带不带压我还没问工艺，先把交出清单出来，说清楚哪些项还定不了。　　**附件：** `examples/sample-equip-ledger-sap.xlsx`
4. V-3401 中间缓冲罐要进人补防腐涂层，介质是再生剂 RX-7，台账里也查不到危险特性，你按什么口径给我列交出条件？　　**附件：** `examples/sample-equip-ledger.xlsx`
5. M-3301 循环水泵电机换轴承，台账里介质是空的，帮我出交出单，重点是停电挂牌上锁和验电接地这些电气条目。　　**附件：** `examples/sample-equip-ledger.xlsx`
