# 检修归档资料规范（中石化炼化厂口径）

> **本表为默认参考口径。** 厂内档案管理制度另有规定的以厂内为准，并在交付时注明采用的口径来源。规则表实现在 `scripts/lib/archive-spec.js`，与本文档同源。

## 零、检修分级

| 分级（`--type`） | 含义 | 旧值映射 |
|---|---|---|
| 大检修 | 装置大检修（停工检修） | 大修、装置大检修、停工检修 → 大检修 |
| 日常维修 | 日常维修 | 中修、小修、日常检修 → 日常维修 |
| 抢修 | 抢修 | 紧急抢修 → 抢修 |
| 专项 | 专项（技改技措） | 技改、技改技措、专项检修 → 专项 |

旧值映射时脚本 warning，概况表显示"大检修（原填「大修」）"。不传或无法识别 → 报错，不默认。

## 一、通用资料（所有分级）

| 资料 | 必备 | 文件名识别关键词 |
|---|---|---|
| **检修方案** | **是** | 方案、施工方案、检修方案、作业指导书、抢修方案 |
| **作业许可（作业票）** | **是** | 作业票、作业证、作业许可、用火、动火票、受限空间、高处作业、吊装作业、临时用电、盲板、动土、断路 |
| 设备交出单 | 否 | 交出单、交出、设备交出 |
| **检修记录卡** | **是** | 检修记录、施工记录、作业记录、检修日志、记录卡 |
| **验收单** | **是** | 验收、验收单、竣工验收、完工验收 |
| 检修照片 | 否 | 照片、图片、影像、现场记录、.jpg/.png |

作业票按《中国石化作业许可管理规定》八大类命名（用火、受限空间、高处、吊装、临时用电、动土、断路、盲板抽堵）；旧称"动火票"的文件名仍可归入作业票。抢修可按厂内规定使用简化方案，但方案仍为必备项。

## 二、按检修分级追加

| 分级 | 追加资料 | 必备 |
|---|---|---|
| 大检修 | 风险分析（JSA）记录、质量验收记录（H/W 点见证）、试车记录、备件领用单、更换部件质量证明、三查四定问题整改记录、中交（中间交接）记录、进度记录 | 否 |
| 大检修 | **检修总结** | **是** |
| 日常维修 | 无 | |
| 抢修 | 故障（事件）记录或分析报告 | 否 |
| 专项 | 技术方案或变更资料（MOC） | 否 |

大检修关键节点：开工前条件确认 → 施工 → 三查四定 → 中交 → 试压/试运/投料前确认 → 开工；三查四定问题整改记录与中交记录是大检修归档的特有项（跟踪用 `turnaround-workshop-tracker`）。

## 三、按检修范围追加

用命令行开关启用，对应实际作业内容：

| 开关 | 追加资料 | 识别关键词 |
|---|---|---|
| `--scope-material` | 材质证明书 | 材质、质保书、合格证、质量证明 |
| `--scope-weld` | 焊接记录与焊工资质 | 焊接、焊工、焊缝、WPS、PQR |
| `--scope-ndt` | 无损检测报告 | 无损、探伤、NDT、RT、UT、MT、PT、射线、超声 |
| `--scope-pressure` | 试压记录 | 试压、压力试验、水压、气密、强度试验 |
| `--scope-trial` | 试运记录 | 试运、试车、运转、空负荷、负荷试运 |

## 四、特种设备必备（`--special-equipment`）

设备属压力容器、压力管道、锅炉等特种设备时启用。以下五项**全部为必备**，缺失即不满足归档要求：

| 资料 | 说明 |
|---|---|
| 特种设备检验报告 | 法定定期检验的检验报告（由检验机构出具） |
| 承压件材质证明书 | 更换承压件的材质与质量证明 |
| 焊工资质证明与焊接记录 | 持证焊工资质与焊接工艺记录 |
| 无损检测报告 | 焊缝与承压部件的无损检测结论 |
| 耐压试验记录 | 水压或气压试验记录 |

启用该开关时，同名的一般项会被特种设备版覆盖（必备等级更严）。常压储罐不是特种设备。

## 五、缺失的处理（硬规则）

| 情形 | 处理 |
|---|---|
| 一般应归档资料缺失 | 列入「缺失资料」，注明「应归档资料缺失」 |
| **必备资料缺失** | 列入「缺失资料」并加粗，同时在报告**开头【注意】提示**「不满足归档要求」 |
| 文件名无法识别归属 | 列入「待认领材料」，由用户人工认领 |

**禁止**：
- 用其他材料替代缺失资料
- 建议事后补编记录
- 按文件名猜测强行归类
- 淡化必备资料缺失的提示

## 六、台账履历更新（EM 检修记录列头）

提供 `--ledger` 时生成履历更新建议（`ledger-update.csv`），列头与 EM 设备管理信息系统检修记录对齐：功能位置、设备编号、设备描述、检修类型、检修项目、检修内容、实际开始日期、实际结束日期、承修单位、归档资料数、缺失资料数、必备缺失数、备注。

**本技能不直接改写用户的台账文件或 EM 数据**，只输出待确认的更新行。位号与设备编号均不在台账中时仍生成建议，但会【注意】提示先确认位号。

## 七、制度引用（只引名称，不转述数值）

- 《中国石化设备管理规定》《炼化企业设备管理技术规定》：检修记录与设备档案（一机一档）的归档要求、检修分级。
- 《中国石化作业许可管理规定》：作业票八大类命名与保存要求。
- 设备完整性管理体系（GB/T 44692 系列）：检修记录、质量验收记录的追溯要求。
- TSG 21 / TSG D7005：特种设备检验报告与使用登记资料。
- 厂内档案管理制度（虚构示例编号写 `Q/XX-虚构-001`）：保管期限、编号规则以厂内制度为准。

## 八、不做的事

- 不判定检修质量与验收结论
- 不替代档案室的实体归档、编号与保管期限管理
- 不补编缺失的检修记录与检测报告
- 不读文件内容（只按文件名归类）
