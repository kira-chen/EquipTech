# 输入规格：检修记录归档

## 必填参数

| 参数 | 说明 |
|---|---|
| `--tag` | 设备位号（功能位置）；提供台账时也可用 SAP 设备编号 |
| `--project` | 检修项目名称 |
| `--type` | 大检修 / 日常维修 / 抢修 / 专项（旧值 大修 / 中修 / 小修 自动映射并 warning；其它值报错，不默认） |
| `--materials` | 材料清单 xlsx 或材料目录 |

## 材料来源的两种形式

### 形式一：材料目录

直接传目录路径，脚本递归扫描全部文件（跳过隐藏文件），按文件名归类。子目录文件保留相对路径。**脚本不读文件内容**，PDF/扫描件无需转换。

```bash
--materials "/path/to/V-2301检修资料/"
```

### 形式二：材料清单 xlsx

sheet 名匹配「材料清单」「资料清单」「归档清单」「材料」。

| 列名 | 必需 | 说明 |
|---|---|---|
| 文件名 | 是 | 为空的行跳过并 warning |
| 资料类型 | 否 | 仅展示，**归类以文件名为准** |
| 位号 | 否 | |
| 备注 | 否 | |

列名别名：文件名 / 资料名称 / 名称 / 材料名称 / 文件 / 附件名称；资料类型 / 类型 / 类别 / 资料类别。

## 可选参数

| 参数 | 说明 |
|---|---|
| `--from` / `--to` | 检修起止日期，YYYY-MM-DD；`--to` 早于 `--from` 时报错 |
| `--contractor` | 承修单位 |
| `--content` | 检修内容（写入 EM 履历建议） |
| `--ledger` | 设备台账 xlsx，用于生成履历更新建议 |
| `--special-equipment` | 特种设备，启用五项必备资料要求 |
| `--scope-material` | 涉及更换承压件 |
| `--scope-weld` | 涉及焊接 |
| `--scope-ndt` | 涉及无损检测 |
| `--scope-pressure` | 涉及试压 |
| `--scope-trial` | 涉及试运 |

范围开关要按实际作业内容勾选。勾得少会漏掉应归档项，勾得多会产生不必要的缺失提示，**不确定时应向用户确认，不要默认全开或全关**。

## 设备台账（`--ledger`）

sheet 名匹配「设备台账」「台账」「设备清单」「技术对象」「设备主数据」。厂内台账与 SAP PM / EM 导出均可。

| 标准列名 | 必需 | 可识别的写法（局部别名优先，再经 `C.mergeAliases` 并入共享 `SYSTEM_ALIASES`） | 来源 |
|---|---|---|---|
| 位号 | 是 | 位号、设备位号、**功能位置**、功能位置编号、技术标识、技术对象、TAG | 厂内 / SAP PM / EM |
| 设备编号 | 否 | 设备编号、**设备**、设备号、设备编码、技术对象编号、EM编码 | SAP PM（8 位流水号）/ EM |
| 设备名称 | 否 | 设备名称、**设备描述**、技术对象描述、功能位置描述、名称、描述 | 厂内 / SAP PM |
| 设备类别 | 否 | 设备类别、设备类型、**对象类型**、设备分类 | SAP PM |
| 装置 / 车间 | 否 | 装置、工厂区段、单元 / 车间、维护工厂、属地单位 | SAP PM |

**设备编号不是位号**：局部别名已不再把「设备编号」当作位号。`--tag` 先按位号（功能位置）匹配，未命中再按设备编号匹配；按设备编号命中时履历建议按功能位置写出并 warning。两者均未命中 → warning + md【注意】提示先确认位号。

表头行识别：取前 10 行中命中必需列最多的一行，因此首行是标题、第三行才是表头的 SAP 导出表也能读。

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 等开头的行（warning）
- 文件名为空的行（warning）
- 目录模式下以 `.` 开头的隐藏文件

## 产出

| 文件 | 内容 |
|---|---|
| `archive.json` | 应归档清单、已归档、缺失、`mandatoryMissing`（必备缺失）、待认领、履历更新建议 |
| `archive.md` | 五节报告 + 附，必备缺失时开头带【注意】提示，末尾声明行 |
| `ledger-update.csv` | 台账履历更新建议（EM 检修记录列头，带 BOM），提供 `--ledger` 时生成 |
| `summary.json` | 末行摘要落盘 |
