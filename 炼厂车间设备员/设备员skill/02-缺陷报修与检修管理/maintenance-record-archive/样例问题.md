# 检修记录归档 · 样例问题

> 附件均在 `examples/`（可用 `node scripts/make-sample.js --out examples --seed <n>` 重新生成，默认 seed=1）。文件编号与照片阶段随 seed 变化，但每题的预期结论——应归档数、已归档数、必备缺失项——不变；预期计数与验证要点见 `examples/README.md` 对照表（仅开发库含，发布包不含）。脚本只按文件名归类，不读文件内容。

1. V-2301 低压分离器大检修的资料清单在附件里，这是压力容器，做了补焊和试压，帮我核一下归档还缺什么。　　**附件：** `examples/sample-materials.xlsx`
2. P-1101A 回流泵日常维修的资料齐了吗，帮我按归档规范过一遍。　　**附件：** `examples/sample-minor-complete.xlsx`
3. 这次报的是"大修"，目前只交了一份检修记录卡，其他还没来，先核一下缺什么、哪些是必备的。　　**附件：** `examples/sample-sparse.xlsx`
4. 归档核对完顺便把 V-2301 的检修履历更新到台账，承修单位是检修公司二队。　　**附件：** `examples/sample-materials.xlsx + examples/sample-equipment-ledger.xlsx`
5. 台账是 SAP 导出的，我只记得设备编号 10023001，能用它查到位号并生成履历建议吗？　　**附件：** `examples/sample-materials.xlsx + examples/sample-equipment-ledger-sap.xlsx`
6. 清单里有一份"会议纪要"，归档的时候该放哪一类？　　**附件：** `examples/sample-materials.xlsx`
7. 大检修归档比日常维修多要哪些资料，三查四定和中交记录算不算？　　**附件：** `examples/sample-materials.xlsx`
8. 无损检测报告承修单位说补不出来了，能不能用检修记录里的描述代替？　　**附件：** `examples/sample-materials.xlsx`
9. 资料都在一个文件夹里没有清单，直接扫文件夹行不行？　　**附件：** 无（不传清单，直接把本技能的 examples 目录当材料目录试跑）
10. 这台是常压储罐，要不要按特种设备口径归档？　　**附件：** `examples/sample-minor-complete.xlsx`

## 平台接入业务系统 MCP 时

不上传附件，台账、工单和作业票原件由 MCP 工具获取，演示数据每天按剧本刷新；其余检修资料以平台知识库或用户后续上传为准。

M1. E-1201 管束内漏抽芯检修今天开工，头盖法兰要补焊、完工后试压，先把今天的作业票原件归进来，看看归档还缺什么，顺便出一份检修履历更新建议。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=E-1201）、`get_work_orders`（tag=E-1201）；作业票系统 `get_permits`（tag=E-1201）、`get_permit_document`（permit_no=当天 E-1201 的许可证编号）
M2. P-2105A 最近一次机封更换的工单已经验收关闭，资料还一份没交上来，先告诉我要归档哪些、哪些是必备的，再按工单把台账检修履历建议填好。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=P-2105A）、`get_work_orders`（tag=P-2105A）
