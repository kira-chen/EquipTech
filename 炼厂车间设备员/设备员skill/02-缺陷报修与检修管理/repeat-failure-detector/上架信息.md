# 重复故障识别
**技能名称**：重复故障识别

**技能简介**：从 SAP 通知单/工单导出或车间故障记录里找出一年内反复出现的故障，按"同一设备同一部位 ≥2 次"的口径识别重复故障和同型号共性故障，优先按 SAP 损坏代码归类，给出该做根因分析的设备清单。只做频次统计，不下原因结论。

**技能描述**

面向炼化厂车间设备员，找出老坏的设备和该做根因分析的设备。上传 SAP 通知单或订单导出、车间工单台账或故障记录，脚本默认按截止日往前一年、同一设备同一部位两次以上判重复故障，阈值可改。带 SAP 损坏代码就按代码归类，不同代码不硬凑；没代码才按故障现象、对象部件做相似匹配，每条附匹配依据供你核。同型号跨台出现相似故障的列为共性线索，故障间隔逐次缩短的单独标出；现象只写"故障""坏了"又没代码的单列无信息量，绝不据此判重复。可接设备台账补型号。产出识别报告（概览、同设备重复、同型号共性、频次排行、间隔缩短、无信息量）和 JSON。只做频次统计，模型不下原因结论，不做可靠性建模，不评价承修单位。

**示例问题**
1. 这一年常减压车间哪些设备老坏？帮我看看有没有重复故障，哪些该安排根因分析。　　**附件：** `examples/sample-failures-2026-09-21.xlsx`
2. 两套装置的维修记录是分开导的，一起看一下，同型号的换热器是不是都有管束内漏的毛病，台账也给你。　　**附件：** `examples/sample-failures-2026-09-21.xlsx + examples/sample-failures-unit2-2026-09-21.xlsx + examples/sample-equip-ledger.xlsx`
3. 这是从 SAP 导出来的通知单，有损坏代码，按代码帮我看哪些是重复故障，短文本写得不全别影响判断。　　**附件：** `examples/sample-sap-notifications.xlsx`
4. 这批记录故障现象基本没填，只写了"故障""坏了"，能看出重复故障吗？看不出就告诉我缺什么。　　**附件：** `examples/sample-vague-desc.xlsx`
5. 我们厂算重复故障的口径是一年内 3 次，按这个口径重新算，看看哪个部位最容易坏。　　**附件：** `examples/sample-failures-2026-09-21.xlsx`
