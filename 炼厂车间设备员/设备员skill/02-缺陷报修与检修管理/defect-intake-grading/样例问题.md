## 平台接入业务系统 MCP 时

不上传附件，设备台账和未关闭的通知单由 MCP 工具获取，演示数据每天按剧本刷新。

M1. P-2101A 进料泵驱动端振动明显变大，轴承箱有异响，暂时不影响生产，今天 10:30 设备员赵三发现的，帮我登记缺陷定级，查一下有没有还没关闭的通知单重复，出通知单草稿。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=P-2101A）、`get_notifications`（tag=P-2101A，open_only=true）
M2. E-1201 循环水回水发现油花，管束可能内漏，换热效果变差，已经影响运行，帮我登记定级，看看是不是之前已经报过。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=E-1201）、`get_notifications`（tag=E-1201，open_only=true）
M3. 把常减压车间还没关闭的通知单按 A/B/C 重新过一遍，和系统里填的缺陷等级对一下。　　**数据：** MCP 设备资产管理 `get_notifications`（workshop=常减压车间，open_only=true）、`get_equipment_ledger`（workshop=常减压车间）
