# 设备缺陷登记与分级
**技能名称**：设备缺陷登记与分级

**技能简介**：把车间设备员口头或巡检记录里的设备问题整理成规范缺陷记录，按 A 级（重大）/B 级（严重）/C 级（一般）定级，并生成可在 SAP 创建维修通知单的草稿。辅助登记，不替代审核。

**技能描述**

面向炼化厂车间设备员，把口头或巡检记录里的设备问题整理成规范缺陷记录并定级。直接口述一句，或上传记录表、SAP 通知单导出。技能先把描述拆成位号、部位、现象、介质、是否影响运行等字段回读给你确认，再由脚本按规则表定级：高危介质泄漏或结构开裂为 A 级，影响运行或中危介质泄漏为 B 级，不影响运行的为 C 级；介质或是否影响运行没填的判未判定单列，不按最轻最重默认。可接设备台账补编号和介质，可对现有台账或通知单查重，疑似重复交你确认。产出缺陷登记单、台账追加行和维修通知单草稿；处理时限可按厂内规定覆盖，兼容旧四级口径。等级由脚本出，模型只写说明；不做故障诊断，不创建工单，不替代审核。
