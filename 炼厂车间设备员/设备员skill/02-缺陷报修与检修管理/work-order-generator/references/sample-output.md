## 交付说明写法示范

本次生成 3 张维修通知单草稿，`notifications.csv` 按 SAP 通知单列整理，通知单号留空由系统生成。

优先级是按缺陷等级的默认口径推的：A 级 → 1 非常高，B 级 → 2 高，C 级 → 3 中；通知单类型按优先级 1/2 → M2 故障报告、3/4 → M1 维修申请。厂内通知单类型目录或优先级规定不同的话给我，可以用 `--priority`/`--notif-type` 按厂内口径重出。

专业归口是查判定表得的**建议值，需车间与承修单位确认**。工时和备件草稿里不填，由承修单位在工单（订单）里编。

有 1 张草稿信息不全：P-XXXXB 功能位置在设备台账里没查到，设备编号、规格型号、安装位置、投用日期都是空的，也没有历史维修记录，这两项都没编，需要核实后补。

这批是草稿，**由车间设备员核对后在 SAP 中创建，通知单号由系统生成；工单、工时与备件由计划员或承修单位编制**。
