# 维修通知单草稿生成 · 样例问题

> 附件均在 `examples/`（可用 `node scripts/make-sample.js --out examples --seed <n>` 重新生成，默认 seed=1）。滴漏滴数、主工作中心随 seed 变化，但每题的预期结论——草稿数、优先级与通知单类型分布、未判定条数、不在台账条数——不变；预期计数与验证要点见 `examples/README.md` 对照表（仅开发库含，发布包不含）。

1. 这几条巡检发现的缺陷帮我出成 SAP 维修通知单草稿，报告单位加氢车间，要求 9 月 28 日前处理完。　　**附件：** `examples/sample-defects-2026-09-21.xlsx`
2. 出草稿的时候对一下设备台账，把 SAP 设备编号、型号和安装位置带全，台账里没有的标出来。　　**附件：** `examples/sample-defects-2026-09-21.xlsx + examples/sample-equip-ledger.xlsx`
3. 这批通知单草稿把每台设备以前修过什么附上，只要最近三次，没修过的写明没有。　　**附件：** `examples/sample-defects-2026-09-21.xlsx + examples/sample-repair-history.xlsx`
4. 这两条缺陷没写等级，能出通知单吗？优先级定不了的告诉我，别自己按中处理。　　**附件：** `examples/sample-no-level.xlsx`
5. 这两条车间定了都按 2 高报，类型报故障报告，重新出一版草稿。　　**附件：** `examples/sample-no-level.xlsx`
6. 单独报一条：P-101A 机封处持续滴漏，大概 5 滴一分钟，报告单位加氢车间，9 月 28 日前处理完，给我通知单草稿。　　**附件：** 无
7. 把刚才缺陷登记技能出的那批缺陷直接转成通知单草稿，等级和定级依据都带上。　　**附件：** 无样例文件，附缺陷登记技能（defect-intake-grading）上一次运行产出的 `defects.json`
8. 要求结束日期我填的是上周，先按这个出，告诉我哪些要改期。　　**附件：** `examples/sample-defects-2026-09-21.xlsx`

## 平台接入业务系统 MCP 时

> 不上传附件，设备台账、维修记录和未关闭通知单由 MCP 工具获取，演示数据每天按剧本刷新。

M1. P-2101A 进料泵驱动端振动明显变大、轴承箱有异响，帮我出一张 SAP 维修通知单草稿，报告单位常减压车间，月底前处理完，台账信息和以前修过什么都带上。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=P-2101A）、设备资产管理 `get_failure_history`（for_skill=work-order-generator，tag=P-2101A）
M2. 同一条 P-2101A 的缺陷，车间定了按 2 高报，重新出一版草稿。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=P-2101A）、设备资产管理 `get_failure_history`（for_skill=work-order-generator，tag=P-2101A）；运行时加 `--priority 2`
M3. 常减压车间现在还没关闭的维修通知单，按 SAP 通知单草稿格式整理一版给我核对，要求一周内完成，带上台账和维修记录。　　**数据：** MCP 设备资产管理 `get_notifications`（open_only=true，workshop=常减压车间）、设备资产管理 `get_equipment_ledger`（workshop=常减压车间）、设备资产管理 `get_failure_history`（for_skill=work-order-generator，workshop=常减压车间）
