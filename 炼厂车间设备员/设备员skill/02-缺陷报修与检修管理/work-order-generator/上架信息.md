# 维修通知单草稿生成
**技能名称**：维修通知单草稿生成

**技能简介**：把已登记的缺陷转成可在 SAP PM 创建维修通知单的草稿，自动从设备台账带出设备编号与规格、附历史维修记录，按缺陷等级映射 SAP 优先级与通知单类型。只出草稿，不编号、不定工时。

**技能描述**

面向炼化厂车间设备员，把登记好的缺陷转成可在 SAP 创建维修通知单的草稿。上传缺陷记录表或缺陷登记技能产出的 defects.json，也可以直接口述；另给设备台账就带出 SAP 设备编号、型号、安装位置，给订单历史就附该设备最近几次维修记录。脚本按缺陷等级 A/B/C 映射 SAP 优先级 1~4，再推通知单类型 M1/M2，给出专业归口建议。位号在台账查不到标"待补充"，不按设备名猜型号；没历史就写明没有；没等级也没指定优先级的判未判定单列，不按"3 中"默认。产出草稿 md、JSON 和按 SAP 通知单列整理的 CSV，通知单号由系统生成。内容由脚本出，模型只写说明；不定级，不编方案，不填工时和备件，不跟踪工单。

**示例问题**
1. 这几条巡检发现的缺陷帮我出成 SAP 维修通知单草稿，报告单位加氢车间，要求 9 月 28 日前处理完。　　**附件：** `examples/sample-defects-2026-09-21.xlsx`
2. 出草稿的时候对一下设备台账，把 SAP 设备编号、型号和安装位置带全，台账里没有的标出来。　　**附件：** `examples/sample-defects-2026-09-21.xlsx + examples/sample-equip-ledger.xlsx`
3. 这批通知单草稿把每台设备以前修过什么附上，只要最近三次，没修过的写明没有。　　**附件：** `examples/sample-defects-2026-09-21.xlsx + examples/sample-repair-history.xlsx`
4. 这两条缺陷没写等级，能出通知单吗？优先级定不了的告诉我，别自己按中处理。　　**附件：** `examples/sample-no-level.xlsx`
5. 这两条车间定了都按 2 高报，类型报故障报告，重新出一版草稿。　　**附件：** `examples/sample-no-level.xlsx`
