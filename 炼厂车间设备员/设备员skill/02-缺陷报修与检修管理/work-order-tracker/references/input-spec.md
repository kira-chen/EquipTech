# 输入规格：维修工单跟踪

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一次一个文件：`--input 工单台账.xlsx` 或 `--input SAP订单导出.xlsx`

## 工单台账 / SAP 订单导出工作表

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「工单台账」「工单台账表」「维修工单」「报修台账」「订单」「维修订单」均可识别。**找不到该表时脚本报错终止**（台账是唯一数据源）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 工单号 | 是 | SAP「订单」号；为空的行会被跳过并 warning；重复时两条均保留并 warning |
| 状态 | 是 | SAP「系统状态」或中文状态，见下方「状态映射」；缺此列时全部工单归入未知状态 |
| 通知单号 | 否 | SAP「通知单」，带入清单便于对账 |
| 位号 | 否 | SAP「功能位置」 |
| 设备编号 | 否 | SAP「设备」，8 位流水号，**不是位号** |
| 设备名称 | 否 | SAP「设备描述」；缺失时报表显示 — |
| 故障描述 | 否 | SAP「订单描述」或通知单短文本；催办清单中直接带给责任方 |
| 工单类型 | 否 | SAP「订单类型」PM01/PM02/PM03 或中文 抢修/日常维修/计划检修，决定时限类别 |
| 优先级 | 否 | SAP 1~4 或 非常高/高/中/低；无工单类型时用于推定时限类别 |
| 报修时间 | 否 | SAP「创建日期」/通知日期；推算要求完成时间与计算闭环时长的起点 |
| 要求完成时间 | 否 | SAP「基本结束日期」；超期判定基准，缺失时按报修时间 + 时限类别时限推算 |
| 派工时间 | 否 | SAP「基本开始日期」/下达日期；节点时间，用于停滞判定 |
| 开工时间 | 否 | 实际开始日期；节点时间 |
| 完工时间 | 否 | SAP「实际结束日期」/技术完成日期；无验收时间时作为闭环时间 |
| 验收时间 | 否 | 关闭日期/业务完成日期；闭环时间优先取此列 |
| 承修单位 | 否 | SAP「主工作中心」；催办分组依据 |
| 责任人 | 否 | 催办分组依据 |
| 超期原因 | 否 | 未填写时报表写「原因未记录」，**不推测** |

| 已闭环 | CLSD、NOCO、业务完成、已关闭、关闭、已闭环、闭环、已验收、已消缺 | 否 |

## 优先级（SAP 1~4）

| 标准优先级 | 可识别的写法 |
|---|---|
| 1 非常高 | 1、非常高、紧急、特急、一级、I |
| 2 高 | 2、高、较急、重要、二级、II |
| 3 中 | 3、中、一般、普通、三级、III |
| 4 低 | 4、低、不急、四级、IV |

优先级为空或取值非法时：warning，按「无优先级」处理；无工单类型时无法推定时限类别。

## 时限类别与默认时限

| 时限类别 | 工单类型写法（厂内可配置） | 无工单类型时按优先级推定 | 默认时限（天） |
|---|---|---|---|
| 抢修 | PM03、抢修、紧急维修、故障抢修 | 1 非常高 | 1（24 小时） |
| 一般 | PM01、日常维修、一般维修、常规维修 | 2 高、3 中 | 7 |
| 计划性 | PM02、计划检修、定期检修、预防性维修、大检修 | 4 低 | 30 |

> 默认时限是脚本内置参考值，**非厂内正式口径**，报告会打【注意】声明行。厂内有规定时用 `--sla` 传入口径表覆盖。
> 工单类型认不出（如「临时」）→ warning 并改按优先级推定；类型与优先级都没有 → 无时限类别，**不推算时限、不判超期、不参与达标率统计**，单独计数。

## 时限口径表（可选，`--sla`）

工作表名匹配「时限口径」「时限」「口径」「SLA」。

| 列名 | 必需 | 说明 |
|---|---|---|
| 时限类别 | 是 | 抢修 / 一般 / 计划性（别名：类别、工单类型、订单类型、优先级；按优先级写的旧表会映射到类别） |
| 时限 | 是 | 支持 `3`、`3天`、`1周`、`1个月` 等写法；无法解析则该行跳过并 warning |

未在口径表中出现的类别仍按脚本默认口径计算，并 warning 提示；同一类别重复给出不同天数时以后出现者为准并 warning。

## 时间字段
- 支持：`2026-09-21 08:15`、`2026/9/21 8:15`、`2026年9月21日`、Excel 日期单元格、Excel 日期序列号
- **无法解析的时间 → warning + 该节点按缺失处理**，不猜测、不按当前时间补齐
- **节点时间倒序**（如完工早于开工、要求完成早于报修）→ warning 并指明具体节点与行号，数据**原样保留不改写**

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 工单号为空的行（warning 提示）

## 不会被跳过、但会单列的情况
- 状态非法或为空 → `unknownStatus`
- 未闭环但节点时间全缺 → `stallUndetermined`（无法判定是否停滞）
- 已闭环但报修/完工验收时间缺失 → 闭环时长 null，不计入平均值
- 无工单类型且无优先级 → 无时限类别，`counts.noCategory`
- 工单号重复 → 两条均保留并各自参与计算，仅 warning 提示核实
