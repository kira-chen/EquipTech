## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 超期原因 | 「台账记录原因为『备件待到货』，另两张台账未记录超期原因」 | 「估计是外委队伍人手不足」 |
| 责任 | 「外委-XX检修 超期 1 张 + 停滞 1 张，需优先跟进」 | 「外委单位履约差，建议扣分考核」 |
| 未知状态 | 「填写为『挂起』，不在规定六态内，需回台账核实」 | 「挂起中，按在办统计」 |
| 已完成 | 「3 张 TECO/已完成工单归待验收，未计入已闭环」 | 「已完成 3 张，算闭环」 |
| 推算依据 | 「按报修时间加『一般』时限 7 天推算，已标注依据」 | 直接给一个要求完成日期而不说来源 |
| 缺时长 | 「2 张因报修或完工时间缺失显示『—』，未计入平均」 | 「按今天估算约 X 天」 |
| 口径 | 「本次采用脚本默认时限口径，非厂内正式口径」 | 略去口径来源直接报达标率 |
