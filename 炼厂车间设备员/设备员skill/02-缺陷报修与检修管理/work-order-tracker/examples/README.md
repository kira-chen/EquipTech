# examples 回归测试数据

> 本目录仅开发包含有（`build.sh --with-examples`），发布包不含。
> 全部样例由 `node scripts/make-sample.js --out examples` 再生，故障描述细节与人员姓氏随 seed 变化但结论不变。
> 样例中的时间按 `--date`（默认 2026-09-21）相对生成，跑脚本时 `--date` 须与生成样例时一致，否则预期结果不成立。

## 关键验证点

1. **SAP 状态映射**：`sample-sap-export` 中 40012302 系统状态 TECO（技术完成）归**待验收**而非已闭环，且基本结束日期已过 → 判超期；只有 CLSD 的 40012303 计入已闭环与完成率分子。
2. **时限类别来源**：40012301 订单类型 PM03 → 抢修，无基本结束日期时按「创建日期 + 1 天」推算，条目 `dueBasis` 写明「类别来源：工单类型「PM03」」；主样例无工单类型列，按 SAP 优先级推定（1→抢修，2/3→一般，4→计划性）并写明「按优先级 X 推定」。
3. **状态非法不就近映射**：主样例 WO-26090112 状态填「挂起」，不在 SAP 状态与六态内 → warning + 归入 `unknownStatus` 单列，不计入状态分布、超期、停滞、完成率任何一项。
4. **节点时间倒序**：WO-26090113 完工时间早于开工时间 → warning 指明具体节点、时间与行号，数据原样保留不改写。
5. **工单号重复**：WO-26090113 出现两次（P-1105A 与 P-1105B）→ warning 提示核实台账，**两条均保留**并各自参与计算，`counts.duplicated` 为 1。
6. **要求完成时间缺失走推算**：WO-26090103 台账无要求完成时间 → 按「报修时间 + 「一般」时限 7 天」推算，条目 `dueBasis` 写明推算依据与类别来源。
7. **时长不可计算不补齐**：WO-26090110 报修时间缺失 → 闭环时长为 null，报告显示「—」，不计入平均值（样本显示 2/3），warning 明确「不按当前时间补齐」。
8. **超期原因不推测**：WO-26090102、WO-26090103 台账「超期原因」列为空 → 报告与催办清单一律写「原因未记录」。
9. **无未闭环工单时各节显示「无」**：`sample-all-closed.xlsx` 的超期、停滞、临期三节均为 `_无_`，催办清单明确写无需催办。
10. **默认口径声明行**：不加 `--sla` 时报告头部必须出现「【注意】默认时限口径（抢修 24 小时、一般 7 天、计划性 30 天）……非厂内正式口径」，加 `--sla` 后该行消失。
11. **合计行与别名列头**：MES 样例末行「合计」被跳过并 warning；「工单编号 / 故障现象 / 工单状态 / 紧急程度 / 计划完成日期 / 施工单位 / 负责人」等别名列头全部可识别；SAP 样例的「设备」列作设备编号，不当位号。
12. **声明行与提示风格**：`tracking.md` 开头有通用声明行，提示用「【注意】」，不含 emoji。

## 再生样例

```bash
node scripts/make-sample.js --out examples            # 默认 seed=1，date=2026-09-21
node scripts/make-sample.js --out examples --seed 7   # 故障描述与人名变化，上述结论不变
```

## MCP 取数对照

> 平台接入设备资产管理 MCP 时不上传附件：`get_work_orders`（不填 for_skill，表名「工单」，默认近 12 个月及全部未关闭工单）的 csv 放新建目录作 `--input`。必须带 `workshop`，脚本 `--workshop` 只写标题不筛选。日常工单每天随演示数据变化，下表只列剧本固定的结论。

| # | 示例问题 | MCP 调用 | 运行参数 | 预期结果 |
|---|---|---|---|---|
| M1 | 常减压车间截至今天哪些工单超期、停滞，出催办清单 | 设备资产管理 `get_work_orders`（workshop=常减压车间） | `--input <目录> --workshop 常减压车间 --date <今天>` | 只统计常减压车间工单（不含加氢车间位号）；SAP 系统状态按 CRTD/REL/PCNF/TECO/CLSD/DLFL 映射；E-1201 管束内漏抽芯工单（PM01、PCNF）计入施工中，不在超期、停滞、临期清单；报告头部有默认时限口径【注意】行 |
| M2 | 只看检维修中心静设备班的工单 | 同 M1 | M1 参数加 `--vendor 静设备班` | 只统计工作中心含「静设备班」的工单，E-1201 抽芯工单在内（施工中）；催办清单只有检维修中心静设备班的分组，无超期、停滞时写「无需催办」 |
| M3 | 加氢车间工单超期和完成率 | 设备资产管理 `get_work_orders`（workshop=加氢车间） | `--input <目录> --workshop 加氢车间 --date <今天>` | 只统计加氢车间工单（位号均为 5 字头加氢装置设备）；完成率 = 已闭环 ÷（已知状态 − 已取消），TECO 归待验收不进分子 |
