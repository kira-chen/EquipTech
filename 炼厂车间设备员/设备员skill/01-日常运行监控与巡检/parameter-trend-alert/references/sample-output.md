## 措辞对照

| 场景 | 应写 | 不应写 |
|---|---|---|
| 到限预测 | 「按线性外推约 9.9 天后达到高报」 | 「9.9 天后设备损坏 / 故障」 |
| 越高高报 | 「已越高高报，请核对 DCS 报警记录并报车间设备主任」 | 「必须立即停机」 |
| 振动分区 | 「按厂内限值表已接近不宜长期运行的区间」 | 「ISO 10816 查表 C 区上限 7.1 mm/s」（不自给分区数值） |
| 期数不足 | 「只有 2 期数据，不足以判断趋势」 | 「两期之间涨了 90%，劣化严重」 |
| 低 R² | 「数据离散，趋势不明显，暂不外推到限时间」 | 挑个斜率硬给一个到限天数 |
| 缺测点 | 「该期数值未记录，已按缺测处理」 | 「该期为 0」 |
| 无限值 | 「未提供限值，未做越限判定」 | 「均未越限」 |
| 振动上升 | 「建议加密点检并安排频谱采集」 | 「确诊为轴承损坏，需更换」 |
| 温度上升 | 「建议核实润滑与冷却，结合工况一起看」 | 「必须立即停机」 |
| 电流上升 | 「先核对处理量，排除负荷因素」 | 「确认为机械卡涩」 |
