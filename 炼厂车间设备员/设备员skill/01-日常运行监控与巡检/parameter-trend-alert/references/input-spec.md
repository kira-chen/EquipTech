# 输入规格：参数越限与劣化趋势预警

## 参数记录（必需）

sheet 名匹配「参数记录」「参数数据」「监测记录」「趋势数据」「测点数据」「参数」。支持两种形态，脚本自动识别：

### 长表（一行一个采集点）

| 列名 | 必需 | 说明 |
|---|---|---|
| 采集时间 | 是 | 无法解析 → 该点不参与趋势计算并 warning，**不猜时间**；缺此列直接报错 |
| 数值 | 是 | 无法解析 → 该点记为 null 并单列，**绝不按 0 计入趋势计算**；带单位（78℃、4.5mm/s、0.35MPa）自动剥离单位取数，每列提示一次请核对单位一致；缺此列直接报错 |
| 位号 | 位号与测点号至少一列 | 设备位号 / SAP 功能位置。为空且无测点号的行跳过并 warning |
| 测点号 | 位号与测点号至少一列 | DCS 仪表位号（TI-1101、VI-2201）。与设备位号分列展示；无位号时用测点号作序列键并 warning 提醒核对所属设备 |
| 参数名 | 参数名与测点号至少一列 | 「位号 + 参数名」构成一条序列；无参数名时用测点号代替并 warning |
| 设备名称 | 否 | SAP 设备描述 / 功能位置描述 |
| 单位 | 否 | 限值表里也有时以参数记录为准 |

一条序列示例：

| 设备位号 | 设备名称 | 参数名 | 采集时间 | 数值 | 单位 |
|---|---|---|---|---|---|
| P-1101A | 常压塔顶回流泵A | 振动速度 | 2026-09-01 08:00 | 4.2 | mm/s |
| P-1101A | 常压塔顶回流泵A | 振动速度 | 2026-09-04 08:00 | 4.8 | mm/s |
| P-1101A | 常压塔顶回流泵A | 振动速度 | 2026-09-07 08:00 | 5.3 | mm/s |

DCS 导出常见的「仪表位号 / 时间 / PV」三列表也可读：测点号兼作序列键与参数名。

### 宽表（一列一期）

表头里有 **≥3 个可解析为日期的列头**（须含年份，如 `2026-09-01`、`2026/9/1`，或 Excel 日期单元格）且有位号或测点号列时识别为宽表，自动展开为长表：日期按列头、时间按 00:00；**空格视为该期未测，不按 0**。

| 功能位置 | 功能位置描述 | 仪表位号 | 参数名称 | 工程单位 | 2026-09-01 | 2026-09-04 | 2026-09-07 |
|---|---|---|---|---|---|---|---|
| P-2101A | 加氢进料泵A | TI-21011 | 轴承温度 | ℃ | 62.1 | 64.3 | 66.0 |

- 宽表没有「参数名」列时用 `--wide-param "<参数名>"` 统一指定，否则报错（脚本不猜参数名）。
- 列头只写「9/1」「9月1日」这类无年份的，脚本不猜年份，请补成 `2026-09-01` 后再传。
- `--wide` 可强制按宽表读取，未识别出日期列头时报错。

## 报警限值（可选）

sheet 名匹配「报警限值」「限值」「报警限值表」「报警设定」「限值表」。支持两级限值，也兼容只给上下限的单级表。**限值以 DCS 组态或厂内限值表为准，脚本不自定限值、不替用户补限值。**

| 列名 | 必需 | 说明 |
|---|---|---|
| 参数名 | 是 | 与参数记录按「位号 + 参数名」或「测点号 + 参数名」配对；DCS 三列表按「测点号」配对 |
| 位号 / 测点号 | 至少一列 | |
| 上限（高报 H） | 否 | |
| 上上限（高高报 HH） | 否 | 须 ≥ 高报；小于时 warning 请核实，不自动交换 |
| 下限（低报 L） | 否 | |
| 下下限（低低报 LL） | 否 | 须 ≤ 低报 |
| 单位 | 否 | |

四项全空或无法解析 → 该项不判越限并 warning。同一位号+参数出现两次 → 以后一条为准并 warning。

**未提供限值表时**：脚本只计算趋势、不判越限、不预测到限时间，并 warning 说明；概览中越限一栏显示「—（未提供限值表）」而不是 0。
**提供了限值表但某条序列查不到对应限值时**：该序列同样只算趋势不判越限，并 warning 指明。

## 列名别名

局部别名在前，再合并共享 `SYSTEM_ALIASES`（口径对照第二节）。局部别名**不含**「设备编号」——SAP 设备编号是 8 位流水号，不是位号；只有「设备编号」列的表会报"既无位号也无测点号"。

| 标准列名 | 可识别写法（局部 + 共享） |
|---|---|
| 位号 | 设备位号、位号、TAG、功能位置、功能位置编号、技术标识、技术对象、技术对象标识、位号编码 |
| 测点号 | 测点号、仪表位号、测点、点号、PI/TI位号、DCS位号、仪表TAG |
| 设备名称 | 设备名称、名称、功能位置描述、设备描述、技术对象描述、描述 |
| 参数名 | 参数名称、参数名、测点名称、测点描述、监测参数、参数、监测项目、测量参数 |
| 采集时间 | 采集时间、记录时间、检测时间、测量时间、采样时间、时间戳、日期时间、日期、时间 |
| 数值 | 数值、测值、测量值、实测值、读数、值、当前值、PV |
| 单位 | 单位、计量单位、工程单位、基本计量单位 |
| 上限 | 报警上限、上限值、上限、高限、高报、高报值、高报限值、H、HI、PH |
| 上上限 | 高高报、高高限、高高报值、高高报限值、上上限、HH、PHH、联锁上限 |
| 下限 | 报警下限、下限值、下限、低限、低报、低报值、低报限值、L、LO、PL |
| 下下限 | 低低报、低低限、低低报值、低低报限值、下下限、LL、PLL、联锁下限 |

匹配规则：去空白后先全等、再前缀；全等轮先于前缀轮，所以 `HH` 不会被 `H` 抢走。

## 时间格式

支持 `2026-09-01 08:00`、`2026/9/1 8:00`、纯日期 `2026-09-01`（按 00:00）、Excel 日期单元格、Excel 序列号。无法解析时 warning 并跳过该点。

**采集时间重复**（同一序列两条记录时间相同）：warning 并**原样保留，不自动去重**。

## 其他参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--periods` | 12 | 回溯期数，取每条序列最近 N 期；须为不小于 3 的整数 |
| `--from` | 无 | 起始日期，写入报告头部；晚于 `--date` 时报错 |
| `--equipment` | 无 | 限定位号或测点号，逗号分隔；范围内无记录时报错 |
| `--param` | 无 | 限定参数名，逗号分隔 |
| `--threshold` | 无 | 斜率告警阈值（单位/天，绝对值）；仅在 R² ≥ `--r2-min` 时生效 |
| `--r2-min` | 0.5 | 给到限日期 / 判恶化的 R² 下限，0~1 |
| `--horizon` | 365 | 到限关注窗口（天），外推超过此天数不作预警 |
| `--wide` | 否 | 强制按宽表读取 |
| `--wide-param` | 无 | 宽表无参数名列时统一指定 |

## 会被跳过 / 不参与计算的行

| 情况 | 处理 |
|---|---|
| 全空行 | 跳过 |
| 首列以 合计 / 小计 / 总计 开头 | 跳过并 warning（长表、宽表均适用） |
| 位号与测点号均为空，或参数名与测点号均为空 | 跳过并 warning |
| 采集时间无法解析 | 该点不参与趋势，单列并 warning |
| 数值无法解析 | 该点记 null 单列，**不按 0** 计入趋势 |
| 宽表空格 | 视为未测，不生成采集点 |

## 期数不足的处理（最关键）

一条序列的**有效期数**（能同时解析出时间与数值的点数）**少于 3 期**时：

- 归入 `insufficientData` 单列一节
- `slope`、`r2`、`changeRate`、`daysToLimit`、`etaDate` 全部为 `null`
- **不得用两点连线当作趋势，不得预测到限时间**
- 若最新值已越限，越限本身是单点事实，仍进入越限清单，但依然不给斜率与到限预测

全部采集时间相同（时间跨度为 0）时同样归入 `insufficientData`，斜率无定义不猜。

| 文件 | 内容 |
|---|---|
| `trends.json` | 逐序列趋势计算结果（含 `pointTag`、`limitLevel`、`limitHighHigh`/`limitLowLow`）、四类清单、计数（含 `overHighHigh`/`overHigh`）、数据质量明细、`meta.inputShape` |
| `alert.md` | 六节报告，分析段留占位符，末尾两条声明行 |
| `summary.json` | 末行摘要落盘 |
