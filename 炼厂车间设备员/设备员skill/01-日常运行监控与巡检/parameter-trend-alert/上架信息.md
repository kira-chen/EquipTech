# 参数越限与劣化趋势预警
**技能名称**：参数越限与劣化趋势预警

**技能简介**：把多期振动、温度、压力、电流数据交给脚本算趋势，按高报/高高报两级判越限，给出已越限、趋势恶化（含线性外推到限时间）、稳定、数据不足四类清单，帮车间设备员在参数到高报前排上复测和点检。辅助预警，不替代精密诊断与停机决策。

**技能描述**

面向炼化厂车间设备员，看振动、温度、压力、电流这些参数是不是在往限值走。上传点检仪、状态监测、DCS 趋势导出或手工巡检表（长表、一列一期的宽表都行），再给一张报警限值表，脚本按最小二乘算每台设备每个参数的斜率和 R²，先判已越高报、高高报，再对还没越限但在恶化的参数做线性外推，给出预计到限天数和日期，输出已越限、趋势恶化、稳定、数据不足四类清单。只有一两期数据的标数据不足，不用两点连线当趋势；填"未记录"的按缺测，不按 0 算；没给限值表就只算趋势不判越限。适合在参数到高报前排复测和点检。到限时间是统计外推不是故障预测，数字由脚本算，模型只写说明；不诊断原因，不改报警限值和联锁定值，不判停机。

**示例问题**
1. 附件是常减压车间这三周的泵振动和轴承温度点检记录，带报警限值表，帮我看看哪些已经越高报、哪些振动在往上走、大概几天到高报。　　**附件：** `sample-trend.xlsx`
2. 这张表里空压机电机电流有一期填的是"未记录"，鼓风机电机振动只测了两次，你算趋势的时候会怎么处理这两个？不要把缺测当 0。　　**附件：** `sample-trend.xlsx`
3. 这是加氢车间从 DCS 导出来的趋势表，一列一个日期，前面是功能位置和仪表位号，限值表是 H/HH 列头，能直接算吗，哪台进料泵轴承温度在涨。　　**附件：** `sample-dcs-wide.xlsx`
4. 我们车间还没整理报警限值表，只有加氢进料泵这几周的振动记录，先帮我看看趋势是不是在涨，涨得快不快。　　**附件：** `sample-no-limit.xlsx`
5. 这台泵振动从 3.0 涨到 8.6，高报是 9.0，是不是马上就要越限了？只有两次测量数据。　　**附件：** `sample-two-points.xlsx`
