# scripts 使用说明

## trend.js —— 主脚本

```bash
node "<技能目录>/scripts/trend.js" \
  --input "<参数记录xlsx>" \
  --workshop "<车间名>" \
  --date <YYYY-MM-DD> \
  --out "<输出目录>"
```

### 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| `--input` | 是 | 含「参数记录」（别名：参数数据/监测记录/趋势数据/测点数据）工作表的 xlsx 或同结构 CSV 目录；可另含「报警限值」（别名：限值/报警设定）。长表与宽表（一列一期）均可，自动识别 |
| `--workshop` | 是 | 车间名称 |
| `--date` | 是 | 分析截止日期 |
| `--out` | 否 | 输出目录，默认 `<os.tmpdir()>/pta-out`（系统临时目录），**建议始终传 `--out`** |
| `--periods` | 否 | 回溯期数，默认 12；须为不小于 3 的整数 |
| `--from` | 否 | 起始日期；晚于 `--date` 时报错 |
| `--equipment` | 否 | 限定位号或测点号（仪表位号），逗号分隔 |
| `--param` | 否 | 限定参数名，逗号分隔 |
| `--threshold` | 否 | 斜率告警阈值（单位/天，绝对值），须 ≥ 0；仅在 R² ≥ `--r2-min` 时生效 |
| `--r2-min` | 否 | 判恶化/给到限日期的 R² 下限，默认 0.5，取值 0~1。R² 低于此值视为数据离散、斜率不可靠，不给到限日期。厂内有自己的判据可调 |
| `--horizon` | 否 | 到限关注窗口（天），默认 365，须为 ≥1 的整数；外推到限超过此天数不作为预警呈现 |
| `--wide` | 否 | 强制按宽表读取；未识别出 ≥3 个日期列头时报错 |
| `--wide-param` | 否 | 宽表没有「参数名」列时统一指定参数名（脚本不猜）；长表时忽略并 warning |

### 产出

| 文件 | 内容 |
|---|---|
| `trends.json` | 逐序列趋势结果 + `overLimit`/`deteriorating`/`stable`/`insufficientData`/`counts`（含 `overHighHigh`、`overHigh`、`twoLevelLimits`）+ `meta`（`r2Min`、`horizonDays`、`inputShape`、两条声明） |
| `alert.md` | 六节报告，分析段留占位符，末尾两条声明行 |
| `summary.json` | 末行摘要落盘 |

### 退出码
- `0`：成功
- `1`：失败（无「参数记录」表、无采集时间/数值列、既无位号也无测点号列、宽表无参数名且无 `--wide-param`、非法日期、periods < 3、负斜率阈值、r2-min 不在 0~1、horizon < 1、范围内无记录、输入不存在）

### 关键行为

1. **期数不足 3 期不算趋势**。有效期数 < 3 的序列归入 `insufficientData`，斜率、R²、变化率、到限时间全部 `null`。两点连线不是趋势。若最新值已越限，越限是单点事实仍会呈现，但依然不给趋势与预测。
2. **数值无法解析记 null 不记 0**。「未记录」「/」这类值按缺测处理并单列；宽表空格视为未测。带单位的数值（`78℃`、`4.5mm/s`、`0.35MPa`）剥离单位取数，每列只提示一次请核对单位一致。
3. **未提供限值表只算趋势不判越限**。概览显示「—（未提供限值表）」而不是 0；查不到限值的单条序列同样只算趋势。**脚本不自定限值**，限值以 DCS 组态或厂内限值表为准。
4. **两级限值**。限值表可给 高报/高高报/低报/低低报（H/HH/L/LL、PH/PHH/PL/PLL、上限/上上限/下限/下下限）。先判 HH/LL，再判 H/L；越 HH/LL 的排在越限清单最前并在 md 加「【注意】」。两级都给时到限时间先向最近一级（H/L）外推，只给 HH/LL 时向 HH/LL 外推。HH<H 或 LL>L 时 warning 请核实，不自动交换。
5. **宽表自动转长表**。表头里有 ≥3 个可解析为日期的列头（含年份，或 Excel 日期）且有位号/测点号列时识别为宽表；日期按列头、时间按 00:00。列头只写「9/1」这类无年份的不猜年份，按长表读取后因缺采集时间列报错。
6. **测点号与设备位号分列**。功能位置/设备位号归位号，仪表位号/测点号/测点归测点号；无位号时用测点号作序列键并 warning 提醒核对所属设备；限值表可按位号或测点号配对。SAP「设备编号」（8 位流水号）不作位号别名。
7. **方向不对不预测**。斜率为正只向上限外推，为负只向下限外推。已越限的不再预测。
8. **R² 与到限窗口两道闸**。R² < `--r2-min`（默认 0.5）不给到限日期；外推到限 > `--horizon`（默认 365 天）不作为预警呈现。两种情况在 `etaNote` 写明原因与参数名，归入「趋势稳定」。
9. **采集时间重复不去重**。原样保留并 warning。
10. **声明行**。md 末尾固定两条：线性外推声明；"本材料由脚本汇总、模型成文，仅供设备员复核参考，不替代审批、定性、验收与签字；厂内制度与系统数据为准。" 产出不用 emoji，醒目提示用「【注意】」。

### 置信提示分档

| R² | 文案 |
|---|---|
| ≥ 0.8 | 趋势明显 |
| 0.5 ~ 0.8 | 趋势一般 |
| < 0.5 | 数据离散，趋势不明显 |

有效期数 < 5 期时追加「（仅 N 期，期数偏少，置信有限）」并把置信等级降一档。分档文案固定；`--r2-min` 只改变"给不给到限日期/判不判恶化"的闸值。

## make-sample.js

```bash
node scripts/make-sample.js --out examples [--seed <n>]
```

- `sample-trend.xlsx`（长表，两级限值）恒 7 条序列：2 条已越限（1 条越高高报、1 条越高报）、2 条趋势恶化、2 条稳定、1 条只有 2 期（数据不足）、1 个无法解析的数值、1 组采集时间重复、1 个带「℃」后缀的数值。
- `sample-dcs-wide.xlsx`（宽表，DCS/SAP 列名：功能位置、功能位置描述、仪表位号、参数名称、工程单位、H/HH/L/LL）恒 3 条序列：1 条恶化、1 条稳定、1 条数据不足（宽表空格）。
- `sample-no-limit.xlsx`：无限值表。`sample-two-points.xlsx`：只有 2 期。

`--seed` 变则数值抖动变，但各类条数不变。

## selftest.js

```bash
node scripts/selftest.js
```

247 条断言，覆盖基础回归与四类分档、期数不足 3 期不算趋势不预测、数值不可解析不按 0、未提供限值表不判越限、方向不对不预测、采集时间重复不去重、R² 分档与置信文案、预测免责声明行、回溯期数与范围过滤、参数校验、产出落盘、别名与合计行、样例可再生（长表与宽表）、**两级限值 H/HH/L/LL 判定与外推顺序、英文列头、HH<H 核实提示**、**宽表自动识别与转换（空格不按 0、带单位、--wide-param、无年份列头不猜）**、**--r2-min / --horizon 参数化**、**SAP/DCS 列名别名（功能位置、设备描述、测点号、采样时间、测量值、PH/PHH）、设备编号不作位号、仅仪表位号导出**、通用声明行、默认输出目录在系统临时目录、md 无 emoji。
