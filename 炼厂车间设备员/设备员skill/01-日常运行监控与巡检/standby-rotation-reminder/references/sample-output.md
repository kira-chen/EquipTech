## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 切换逾期 | 「切换逾期 14X 天，已漏掉整轮周期，建议优先安排」 | 「主泵超期服役，随时可能损坏」 |
| 当前主用 | 「当前主用为 B 泵（按切换记录推导），与台账相反，请核对」 | 「切了奇数次所以现在是 B 泵」 |
| 无法判定 | 「台账未填切换周期，未按默认周期推算，需补齐后重跑」 | 「按一般一月一切估计已到期」 |
| 配对异常 | 「备用位号为空，主备配对无法确定，未作判定」 | 「按位号规律推测备用应为 P-37XXB」 |
| 长期未切换 | 「距上次切换 20X 天，超出 2 倍切换周期阈值，建议先盘车或试运确认可用性」 | 「备泵已锈死，需解体检查」 |
| 检修中备机 | 「备机检修中，不进提醒清单，验收后更新台账」 | 「P-36XX 切换逾期 150 天」 |
| 执行率分母 0 | 「本区间内无切换计划，执行率不适用，显示「—」」 | 「切换执行率 0%」 |
| 切换实施 | 「联系工艺确认切换条件后按操作票执行」 | 「明日 8 点切至 B 泵，先开备泵再停主泵」 |
