# 运行小时与启停次数统计
**技能名称**：运行小时与启停次数统计

**技能简介**：把启停记录、运行状态记录或运行记录累计成"自上次大检修后"的运行小时与启停次数，对照运行小时、启停次数和日历周期（年）三类阈值，列出已超、临期、未判定清单，供申报大检修与部件更换。

**技能描述**

面向炼化厂车间设备员，统计机泵、压缩机、风机等关键设备自上次大检修后的累计运行小时和启停次数。上传启停记录、巡检系统导出的运行状态记录或直接记运行时长的台账，再给一张阈值表，脚本按"期初累计加本期增量"逐台累计，对照运行小时、启停次数、按年算的检修周期三类阈值，列出已超、临期、未判定三份清单，产出报告和 JSON，累计小时可直接给润滑管理技能用。只有开机没停机的段不补、重叠区间不去重、阈值类型没填不默认，一律单列说明。适合月度运行统计、申报大检修、部件寿命跟踪。数字全由脚本算，模型只写说明；不做剩余寿命评估，不编检修计划，检修时机由设备工程师定。

**示例问题**
1. 这是常减压车间 9 月的机泵启停记录和阈值表，帮我统计自上次大检修累计运行多少小时、启停多少次，哪些到了大修周期。　　**附件：** `sample-runtime.xlsx`
2. 渣油泵有一条记录只填了开机没填停机，联轴器那行阈值类型也没填，你算的时候别瞎补，告诉我哪些算不了、缺什么。　　**附件：** `sample-runtime.xlsx`
3. 这是从 SAP 导出来的催化主风机开停机记录和检修周期表，功能位置和设备号都在里面，帮我看运行小时和三年大检修周期到没到，到期日是哪天。　　**附件：** `sample-sap-export.xlsx`
4. 巡检系统导出的是每个时间点的运行/停机状态，不是启停段，加氢循环泵能不能按这个算运行小时。　　**附件：** `sample-status-series.xlsx`
5. 台账里直接记的是运行时长带 h 的，有一台写的"未记录"，帮我按阈值判一下，不要把没记录的当 0。　　**附件：** `sample-run-hours.xlsx`
