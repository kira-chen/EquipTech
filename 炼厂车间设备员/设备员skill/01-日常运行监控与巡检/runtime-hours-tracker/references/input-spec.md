# 输入规格：运行小时与启停次数统计

列名匹配：去空白后全等优先，再前缀匹配；局部别名在前，再合并共享 `SYSTEM_ALIASES`（SAP PM / EM / 智能巡检导出列名）。

## 数据来源（三种，至少提供一种；优先级 启停记录 > 运行状态记录 > 运行记录）

### 启停记录（推荐）

sheet 名匹配「启停记录」「开停机记录」「开停车记录」「启停」。一行一段运行。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 为空的行跳过并 warning |
| 开机时间 | 否 | 见下方时间格式 |
| 停机时间 | 否 | 只有其一时该段不计入累计，单列 |
| 设备名称 | 否 | |
| 设备编号 | 否 | SAP 设备流水号，仅展示 |

### 运行状态记录（时序）

sheet 名匹配「运行状态记录」「状态时序」「状态记录」「运行状态」「开停状态」。一行一个状态点，脚本按位号排序后把「运行 → 停机」折算为一段运行。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | |
| 时间 | 是 | 无法解析的行跳过并 warning |
| 运行状态 | 是 | 运行/开机/启动/RUN/ON/1 → 运行；停机/停车/停运/备用/检修/停用/OFF/0 → 停机；其他 → 跳过并 warning |
| 设备名称、设备编号 | 否 | |

规则：连续多条"运行"视为同一段，只计一次启动；末条为运行且无后续停机 → 单列不计入（不按截止时间补）；首条为停机 → 单列。同一位号同时出现在启停记录中时，以启停记录为准。

### 运行记录

sheet 名匹配「运行记录」「运行时长记录」「运行台时」「运行」。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | |
| 运行时长 | 否 | 支持带单位（`168h`、`72 小时`）；无法解析 → null（不计入），**绝不按 0** |
| 设备名称、设备编号 | 否 | |

与启停/状态记录同时存在时以后者为准，运行记录值仅作参考并 warning。

## 阈值表（可选）

sheet 名匹配「阈值表」「阈值」「周期阈值」「检修周期」。同一位号可有多条（不同部件、不同类型）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | |
| 阈值类型 | 否 | 见下表三类；为空时按阈值取值的单位推断，推不出 → 未判定（**不默认按运行小时**） |
| 阈值 | 否 | 为空或无法解析时该项不预警；可带单位（`24000h`、`3年`） |
| 部件 | 否 | 如「轴承」「机械密封」「机组」；部件为空/整机/机组 的行作为设备级期初 |
| 上次归零日期 | 否 | 上次大检修/更换日期；**日历周期阈值必需**，缺则未判定 |
| 期初累计小时 | 否 | 上次大检修（或部件更换）后至本期统计起点的累计运行小时；累计 = 期初 + 本期增量。整列缺失 → warning，累计仅为本期增量 |
| 期初累计启停 | 否 | 同上，启停次数基数 |
| 设备名称 | 否 | 仅用于本期无运行记录的设备显示名称 |

阈值表里有、但启停/状态/运行记录里没有的位号，按「本期无运行记录」列出：本期 0h、0 次，累计取期初/上期值照常判阈值，并 warning 点名。

### 阈值类型三类

| 阈值类型写法 | 归类 | 比对对象 | 取值写法 |
|---|---|---|---|
| 含「启停」「次数」「启动」 | starts | 累计启停次数 | 数字 |
| 含「日历」「年」「月」「季」「天」 | calendar | 自上次归零日期起已运行天数 vs 周期；到期日 = 归零日期 + 自然月 | `3年` / `36个月` / 类型写"日历周期（年）"+ 数字 3 |
| 含「小时」「运行」「台时」「h」 | hours | 累计运行小时 | `8000` / `24000h` |
| 为空 | 按取值：`24000h` → hours，`3年` → calendar，纯数字 → **未判定** | | |
| 其他（如"振动"） | 未判定 | | |

「阈值类型」不再认裸「类型」列头（避免把 SAP「设备类型/对象类型」误认为阈值类型）。

## 时间格式

支持 `2026-09-01 08:00`、`2026/9/1 8:00`、Excel 日期单元格、Excel 序列号。无法解析时 warning 并按该字段缺失处理。日期按北京时间解释。

## 其他参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--from` | 无 | 统计起始日期，仅写入报告头部；晚于 `--date` 时报错 |
| `--prev` | 无 | 上期 `runtime.json`，累计续算；与期初累计并存时以 `--prev` 为准；上期截止日不早于本期最早运行段时 warning（会重复计入）；上期累计小时为空 → 本期累计 null，不按 0 续算 |
| `--running-until` | 无 | `YYYY-MM-DD HH:mm`；每台时间上最后一段（上一段停机时刻等于本段开机时刻也算最后一段）、停机时间为空（或状态末条为运行）的段按「截至该时刻仍在运行」计入并 warning（同台更早的空停机行仍单列），仅用于明确以空停机时间表示仍在运行的数据源（如 DCS 启停记录）；不给则单列不配对 |
| `--equipment` | 无 | 限定位号，逗号分隔；范围内无记录时报错 |
| `--warn-ratio` | 0.9 | 接近阈值的预警比例，须在 0~1 之间 |
| `--out` | `<os.tmpdir()>/rht-out` | 建议始终传 |

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 等开头的行（warning）
- 位号为空的行（warning）
- 状态记录中时间或运行状态无法解析的行（warning）

## 产出

| 文件 | 内容 |
|---|---|
| `runtime.json` | 逐台累计、阈值判定、超阈值与临期、未判定、数据不完整项、`items[]`（下游用） |
| `runtime-report.md` | 七节报告，分析段留占位符 |
| `summary.json` | 末行摘要落盘 |
