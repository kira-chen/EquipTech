## 平台接入业务系统 MCP 时

> 不上传附件，数据由 MCP 工具获取；演示数据每天按剧本刷新，题目只依赖剧本里固定的位号和现象。

M1. 常减压车间的机泵和压缩机自上次大检修累计运行多少小时了？哪些超了 8000 小时、哪些快到了，还在运行的算到现在。　　**数据：** MCP DCS位号数据 `get_run_events`（workshop=常减压车间）、设备资产管理 `get_maintenance_plans`（workshop=常减压车间，for_skill=runtime-hours-tracker）；运行时加 `--running-until "<DCS 数据截止时刻>"`（演示数据为当天 09:00）
