## 措辞对照

| 场景 | 本示范写法 | 不应写成 |

| 特护设备 | 「特护设备主风机 K-31XX……接班后第一时间完成」 | 「主风机顺便看一眼」 |
| 逾期项 | 「已逾期 1.5 小时，上次记录为报警，请如实记录数值」 | 「主风机估计已经出问题了」 |
| 周期待确认 | 「脚本未按日检默认排期，已单列，请确认周期后补入标准表」 | 「暂按日检安排，先检着」 |
| 无标准设备 | 「没有对应巡检标准，本班未排任务，需要补齐」 | 「参照同类离心泵的标准先检一下」 |
| 路线 | 「建议顺序仅供参考，实际走法请班长按现场情况确定」 | 「已按最优路线编排，按序执行即可」 |
| 数字 | 引用 tasks.json 的 counts | 自行统计或估算 |
