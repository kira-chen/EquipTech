## 关键验证点

1. **周期待确认不默认日检**：M-1501「电机接线盒检查」周期为空、I-1601「变送器取压管检查」周期填「视情况」，两项都进 `unscheduled`，**不进任务清单**，warning 明确写「未按日检默认处理」，行号可追溯到巡检标准表。运行小时周期（「运行 2000 小时」）同样进待确认并提示转 runtime-hours-tracker。
2. **特护强制最高优先级**：K-1801 富气压缩机台账「特护=是」，任务为 P1，概览【注意】行点名；逾期项（P2）排在其后。
3. **无巡检标准不造占位项**：A-1701 常压塔顶空冷器按位号与设备类型「空冷器」都匹配不到标准，进 `noStandard` 单列，不生成任何任务项。
4. **标「否」的设备排除**：V-1302 备用储罐台账标「否」，进 `excluded` 并附原因，不出现在任务清单与 `noStandard` 中。
5. **优先级六级**：特护 P1 > 逾期 P2 > 关键设备 A P3 > 上次异常 P4 > 临期 P5 > 常规/未检 P6；`priorityReason` 写明定级理由。
6. **临期阈值随周期比例**：默认周期的 10%，E-1201 法兰泄漏检查（30 天周期，距到期 2 天 ≤ 3 天）临期；P-1101A 的 7 天周期项未到期不进清单。`--due-soon 2` 或 `--due-soon 20%` 可改。
7. **上次记录缺失全按未检**：`sample-no-history.xlsx` 无「上次巡检记录」表，全部设备 `dueStatus` 为 `never`，`meta.lastRecordProvided` 为 `false`，不假设已检过。
8. **`--shift` 可选**：给了按标准表「适用班次」过滤（未填/每班/全部任何班次都排）；不给按全天排不过滤。
9. **班次级周期按小时**：每班=8 小时、每 2 小时；上次记录带时间且给 `--time` 才按小时判逾期，否则「本班到期」并 warning，不捏造逾期小时数。
10. **系统列名与一行一检查项**：SAP 样例的「功能位置/设备/设备描述/工厂区段/ABC标识/对象类型」、智能巡检「检查内容/巡检时间/测值/是否报警」直接识别；同一位号多条明细按位号聚合取最近一次，任一检查项报警即记上次异常。
11. **路线仅为建议**：区域按一区 → 二区聚类、区内按位号升序编号；`meta.routeNote` 与报告末尾均保留「实际巡检路线由车间确定」。

## 再生样例

```bash
node scripts/make-sample.js --out examples            # 默认 seed=1
node scripts/make-sample.js --out examples --seed 7   # 上次巡检日期变化，结论不变
```
