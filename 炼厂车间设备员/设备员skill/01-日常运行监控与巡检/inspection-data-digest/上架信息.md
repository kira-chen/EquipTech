# 巡检点检数据汇总
**技能名称**：巡检点检数据汇总

**技能简介**：把智能巡检 APP、点检仪、状态监测导出的记录按位号聚合成车间设备日状态一览，自动判异常、找漏检、标特护，交车间设备主任复核。

**技能描述**

面向炼化厂车间（运行部）设备员，把智能巡检 APP、点检仪、状态监测三条线的导出表（含一行一检查项的巡检明细、只有测值与上下限的监测表）一次并好。上传一份或多份后，脚本按位号聚合，按"检查结果 → 是否报警 → 测值对限值"判异常，输出运行/备用/检修/停用/异常/未判定六档状态一览、异常项清单（特护设备置顶并提示上报）、同一检查项正常/异常并存的记录冲突（就严判定并列出原始记录）、未判定项；配 SAP 技术对象清单可识别漏检；夜班跨 0 点记录按班次日归属。模型只在脚本数字上写状态分析，不自行统计、不诊断原因。适合每日巡检汇总与日报前数据准备；不生成巡检任务清单、不做趋势预测。

**示例问题**
1. 把今天智能巡检、点检仪和状态监测这三张导出表汇总一下，出常减压车间的设备状态一览，告诉我哪几台异常、有没有特护设备出问题。　　**附件：** `sample-inspection-2026-09-21.xlsx`
2. 汇总今天的巡检点检数据，再对一下 SAP 导出的技术对象清单，看看哪些设备今天没人检。　　**附件：** `sample-inspection-2026-09-21.xlsx + sample-ledger.xlsx`
3. 点检数据还没交上来，先把操作工的智能巡检明细汇总了，异常的先列出来我去现场看。　　**附件：** `sample-patrol-only-2026-09-21.xlsx`
4. 这是系统直接导出的巡检表，第一行是标题，列名是技术标识和技术对象描述，底下还有合计行，帮我看看能不能读、今天有什么异常。　　**附件：** `sample-system-export.xlsx`
5. 夜班有几条巡检记录是过了 0 点才上传的，按班次日（早 8 点起算）算到 9 月 21 日这个班，帮我汇总减压车间的情况。　　**附件：** `sample-night-shift-2026-09-21.xlsx`
