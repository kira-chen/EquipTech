# 设备异常初判与处置建议
**技能名称**：设备异常初判与处置建议

**技能简介**：设备出现振动、异响、温升、泄漏等异常时，结合现象、运行参数、厂内限值和 SAP 通知单历史给出可能原因排序、建议核实项、红/橙/黄关注度和上报建议，供设备员判断要不要报工程师。不替代专业诊断与停机决策。

**技能描述**

面向炼化厂车间（运行部）设备员，在设备出现异常时做快速初判。说明位号、设备类型（泵、压缩机、换热器、电机、安全阀）和现象，可附 DCS 或点检仪导出的运行参数（功能位置、测点号、带单位测值可直接读）、厂内限值表、维修通知单导出。脚本按设备类型选口径表，逐条列出候选原因的支持依据与反证，可能性一律标"需核实"，缺数据的进"未判定"但不从候选里删除。参数趋势只按限值表、行内高报低报或用户给的偏差阈值判，无阈值不判。关注度用红/橙/黄三档，特护设备强制红，信息不全按未判定。不给停机、降负荷意见，不判读频谱、油液、无损结论，确认缺陷只提示在 SAP 建维修通知单。适合现场异常先行排查和向工程师汇报前整理材料。

**示例问题**
1. P-2101A 进料泵振动比平时大，靠近听还有点异响，不是突然出现的，暂时不影响生产，附件是今天的点检参数和这台泵的历史故障记录，帮我判一下可能是什么原因，要不要报工程师。　　**附件：** `examples/sample-params-pump.xlsx + examples/sample-history-pump.xlsx`
2. 同一台泵，这次把厂里的限值表也给你，历史记录是 SAP 导出的通知单，看看哪些参数超限了，原因排序有没有变化。　　**附件：** `examples/sample-params-pump.xlsx + examples/sample-limits-pump.xlsx + examples/sample-history-sap.xlsx`
3. 这是 DCS 导出的趋势表，数值带着单位，有高报低报列，P-2101A 振动大、轴承温度也高，帮我初判。　　**附件：** `examples/sample-params-dcs.xlsx`
4. K-3101 循环氢压缩机出力上不去，流量明显掉了，已经影响装置负荷，附件是近期参数，先帮我理一下可能的原因和要核实的项目。　　**附件：** `examples/sample-params-compressor.xlsx`
5. PSV-3102 安全阀出口侧有介质泄漏，系统压力最近提高过，附件只有压力记录，你看是什么情况，校验的事要不要报。　　**附件：** `examples/sample-params-psv.xlsx`
