# 设备异常初判与处置建议 · 样例问题

> 附件均在 `examples/`（**可再生数据**，`node scripts/make-sample.js --out examples --seed <n>` 重新生成，默认 seed=1）。参数数值与记录人随 seed 变化，但每题的预期结论——候选原因数、未判定项数、关注度档位——不变；预期计数与验证要点见 `examples/README.md` 对照表（仅开发库含，发布包不含）。位号统一用 P-2101A（离心泵）、K-3101（压缩机）、PSV-3102（安全阀）。

1. P-2101A 进料泵振动比平时大，靠近听还有点异响，不是突然出现的，暂时不影响生产，附件是今天的点检参数和这台泵的历史故障记录，帮我判一下可能是什么原因，要不要报工程师。　　**附件：** `examples/sample-params-pump.xlsx + examples/sample-history-pump.xlsx`
2. 同一台泵，这次把厂里的限值表也给你，历史记录是 SAP 导出的通知单，看看哪些参数超限了，原因排序有没有变化。　　**附件：** `examples/sample-params-pump.xlsx + examples/sample-limits-pump.xlsx + examples/sample-history-sap.xlsx`
3. 这是 DCS 导出的趋势表，数值带着单位，有高报低报列，P-2101A 振动大、轴承温度也高，帮我初判。　　**附件：** `examples/sample-params-dcs.xlsx`
4. 现在什么数据都没有，就是操作工说 P-2101A 振动比平时大，先按现象帮我列一下可能原因和要去现场核实的项目，缺什么数据告诉我。　　**附件：** 无
5. 参数表只有一行出口压力，基准值还是空的，这样能判吗？别硬判。　　**附件：** `examples/sample-params-sparse.xlsx`
6. 这份表温度那栏填的是"偏高"两个字不是数字，底下还有合计行，看看能不能读，读不了的地方说清楚。　　**附件：** `examples/sample-params-badnum.xlsx`
7. K-3101 循环氢压缩机出力上不去，流量明显掉了，已经影响装置负荷，附件是近期参数，先帮我理一下可能的原因和要核实的项目。　　**附件：** `examples/sample-params-compressor.xlsx`
8. K-3101 是特护机组，刚才突然振动大，已经影响运行，没来得及导数据，先给我一个关注度和上报建议。　　**附件：** 无（运行时加 `--special 是 --sudden 是 --affects-run 是`）
9. PSV-3102 安全阀出口侧有介质泄漏，系统压力最近提高过，附件只有压力记录，你看是什么情况，校验的事要不要报。　　**附件：** `examples/sample-params-psv.xlsx`
10. 胶带输送机运行时振动大，这种设备你那边有没有口径？没有就别套泵的原因，给我个通用排查框架就行。　　**附件：** 无
