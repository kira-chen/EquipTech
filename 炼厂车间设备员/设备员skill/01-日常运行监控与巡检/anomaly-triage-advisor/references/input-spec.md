# 输入规格：设备异常初判

## 最小调用

```bash
node scripts/triage.js --symptom "<现象描述>" --equip-type "<设备类型>" --tag "<位号>" --out "<输出目录>"
```

现象描述与位号必填，缺任一报错退出。设备类型不填不报错，但只给通用框架并打 warning。

## 命令行字段

| 参数 | 必需 | 说明 | 缺失时的行为 |
|---|---|---|---|
| `--symptom` | 是 | 异常现象描述，自由文本 | 报错退出 |
| `--tag` | 是 | 设备位号 | 报错退出 |
| `--equip-type` | 否 | 设备类型 | warning + 仅通用框架 |
| `--name` | 否 | 设备名称 | 报告中显示「—」 |
| `--time` | 否 | 发现时间，**ISO 8601 带时区**，如 `2026-09-21T08:15:00+08:00` | 非法时报错退出 |
| `--sudden` | 否 | 是否突发（是/否） | **关注度判未判定**，不按最轻或最重默认 |
| `--affects-run` | 否 | 是否影响运行（是/否） | **关注度判未判定** |
| `--special` | 否 | 是否特护设备（是/否） | 不提供不抬档；**是 → 关注度强制红**，上报建议含公司设备管理部门 |
| `--limits` | 否 | 限值表 xlsx | 参数趋势依赖 `--dev-pct` 或参数表行内限值 |
| `--dev-pct` | 否 | 偏差阈值百分比，`15` 或 `温度=10,压力=8,…` | **无限值时参数不判升高/偏低**，不按固定百分比默认 |
| `--recent-repair` | 否 | 近期是否检修（是/否） | 依赖该项的原因判未判定，但仍保留在候选中 |
| `--load` | 否 | 负荷/工况是否调整 | 同上 |
| `--params` | 否 | 运行参数 xlsx 或 CSV 目录 | warning + 参数类依据缺失 |
| `--history` | 否 | 历史故障记录 xlsx 或 CSV 目录 | warning + 历史依据缺失 |
| `--workshop` | 否 | 车间名 | 不影响判定 |
| `--out` | 否 | 输出目录 | 默认系统临时目录 `<os.tmpdir()>/ata-out`，建议始终传 |

### 设备类型识别

匹配规则：**末尾词优先，其次最长匹配**。「离心压缩机」→ 机组类（不被「泵/机」误抢）；「循环氢压缩机电机」→ 电仪类（末尾词电机）；「柴油加氢进料泵A」→ 泵类。

| 归入类型 | 识别关键词 | 用哪张口径表 |
|---|---|---|
| 安全阀（单列） | 安全阀、弹簧式安全阀、先导式安全阀、安全泄放阀、PSV | `fault-patterns-safety-valve.md`（校验与整定以厂内规定与校验报告为准） |
| 泵类 | 离心泵、往复泵、柱塞泵、齿轮泵、螺杆泵、屏蔽泵、磁力泵、计量泵、隔膜泵、真空泵、液下泵、泵 | `fault-patterns-pump.md` |
| 机组类 | 离心/往复/螺杆压缩机、压缩机、风机、鼓风机、引风机、汽轮机、透平、膨胀机、机组、大机组 | `fault-patterns-compressor.md` |
| 静设备类 | 换热器、冷却器、再沸器、空冷（器）、塔、容器、储罐、罐、反应器、管道、管线、法兰、阀门、调节阀、截止阀、闸阀、球阀、加热炉 | `fault-patterns-static.md` |
| 电仪类 | 电机、电动机、马达、变频器、配电、开关柜、软启（动器）、仪表、变送器、流量计、分析仪、热电偶、液位计 | `fault-patterns-electrical.md` |
| **未覆盖** | 以上均不匹配 | `fault-patterns-generic.md`，**只给通用框架** |

### 现象识别

| 现象类型 | 识别关键词 |
|---|---|
| 振动偏大 | 振动、震动、抖动、摆动、晃动 |
| 异响 | 异响、异音、噪音、响声、杂音、敲击、摩擦声、尖叫、啸叫 |
| 温度异常 | 温度高、温升、过热、发烫、高温、超温、温度异常、烫手 |
| 泄漏 | 泄漏、渗漏、滴漏、漏油、漏气、漏水、漏料、冒油、外漏、窜漏 |
| 性能下降 | 流量不足、压力不足、打不上量、出力下降、效率下降、抽空、汽蚀、憋压、压差大 |
| 电流/负荷异常 | 电流、负荷波动、功率波动、跳闸、过载 |
| 仪表指示异常 | 指示不准、示值、偏差、信号、显示异常、无显示、飘移、波动大 |
| 润滑异常 | 油位、油压低、油温、乳化、油质、润滑不良、断油 |

一条描述可同时命中多个现象，各现象的候选原因合并后去重；同一原因在多张现象表里出现时只保留一条，并在 `symptomCn` 中并列两个现象。

## 运行参数工作表（`--params`）

sheet 名匹配「运行参数」「参数记录」「参数」「点检数据」「点检记录」「巡检记录」「监测数据」「运行记录」「DCS」「趋势」「点检仪」。一行一参数（智能巡检/点检仪"一行一检查项"导出可直接用，检查项列作参数名）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 参数名 | 是 | 为空的行跳过并 warning |
| 参数值 | 是 | 无法解析为数字 → warning + null，**绝不按 0 计**；带单位（78℃、4.5mm/s、0.35MPa）自动剥离单位取数值，每列提示一次核对单位 |
| 位号 | 否 | 填了则只取与 `--tag` 一致的行；不填视为本机。SAP「功能位置」是位号；「设备」（8 位流水号）不是 |
| 设备编号 | 否 | SAP 设备流水号 / EM 编码，只展示 |
| 测点号 | 否 | DCS 仪表位号（TI/PI/VI…），只展示，与设备位号区分 |
| 基准值 | 否 | 有基准且有偏差阈值才做「升高/偏低/正常」比较；基准为空则该项不产生依据 |
| 上限 / 下限 | 否 | 行内一级限值（高报/低报/H/L）；有则优先于基准值比较 |
| 偏差阈值 | 否 | 行内偏差阈值%，优先于 `--limits` 与 `--dev-pct` |
| 单位 | 否 | 参与参数类型识别（℃→温度、MPa→压力、mm/s→振动…） |
| 记录时间 | 否 | 无法解析时 warning |
| 备注 | 否 | **优先于数值比较**：备注里的文字结论（如「高频冲击成分明显」）直接作为依据采信 |

### 偏差阈值（不写死，无阈值不判）

| 优先级 | 来源 | 判法 |
|---|---|---|
| 1 | 参数表行内 上限/下限 | 实测 > 上限 → 升高；< 下限 → 偏低；否则正常 |
| 2 | 限值表（`--limits`）上限/下限 | 同上 |
| 3 | 参数表行内 偏差阈值% | (实测-基准)/基准 ≥ +阈值 → 升高；≤ -阈值 → 偏低 |
| 4 | 限值表 偏差阈值% | 同上 |
| 5 | `--dev-pct` 按参数类型 | 同上；`15` 对全部类型；`温度=10,压力=8,振动=20,电流=10,流量=5,液位=10,其他=15` 分类型 |
| — | 都没有 | `trend:null`，warning「未按固定百分比默认」，依赖该参数的原因进未判定 |

参数类型由参数名与单位识别：温度（温度/瓦温/油温/排温/℃）、压力（压力/压差/压降/MPa/kPa）、振动（振动/振幅/振速/位移/mm/s/μm）、电流（电流/功率/负荷率/A/kW）、流量（流量/排量/t/h/m3/h）、液位（液位/罐位/油位/%）、其他。阈值数值由厂内给（限值表来自 DCS 报警组态或设备运行规程），脚本不内置任何百分比或限值。高高报/低低报两级越限请用 `parameter-trend-alert`。

| 列名 | 必需 | 说明 |

## 会被跳过的行

- 首列为「合计 / 小计 / 总计 / 共计 / 总数」的行 → 跳过并 warning
- 整行为空 → 静默跳过
- 参数名为空的行 → 跳过并 warning
- 位号与 `--tag` 不一致的行 → 静默跳过（不算数据缺失）

## 表头识别

表头行取前 10 行中命中必需列最多的一行，因此文件顶部有标题行、空行时仍可正确识别。
