## 平台接入业务系统 MCP 时

> 不上传附件，数据由 MCP 工具获取；演示数据每天按剧本刷新，题目只依赖剧本里固定的位号和现象。

M1. 常减压车间的润滑计划看一下，哪些润滑点该换油了、哪些快到了，近 90 天用了多少油、按单价算多少钱，最近的油样有没有超标的。　　**数据：** MCP 点检巡检App `get_lubrication_ledger`（workshop=常减压车间）、`get_lubrication_records`（workshop=常减压车间）、`get_oil_analysis`（tag=润滑台账里的位号）、`get_oil_prices`；运行时加 `--oil-analysis`
M2. 富气压缩机 C-3101A/B 是按运行 2000 小时换油的，用 DCS 启停记录算的累计运行小时核一下台账，再判到没到期。　　**数据：** MCP 同 M1，另加 DCS位号数据 `get_run_events`（workshop=常减压车间，for_skill=lubrication-manager）
M3. 加氢车间的润滑到期情况出一份，油样结果也带上。　　**数据：** MCP 点检巡检App `get_lubrication_ledger`（workshop=加氢车间）、`get_lubrication_records`（workshop=加氢车间）、`get_oil_analysis`（tag=润滑台账里的位号）、`get_oil_prices`、DCS位号数据 `get_run_events`（workshop=加氢车间，for_skill=lubrication-manager）；运行时加 `--oil-analysis`
