## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 逾期 | 「换油逾期 3X 天，属明显逾期，建议本周内补作业」 | 「润滑严重不足，轴承已受损」 |
| 运行小时周期 | 「按运行 2000 小时换油已超 2XX 小时」 | 「按每天 24 小时折算已逾期 1X 天」 |
| 五定 | 「定人齐备率 83.3%，4 个润滑点未落实责任人」 | 「润滑管理混乱」 |
| 无法判定 | 「台账未填周期，未按常见周期推算，需补齐后重跑」 | 「按一般 3 个月周期估计已到期」 |
| 单位混用 | 「桶与 L 混用，已按单位分列，未作任何换算」 | 「折合约 12X L」 |
| 无限值 | 「未给出厂内判定限值，仅列示数值未作判定」 | 「参照通用标准该值偏低，油品已劣化」 |
| 参考比对 | 「按参考限值表比对超限，非厂内标准仅供参考」 | 「按国标已到换油指标，必须换油」 |
| 油液异常 | 「水分 5XX ppm，超出厂内限值 3XX ppm」 | 「油品乳化，需立即停机换油」 |
| 消耗金额 | 未提供单价时：「未折算金额」 | 「按市价估算约 X 千元」 |
