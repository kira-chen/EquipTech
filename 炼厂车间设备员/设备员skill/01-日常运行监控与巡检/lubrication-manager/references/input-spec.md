# 输入规格：设备润滑管理（五定表）

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一次一个文件：`--input 润滑数据.xlsx`；油品单价表另用 `--price`、累计运行小时另用 `--run-hours`、参考限值表另用 `--ref-standard` 传入
- 列名支持 SAP PM / EM 设备管理信息系统导出写法（共享别名表 `SYSTEM_ALIASES` 已合并），见文末「列名别名」

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「润滑台账」「润滑台账表」「润滑计划」「润滑点台账」「五定表」均可识别。

## 一、润滑台账 / 五定表（必需）

缺此表脚本直接报错终止 —— 它是到期判定的唯一数据源。

| 列名 | 五定 | 必需 | 说明 |
|---|---|---|---|
| 位号 | — | 是 | 设备位号 / SAP 功能位置；为空的行会被跳过并 warning。**SAP「设备编号」（8 位流水号）不是位号**，有该列时单独展示 |
| 油品名称 | 定质 | 是 | 油品牌号，如「L-TSA46 透平油」「3号锂基脂」；品牌词（长城/昆仑/壳牌/美孚…）仅在比对时剥离，展示不改写 |
| 设备名称 | — | 否 | SAP「设备描述 / 功能位置描述」；缺失时报表显示 —，并用于给其余表补设备名 |
| 润滑部位 | 定点 | 否 | 润滑点名称，如「驱动端轴承箱」「主油箱」「减速机」 |
| 润滑方式 | — | 否 | 加油 / 换油 / 补油；含「换」判为换油、含「补」判为补油、含「加」判为加油 |
| 润滑周期 | 定期 | 否* | 见下方「周期表达式」；**为空或无法解析时该项进「无法判定」** |
| 上次加换油日期 | — | 否* | 日历周期必需；**为空或无法解析时该项进「无法判定」**（运行小时周期不依赖此列，但建议填写） |
| 加油量 | 定量 | 否 | 标准/定额加油量；带单位（"12L"）剥离单位取数值并提示；无法解析输出 null 并 warning，**绝不按 0 计** |
| 责任人 | 定人 | 否 | 润滑责任人 / 包机人 / 岗位责任人；**缺此列时「定人」齐备率为 null 并 warning，不按齐备处理** |
| 油品规格 | — | 否 | 如「ISO VG46」「NLGI 3」 |
| 累计运行小时 | — | 否 | 运行小时周期用；缺此列可用 `--run-hours` 提供 |
| 上次加换油时累计小时 | — | 否 | 运行小时周期用：已运行 = 累计运行小时 − 本列 |
| 自上次加换油运行小时 | — | 否 | 运行小时周期用：直接给出已运行小时数，优先于上两列 |

\* 日历周期：周期与上次加换油日期任一缺失即无法算到期日；运行小时周期：缺累计小时或缺上次加换油时小时数即无法判定。**脚本绝不按一月一次之类的常见周期默认填补，也不把运行小时折算成日历天。**

### 五定齐备率

| 五定 | 对应列 | 齐备率 |
|---|---|---|
| 定点 | 润滑部位 | 已填行数 ÷ 参与判定行数 |
| 定质 | 油品名称 | 同上 |
| 定量 | 加油量 | 同上 |
| 定期 | 润滑周期 | 同上 |
| 定人 | 责任人 | 同上；**台账无此列 → null** |

三过滤（领油、转桶、加油）是现场作业要求，台账无对应列，不统计；检查要点见 `lube-rules.md`。

### 周期表达式

| 写法 | 解析 |
|---|---|
| `每班` / `1班` | 日历周期 8 小时（三班两运转 12 小时班取较严的 8 小时） |
| `每2小时` / `2h`（≤168 小时） | 日历周期，按小时折算为小数天 |
| `每天` / `每周` / `每月` / `每季` / `每年` | 1 / 7 / 30 / 90 / 365 天 |
| `半月` / `半年` | 15 / 182 天 |
| `30d` / `30天` / `2w` / `2周` / `3m` / `3个月` / `1q` / `1y` / `1年` / `两年` | 按天折算（月=30、年=365） |
| 纯数字 `180` | 180 天 |
| **`运行2000小时` / `2000h` / `2000H` / `每运行2000小时`**（> 168 小时） | **运行小时周期**，按累计运行小时判定 |
| `视情况`「随机组检修」 | **无法解析 → 该项进「无法判定」** |

日历周期：应到期日 = 上次加换油日期 + 周期天数。
运行小时周期：剩余小时 = 周期小时 − 已运行小时；剩余 < 0 逾期，≤ `--lead-hours` 临期。

## 二、加换油记录（可选）

缺此表时不输出油品消耗统计，warning 提示，报告该节写「未提供」。

| 列名 | 必需 | 说明 |
|---|---|---|
| 日期 | 是 | 加换油作业日期 |
| 位号 | 是 | 为空的行会被跳过并 warning |
| 油品名称 | 是 | 消耗统计的分组键（按原写法分列） |
| 数量 | 是 | 无法解析时计入「数量缺失条数」，**绝不按 0 计** |
| 类型 | 否 | 加油 / 换油 / 补油 |
| 单位 | 否 | L / kg / g / 桶 / 支；**多种单位并存时按单位分别统计，不做换算** |
| 执行人 | 否 | |

## 三、油液分析（可选）

缺此表时报告第七节写「未提供油液分析数据」，`counts.oaAbnormal` 为 `null`（不是 0）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 为空的行会被跳过并 warning |
| 检测项 | 是 | 粘度 / 水分 / 铁含量 / 铜含量 / 酸值 / 闪点等 |
| 检测值 | 是 | 无法解析时不判异常，**绝不按 0 计** |
| 取样日期 | 否 | |
| 限值 | 否* | **厂内**判定限值（厂内换油指标），见下方「限值表达式」 |
| 结论 | 否 | 化验室结论原文，脚本照录不改写 |
| 油品名称 | 否 | 缺失时取台账中该位号的油品，用于参考限值表的油品类型匹配 |

\* **限值为空或无法解析时，该检测项只列示数值、不判异常**，进 `oilAnalysis.noLimit` 单列一节并 warning。脚本**不内置、不引用任何通用限值或行业经验值替代厂内标准**；仅当用户用 `--ref-standard` 显式提供参考限值表时，这些项才进 `oilAnalysis.refChecked` 做参考比对并标注"非厂内标准，仅供参考"。

### 限值表达式

| 写法 | 判异常条件 |
|---|---|
| `≤300` / `<=300` / `不大于300` / `不超过300` | 实测 > 300 |
| `<300` | 实测 ≥ 300 |
| `≥40` / `>=40` / `不低于40` | 实测 < 40 |
| `>40` | 实测 ≤ 40 |
| `198~242` / `40-60` / `2至8` | 实测落在区间外 |
| 纯数字 `50` | 按上限处理：实测 > 50 |
| **`参照标准`「见报告」「按厂家要求」** | **无法解析 → 只列数值不判异常** |

## 四、油品单价表（可选，`--price`）

工作表名「油品单价」。缺此参数时不折算金额，报告写「未使用任何估计单价」。

| 列名 | 必需 | 说明 |
|---|---|---|
| 油品名称 | 是 | 与加换油记录中的写法按归一后匹配（忽略品牌词、空格、横杠、大小写） |
| 单价 | 是 | 元；无法解析则该油品不折算并 warning |
| 单位 | 否 | 填写时按「油品+单位」精确匹配；留空则对该油品任一单位通用 |

单价表中找不到匹配项的油品/单位组合，金额列显示「—」并注明「单价表无匹配项」，**不使用估计单价**。

## 五、累计运行小时（可选，`--run-hours`）

两种形态任选其一：
- `runtime-hours-tracker` 产出的 `runtime.json`：读 `byEquipment[].tag` 与 `cumHours`；`cumHours` 为空的设备 warning 并不判定。
- xlsx：工作表「累计运行小时」（或首个工作表），列「位号」「累计运行小时」（带单位 "33500h" 可解析）。

只对运行小时周期项生效；台账自带「累计运行小时」列时以台账为先。仍需台账给「上次加换油时累计小时」或「自上次加换油运行小时」，否则该项无法判定。

## 六、参考限值表（可选，`--ref-standard`）

工作表名「参考限值」。由用户按厂内认可的国标换油指标或厂家推荐值**自行转录**，脚本不内置任何数值。

| 列名 | 必需 | 说明 |
|---|---|---|
| 检测项 | 是 | 与油液分析「检测项」归一后匹配（忽略括号内单位、空格） |
| 限值 | 是 | 写法同「限值表达式」；无法解析的行不启用并 warning |
| 油品类型 | 否 | 如「透平油」「齿轮油」；填写时须与油样油品（或台账油品）归一后互含才匹配；留空为通用 |
| 标准号 | 否 | 写入报告「参考出处」列；示例文件中为虚构写法 `Q/XX-虚构-001` |

匹配到的项只做"参考比对"，**不计入 `oaAbnormal`**，报告单列并标注"非厂内标准，仅供参考"。

## 日期字段
- 支持：`2026-09-21`、`2026/9/21`、`2026年9月21日`、`20260921`、Excel 日期单元格、Excel 日期序列号
- 无法解析时不猜测：台账的上次加换油日期 → 该项进「无法判定」；记录表的日期 → warning 后仍计入消耗总量（消耗统计不做期间过滤）

## 油品牌号一致性

脚本把油品牌号归一（转大写、去品牌词、去空格/横杠/下划线/括号/标点）后比对，发现同一归一键下有多种原始写法时：
- 列入 `oilNameConflicts` 并 warning，报告「附一」列出疑似同一油品
- **统计仍按原始写法分列，不自动合并** —— 合并与否由设备员确认后在台账中统一
- 不同牌号（L-TSA32 与 L-TSA46）不会归为一组

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 位号为空的行（warning 提示）
- `--equipment` 限定范围外的行（warning 提示行数）
