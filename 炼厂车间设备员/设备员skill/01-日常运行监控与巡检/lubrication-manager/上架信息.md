# 设备润滑五定管理
**技能名称**：设备润滑五定管理

**技能简介**：按润滑五定台账生成加换油到期清单（日历周期与运行小时周期都认），统计五定齐备率与油品消耗，按厂内限值标记油样超限项。辅助车间设备员排润滑计划，不替代化验结论。

**技能描述**

面向炼化厂车间设备员和润滑专责，管润滑点的加换油计划。上传润滑台账（五定表）、加换油记录、油液分析表后，脚本核对五定齐备率，按每个润滑点的周期算出已逾期、临期、周期内的加换油清单，周期写"每月、半年"按日历算，写"运行 2000 小时"按累计运行小时算，累计小时可接运行时长统计的结果。加换油记录按油品和设备统计消耗，单位混用时分列不换算，有单价表才算金额；油液分析按厂内限值标超限项，没限值只列数不判。周期、上次加换油日期、累计小时缺失的单列无法判定，不按常见周期推算。产出到期清单、五定齐备率、消耗统计、油液超限四部分报告。数字由脚本算，模型只写说明；不做油品选型，不做故障诊断，不替代化验结论。

**示例问题**
1. 这是我们车间的润滑台账，基准日按今天，帮我看看哪些润滑点该换油了、哪些快到了，五定里有没有没填的。　　**附件：** `sample-lube-2026-09-21.xlsx`
2. 这份是从 EM 里导出的润滑计划，第一行是标题，列名是功能位置、设备描述、润滑责任人这一套，底下还有合计行，有几台周期写的"半年"和"每班"，帮我出到期清单。　　**附件：** `sample-lube-export.xlsx`
3. 气压机油泵和减压塔底泵是按运行 2000 小时、4000 小时换油的，累计小时在运行时长统计的结果里，帮我接上一起判，缺数据的单独列出来。　　**附件：** `sample-lube-2026-09-21.xlsx + sample-runtime.json`
4. 把近期的加换油记录按油品和设备统计一下用量，再按单价表算一下花了多少钱，有的记录单位写的是桶，别给我折算。　　**附件：** `sample-lube-2026-09-21.xlsx + sample-oil-price.xlsx`
5. 化验室回来的油样结果帮我对一下厂内限值，闪点和铁含量厂里没定限值，我按国标抄了一张参考表，先对着看看但不要当正式结论。　　**附件：** `sample-lube-2026-09-21.xlsx + sample-ref-limits.xlsx`
