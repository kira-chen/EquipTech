# 输入规格：泄漏点登记与修复跟踪

## 主输入：检测记录 / 漏点记录（必需）

一个 `.xlsx`（或同结构 CSV 目录，UTF-8 或 GBK），含「检测记录」「漏点记录」或 LDAR 系统导出的「LDAR检测数据」工作表。

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「检测记录」「漏点记录」「泄漏点记录」「LDAR检测记录」「LDAR检测数据」「密封点检测」「检测明细」均可识别。找不到时脚本报错终止（检测记录是唯一数据源）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 密封点编号 | 是 | LDAR 系统标签号。与位号同时为空的行会被跳过并 warning；仅编号为空时按位号跟踪并 warning。**编号重复时两条均保留，不自动合并** |
| 位号 | 否 | 所属设备 / 管线位号（SAP 功能位置） |
| 设备编号 | 否 | SAP 设备流水号 / EM 编码，单独展示，**不是位号** |
| 装置 | 否 | SAP 工厂区段 / 生产单元，展示用 |
| 组件类型 | 否 | 泵密封、压缩机密封、法兰、阀门、连接件、开口管线、取样口、泄压设备等；缺「密封类型」列时用它推定静/动密封 |
| 组件子类型 | 否 | LDAR 系统细分（机械密封、填料密封、闸阀、截止阀、螺纹接头……），展示用 |
| 密封类型 | 否 | 静密封 / 动密封。缺失时按组件类型推定（见下），仍无法推定 → 该点不进任一泄漏率分子并 warning |
| 介质 | 否 | 物料名称（汽油、干气、渣油……），与「介质状态」共同决定适用阈值 |
| 介质状态 | 否 | 气体 / 轻液 / 重液。**缺失或无法归类时阈值无法确定，该点进 `undetermined`，绝不按任一阈值默认处理** |
| 检测方法 | 否 | HJ 733 / OGI 红外 / 目视等，展示用 |
| 检测值 | 否 | LDAR 仪器净检测值，单位 μmol/mol。**为空或无法解析时输出 null 并进 `undetermined`，绝不按 0 计为不泄漏**。带单位（「3200ppm」）剥离单位取数；带比较符（「>10000」）不猜测 → null |
| 本底值 | 否 | 环境本底浓度，仅登记留痕，**不参与判定，不从检测值中扣除**。有非空值时给一条 warning（含行数），报告口径处写「本底值仅登记，未从检测值中扣除；如厂内按扣除本底后的净值判定泄漏，请按厂内口径复核」 |
| 检测时间 | 否 | 修复时限的起算日；缺失时该泄漏点的时限无法计算，不按超期处理并 warning |
| 发现人 | 否 | 检测人 / 巡检人 |
| 泄漏形态 | 否 | 现场目视情况，见下方「泄漏形态取值」。**无检测值时按此定性判定，不折算为浓度** |
| 不可达点 | 否 | 是 / 否。为「是」且无检测值、无可见泄漏记录 → `undetermined`（不按不泄漏） |
| 状态 | 否 | 见下方「修复状态取值」 |
| 首次修复日期 | 否 | 临时性消漏措施（紧固、带压堵漏等）的完成日期 |
| 最终修复日期 | 否 | 彻底消漏并复测合格的日期。**无此日期时即便状态填「已修复」也不计入闭环** |
| 复测日期 | 否 | 修复后复测日期，展示用 |
| 复测值 | 否 | 修复后复测浓度，展示用 |
| 延迟修复批准日期 | 否 | 状态为「延迟修复」时必填：有则单列延迟修复不计超期，**无则进 `undetermined`** |
| 延迟修复批准人 | 否 | 展示用 |
| 责任人 | 否 | 修复责任人 |
| 备注 | 否 | 展示用（**不再作为任何判定字段的别名**） |

## 静/动密封归类

| 来源 | 规则 |
|---|---|
| 「密封类型」列 | 含「动密封 / 动态密封 / dynamic」或恰为「动」→ 动密封；含「静密封 / 静态密封 / static」或恰为「静」→ 静密封；其他文字 → 未识别 |
| 按组件类型推定（密封类型列为空时） | 泵密封、泵轴封、机械密封、压缩机密封、搅拌器密封、风机密封、轴封 → **动密封**；法兰、阀门、连接件、开口管线、取样口、泄压设备、安全阀、螺纹、盲板、人孔、仪表接口、接头 → **静密封**；其他 → 未识别 |

未识别的泄漏点单独计数（`counts.unclassifiedLeaks`），不进静、动任一泄漏率分子，报告「【注意】」提示补「密封类型」列。推定来源写在 `items[].sealBasis`。

## 介质状态取值

| 归类 | 可识别的写法 | 适用阈值 |
|---|---|---|
| 气体 / 轻液 | 气体、气相、气、轻液、轻油、轻质液、轻组分、汽油、石脑油、液化气 | 默认参考口径 2000 μmol/mol |
| 重液 | 重液、重油、渣油、蜡油、稠油、沥青、重质液、重组分 | 默认参考口径 500 μmol/mol |
| **介质状态缺失** | 介质与介质状态两列均为空 | **无法确定 → `undetermined`** |
| **介质状态无法识别** | 以上都不匹配的其他文字（如「未知相」） | **无法确定 → `undetermined`** |

脚本先看「介质状态」列，再看「介质」列，两列文本合并后做关键词匹配。

## 泄漏形态取值（无检测值时的定性判定通道）

| 归类 | 可识别的写法 | 判定 |
|---|---|---|
| 滴漏 / 成股流出 | 滴漏、滴落、成股、流出、喷溅、喷出、漏液、漏油、连续滴、明显泄漏 | **认定泄漏** |
| 渗漏（观察项） | 渗漏、渗油、油迹、油渍、微渗、湿润、挂壁、轻微渗 | 不认定泄漏，列为观察项 |
| 未见可见泄漏 | 无、无泄漏、正常、未见泄漏、干燥、无渗漏 | 不认定泄漏 |
| **形态无法识别** | 以上都不匹配的其他文字 | 与检测值同时缺失时 → `undetermined` |

> **关键口径**：可见泄漏判定**不折算为浓度**，也**不与仪器检测值混算**；报告中两类来源分别列示各自的记录数与认定泄漏数。一条记录同时有可解析检测值与泄漏形态时，以仪器检测值为准（形态文字仍原样留痕）。

## 修复状态取值

| 归类 | 可识别的写法 | 处理 |
|---|---|---|
| 延迟修复 | 延迟修复、延期修复、延迟维修、延期维修、批准延迟、已批延迟、延迟至停工、延迟到大检修、延迟 | 有「延迟修复批准日期」→ `delayed` 单列不计超期；无 → `undetermined` |
| 已修复 | 已修复、已消漏、修复完毕、已完成、已整改、已消除、复测合格、已闭环、完成 | 有最终修复日期 → `repaired`；无 → `open` |
| 已首次修复（未最终修复） | 已临时修复、临时修复、首次修复、已紧固、紧固处理、带压堵漏、临时处理 | `open`（按最终修复时限判超期） |
| 未修复 | 未修复、未处理、待修复、挂牌、未消漏、待处理、计划检修、停车修复、已提通知单、待维修 | `open` / `overdue` |
| **状态无法识别** | 以上都不匹配的其他文字（如「待定」） | 已认定泄漏时 → `undetermined` |
| **状态未填** | 空单元格 | 已认定泄漏时 → `undetermined` |

未认定泄漏的记录不因状态空白而进未判定。

## 日期字段
- 支持：`2026-09-21`、`2026/9/21`、`2026年9月21日`、`20260921`、Excel 日期单元格、Excel 日期序列号
- 无法解析时输出 `null` 并 warning，**不猜测**；该字段参与的判定相应不予推算

## 历史漏点台账（可选，`--ledger`）

传入上期本脚本产出的 `ledger.xlsx`（或同结构的厂内漏点台账 / LDAR 系统导出），需含「漏点台账」工作表，列名与主输入一致（别名同样可识别）。用途：

1. 判定本期认定的漏点是新增还是历史续跟踪（`isNew` / `counts.carryOver`）
2. 合成全量台账：历史中**本期未复测**的条目原样保留并标注「历史遗留（本期未复测）」；本期出现的条目以本期记录为准

未找到「漏点台账」工作表时 warning 并按全新登记处理，不中断。未传 `--ledger` 时 warning，并说明无法判断续跟踪项。

## 密封点总数（可选，`--seal-points`，泄漏率分母）

| 形式 | 写法 | 说明 |
|---|---|---|
| 参数字符串 | `--seal-points "静:12000,动:800"`（也认 静密封:/动密封:/static:/dynamic:） | 只给一类时另一类为 null |
| 密封点台账（逐点） | xlsx 工作表「密封点台账 / 密封点清单 / 密封点」，必需列「密封点编号」，可选「组件类型」「密封类型」 | 一行一密封点，按密封类型列或组件类型推定计数；无法识别的行不进任一分母并 warning |
| 密封点台账（汇总） | 同上工作表，首行表头含「静密封点数」「动密封点数」列，第二行为数值 | 直接取数 |

不传 → 静/动泄漏率均为 `null`，报告「【未判定】未提供密封点总数」，不得写 0‰。

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 密封点编号与位号均为空的行（warning 提示）

## 不会被跳过、但会单列的情况
- 密封点编号重复：**两条均保留并各自判定**，warning 注明两处行号，报告「八、编号重复与数据提示」单列
- 检测值无法解析：进 `undetermined`，warning 明示**未按 0 计为不泄漏**
- 延迟修复无批准日期：进 `undetermined`，原因写明缺批准日期
- 不可达点未检测：进 `undetermined`，同时计入 `counts.unreachable`
- 检测时间晚于统计截止日期：仍予保留，warning 提示
