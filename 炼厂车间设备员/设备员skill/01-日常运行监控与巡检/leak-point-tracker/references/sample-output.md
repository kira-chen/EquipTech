## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 未判定 | 「检测值缺失或超量程，须补测后重新判定，在此之前不得按不泄漏处理」 | 「未测到，按合格计」「检测值 0，未泄漏」 |
| 可见泄漏 | 「现场目视连续滴漏，按定性口径认定，无仪器检测值」 | 「目测约 3000 μmol/mol」「折合浓度已超标」 |
| 渗漏观察项 | 「法兰面渗油，按定性口径列为观察项，未认定泄漏」 | 「轻微泄漏已认定」「基本不漏可忽略」 |
| 超期 | 「台账记录状态为未修复，已超出最终修复时限 2X 天」 | 「责任人拖延」「车间不重视」 |
| 阈值 | 「按默认参考口径……以现行法规与厂内规定为准」 | 「按国标 2000 判定」「法定限值 2000」 |
| 修复率 | 引用 leaks.json 的 `metrics.repairRate` | 自行换算口径或取整 |
| 编号重复 | 「须核实是否为同一密封点后修正台账」 | 「已去重，按一处漏点计」 |
| 与排放日检的关系 | 不提排放浓度达标与否 | 「本期漏点多，排放大概率超标」 |
