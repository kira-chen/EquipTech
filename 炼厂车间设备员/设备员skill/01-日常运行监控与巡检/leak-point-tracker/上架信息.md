# 泄漏点登记与修复跟踪
**技能名称**：泄漏点登记与修复跟踪

**技能简介**：把 LDAR 检测数据和现场跑冒滴漏统一登记成漏点台账，按修复时限算出超期未修、延迟修复、闭环情况，并按静/动密封点分别算泄漏率（‰）。车间内部跟踪材料，不替代法定 LDAR 检测报告。

**技能描述**

面向炼化厂车间设备员，把 LDAR 系统导出的检测数据和巡检发现的滴漏、渗漏统一登记成漏点台账。上传 Excel 后，脚本按介质判定泄漏，按检测日期起算首次和最终修复时限，输出新增、超期未修、期限内未修、批准延迟修复、修复闭环五类清单和更新后的全量台账；再给密封点台账或"静 N、动 M"总数，就分别算静、动密封点泄漏率，考核线由你给，不给就只列数不判达标。检测值缺失或超量程、不可达点、延迟修复没有批准日期的记录单列未判定，不按没漏处理；编号重复的两条都保留。适合周月漏点跟踪、月报泄漏率填报、向上汇报整改进度。数字由脚本算，模型只写说明；不诊断原因，不核算排放量，不替代法定 LDAR 报告和环保达标判定。

**示例问题**
1. 这是本周 LDAR 检测数据，帮我登记漏点，看看哪些超期没修、哪些还在期限内，报告要能直接发给车间设备主任。　　**附件：** `examples/sample-leak-detect-2026-09-21.xlsx`
2. 上期的漏点台账在这里，和本期检测数据对一下，这期哪些是新增的、哪些是历史遗留还没修的，台账帮我合成一份。　　**附件：** `examples/sample-leak-detect-2026-09-21.xlsx + examples/sample-leak-ledger.xlsx`
3. 月报要填静密封点泄漏率和动密封点泄漏率，密封点台账在附件里，帮我算一下；我们厂考核线静 0.5‰、动 2‰，顺便看看达没达标。　　**附件：** `examples/sample-leak-detect-2026-09-21.xlsx + examples/sample-seal-points.xlsx`
4. 这是 LDAR 系统直接导出的表，列名是标签号、功能位置、设备那一套，里面有两个延迟修复的点、一个不可达点，帮我看看能不能直接读，延迟修复怎么算。　　**附件：** `examples/sample-leak-ldar-export.xlsx`
5. 这张表是别人整理的，列名不标准，底下还有合计行，有两条密封点编号重复了，帮我处理一下并指出有问题的数据。　　**附件：** `examples/sample-leak-messy.xlsx`
