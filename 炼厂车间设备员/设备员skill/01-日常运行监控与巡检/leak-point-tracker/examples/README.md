## 关键验证点

1. **检测值缺失绝不按 0 计为不泄漏**（环保合规红线）：主样例 MFD-1111-010 检测值为空、MFD-1112-015 为「超量程」，两条 `value` 均为 `null`，归 `undetermined`，**未出现在 `noLeak`**，报告开头与「六、未判定清单」两处写明未按 0 计。
2. **介质状态不明时不套用任一阈值**：MFD-1113-021 有检测值但介质与介质状态均空，归 `undetermined`。
3. **可见泄漏按定性口径单独处理**：MFD-1103-012、MFD-1109-006 无检测值，`value` 与 `threshold` 均为 `null`；「一、总体概览」中仪器检测 10/7 与可见泄漏 3/2 分行列出。
4. **渗漏是观察项不是泄漏**：MFD-1107-005 归 `noLeak` 并注明观察项。
5. **重液阈值生效**：MFD-1105-003 渣油约 1XXX，按重液阈值认定；MFD-1105-009 蜡油约 3XX 未认定。
6. **延迟修复两个方向**：主样例 MFD-1114-002 与 LDAR 样例 LD-4402-0017 有批准日期 → 「五、延迟修复（经批准）」，不进超期；LDAR 样例 LD-4403-0005 无批准日期 → 未判定，既不按已批准也不按超期。
7. **不可达点**：LDAR 样例 LD-4404-0032「是否不可达=是」且无检测值 → 未判定并计入 `counts.unreachable`，不按不泄漏。
8. **静/动密封点泄漏率**：不传 `--seal-points` 时两项 `rate` 为 `null`、表中显示「—」；传密封点台账后静 4.17‰ / 动 10‰；无考核线不判，给考核线后按用户参数判定。
9. **中石化系统列名**：LDAR 样例的「序号」不被当作密封点编号；「功能位置」→ 位号、「设备」（8 位流水号）→ 设备编号单独展示、「工厂区段」→ 装置、「检测净值」→ 检测值、「密封类型」列与按组件类型推定（LD-4405-0008 泵密封 → 动密封）。
10. **带单位检测值**：LD-4405-0008「2600ppm」左右的值剥离单位后参与判定，warning 一次性提示核对单位。
11. **密封点编号重复两条均保留**：脏数据样例 MFD-2201-001 出现两次，各自判定，warning 注明两处行号。
12. **超期未修含超期类型与天数**：MFD-1101-001 最终修复超期、MFD-1102-004 首次修复超期。
13. **无最终修复日期不计闭环**；**超时限后才修复仍计闭环但标注**（MFD-1110-008）。
14. **合规提示行、制度出处行、「【注意】」**：所有样例产出均含「不替代法定 LDAR 检测报告……达标判定以生态环境主管部门意见为准」与「制度出处：GB 31570 与中国石化 LDAR 管理要求」，md 不含 emoji。
15. **续跟踪与全量台账**：提供 `--ledger` 后，MFD-9001-001 保留并标注「历史遗留（本期未复测）」；MFD-1101-001、MFD-1103-012 标为「历史续跟踪」。
