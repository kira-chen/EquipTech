# 铭牌识别与台账录入（nameplate-ocr-intake）

面向中石化体系炼化厂车间设备员，把现场拍摄的设备铭牌照片转成结构化台账字段（EM / SAP PM 技术对象字段口径），减少手工录入。**读图识别由模型完成，识别值由模型读图产生、未经脚本验证；脚本只做字段对齐、原文量级校验、单位校验与台账比对。识别结果必须逐项标注置信度并由用户核对确认；模型不得补充照片中看不清或没有的参数。**

## 适用条件
- 用户说"拍了铭牌帮我录一下 / 这张照片里的参数 / 新设备建档 / 台账缺的参数从照片补 / 铭牌和台账对一下"，并提供铭牌照片。
- 支持设备类型：泵、电机、压缩机、换热器、容器、阀门、仪表等常见铭牌；压力容器、换热器铭牌含「设备代码」（与特种设备台账衔接）。
- 车间设备员可做：铭牌参数提取与台账比对、新设备建档的待确认录入表、台账缺项补录建议。
- 由其他流程归口（技能只提示）：台账数据的正式录入与修改（EM / SAP 主数据维护流程）；设备已更换的认定与变更（moc-change-assistant）；特种设备使用登记与定检（special-equipment-inspection-due）。
- 不适用：台账数据的查询（equipment-ledger-query）；直接改写用户的台账文件；作为设备档案的原始凭证（须以出厂资料为准）。

## 前提条件
- 输入：铭牌照片（`.jpg` / `.png`，建议正对拍摄、光线均匀、铭牌完整入框）。可选：现有台账文件（SAP PM 技术对象清单 / EM 导出 / 车间自维护台账，用于字段对齐与查重）、设备类型说明。
- 必填信息：设备位号（功能位置，照片中通常没有，须用户提供；也可给 SAP 设备编号，脚本按设备编号命中台账但不把它当位号）、设备类型。
- 环境：
  - **平台须具备图像读取能力**（用 Read 工具读取图片附件）。**图片附件缺失，或 Read 读图失败、返回的不是图像内容，一律明确告知用户并终止，不得根据文件名、台账现值或用户口述编造铭牌参数。**
  - 后处理脚本需可执行 Node.js ≥ 18，仅用内置模块，无需 npm 安装。**若环境无法执行 node（无 Bash 工具或 `node --version` 失败），明确告知用户并终止，不得手工成文输出录入表。**

## 数据获取（MCP）

平台接入了业务系统 MCP 服务时，按下表调用工具取数，不再请用户上传导出文件；未接入时按操作步骤请用户提供系统导出文件。工具全部只读，不在业务系统里创建或修改任何单据。

| 服务 | 工具 | 参数 | 交给脚本 |
|---|---|---|---|
| 设备资产管理 | `get_equipment_ledger` | `tag`：位号 | `--ledger` |

取数后：

1. 工具返回下载链接（60 分钟内有效，过期重新调用）。csv 按原文件名放进新建的空目录，不改文件名，不与其他技能的文件混放；把目录作为“交给脚本”一列的参数值。
2. 按位号取到 0 行，说明位号不在台账中，照常交给脚本，按新增建档处理；新设备也可改带 `workshop`（车间名）取本车间台账。

## 操作步骤
1. **确认位号与设备类型** —— 位号一般不在铭牌上，**必须由用户提供，不得从照片推断或留空猜测**。设备类型决定字段模板。
2. **读取照片并逐字段提取（模型读图）** —— 用 Read 读取图片；按 `references/nameplate-fields.md` 中对应设备类型的字段模板逐项提取：制造厂、型号、规格、出厂编号、设备代码（承压设备）、制造日期、设计参数（压力、温度、流量、扬程、功率、转速、电压、电流）、材质、重量、执行标准。**每个字段标注三档置信度：清晰可读 / 部分模糊需核对 / 无法辨认；clear 与 blurry 字段必须同时抄录铭牌原文 `raw`（含单位、原始写法），供脚本做量级校验。绝不猜测模糊字符，模糊位用 ▢ 占位并标注。**
3. **对齐台账字段并查重（脚本）** ——
   ```bash
   node "<技能目录绝对路径>/scripts/intake.js" --fields "<提取结果JSON文件>" --tag "<位号>" --equip-type "<设备类型>" --ledger "<台账xlsx 或 CSV 目录>" --out "<工作目录>/铭牌录入"
   ```
   脚本完成字段名对齐（支持 SAP 功能位置 / 设备 / 设备描述 / 制造商 / 型号编号 / 制造商序列号 / 设备代码 等列名）、raw 量级校验（识别值与原文相差 10 的整数倍 → 改判部分模糊）、单位换算校验、与台账现有记录的查重（制造日期按铭牌印的精度比，台账「2015-02-01」或「2015-02-01 00:00:00」与铭牌「2015.02」算一致；数值参数按数值比，2.50 与 2.5 一致；材质按部位分段比，「泵体铸铁」这类部位名紧挨材质的写法也能分开）。读取末行 JSON 摘要（同时写入 `<out>/summary.json`）：`ok` 必须为 `true`，`ok:false` 时把 `error` 告知用户并终止；`warnings` 逐条告知（位号已存在 / 字段与台账不一致 / 单位缺失 / 未提供 raw / 量级疑似错位 / 按设备编号命中等）。
   - 位号在台账中已存在且参数不一致：列出差异项供用户判断是"识别错误"还是"设备已更换"，**不得自动覆盖**；识别值与台账值相差 10 的整数倍时提示疑似小数点错位，优先核对识别。
4. **生成录入建议表** —— 按 `assets/templates/intake-template.md` 成文，含：识别概览、逐字段识别结果表（字段、识别值、置信度、台账现值、是否一致）、需人工核对项（模糊 / 单位 / raw 量级）、无法辨认项、与台账的差异项、建议录入内容、录入建议说明。**"建议录入内容"仅为待确认稿，须用户逐项确认。**
5. **交付前自检** —— 对照 `references/checklist.md` 逐项检查；通过后交付 `intake.md` 与 `intake.csv`（UTF-8 带 BOM，确认后可导入）。**必须保留声明行："识别值由模型读图产生，未经脚本验证，须与铭牌原件或出厂资料核对后方可录入台账；本技能不直接修改台账文件"，不得删除或改写。**

## 预期结果
- `intake.md`：七节铭牌录入建议——识别概览、逐字段识别结果、需人工核对项（3.1 识别模糊 / 3.2 单位 / 3.3 raw 量级校验）、无法辨认项、与台账的差异项、建议录入内容（待确认稿）、录入建议说明（分析段占位）；顶部与末尾为固定声明行。
- `intake.csv`：确认后可导入台账的字段行（UTF-8 带 BOM）；`intake.json`；`summary.json`。
- 交付时向用户说明：识别字段数、清晰可读数、需核对数（含 raw 量级疑似错位）、无法辨认数、与台账的差异项、按位号还是设备编号命中台账、脚本 warnings（如有）。

## 不适用范围
- 不猜测模糊或缺损的铭牌字符；不在读图失败时凭文件名或口述编造参数。
- 不补充铭牌上没有的参数（如实际运行参数、检修历史、投用日期）。
- 不直接修改用户台账文件，只输出待确认的录入行（正式录入走 EM / SAP 主数据流程）。
- 不作为设备档案原始凭证，不替代出厂合格证与质量证明书。
