# 铭牌字段模板（按设备类型）

读图提取字段前先读本文件，按设备类型取对应模板逐项提取。**模板里有、铭牌上没有的字段，按「铭牌无此项」处理（置信度 `unreadable`、`reason` 写「铭牌上无此项」），不得凭常识补值。**

**识别值由模型读图产生，未经脚本验证。** 每个 clear / blurry 字段除 `value` 外必须同时抄录铭牌原文 `raw`（含单位与原始写法，如 `4.0MPa`、`180 马力`、`2９８０ r/min`，模糊位用 ▢），脚本据此做量级校验：识别值与原文相差 10 的整数倍（4.0 抄成 40）会被改判为部分模糊。只给 `value` 不给 `raw` 的字段无法校验，报告会标注"未做量级校验"。

## 八、位号不在铭牌上

炼化厂的**位号（P-1101A、E-1201，SAP 里叫功能位置）是本厂工艺编号，铭牌上通常没有**。铭牌上的「出厂编号 / 产品编号 / 机号 / No.」是制造厂的产品序号，SAP 台账里的「设备」是 8 位流水号（设备编号），**三者完全不同，不得互相当作对方**。

- 位号**必须由用户提供**（`--tag`），缺失时脚本报错终止。
- **绝不从照片背景、设备外壳的喷漆字、文件名（如 `P-1101A铭牌.jpg`）推断位号。** 照片里若看到疑似位号的喷漆字，只能作为向用户确认的线索提出，不能直接填入。

## 九、易混字符与模糊处理

铭牌常年在户外，锈蚀、油污、反光、拍摄角度都会造成字符残缺。以下字符对在铭牌上尤其易混：

`0 / O / D`　`1 / I / l / 7`　`5 / S`　`6 / 8 / B`　`2 / Z`　`M / N`　`. / ,`（小数点与千分位）

**处理规则**：

1. 只要一个字符不能确定，整个字段判 `blurry`，模糊位用 `▢` 占位，例如 `ZA-1▢0-250`。
2. **绝不"择优猜测"**——不得因为「常见型号是 ZA-100-250」就把 `▢` 补成 `0`。
3. 整个字段读不出来判 `unreadable`，`value` 必须为 `null`。
4. 小数点位置存疑（`2.5` / `25`）一律判 `blurry`，因为量级错误后果严重；脚本也会用 `raw` 做一次量级核对，识别值与原文相差 10 的整数倍会被改判为 `blurry`。

## 十、单位规范

脚本按 `references/input-spec.md` 的换算表做**校验**，不做自动换算。铭牌上常见的非法定单位：

| 铭牌写法 | 法定单位 | 台账口径 |
|---|---|---|
| 马力 / HP / PS | kW | 1 HP ≈ 0.7457 kW，1 PS ≈ 0.7355 kW |
| kgf/cm² / kg/cm² / 公斤 | MPa | 1 kgf/cm² ≈ 0.098 MPa |
| bar | MPa | 1 bar = 0.1 MPa |
| psi | MPa | 1 psi ≈ 0.006895 MPa |
| mmH₂O / mmHg | kPa | 换算需注明 |
| rpm | r/min | 同量纲，直接等价 |
| t | kg | 1 t = 1000 kg |

铭牌单位与台账口径不一致时，脚本出 **warning 提示人工核对并给出换算参考值，不自动改写 `value`**。

## 十一、铭牌上没有的东西不要找

以下信息**不在铭牌上**，即使用户追问也不得从照片"推断"：

- 实际运行参数（当前流量、当前电流、实测振动）
- 检修历史、上次大修时间
- 位号、所在装置区、所属专业
- 备件清单、配套电机位号
- 投用日期（铭牌上是**制造日期**，投用日期通常晚于制造日期数月至数年，两者不得混用；SAP「建造年份」「开始日期」也不是铭牌字段）

## 十二、读图失败即终止

图片附件缺失、Read 读图失败、返回的不是图像内容（例如只拿到文件名或一段说明文字）时，**明确告知用户并终止**，不得根据文件名、台账现值、用户口述或"常见型号"编造任何铭牌参数；node 不可用时同样终止，不手工成文录入表。
