# 铭牌识别与台账录入
**技能名称**：铭牌识别与台账录入

**技能简介**：拍一张设备铭牌，它逐字段读出制造厂、型号、出厂编号、设备代码和设计参数，对齐 EM / SAP PM 台账字段，查重比对台账现值，输出带置信度的待确认录入表；识别值由模型读图产生，每一项都要你核对原件后才录入。

**技能描述**

面向炼化厂车间设备员，解决新设备建档和台账补录时逐字抄铭牌的麻烦。上传铭牌照片并告知位号和设备类型，模型按泵、电机、换热器、容器等类型的字段模板逐项识别并抄录原文，看不清的字符用占位符标出、不猜；脚本再把识别字段对齐到 EM / SAP PM 台账列名，用原文核对量级和单位，疑似小数点错位的改成需核对，不自动改值；提供台账时按位号或设备编号查重，参数不一致的逐项列出，提示是识别错误还是设备已更换，不自动覆盖。产出带置信度的录入建议和可导入 CSV，模糊项、冲突项的建议值留空。铭牌上没有的不补；图片读不到就终止，不凭文件名编数。正式录入走主数据流程，每一项都要核对原件后才录入。

**示例问题**
1. 这是 P-1101A 回流泵的铭牌照片，位号 P-1101A，台账也发你了，帮我把铭牌参数读出来跟台账对一下，不一样的地方标出来。　　**附件：** `examples/sample-pump-fields.json + examples/sample-equipment-ledger.xlsx`
2. 新上的电机 M-1501，铭牌拍好了，台账里还没有这台，帮我出一份建档用的录入表，铭牌上功率印的是马力，注意一下单位。　　**附件：** `examples/sample-motor-fields.json + examples/sample-equipment-ledger.xlsx`
3. V-1301 缓冲罐铭牌上有设备代码，帮我看看跟 SAP 技术对象清单里的设备代码和出厂编号对不对得上。　　**附件：** `examples/sample-vessel-fields.json + examples/sample-sap-pm-ledger.xlsx`
4. 这份台账是 SAP 导出来的，列名是功能位置、设备描述、制造商那一套，拿铭牌识别结果对一下，设备编号那列别当成位号。　　**附件：** `examples/sample-pump-fields.json + examples/sample-sap-pm-ledger.xlsx`
5. 铭牌照片在这，位号 P-1101A，台账我没带，先把能认出来的字段列出来，认不清的标出来，我回去再核。　　**附件：** `examples/sample-pump-fields.json`
