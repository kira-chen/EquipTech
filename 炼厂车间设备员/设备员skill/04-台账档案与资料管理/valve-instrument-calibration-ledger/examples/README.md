## 关键验证点

1. **默认只统计安全阀（车间设备员归口）**：示例 1 不给 `--category` 时 `counts.total` 为 4、`counts.totalInLedger` 为 16，`meta.categoryDefaulted` 为 true，warning 说明排除了哪些类别；压力表/报警器/联锁回路只有在 `--category 全部` 时才出现，且标注「计量（仪表）专业归口，本表仅作台账提醒」。
2. **周期缺失不按默认处理**：PI-1206 校验周期为空，归入待确认并注明缺「校验周期」，**不按计量器具默认 6 个月推算**；SIS-1502 上次校验日期为空，同样单列。
3. **到期按自然月推算**：1 年 = 12 个月、6 个月 = 6 个自然月（`C.addMonths`），不按 365 / 180 天；PI-1207 台账登记值与计算值不一致时附一两者并列 + warning，报告不声称台账有误。
4. **不合格未整改不参与到期计算**：PSV-1103 与 GD-1603 上次结论为不合格。不加 `--issues` 时两项均为 `unresolvedFail`，`daysLeft` 与 `overdueDays` 均为 null；加 `--issues` 后仅 PSV-1103（「已整改」）恢复到期计算，GD-1603（「整改中」）仍为未整改。
5. **「故障」不是校验结论**：SAP 变体中 2000-HDS-PSV2104 结论为「故障」，`result` 为 null、不计入不合格未整改，warning 提示补填检定机构结论。
6. **证书编号重复**：PSV-1102 与 PSV-1104 同为 `AQ-2026-0233`，附二列出并 warning 提示核实是否串号。
7. **类别无法识别**：XX-1801 类别为「特殊装置」，`--category 全部` 时归入待确认，分类汇总中单列「未识别」一档，并 warning。
8. **安全附件超期提示**：PSV-1101（安全阀）与 SIS-1501（联锁回路）超期，`safetyCriticalOverdue` 为 2，超期表中「影响安全保护」列为「是」。
9. **送检批次归并**：按「对象类别 ｜ 校验周期」归批，`送检清单.xlsx` 含「送检清单」与「批次汇总」两张表；不合格未整改项备注「须先整改后复校」。
10. **产出无 emoji**：醒目提示用「【注意】」。

## 再生样例

```bash
node scripts/make-sample.js --out examples            # 默认 seed=1
node scripts/make-sample.js --out examples --seed 7   # 数值与 SAP 设备编号变化，结论不变
```
