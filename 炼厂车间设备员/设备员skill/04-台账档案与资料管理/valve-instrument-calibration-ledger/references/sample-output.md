## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 超期安全阀 | 「超期 6X 天，在校验有效期外，不得作为有效安全保护措施」 | 「超期但整定压力应该没跑偏，可继续用」 |
| 超期联锁 | 「安全联锁有效性无保障，建议补做功能测试」 | 「联锁还能动作，问题不大」 |
| 不合格项 | 「无整改闭环记录，未按合格参与到期计算，须先整改再复校」 | 「重新送检一次就行」 |
| 待确认项 | 「周期未登记，未按同类默认周期推算，请核实厂内规定后补入台账」 | 「按安全阀 1 年周期算，已超期 X 天」 |
| 「故障」结论 | 「结论栏填的是设备状态，请补填检定机构结论」 | 「故障按不合格处理」 |
| 计量/仪表类 | 「已提醒仪表专责，检定由计量（仪表）专业安排」 | 「建议安排检定、建议做功能测试」（替其归口安排） |
| 下次日期不一致 | 「台账登记与按周期计算相差 70 天，两者并列，请核实」 | 「台账登记有误，以计算值为准」 |
