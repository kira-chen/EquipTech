# 输入规格：安全阀校验台账与到期管理

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一次只读一个台账文件：`--input 校验台账.xlsx`

## 校验台账工作表（必需）

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「校验台账」「校验台账表」「检定台账」「仪表台账」「计量台账」「安全阀台账」「安全附件台账」均可识别。**找不到任一匹配的工作表时脚本报错退出**（这是唯一数据源）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 设备/器具位号（SAP 功能位置），为空的行会被跳过并 warning |
| 校验周期 | 是 | 见「周期取值」；缺失或无法解析 → 该项归入待确认 |
| 上次校验日期 | 是 | 见「日期取值」；缺失或无法解析 → 该项归入待确认 |
| 对象类别 | 否 | 见「对象类别」；无法识别 → 归入待确认并 warning |
| 名称 | 否 | 类别为空时，脚本会用名称关键词辅助识别类别 |
| 设备编号 | 否 | SAP 8 位设备流水号 / EM 编码，**单列展示，不作位号** |
| 型号 | 否 | 写入送检清单 |
| 量程 | 否 | 安全阀台账常为「整定压力」，写入送检清单 |
| 精度等级 | 否 | 写入送检清单 |
| 校验结论 | 否 | 见「结论取值」；为「不合格」且无整改记录 → 标 unresolvedFail |
| 证书编号 | 否 | 同一编号出现多次 → warning 提示核实是否串号；`--certs` 按此匹配证书文件名 |
| 下次校验日期 | 否 | 与按周期计算值不一致时**两者并列**并 warning，不擅自采信其一 |
| 安装位置 | 否 | 安全阀台账常为「所属设备」，写入送检清单，便于安排拆装 |
| 检验机构 | 否 | 原样带出 |

## 列名别名

脚本别名表 = 局部别名（优先）+ 共享 `SYSTEM_ALIASES`（EM / SAP PM / 特种设备平台列名，见顶层《中石化口径对照.md》第二节），以下写法均可识别：

| 标准列名 | 可识别的写法（局部） | 共享别名追加（系统导出） |
|---|---|---|
| 对象类别 | 对象类别、类别、设备类别、器具类别、对象类型、类型、设备品种 | 设备类型、对象类型、设备分类、专业类别 |
| 位号 | 位号、设备位号、仪表位号、器具编号、安全阀位号、TAG、tag | 位号编码、**功能位置**、功能位置编号、技术标识、技术对象、技术对象标识 |
| 设备编号 | — | 设备编号、**设备**（SAP 8 位流水号）、设备号、设备编码、技术对象编号、EM编码 |
| 名称 | 名称、设备名称、器具名称、仪表名称、设备描述 | 技术对象描述、功能位置描述、描述 |
| 型号 | 型号、规格型号、规格、型号编号 | 技术参数 |
| 量程 | 量程、测量范围、范围、整定压力 | — |
| 精度等级 | 精度等级、精度、准确度等级、准确度 | — |
| 校验周期 | 校验周期、检定周期、周期、标定周期、检验周期 | — |
| 上次校验日期 | 上次校验日期、上次校验、末次校验日期、上次检定日期、检定日期、校验日期、上次标定日期、上次检验日期、检验日期 | — |
| 校验结论 | 校验结论、结论、检定结论、校验结果、结果、判定、检验结论 | — |
| 证书编号 | 证书编号、证书号、检定证书编号、报告编号、证书、校验报告编号 | — |
| 下次校验日期 | 下次校验日期、下次校验、下次检定日期、到期日期、有效期至、下次检验日期 | — |
| 安装位置 | 安装位置、位置、装置区、区域、所在位置、所属设备 | — |
| 检验机构 | — | 检验机构、检验单位、检测机构、检验检测机构 |

表头行识别：取前 10 行中命中必需列最多的一行，因此首行是标题、第三行才是表头的系统导出表也能读。「设备编号」不是位号别名：SAP 导出表里「功能位置」是位号、「设备」是流水号，两者分列。

## 对象类别与归口

按「对象类别」列，列为空时用「名称」列的关键词辅助识别，归入以下六类之一：

| 归类 | 可识别的关键词 | 归口 | 默认是否统计 |
|---|---|---|---|
| 安全阀 | 安全阀、泄压阀、PSV、SV | 车间设备员 | **是（默认 `--category 安全阀`）** |
| 爆破片 | 爆破片、防爆片、爆破盘、泄爆片 | 车间设备员 | 否（指定类别或 全部） |
| 计量器具 | 压力表、温度计、压力变送器、温度变送器、计量器具、压力仪表、热电偶、双金属、真空表 | 计量（仪表）专业，仅台账提醒 | 否 |
| 报警器 | 报警器、可燃气体、有毒气体、气体检测、探测器、检测报警 | 计量（仪表）专业，仅台账提醒 | 否 |
| 联锁回路 | 联锁、连锁、安全仪表、SIS、ESD、安全回路 | 计量（仪表）专业，仅台账提醒 | 否 |
| 计量装置 | 流量计、称重、地磅、衡器、质量流量、计量装置、流量计量 | 计量（仪表）专业，仅台账提醒 | 否 |
| **未识别** | 以上都不匹配的其他文字（如「特殊装置」） | — | 随 全部 纳入待确认 |

**未识别的对象归入待确认单列**，不按任何一类的默认周期处理。安全阀、爆破片、报警器、联锁回路四类标记 `safetyCritical: true`，超期时在报告中标注「影响安全保护」。默认范围排除的记录数与类别写入 warning，提示用 `--category 全部`。

## 周期取值

| 写法 | 折算方式 |
|---|---|
| `1年` / `1y` / `两年` | 按自然月推：+12 / +24 个月（`C.addMonths`） |
| `6个月` / `6月` / `6m` / `半年` | 按自然月推：+6 个月 |
| `1季度` / `1q` | 按自然月推：+3 个月 |
| `4周` / `4w` | 按天推：+28 天 |
| `30天` / `30d` / `30` | 按天推：+30 天 |

自然月推算示例：2026-03-31 + 6 个月 = 2026-09-30；2024-02-29 + 1 年 = 2025-02-28。无法解析（如「视情况」「按需」）→ warning + `periodDays: null`，该项归入待确认，**绝不代入同类对象的默认周期**。

## 日期取值
- 支持：`2026-09-21`、`2026/9/21`、`2026年9月21日`、`20260921`、Excel 日期单元格、Excel 日期序列号
- 无法解析 → warning + `null`，该项归入待确认

## 结论取值

| 归类 | 可识别的写法 |
|---|---|
| 合格 | 合格、通过、符合、正常、OK、校验合格、检定合格、√ |
| 不合格 | 不合格、未通过、不符合、超差、失效、NG、报废 |
| **设备状态（不是结论）** | 故障、待修、检修中、停用 —— warning「是设备状态不是校验结论」，`result: null`，不归不合格也不按合格 |
| **无法归类** | 以上都不匹配的其他文字（如「待出报告」），warning + `result: null` |
| **未填写** | 空单元格，`result: null`，不按合格处理 |

## 不合格整改清单（可选，`--issues`）

工作表名：「整改清单」「不合格整改」「整改」「不合格项」。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 与台账位号对应 |
| 整改状态 | 否 | 含「已整改/已完成/已处理/已更换/已复校/已复检/闭环」且不含否定词（未/待/不/正在/进行中）才算闭环 |
| 整改完成日期 | 否 | 写入 JSON 的 `remediation` |
| 证书编号 | 否 | 复校后的新证书号 |

**未提供此项时，台账中所有「不合格」结论一律按未整改处理并单列**，并 warning 提示。这是就严口径，不得反向理解为「无整改记录即已整改」。

## 校验证书目录（可选，`--certs`）

传入一个目录，脚本按文件名是否包含台账「证书编号」或「位号」判断该台件的证书是否已归档，列出未匹配到的台件（`certs.missing`、`counts.certsMissing`）。**只核对文件是否存在，不读取证书内容，不解析校验结论。** 未提供时 `certsMissing` 为 null，报告附三写「未提供校验证书目录」。

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 位号为空的行（warning 提示）
- 不在 `--category` 范围内的行（默认只统计安全阀；排除数写入 warning，不计入 `counts.total`，计入 `counts.totalInLedger`）
