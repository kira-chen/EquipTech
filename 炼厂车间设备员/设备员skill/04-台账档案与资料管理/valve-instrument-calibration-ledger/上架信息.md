# 安全阀校验台账到期管理
**技能名称**：安全阀校验台账到期管理

**技能简介**：把车间的安全阀校验台账（EM / SAP PM / 特种设备平台导出均可）交给它，按自然月算出哪些安全阀超期、临期，整理送检批次，核对不合格项整改与证书归档；压力表、报警器、联锁只作台账提醒，不替计量仪表专业安排检定。

**技能描述**

面向炼化厂车间设备员，解决安全阀送校、不合格整改、证书归档这类台账跟踪问题。上传校验台账（系统导出列名可直接识别），脚本默认只统计安全阀，按自然月推算到期日，分出超期、临期、待确认、不合格未整改等档，归并送检批次并生成送检清单 Excel；可接整改清单核对闭环，可接证书目录按文件名核对归档。周期或上次校验日期缺失的单列待确认，不代入默认周期；台账登记的下次日期与计算值不一致时并列、不擅自采信。压力表、报警器、联锁只作台账提醒，检定由仪表专业归口；容器、管道法定定检请用特种设备定检到期管理。报告由模型成文并固定声明：结论以有资质机构证书为准，超期未校的安全阀不得作为有效保护措施。

**示例问题**
1. 这是我们车间的安全阀校验台账，帮我看看哪些已经超期、哪些一个月内到期，出一份送检清单。　　**附件：** `examples/sample-calibration-ledger-2026-09-21.xlsx`
2. 上次校验不合格的几台安全阀，这是整改清单，对一下哪些已经闭环可以按正常周期算、哪些还没整改完。　　**附件：** `examples/sample-calibration-ledger-2026-09-21.xlsx + examples/sample-issues.xlsx`
3. 下个月装置要停工检修，把提前 60 天内到期的安全阀都列出来，按类别和周期分好批，我好一次委托。　　**附件：** `examples/sample-calibration-ledger-2026-09-21.xlsx`
4. 这份是 EM 里导出来的安全阀台账，列名是功能位置、设备描述那一套，还有一行结论填的是"故障"，能读吗，到期情况怎么样。　　**附件：** `examples/sample-export-style.xlsx`
5. 压力表、气体报警器和联锁回路也在这份台账里，一并提醒一下哪些到期了，但检定是仪表那边的事，你只列到期情况就行。　　**附件：** `examples/sample-calibration-ledger-2026-09-21.xlsx`
