# 交付自检清单

## 输入确认
- [ ] 设备位号（功能位置）或设备编号已明确
- [ ] 查询内容已明确（找哪类资料 / 问什么技术问题）
- [ ] 问题涉及具体数值（力矩、间隙、试压压力、材质牌号）时，已告知用户答案必须来自资料原文
- [ ] 资料里的 PDF 已按前置步骤用平台 pdf 技能转为 txt/docx（扫描件先 OCR），转换产物按「原名.pdf.txt」命名；.doc/.xls 已另存为 .docx/.xlsx

## 脚本执行
- [ ] 末行 JSON 的 `ok` 为 `true`；为 `false` 时已告知 `error` 原文并终止（含文件数超过 `--max-files`），未凭通用知识回答
- [ ] `warnings` 已逐条告知用户
- [ ] 数字、计数、命中数全部来自 `matches.json`，未自行统计

## 未解析文件与转换文本（最关键）
- [ ] 未转换的 PDF、图片、CAD、.doc 只做了文件定位
- [ ] 回答中**没有任何一句**声称读到了未转换 PDF / 图纸 / 扫描件里的内容
- [ ] 已明确告知用户「该文件未读取内容，需用平台 pdf 技能转换后重跑 / 打开原件查看」
- [ ] 来自 PDF 转换文本的引用已标注「PDF 转换文本，须核对原件」，并说明转换文本由模型读取产生、未经脚本验证
- [ ] 未解析的文件已全部列出（含损坏文件、空文件、.doc/.xls）

## 命中为空
- [ ] 命中为空时明确回答「所提供资料中未找到相关内容」
- [ ] 未用通用知识、行业惯例、标准条文补答（通用问题指引 equipment-knowledge-qa）
- [ ] 未用其他设备、其他型号的资料代替
- [ ] 已说明缺哪类资料、该去哪补（描述去向，不替资料给数）

## 原文引用
- [ ] 每条引用都带出处（文件名 + 第 N 段，有版本时含版本）
- [ ] 引用用的是完整段落原文，未改写、未节选到失真
- [ ] 原文与解释分开呈现
- [ ] 解释中没有引入原文没有的数值、判定、条件

## 版本冲突
- [ ] 多处原文不一致时全部列出，标明各自出处与版本
- [ ] 未自行取其一（未按"版本新""数值保守"择一）
- [ ] 已提示用户核实受控文件系统（设备档案室 / EM 文档模块）

## 交付说明
- [ ] 已说明检索了多少份资料、命中多少段、几份是转换文本
- [ ] 已说明无法关联的文件（如用户关心）
- [ ] 已说明「引用内容来自所提供资料，资料版本有效性请以受控文件系统为准；未能解析的文件已列出。经平台 pdf 技能转换的文本属模型读取产生，未经脚本验证，须人工核对原件。」
- [ ] 产出未使用 emoji，醒目提示用「【注意】」
