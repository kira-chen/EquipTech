## 示范二：资料问答（原文与解释分开）

**用户问**：P-XXXXA 机械密封压盖螺栓上多大力矩？

>
> 机械密封压盖螺栓应对角均匀紧固，安装力矩 XXN·m，不得超拧。

> **出处：P-XXXXA检修规程.md　第7段　版本 B/1**

## 措辞对照

| 场景 | 应写 | 不应写 |
|---|---|---|
| 未转换 PDF / 扫描件图纸 | 「脚本不读 PDF，只能定位到文件；请先用平台 pdf 技能转为 txt 再传入」 | 「图纸上显示……」「按图纸标注……」 |
| PDF 转换文本 | 「出处：X.pdf.txt 第 N 段（PDF 转换文本，须核对原件）」 | 把转换文本当作已核对的原件引用 |
| 资料没写 | 「所提供资料中未找到，未用通用知识补充」 | 「一般取 40~50N·m」「行业惯例是……」 |
| 别的设备有 | 「未用其他设备的资料代替」 | 「同型号的 P-XXXXB 说明书里写的是……」 |
| 多处不一致 | 两处都列，注明出处与版本，请用户核实 | 「按较新的 B/1 版，取 YYN·m」 |
| 引用 | 「出处：XX说明书.docx 第11段 版本A/0」 | 「说明书里写了……」（无位置） |
| 解释 | 原文照录 + 另起一段解释 | 把原文和自己的补充揉成一段 |
| 版本有效性 | 「版本有效性以受控文件系统为准」 | 「以最新版为准」（等于替用户判定了） |
