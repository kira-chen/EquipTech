# 输入规格：设备台账查询

## 设备台账（必需）

sheet 名匹配「设备台账」「台账」「设备清单」「技术对象」「功能位置」「设备」（去空白与"表"字后包含匹配）。SAP PM 技术对象清单（IH08 / IL03 导出）、EM 设备管理信息系统导出表、车间自维护台账均可。

| 技能内列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是（或设备编号二选一） | SAP 功能位置 / EM 设备位号，唯一标识 |
| 设备编号 | 否 | SAP 8 位设备流水号 / EM 编码。**与位号分列**；只有设备编号的旧台账按设备编号定位并 warning |
| 设备名称 | 否 | SAP 设备描述 |
| 规格型号 | 否 | SAP 型号编号 |
| 制造厂 | 否 | SAP 制造商 |
| 建造年份 | 否 | SAP 建造年份，只到年；**不用于推算投用年限** |
| 投用日期 | 否 | SAP 开始日期；完整日期才推算投用年限 |
| 专业 | 否 | 静设备/动设备/电气/仪表，或 SAP 对象类型 |
| 区域 | 否 | |
| 介质 | 否 | |
| 重要度 | 否 | 关键设备（A）/ 主要设备（B）/ 一般设备（C），SAP ABC 标识 |
| 状态 | 否 | 运行/备用/检修/停用 |
| 装置 | 否 | SAP 工厂区段 |
| 车间 | 否 | SAP 维护工厂 / 属地单位 |
| 成本中心、工作中心、出厂编号、设备代码 | 否 | 有则原样返回 |

台账可以有以上之外的任意列（如业务系统导出的「设备类型」「特护标记」「使用状态」「材质」「功率(kW)」「扬程(m)」「设计压力(MPa)」），不改名、以表头原文（去空白）为列名原样保留，详情里返回，筛选、排序、统计一并支持。原列名末尾带单位括号时，写不带单位的名字（如「设计压力」）在唯一对应时解析到该列，生效条件写实际列名；不做包含或近义匹配（「压力」不会匹配到「设计压力(MPa)」）。脚本会记录台账**实际存在的列**，查询不存在的列时报错并列出实际字段；不确定有哪些列时先用 `--describe`。

| 专业 | 专业、所属专业、类别、设备类别、对象类型（「设备类型」不归入专业，作为其它列原样保留） | SAP PM / EM |
| 区域 | 区域、装置区、位置、所在区域、安装位置 | 车间台账 |
| 介质 | 介质、工艺介质 | 车间台账 |

**不作位号别名的列**：「设备编号」「设备」「技术对象编号」——SAP 中是流水号，不是功能位置。前缀匹配时「设备编号」最后分配；表头恰为「设备」（SAP 设备编号列）时按全等归设备编号，「设备」不作前缀别名，台账没有设备编号列时「设备类型」「设备类别」「设备等级」「设备名称」等不会被前缀匹配进设备编号。

**「设备类型」不作「专业」别名**（2026-11-04 起）：台账没有专业列时，「设备类型」按原列名保留为其它列，可直接按「设备类型」查、筛、统计，不再改名为「专业」；按「专业」筛选时报字段不存在，请改用「设备类型」或先 `--describe`。SAP 的「对象类型」仍归专业。

表头行取前 10 行中命中必需列最多的一行，因此带标题行的导出表也能读。

## 检修历史（可选，`--history`）

sheet 名匹配「检修历史」「检修记录」「维修记录」「历史」「工单」「订单」。SAP PM 工单导出（IW38/IW39）可直接用。

| 技能内列名 | 必需 | 可识别写法 |
|---|---|---|
| 位号 | 是 | 同上（功能位置） |
| 检修日期 | 否 | 检修日期、日期、完工日期、检修时间、实际结束日期 |
| 检修内容 | 否 | 检修内容、内容、工作内容、检修项目、订单描述 |
| 工作中心 | 否 | 工作中心、主工作中心、承修单位、维修班组、施工单位 |
| 工单号 | 否 | 工单号、订单、订单号、工单、PM订单、维修订单号 |
| 工单类型 | 否 | 工单类型、订单类型、维修类型 |
| 故障现象 | 否 | 故障现象、故障描述（检修内容未填时在报告中带出） |
| 发生时间 | 否 | 发生时间、故障发生时间、发生日期（无完工日期的记录按它排序） |

按位号关联，同一设备的记录按完工日期倒序；未完工（无完工日期）的记录按发生时间参与排序，检修日期不用发生时间冒充，报告写「无完工日期，某日发生」并带出故障现象。无记录的设备返回空数组，**不编造检修履历**。

## 备件对应表

本技能不再读备件表（`--spare` 传入即报错）。按位号查备件库存、在途与代用请用 `spare-parts-inventory-query`。

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）

## 产出

| 文件 | 内容 |
|---|---|
| `result.json` | 命中记录（含 `_matchedBy`、`_投用年限`）、统计结果、生效条件、台账实际列、缺失字段；`--describe` 时为列名与样例值 |
| `result.md` | 查询结果报告，含互指提示与声明行 |
| `result.xlsx` | 多条结果时导出，便于继续处理 |
| `summary.json` | 末行摘要落盘 |
