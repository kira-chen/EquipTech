## 示范三：字段不存在

**用户问**：设计压力大于 1.0 的设备有哪些？

**回答**：

所提供台账中**没有「设计压力」这一列**，无法按该条件筛选。台账实际包含的字段是：位号、设备名称、规格型号、制造厂、投用日期、专业、区域、介质、重要度、状态。

设计压力通常记录在设备档案或压力容器台账中，可以：
1. 提供含该字段的台账重新查询
2. 或用 technical-document-finder 技能从设备档案（压力容器登记资料）中查找
3. 先用 `--describe` 看台账到底有哪些列

**未用「操作压力」等相近字段代替，也未补充推算值。**

## 措辞对照

| 场景 | 应写 | 不应写 |
|---|---|---|
| 字段缺失 | 「台账中没有这一列，实际字段是……」 | 用相近字段回答而不说明 |
| 值为空 | 「规格型号：—（台账未填）」 | 留白，或写「无」 |
| 派生值 | 「约 14.3 年（以 XX 为基准）」 | 「用了 14 年」 |
| 查不到 | 「未查到，未放宽条件返回近似结果」 | 「可能是 P-9998？」 |
| 权威性 | 「权威数据以 EM / SAP PM 为准」 | 直接呈现不加说明 |
| 设备编号 | 「设备编号 1000XXXX（SAP 流水号），位号 P-XXXXA」 | 把设备编号写成位号 |
| 建造年份 | 「台账只有建造年份 2012，未推算年限」 | 「用了 14 年」 |
