# 查询口径与回答规范

## 一、三种查询类型

| 类型 | 用途 | 表达式 |
|---|---|---|
| `detail` | 单台设备详情 | `{"type":"detail","tag":"P-101A"}` 或直接写位号 / 设备编号（两列都查，分别展示） |
| `filter` | 条件筛选 | `{"type":"filter","where":[...],"orderBy":{...}}` |
| `stats` | 统计汇总 | `{"type":"stats","groupBy":"专业","where":[...]}` |
| `--describe` | 只看列名与样例值 | 不带 `--query`，先确认台账有什么列再提问 |

## 二、操作符

| 操作符 | 含义 | 示例 |
|---|---|---|
| `eq` / `ne` | 等于 / 不等于 | `["专业","eq","动设备"]` |
| `contains` | 包含 | `["制造厂","contains","沈阳"]` |
| `startsWith` | 开头匹配 | `["位号","startsWith","P-11"]` |
| `in` | 在列表中 | `["重要度","in",["A","B"]]` |
| `gt` / `gte` / `lt` / `lte` | 数值或日期比较 | `["投用日期","lt","2015-01-01"]` |
| `empty` / `notEmpty` | 为空 / 非空 | `["规格型号","empty"]` |

比较操作符会自动识别日期与数字，都不是时按文本比较。

## 三、意图解析的歧义处理

用户的自然语言常有歧义，**歧义时必须向用户确认一次，不得自行设定口径**。

| 用户说法 | 可能的口径 | 处理 |
|---|---|---|
| 「老设备」 | 投用年限长？型号老旧？ | 确认：按投用日期早于哪一年？ |
| 「关键设备」 | ABC 标识 A 类（关键设备）？还是特护设备？ | 确认：按台账的重要度列取 A 类，还是只要特护标记？ |
| 「设备号 / 设备编号」 | SAP 8 位设备流水号？还是口头说的位号？ | 两列都查；回答时写明按哪一列命中 |
| 「坏的设备」 | 状态=故障？有未闭环缺陷？ | 确认：台账状态列还是缺陷台账？ |
| 「常用的泵」 | 运行中？还是频次高？ | 确认：按状态列？ |
| 「大机组」 | 功率？还是设备类型？ | 确认：台账里有功率列吗？ |

## 四、结果表述硬规则

### 字段不存在
查询条件涉及台账中没有的字段时，**脚本直接报错终止**，错误信息列出台账实际字段。

**禁止**：用相近字段代替（如查「设计压力」时用「操作压力」）、跳过该条件后照常返回结果（用户会误以为结果是按条件筛出来的）、凭常识补充数值。

### 结果为空
明确回答「台账中未查到符合条件的设备」，报告中会自动带一行「未放宽条件返回近似结果」。

**禁止**：放宽条件后返回近似结果而不说明。

### 字段为空
显示 `—（台账未填）`，JSON 中为 `null`。

**禁止**：留白让用户误以为是零或「无」；用其他设备的值推断。

### 位号与设备编号
「位号」= SAP 功能位置 / EM 设备位号；「设备编号」= SAP 8 位流水号 / EM 编码。两者分列展示，不得把设备编号当位号报；只有设备编号列的旧台账按设备编号定位并 warning。

### 派生值
「投用年限」由投用日期（SAP 开始日期）与当前日期计算，报告中必须注明基准日期。SAP 只有「建造年份」（到年）没有开始日期的设备**不推算年限**，照实说明。其余字段一律原样返回，不做任何推算。

## 五、回答组织

| 场景 | 呈现方式 |
|---|---|
| 单台详情 | 字段表格（位号与设备编号分别列出）+ 检修历史（通知单/工单） |
| 多条结果 | Markdown 表格，超过 1 条时同时导出 `result.xlsx` |
| 统计 | 分组表格，含数量与占比 |

结果较多时提示用户可用 `--fields` 指定返回列、用 `--limit` 控制条数。

## 六、必须附带的说明

每次回答都要说明：

1. 数据来源文件与台账总条数
2. 生效的筛选条件
3. 台账中缺失的字段（如有）
4. **「数据来自所提供台账文件，权威数据以 EM 设备管理信息系统 / ERP（SAP PM）技术对象主数据与设备档案为准」**（报告中已自动带）

## 七、不做的事

- 不修改、新增、删除台账数据（EM / SAP 主数据维护由公司设备管理部门与主数据流程归口）
- 不查备件库存、在途与代用（用 `spare-parts-inventory-query`）
- 不补充台账中没有的设备参数
- 不做型号推荐与选型建议
- 不检索图纸、说明书（用 `technical-document-finder`）
- 不作为设计、选型或安全计算的权威依据
