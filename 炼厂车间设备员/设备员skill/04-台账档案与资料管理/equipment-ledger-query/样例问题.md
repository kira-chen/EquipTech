# 设备台账查询 · 样例问题

> 附件均在 `演示case/04-台账档案与资料管理/equipment-ledger-query/`（由 `node scripts/make-sample.js --seed <n>` 再生，默认 seed=1）。厂家、型号与 SAP 设备编号随 seed 变化，但每题的预期结论（命中台数、分组数、报错与否、是否推算年限）不变；预期计数与验证要点见 `演示case/04-台账档案与资料管理/equipment-ledger-query/README.md` 对照表（不进发布包）。示例 3 的设备编号以当前 `sample-sap-pm-ledger.xlsx` 里 1000-CDU-V1301 那一行为准。

1. 这是我们车间的设备台账，帮我查一下 P-1101A 是什么型号、哪个厂的、投用多久了，再把它这几年的检修记录列出来。　　**附件：** `sample-equipment-ledger.xlsx + sample-maintenance-history.xlsx`
2. 动设备里 2015 年以前投用的有哪几台，按投用时间从早到晚排一下，我要报老旧设备清单。　　**附件：** `sample-equipment-ledger.xlsx`
3. 这是从 SAP 导出来的技术对象清单，设备编号 10007947 对应的是哪台设备，建造年份和开始日期分别是多少，能算投用年限吗。　　**附件：** `sample-sap-pm-ledger.xlsx`
4. 台账里各专业各有多少台设备，A 类设备占多少，给我一张统计表。　　**附件：** `sample-equipment-ledger.xlsx`
5. 这份 EM 导出的台账列名跟平时不一样，先告诉我它有哪些列、每列大概填的什么，再帮我查 P-2101。　　**附件：** `sample-alias-ledger.xlsx`
6. 查一下台账里设计压力大于 1.0 MPa 的设备有哪些。（预期：台账无此列，明确回答并列出实际字段，不用操作压力代替）　　**附件：** `sample-equipment-ledger.xlsx`
7. P-9999 这台泵的参数是什么？（预期：未查到，不返回近似位号）　　**附件：** `sample-equipment-ledger.xlsx`
8. SAP 清单里 ABC 标识是 A 的有几台，分别是哪几台。　　**附件：** `sample-sap-pm-ledger.xlsx`
9. P-1101A 的机械密封库里还有没有？（预期：指引到 spare-parts-inventory-query，本技能不查备件）　　**附件：** `sample-equipment-ledger.xlsx`
10. 把二区的静设备按投用日期倒序列出来，只要位号、设备名称、投用日期、重要度四列。　　**附件：** `sample-equipment-ledger.xlsx`

## 平台接入业务系统 MCP 时

> 不上传附件，数据由 MCP 工具获取；演示数据每天按剧本刷新，题目只依赖剧本里固定的位号和台账参数。

M1. 常减压车间 P-2101A 是什么型号、哪个厂的、功率和扬程多少、投用多久了？再把它的检修记录列出来。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（不带参数）、设备资产管理 `get_failure_history`（tag=P-2101A，for_skill=equipment-ledger-query）
M2. 常减压车间台账里各类设备各有几台？再把换热器列出来，只要位号、设备名称、规格型号、设计压力、投用日期、重要度，按投用时间从早到晚排。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（不带参数）
M3. E-1201 换热器的设计压力、设计温度、材质是多少？以前修过哪些，最近这次管束内漏修完了没有？　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（不带参数）、设备资产管理 `get_failure_history`（tag=E-1201，for_skill=equipment-ledger-query）
