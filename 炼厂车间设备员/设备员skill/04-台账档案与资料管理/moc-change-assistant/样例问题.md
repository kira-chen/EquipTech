# 设备变更管理辅助 · 样例问题

> 附件均在 `演示case/04-台账档案与资料管理/moc-change-assistant/`（由 `node scripts/make-sample.js --seed <n> --date 2026-11-30` 再生，默认 seed=1）。SAP 设备编号与设计参数数值随 seed 变化，但每题的预期结论（是否变更、变更类型、级别、冲突数、未判定数、法定手续是否适用）不变；预期计数、运行参数与验证要点见 `演示case/04-台账档案与资料管理/moc-change-assistant/README.md` 对照表与 `演示case/04-台账档案与资料管理/moc-change-assistant/sample-cases.md`（不进发布包）。本技能主要靠对话给出原状态与变更后状态，附件为可选的台账与厂内制度表。

1. 进料换热器 E-2201 的管束想从 316L 改成碳钢 Q345R 降成本，这算不算变更，要走到哪一级，台账我发你了。（预期：设备设施变更 / 重大，R1；第八节列三项法定手续）　　**附件：** `sample-equip-ledger.xlsx`
2. 低压分离器 V-2301 筒体下部想加一个 DN25 的取样口，这台是压力容器，除了报变更还要办什么手续。（预期：重大，R3；改造告知、监督检验、使用登记变更）　　**附件：** `sample-equip-ledger.xlsx`
3. P-2101A 的机械密封要换，型号材质都一样就是换了个厂家，我们厂的变更实施细则在这，按厂里的规定要不要报。（预期：默认待厂内评审 R6，厂内制度定重大，冲突 1 处以厂内为准）　　**附件：** `sample-plant-spec.xlsx`
4. 塔顶冷却器 T-2501 冷却水线临时加一条 DN50 跨线顶到下个月大检修，临时的也要走变更吗，期限怎么定。（预期：重大（临时），R3+R7，输出恢复期限与恢复计划四项）　　**附件：** 无
5. 急冷油泵 P-2103A 低流量联锁值想从 12 调到 8，这个该我报还是仪表报，设备这边要评估什么。（预期：工艺技术变更 / 重大，R5，由仪表专业提报，设备员不可直接提报）　　**附件：** `sample-equip-ledger.xlsx`
6. 机封坏了换一个同型号同材质同厂家的新件，这个总不用走变更了吧。（预期：确认 `--same-model-material 是` 后判不属于变更 RN1；未确认则按 R6 待评审）　　**附件：** 无
7. P-2101A 那台泵坏了，想直接换成备用的 P-2101B 顶上，要走变更吗。（预期：未判定 U1，只给位号不算具体，追问两台泵型号、扬程、材质是否相同）　　**附件：** 无
8. 分馏塔 C-2401 操作压力想从 0.6 提到 0.95 MPa，设计压力 0.8，算什么变更，我能直接报吗。（预期：工艺技术变更 / 重大，R4，由工艺专业提报）　　**附件：** 无
9. 车间的维保单位要换成乙公司，这个算变更吗，级别怎么定。（预期：管理变更；无厂内制度时级别未判定 U6，加 `--spec` 后按厂内定级）　　**附件：** `sample-plant-spec.xlsx`
10. 这份厂内制度表里有两条写得不规范，脚本能用吗。（预期：无法识别的类别 / 等级逐条 warning 并跳过，其余条款照常生效，不中断）　　**附件：** `sample-plant-spec-bad.xlsx`

## 平台接入业务系统 MCP 时

> 不上传附件，设备台账由 MCP 工具按位号获取，演示数据每天按剧本刷新；原状态、变更后状态与变更原因仍由用户在对话中说明。

M1. E-1201 管束内漏今天抽芯检修，打算把换热管从 10# 碳钢换成 S30408 不锈钢，规格还是 φ25×2.5，这算什么变更，要走到哪一级，除了报变更还要办什么手续。（预期：设备设施变更 / 重大，R1；台账设备类型为换热器，第八节列改造告知、监督检验、使用登记变更三项）　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=E-1201）
M2. P-2101A 的原厂机械密封（OH2 150-400 单端面，SiC/石墨）库里没货了，想用另一家同规格的顶上，要走变更吗。（预期：备件代用待厂内评审 R6，走材料代用单 / 同类替换评审；台账为离心泵，不附承压设备法定手续）　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=P-2101A）
M3. 常顶回流罐 V-1201 罐底想新增一个 DN50 排凝管口，法兰连接，算不算变更，要办什么手续。（预期：设备设施变更 / 重大，R3；台账设备类型为压力容器，列三项法定手续）　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（tag=V-1201）
