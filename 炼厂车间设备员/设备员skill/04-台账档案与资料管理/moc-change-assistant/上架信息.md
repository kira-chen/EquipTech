# 设备变更管理辅助
**技能名称**：设备变更管理辅助

**技能简介**：把一项设备改动的原状态和变更后状态说清楚，它按《中国石化变更管理规定》的口径判定算不算变更、是工艺技术还是设备设施变更、重大还是一般、是否临时，列出需评估项、要改的台账图纸和承压设备的法定手续；信息不够就说未判定，绝不替你说"不用走变更"。

**技能描述**

面向炼化厂车间设备员，解决"换个型号要不要报变更、材质降档行不行"这类拿不准的问题。说明位号、原状态、变更后状态和原因，可附 SAP PM 台账核对，脚本按规则判定：同型号同材质同厂家更换是同类替换不走变更，换厂家代用待厂内评审；材质降级、结构改动判重大，型号影响性能判一般；工艺参数和联锁值由工艺、仪表专业提报；承压设备改动固定附改造告知、监督检验等法定手续提示；临时变更必须有恢复期限。有厂内细则就传进来，冲突时以厂内为准。要素不全一律追问并输出未判定。产出需评估项、应更新的台账图纸规程清单和 JSON，每条带条款号，由模型成文。不审批、不做方案设计，以厂内变更管理部门认定为准，未经批准不得实施。

**示例问题**
1. 进料换热器 E-2201 的管束想从 316L 改成碳钢 Q345R 降成本，这算不算变更，要走到哪一级，台账我发你了。　　**附件：** `sample-equip-ledger.xlsx`
2. 低压分离器 V-2301 筒体下部想加一个 DN25 的取样口，这台是压力容器，除了报变更还要办什么手续。　　**附件：** `sample-equip-ledger.xlsx`
3. P-2101A 的机械密封要换，型号材质都一样就是换了个厂家，我们厂的变更实施细则在这，按厂里的规定要不要报。　　**附件：** `sample-plant-spec.xlsx`
4. 塔顶冷却器 T-2501 冷却水线临时加一条 DN50 跨线顶到下个月大检修，临时的也要走变更吗，期限怎么定。　　**附件：** 无
5. 急冷油泵 P-2103A 低流量联锁值想从 12 调到 8，这个该我报还是仪表报，设备这边要评估什么。　　**附件：** `sample-equip-ledger.xlsx`
