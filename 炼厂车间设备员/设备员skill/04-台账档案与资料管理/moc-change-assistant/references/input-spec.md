# 输入规格：设备变更管理辅助

## 一、命令行输入（主要方式）

```bash
node scripts/moc.js \
  --tag "<位号>" --before "<原状态>" --after "<变更后状态>" --reason "<变更原因>" \
  --category <材质|型号|结构|工艺|控制|备件代用|管理> \
  --out "<输出目录>"
```

### 必需参数

| 参数 | 说明 |
|---|---|
| `--tag` | 设备位号（SAP 功能位置）；配台账时也可给 SAP 设备编号 |
| `--before` | 原状态，**必须具体到参数或型号**，笼统描述或只给位号触发未判定 U1 |
| `--after` | 变更后状态，同上 |

### 判定要素参数

| 参数 | 取值 | 缺失时的后果 |
|---|---|---|
| `--category` | 材质 / 型号 / 结构 / 工艺 / 控制 / 备件代用 / 管理 | 脚本从描述自动识别；识别不出 → **未判定 U2**。「临时」不是类别：写了按临时属性处理并 warning |
| `--same-model-material` | 是 / 否 | 未填 → **不命中 RN1**，按对应类别规则判定，绝不默认为「不属于变更」 |
| `--affects-perf` | 是 / 否 | 型号规格类变更未填 → **未判定 U4** |
| `--exceeds-design` | 是 / 否 | 工艺参数类变更未填 → **未判定 U4** |
| `--special` | 是 / 否 | 结构或材质改动时：未填 → 按台账对象类型 / 名称 / 描述推断是否压力容器 / 压力管道；推断不出 → 三项法定手续按「待确认」列出并进未判定清单，**不默认免办**；取值非法报错 |
| `--temporary` | 开关参数（无取值） | 标记为临时属性（不改变级别） |
| `--until` | `YYYY-MM-DD` | 临时变更未填 → **未判定 U5**；格式非法 → 报错终止 |

### 其他参数

| 参数 | 说明 |
|---|---|
| `--reason` | 变更原因；缺失时 warning，不中断 |
| `--spec` | 厂内变更管理实施细则 xlsx，见下 |
| `--ledger` | 设备台账 xlsx（SAP PM / EM 列名），用于核对原状态与识别承压设备 |
| `--workshop` | 车间名，写入报告标题 |
| `--applicant` | 申请人 |
| `--name` | 设备名称（台账未提供时手工指定，也用于承压设备识别） |
| `--out` | 输出目录，默认 `<os.tmpdir()>/moc-out`，建议始终传 |

布尔类参数的取值识别：

| 解析结果 | 可识别写法 |
|---|---|
| 是 | 是、有、会、影响、超出、改变、Y、yes、true、1 |
| 否 | 否、无、不、不影响、未超、不变、N、no、false、0 |
| **未填（null）** | 空，或以上均不匹配 |

## 二、厂内变更管理制度（可选，`--spec`）

sheet 名匹配「变更判定」「判定口径」「变更管理」「制度」。预填模板：`assets/templates/plant-spec-template.xlsx`（按《中国石化变更管理规定》分类框架预填变更类型与默认级别，级别与条款号由厂内按实施细则改填）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 变更类别 | 是 | 七类之一（材质 / 型号规格 / 结构 / 工艺参数 / 控制方案 / 备件代用 / 管理）；无法识别的行 warning 并跳过该条 |
| 变更类型 | 否 | 工艺技术变更 / 设备设施变更 / 管理变更；与默认映射不同时按厂内并 warning |
| 变更等级 | 否 | 重大变更 / 一般变更 / 厂内评审（走材料代用单 / 同类替换评审）/ 不属于变更 |
| 判定 | 否 | 变更等级为空时从此列取 |
| 条款号 | 否 | 冲突时引用；缺失时用「厂内制度第 N 行」。虚构示例一律写 `Q/XX-虚构-001 第 x 条` |

**厂内制度与默认口径冲突时以厂内制度为准**，冲突点写入 `conflicts`，默认口径结论保留在 `defaultVerdict` 中备查。本次判定为未判定时不覆盖，只 warning 提示补齐要素后按厂内制度定级；管理变更（U6）由厂内制度定级不算冲突。

表头行识别：取前 10 行中命中必需列最多的一行，因此首行是标题、第三行才是表头的制度摘录表也能读。首列以「合计」「小计」等开头的行跳过并 warning。

## 三、设备台账（可选，`--ledger`）

sheet 名匹配「设备台账」「台账」「设备清单」「技术对象」。用于核对原状态、补全设备名称、按设备类别识别压力容器 / 压力管道。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 与 `--tag` 匹配（SAP 功能位置）；未命中时再按设备编号匹配；都未命中 warning，`equip` 输出 null |
| 设备编号 | 否 | SAP 8 位流水号 / EM 编码，单列展示，**不作位号** |
| 设备名称 | 否 | SAP「设备描述」 |
| 设备类别 | 否 | SAP「对象类型」/ 特种设备「设备品种」；含「压力容器 / 压力管道 / 换热器 / 反应器 / 塔 …」时识别为承压设备 |
| 设备代码 | 否 | 特种设备代码，原样带出 |
| 材质 / 型号 / 设计压力 / 设计温度 / 介质 | 否 | 仅用于展示核对，**不用于替用户填写原状态** |

### 列名别名（局部别名 + 共享 SYSTEM_ALIASES）

| 标准列名 | 可识别写法（局部） | 共享别名追加（SAP PM / EM 导出） |
|---|---|---|
| 位号 | 位号、设备位号、TAG | 位号编码、**功能位置**、功能位置编号、技术标识、技术对象、技术对象标识 |
| 设备编号 | — | 设备编号、**设备**（SAP 流水号）、设备号、设备编码、技术对象编号、EM编码 |
| 设备名称 | 设备名称、设备描述、名称 | 技术对象描述、功能位置描述、描述 |
| 设备类别 | — | 设备类别、设备类型、**对象类型**、设备分类、专业类别、设备品种 |
| 设备代码 | — | 设备代码、特种设备代码、注册代码、注册编号 |
| 材质 | 材质、主体材质、材料、主要材质 | — |
| 型号 | 型号、规格型号、型号编号、规格 | — |
| 设计压力 / 设计温度 | 设计压力(MPa)、设计温度(℃) 等 | — |
| 介质 | 介质、工艺介质 | — |
| 变更类别 | 变更类别、类别、细分类别 | — |
| 变更类型 | 变更类型、变更大类、三大类、类型 | — |
| 判定 | 判定、结论、是否变更、认定 | — |
| 变更等级 | 变更等级、变更级别、等级、级别 | — |
| 条款号 | 条款号、条款、制度条款、编号 | — |

「设备编号」不是位号别名：SAP 导出表里「功能位置」是位号、「设备」是流水号，两者分列。

## 四、会被跳过的行

- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 制度表中变更类别或变更等级无法识别的行（warning 提示，该条不采用）

## 五、产出

| 文件 | 内容 |
|---|---|
| `moc.json` | `isChange`、`changeType` / `changeTypeCn`、`level` / `levelCn`、`temporary`、`basis`、`ruleId`、`defaultVerdict`、`ownership`、`statutory`、`equip`、`assessItems`、`docUpdates`、`undetermined`、`conflicts`、`temporaryPlan`、`counts`、`declaration` |
| `moc.md` | 十节固定报告，末尾含固定声明行 |
| `summary.json` | 末行摘要落盘 |

`isChange` 三态：`true` 属于变更 / `false` 不属于变更（仅 RN1 正面命中）/ **`null` 未判定或待厂内评审**（看 `level`）。
