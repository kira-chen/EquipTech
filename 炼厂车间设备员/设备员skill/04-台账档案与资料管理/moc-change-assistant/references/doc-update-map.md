# 变更类别 ↔ 应更新资料对照表

> 变更实施后须同步更新的台账、图纸、档案与规程。**本表为默认口径，厂内资料管理制度另有规定的以厂内为准。**
> 本清单是提示，实际更新由资料管理岗与设备员按厂内流程执行（EM / SAP PM 主数据走主数据维护流程）；**本技能不替用户修改任何台账与图纸**。
> 脚本 `scripts/lib/rules.js` 的 `DOC_MAP` 与本表同源，修改一处须同步另一处。

## 一、通用原则

1. **先批后改、先改后用**：变更批准前不得修改正式资料；变更实施后资料未更新不得视为变更闭环。
2. **图物一致**：现场实物与 P&ID、台账、设备档案必须一致，不一致即为变更未闭环。
3. **临时变更的资料**用临时标识标注，恢复后撤除标识并恢复原始版本，恢复记录归档。
4. 涉及操作方式改变的，**必须有培训记录**，培训未完成不得视为变更闭环。
5. 承压设备改造的**改造告知、监督检验资料与使用登记变更**归入设备档案与特种设备台账。

## 二、分类别对照表

### 材质变更

| 应更新资料 | 更新内容 |
|---|---|
| 设备台账（EM / SAP PM 技术对象） | 材质字段、设计参数字段 |
| 设备档案 | 材质证明书、材料代用单、焊接工艺评定记录 |
| P&ID | 如材质等级号（管道等级）随之变化需同步修改 |
| 设备技术档案（竣工资料） | 制造数据表、质量证明文件 |
| 定期检验计划 / 特种设备台账 | 检验周期与检验方法；承压设备附使用登记变更 |
| 操作规程 | 涉及材质限制的操作条件说明 |

### 型号规格变更

| 应更新资料 | 更新内容 |
|---|---|
| 设备台账（EM / SAP PM 技术对象） | 型号、规格、性能参数、制造厂 |
| 设备档案 | 新设备说明书、合格证、性能曲线 |
| P&ID | 设备位号后的规格标注 |
| 备件台账 / SAP MM 物料主数据 | 物料编码、通用性关系 |
| 操作规程 | 正常操作参数范围、开停机步骤 |
| 培训记录 | 操作与维护人员对新型号的培训 |

### 结构改动

| 应更新资料 | 更新内容 |
|---|---|
| 设备台账（EM / SAP PM 技术对象） | 结构参数、管口表 |
| P&ID | 管口增减、连接方式、走向 |
| 设备布置图 / 管道单线图 | 改动部位 |
| 设备档案 | 改造施工方案、竣工图、无损检测报告、耐压试验记录 |
| 定期检验计划 / 特种设备台账 | 新增检查部位与测厚点；承压设备附改造告知与监督检验资料、使用登记变更 |
| 操作规程 | 巡检路线与检查部位 |
| 培训记录 | 改动部位的操作与巡检交底 |

### 工艺参数变更（由工艺专业修订，设备员配合）

| 应更新资料 | 更新内容 |
|---|---|
| 工艺卡片 / 工艺指标 | 操作压力、温度、流量、处理量（由工艺专业修订） |
| P&ID | 注明的操作条件与设计条件 |
| 设备台账（EM / SAP PM 技术对象） | 实际操作参数字段 |
| 操作规程 | 正常操作法、开停工方案、异常处置 |
| 联锁定值台账 | 报警值与联锁值（由仪表专业修订） |
| 培训记录 | 新参数下的操作培训与考核 |
| 排污许可 / 环保台账 | 排放参数如有变化 |

### 控制方案变更（由仪表专业修订，设备员配合）

| 应更新资料 | 更新内容 |
|---|---|
| 联锁定值台账 | 联锁值、报警值、动作逻辑（由仪表专业修订） |
| 控制逻辑图 / 因果图 | 逻辑关系 |
| DCS/SIS 组态文件与版本记录 | 组态修改记录与回路测试报告 |
| P&ID | 仪表回路与联锁标注 |
| 操作规程 | 报警响应卡、异常处置预案 |
| 培训记录 | 新逻辑的操作培训 |
| 设备档案 | 回路功能测试记录 |

### 备件代用

| 应更新资料 | 更新内容 |
|---|---|
| 材料代用单 / 同类替换评审记录 | 代用依据、评审意见、批准人 |
| 备件台账 / SAP MM 物料主数据 | 代用关系、厂家、物料编码 |
| 设备档案 | 代用件材质证明、合格证、技术协议 |
| 设备台账（EM / SAP PM 技术对象） | 如实际装用件与台账不一致需注明 |
| 维护保养规程 | 保养要求差异 |

### 管理变更

| 应更新资料 | 更新内容 |
|---|---|
| 管理制度 / 岗位职责文件 | 修订版本与发布记录 |
| 设备管理责任清单 | 责任人、维保单位、承包商变更 |
| 培训记录 | 制度宣贯与考核 |

### 临时措施（临时属性时并入）

| 应更新资料 | 更新内容 |
|---|---|
| 临时变更台账 | 期限、恢复责任人、恢复计划 |
| 设备台账（EM / SAP PM 技术对象） | 临时状态标注 |
| P&ID | 临时流程以临时标识标注，恢复后撤除 |
| 操作规程 | 临时操作规定 |
| 值班与工作交接记录 | 临时状态的交接（设备员值班 / 休假 / 调岗交接，不是操作班组交接班） |
| 旁路 / 强制点登记表 | 仪表联锁临时旁路时 |

## 三、资料更新的闭环要求

| 环节 | 要求 |
|---|---|
| 变更批准后 | 明确各项资料的更新责任人与完成期限 |
| 变更实施中 | 现场保留变更标识，防止误操作 |
| 变更实施后 | 逐项核对本表清单，全部更新完成后方可申请变更闭环 |
| 临时变更到期 | 恢复原状并撤除临时标识，恢复记录归档；未恢复须重新申请延期 |
| 承压设备改造 | 改造告知、监督检验报告、使用登记变更资料归档后方可闭环 |

## 四、临时变更的资料合并口径

判定带**临时属性**时，除按实际改动类别（如结构改动）列出的资料外，**自动并入「临时措施」一节的资料**（临时变更台账、旁路/强制点登记表、值班与工作交接记录等），按资料名去重。
恢复后须反向核对：临时标识是否撤除、P&ID 是否恢复原版本、临时变更台账是否已销项。

## 五、兜底

**未列入本表但厂内制度要求的资料，一律按厂内制度补充。** 清单遗漏不构成免责理由。
