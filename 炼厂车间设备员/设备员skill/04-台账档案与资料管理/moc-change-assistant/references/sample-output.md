## 未判定情形的写法示范

当用户只说「那个泵换一下」时，产出应是：

## 二、是否属于变更及依据

| 项目 | 内容 |
|---|---|
| **是否属于变更** | **未判定** |
| **变更类型** | **—** |
| **建议变更级别** | **未判定** |
| 判定依据 | 原状态与变更后状态必须具体到参数或型号（只写位号不算），请补充后重新判定；在补齐前不得认定为「不需要走变更」 |
| 依据条款 | U1 |

## 六、待确认信息

| 未判定项 | 缺少的要素 | 说明 | 条款 |
|---|---|---|---|
| 是否属于变更及变更等级 | 原状态：描述笼统（「换个泵」），未说明具体参数或型号；变更后状态：描述笼统（「换个新的」），未说明具体参数或型号 | 原状态与变更后状态必须具体到参数或型号 | U1 |

> 信息不足时**不得**判定为「不需要走变更」，须补齐上述要素后重新运行判定。

对应的交付说明写法：

> 目前还判不了。「换个泵」「换成 P-2101B」这样的描述没法作为判定依据 —— 换的是同型号同材质同厂家的泵（那是同类替换，不算变更），还是换了型号或扬程（那就要走设备设施变更），结论完全不同。请补充：原泵型号与材质、新泵型号与材质、扬程流量是否变化。补齐后重新判定。**在判定明确之前，不能按「不用走变更」处理。**

## 措辞对照

| 场景 | 应写 | 不应写 |
|---|---|---|
| 判定 | 「设备设施变更，判重大变更，依据 R1：材质由 316 系不锈钢降为碳钢」 | 「这个改动挺大的，得走变更」 |
| 不属于变更 | 「已确认型号、材质与厂家均未改变，依据 RN1 同类替换，不属于变更」 | 「就是换个件，不用走变更」 |
| 换厂家代用 | 「同规格不同厂家代用，待厂内评审（R6），走材料代用单」 | 「换厂家不用报」或直接判一般变更 |
| 归口 | 「联锁定值属工艺技术变更，由仪表专业提报（R5），设备侧提示……」 | 设备员替仪表提报 |
| 承压设备 | 「结构改动属改造，须办改造告知、监督检验、使用登记变更」 | 只报变更不提法定手续 |
| 未判定 | 「未判定（U4），需确认是否影响性能参数，补齐后重判」 | 「看着不影响，应该不用报」 |
| 描述笼统 | 「原状态需具体到型号与材质，否则判不了」 | 按笼统描述直接给结论 |
| 厂内制度 | 「以厂内制度 Q/XX-虚构-001 第X.X.X条为准判重大，默认口径为待厂内评审（R6）」 | 只报一个等级不说口径来源 |
| 临时变更 | 「期限 2026-XX-XX，恢复责任人与验收方式须填写」 | 「临时用一下，到时候改回来就行」 |
| 审批 | 「未经变更管理部门批准不得实施」 | 「按这个走就行了」 |
