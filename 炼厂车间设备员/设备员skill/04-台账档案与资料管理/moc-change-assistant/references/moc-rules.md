# 设备变更判定规则表（中石化口径）

> **本表为默认参考口径**，分类框架依据《中国石化变更管理规定》；各厂实施细则不同，**厂内有正式制度时一律以厂内制度为准**，脚本用 `--spec` 读入厂内制度后会自动覆盖默认口径，并把冲突点列入 `conflicts`。
> 本判定为辅助参考，变更是否成立、变更类型、级别与审批要求以厂内变更管理部门按《中国石化变更管理规定》及厂内实施细则认定为准；未经批准不得实施变更。

## 一、变更类型（三大类）与级别

| 变更类型 | 包含的细分类别 | 提报专业 |
|---|---|---|
| **设备设施变更** | 材质变更、型号规格变更、结构改动、备件代用 | **车间设备员**（涉及承压设备须附特种设备法定手续） |
| **工艺技术变更** | 工艺参数变更、控制方案 / 联锁定值变更 | 工艺专业（工艺参数）、仪表专业（联锁定值 / 控制方案，SIS 由仪表与工艺共同）；**车间设备员只做设备适应性提示与台账衔接，不自行提报** |
| **管理变更** | 组织机构、制度、人员、承包商 / 维保单位 | 车间 / 分厂管理部门；级别按厂内制度确定 |

| 级别 | 含义 | 典型审批深度（默认口径） |
|---|---|---|
| 重大变更 | 影响安全、工艺包络或设备完整性 | 多专业会审 + 分厂 / 公司审批，须做变更风险分析 |
| 一般变更 | 影响性能或维护方式，不突破设计包络 | 专业审核 + 车间 / 分厂审批 |
| 待厂内评审 | 同规格不同厂家代用：走材料代用单 / 同类替换评审 | 是否报变更以厂内制度为准 |
| 不属于变更 | 同类替换（同型号、同材质、同厂家），恢复性维修 | 走日常维修流程，不走变更 |
| **未判定** | 判定要素缺失 | **不得按「不需要走变更」放行**，补齐要素后重判 |

**「临时」是属性，不是级别也不是类别**：临时变更在上述级别上标 `temporary: true`，必须有恢复期限（`--until`）与恢复计划（恢复责任人、恢复内容、验收方式、到期未恢复的升级处置）；`--category 临时` 会被转为临时属性并 warning。

## 二、细分类别

材质变更、型号规格变更、结构改动、工艺参数变更、控制方案变更、备件代用、管理变更，共七类。
类别可由 `--category` 指定，也可由脚本从原状态、变更后状态与变更原因的文本中识别；**识别不出时判未判定（U2），不得默认为「不属于变更」**。

## 三、判定规则表（按顺序匹配，命中即返回）

| 规则号 | 条件 | 变更类型 | 判定 |
|---|---|---|---|
| **RN1** | 同型号、同材质、同厂家的备件更换（已**正面确认** `--same-model-material 是`） | — | **不属于变更（同类替换）** |
| R1 | 材质降级，或改变材质类别 | 设备设施 | 重大变更 |
| R2 | 型号规格改变且影响性能参数（流量、扬程、功率、换热面积等） | 设备设施 | 一般变更 |
| R3 | 结构改动（增减管口、改变连接方式、增设或拆除构件、加装跨线） | 设备设施 | 重大变更；承压设备附三项法定手续 |
| R4 | 工艺参数超出设计范围（操作压力、温度、介质、处理量） | 工艺技术 | 重大变更（未超 → 一般）；由工艺专业提报 |
| R5 | 控制方案 / 联锁定值改变（联锁逻辑、报警值、保护定值、控制回路） | 工艺技术 | 重大变更；由仪表专业提报 |
| R6 | 同规格不同厂家代用 | 设备设施 | **待厂内评审**：建议走材料代用单 / 同类替换评审，是否报变更以厂内制度为准 |
| R7 | 临时属性 | 随类别 | 在上述级别上标 temporary，须设期限与恢复计划（`ruleId` 写成 `R3+R7` 等） |
| R8 | 管理变更 | 管理 | 级别按厂内制度确定（未提供 `--spec` → U6） |

补充口径：

- **R1 的判定**：按材质耐蚀/耐温能力排序 —— 铸铁 < 碳钢 < 低合金钢 < 304 系 < 316 系 < 双相钢 < 钛材/镍基合金。序位下降即「降级」；跨越黑色金属 / 不锈钢系 / 特种合金三个大类即「改变材质类别」。两者任一成立都判重大变更。
- **同类别材质升级**（如 316L → 2205）仍属变更，按一般变更处理，须确认焊接工艺评定与热处理适应性。
- **R4 未超设计范围**时按一般变更处理，仍须评估操作规程与联锁定值的适应性，不按「不属于变更」；无论级别都由工艺专业提报。
- **R2 不影响性能参数**时等同同规格代用（R6），待厂内评审。
- **R6 不自动判一般变更**：同规格不同厂家代用在中石化口径下走材料代用单 / 同类替换评审，是否需报变更由厂内制度定（`--spec` 可把它定为一般或重大）。
- **R7 不优先于类别**：临时属性不改变级别（临时结构改动仍按 R3 重大），只叠加期限与恢复计划要求。

## 四、未判定条款（U 条款优先于所有判定规则）

| 条款 | 触发条件 | 需补充的要素 |
|---|---|---|
| **U1** | 原状态或变更后状态未具体到参数或型号（**只写位号、"换成备用那台"不算**） | 原状态、变更后状态的具体参数或型号 |
| **U2** | 变更类别无法识别 | 属于七类中的哪一类 |
| **U3** | 材质类变更但原材质或变更后材质牌号无法识别 | 材质牌号 |
| **U4** | 型号规格变更未确认「是否影响性能参数」，或工艺参数变更未确认「是否超出设计范围」 | 对应的是/否确认 |
| **U5** | 临时变更未给出恢复期限 | 恢复期限（`--until`） |
| **U6** | 管理变更未提供厂内制度定级 | `--spec` 或主管部门确定级别 |

另有一类"待确认"不影响级别但单列：结构或材质改动时**未确认对象是否为压力容器 / 压力管道**（`--special` 未填且台账 / 描述推断不出）→ 三项法定手续按「待确认」列出并进未判定清单，不默认免办。

**未判定的处理要求（硬约束）：**

1. `moc.json` 的 `isChange` 输出 `null`（**不是 `false`**），`level` 输出 `undetermined`。
2. 在 `undetermined` 数组与报告「六、待确认信息」中单列，逐项写明还需补充哪个要素。
3. **绝不因信息不足而判定「不需要走变更」。** 「不属于变更」只能由 RN1 正面命中 —— 即已明确确认型号、材质与厂家均未改变。
4. 也不得反过来一律从严按重大变更处理；未判定就是未判定，补齐要素后重新运行。

## 五、描述具体性要求

原状态与变更后状态必须**具体到参数或型号**。以下情况视为描述不足，直接触发 U1：

| 不可接受 | 应写成 |
|---|---|
| 换个泵 | 原 IH100-65-200 离心泵（扬程 50m），换为 IH100-65-250（扬程 80m） |
| 换成 P-2101B / 用备用的顶上 | 原泵型号 IH100-65-200 扬程 50m，备用泵型号 IH100-65-250 扬程 80m（位号只说明是哪台，不说明参数变了什么） |
| 改一下材质 | 管束材质由 316L 改为 Q345R 碳钢 |
| 动一下联锁 | 低流量联锁值由 12 m³/h 改为 8 m³/h |
| 加个口 | 筒体下部新增 DN25 取样管口一个，法兰连接 |
| 压力提一提 | 操作压力由 0.6 MPa 提至 0.95 MPa（设计压力 0.8 MPa） |

判定为具体的依据：描述中出现数值加单位（MPa、℃、mm、m³/h、kW 等）、公称直径（DN）、型号串（字母+两位以上数字，位号样式除外）、或材质牌号（316L、Q345R、15CrMo 等）。管理变更不要求参数或型号，只要求原状态与变更后状态写清对象。

## 六、压力容器 / 压力管道的三项法定手续

结构或材质改动的对象是压力容器 / 压力管道（特种设备）时，改动属改造，报告第八节固定附加三项提示（只提示名称，不写数值与期限；具体要求依据 TSG 21 / TSG D7005 与厂内特种设备管理规定）：

| 法定手续 | 说明 | 由谁办理 |
|---|---|---|
| 改造告知 | 改造施工前向特种设备安全监督管理部门办理告知 | 特种设备管理员 |
| 监督检验 | 改造过程由有资质的检验机构实施监督检验 | 检验机构（特种设备管理员委托） |
| 使用登记变更 | 改造完成后办理使用登记证变更 | 特种设备管理员 |

是否承压设备的判断顺序：`--special` 用户指定 → 台账「设备类别 / 对象类型 / 设备品种」或设备描述含压力容器、压力管道、换热器、反应器、分离器、塔、汽包、锅炉、管道等 → 描述文本；都判断不出按「待确认」处理。衔接 `special-equipment-inspection-due`（改造后的使用登记与定检）。

## 七、厂内制度冲突处理

`--spec` 传入的厂内制度表（工作表「变更判定」，列：变更类别、变更类型、判定、变更等级、条款号）按类别匹配：

- 厂内制度与默认口径**等级不同** → 记入 `conflicts`，**采用厂内制度的等级**，`ruleId` 改为厂内条款号，`basisSource` 标为「厂内制度」，同时在 `defaultVerdict` 保留默认口径结论备查。
- 厂内制度的**变更类型**与默认映射不同 → 按厂内并 warning。
- 等级相同 → 不记冲突，判定依据注明「与厂内制度第 X 条一致」。
- 本次判定为**未判定**时 → 不做覆盖，只出 warning 提示补齐要素后按厂内制度定级；管理变更（U6）由厂内制度定级不算冲突。
- 制度条目的类别或等级无法识别 → warning 提示该条未采用，不中断，其余条款照常生效。

## 八、需评估项分组

需评估项固定按六个专业分组输出，顺序为：**安全、工艺、设备、电气仪表、环保、操作规程**。各类别下的具体条目见 `scripts/lib/rules.js` 的 `ASSESS_MAP`，与本表口径一致；作业许可相关条目一律写「用火作业」「受限空间作业」「盲板抽堵作业」（八大类命名）。

判定为**重大变更**时，「安全」组自动附加一条「重大变更须组织多专业会审并保留评审记录」。

**临时属性**时，在原类别评估项的基础上**并入「临时措施」类的评估项**（补偿性安全措施、加密巡检、恢复计划、旁路强制点登记等），按专业合并去重；应更新资料清单同样并入临时变更台账、旁路登记表、值班与工作交接记录等临时类资料。

需评估项是**提示清单**，不是评估结论；HAZOP、SIL 定级、强度校核等专业结论须由对应专业出具，本技能不替代。

## 九、判定依据的写法要求

判定依据必须引用规则条款编号（RN1、R1~R8、U1~U6），采用厂内制度时引用厂内条款号（如「Q/XX-虚构-001 第4.2.5条」）。**不得只写结论**，例如：

| 应写 | 不应写 |
|---|---|
| 「设备设施变更，判重大变更，依据 R1：材质由 316 系不锈钢降为碳钢」 | 「这个改动比较大，按重大变更走」 |
| 「未判定（U4）：需确认是否影响性能参数」 | 「看着不影响，应该不用走变更」 |
| 「同规格不同厂家代用，待厂内评审（R6）：走材料代用单 / 同类替换评审」 | 「换个厂家不用报」 |
| 「以厂内制度第4.2.5条为准判重大变更，默认口径为待厂内评审（R6）」 | 「厂里要求严，按重大」 |
| 「工艺技术变更，由工艺专业提报（R4）；设备侧提示：承压设备在新参数下的强度裕度」 | 设备员代工艺提报 |
