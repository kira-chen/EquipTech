# 变更要素确认清单与追问话术

## 一、必需要素

| 要素 | 为什么必需 | 缺失时的追问 |
|---|---|---|
| 设备位号 | 变更必须挂到具体设备 | 「这个改动是哪台设备？位号是多少？」 |
| **原状态** | **判定的基准，必须具体到参数或型号** | 「原来是什么型号/材质/参数？具体数值是多少？」 |
| **变更后状态** | **判定的对象，必须具体到参数或型号** | 「改完以后是什么型号/材质/参数？」 |
| 变更原因 | 申请时的必要性说明 | 「为什么要改？是坏了、还是为了提量或降本？」 |
| 是否临时 | 临时变更须设期限与恢复计划 | 「这是长期改，还是临时顶一段时间？」 |
| 临时变更期限 | 临时变更缺期限即未判定（U5） | 「打算顶到什么时候？哪天之前恢复？」 |
| 是否压力容器 / 压力管道 | 结构或材质改动时决定是否附改造告知、监督检验、使用登记变更三项法定手续 | 「这台是压力容器 / 压力管道吗？有使用登记证吗？」（有台账时按对象类型识别） |

## 二、条件必需要素

| 要素 | 什么情况下必需 | 追问 |
|---|---|---|
| 材质牌号 | 材质类变更 | 「原来的材质牌号是什么？改成什么牌号？」 |
| 是否影响性能参数 | 型号规格类变更 | 「新型号的流量/扬程/功率跟原来一样吗？」 |
| 是否超出设计范围 | 工艺参数类变更 | 「改后的压力/温度超设计值了吗？设计值是多少？」 |
| 是否同型号同材质同厂家 | 疑似只是备件更换时 | 「换的是完全一样的型号、材质和厂家吗？还是换了厂家或规格？」（同规格换厂家走材料代用单 / 同类替换评审） |
| 归口专业 | 工艺参数、联锁定值类改动 | 「这个是工艺 / 仪表那边要改的吗？由他们提报，我这边做设备适应性提示」 |
| 是否影响安全设施 | 涉及安全阀、联锁、报警时 | 「这个改动动到安全阀、联锁或报警了吗？」 |
| 是否影响介质与操作条件 | 工艺与结构类变更 | 「走的介质和操作条件跟以前一样吗？」 |

## 三、「原状态 / 变更后状态」的具体性要求

这是本技能最关键的一条：**笼统描述必须追问，不得据以判定。**

| 用户这样说 | 必须追问 | 追问后应得到 |
|---|---|---|
| 「换个泵」 | 「原来什么型号？换成什么型号？扬程流量变了吗？」 | 「IH100-65-200 换 IH100-65-250，扬程 50m→80m」 |
| 「换成 P-2101B 顶上」 | 「两台泵型号、扬程、材质一样吗？位号只说明是哪台」 | 「原 IH100-65-200 扬程 50m，备用泵 IH100-65-250 扬程 80m」 |
| 「改一下材质」 | 「原材质牌号？改成什么牌号？」 | 「管束由 316L 改为 Q345R」 |
| 「动一下联锁」 | 「哪个联锁？原定值多少？改成多少？」 | 「低流量联锁由 12 m³/h 改为 8 m³/h」 |
| 「加个口」 | 「加在哪个部位？公称直径多少？什么连接方式？」 | 「筒体下部新增 DN25 取样口，法兰连接」 |
| 「压力提一提」 | 「原操作压力多少？提到多少？设计压力多少？」 | 「0.6 MPa 提至 0.95 MPa，设计 0.8 MPa」 |
| 「用个别的厂家的件」 | 「规格一样吗？哪个厂家换哪个厂家？」 | 「同规格 5610 机封，A 厂换 B 厂」（待厂内评审，走材料代用单） |
| 「维保单位换一家」 | 「原维保单位、新维保单位各是谁？资质与范围变了吗？」 | 「维保单位由甲公司改为乙公司」（管理变更，级别按厂内制度） |

追问到位的标志：描述中含**数值加单位**、**公称直径**、**型号串**或**材质牌号**。

## 四、追问原则

1. **一次性列出所有缺项**，不要逐个挤牙膏。
2. **绝不因用户说不清就判定「不需要走变更」。** 用户说「就是个小改动」「跟原来差不多」都不构成 RN1 的正面确认；只有明确确认「型号、材质与厂家均未改变」才能判不属于变更。
3. 用户明确说「不知道」时，按未判定输出并说明补齐后可判定，**不要替用户猜**。
4. 追问结果要**回读给用户确认**后再运行脚本。
5. 若用户提供了厂内变更管理制度，**以厂内制度为准**，并把与默认口径的冲突点告知用户。

## 五、容易被漏掉的追问点

| 情形 | 容易漏掉的追问 |
|---|---|
| 「就是修一下，恢复原样」 | 真的是原型号原材质吗？备件是否换了厂家？ |
| 「厂家说这个能替代」 | 厂家说法不等于变更判定，技术参数等效性是否已核实？ |
| 「临时用一下，很快就换回来」 | 「很快」是哪天？恢复责任人是谁？ |
| 「只是把报警值调一下」 | 报警值属控制方案变更（R5，工艺技术变更），由仪表专业提报，不是参数微调。 |
| 「容器加个口，告知什么的以后再说」 | 压力容器 / 压力管道结构改动属改造，改造告知、监督检验、使用登记变更三项由特种设备管理员办理，不能事后补。 |
| 「材质换更好的，应该没问题」 | 升级仍属变更；焊接工艺与热处理适应性是否评估过？ |
| 「设计院同意了」 | 设计院意见不替代厂内变更审批。 |
