## 两条硬约束
1. **不凭记忆给数值。** `technical-document-finder` 与 `equipment-ledger-query` 均要求技术数值来自所提供资料或台账，无出处时明确回答"未找到"。
2. **法定周期不放宽。** `special-equipment-inspection-due` 存在超期设备时必须醒目提示超期使用违反《特种设备安全法》，该提示不得删除或弱化。
