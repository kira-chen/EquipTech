# examples 回归测试数据

> 本目录仅开发包含有（`build.sh --with-examples`），发布包不含。
> 全部样例由 `node scripts/make-sample.js --out examples` 再生，设备代码与组内日期随 seed 变化但结论不变。
> **样例中的设备代码、使用登记证编号、设备位号、检验机构均为虚构。**

| M1 | 常减压车间特种设备哪些超期、哪些 90 天内到期，年度检查也列出来 | 设备资产管理 `get_special_equipment`（workshop=常减压车间）→ A | `--input A --workshop 常减压车间 --date <当天>` | 20 台：压力容器 16、压力管道 3、起重机械 1，不含加氢车间设备（不带 workshop 时为全厂 30 台）；日期不一致 0、待核实 0；E-1103 按 3 级 36 个月、其余容器管道按 2 级 72 个月、Q-2101 按 24 个月校验；压力管道 W-1101、W-1201、W-3201 无上次年度检查日期，进年度检查待核实 |

## 关键验证点

1. **超期醒目提示的出现与不出现**：主样例有超期 → `inspection.md` 与 `报检准备清单.md` 开头均出现「【注意】存在超期未检特种设备，超期使用违反《特种设备安全法》，应立即停用并报检」原文；`sample-all-normal.xlsx` 无超期 → 该句不出现。
2. **等级缺失不按最长周期**：主样例 V-1305 为压力容器但安全状况等级为空，进 `undetermined`，**未按 6 年推算到期日**，也不出现在超期/临期/正常任一分组；压力管道规格型号里的 GC1 不决定周期。
3. **储罐待核实**：TK-0401 类别写「储罐」，进 `undetermined` 并标「设备类别（储罐待核实）」，warning 说明常压储罐不是特种设备，**未按压力容器处理**。
4. **安全阀不代入周期**：SV-1401A 只按台账载明的下次检验日期判超期，warning 互指 `valve-instrument-calibration-ledger`；SAP 变体中安全阀同理（临期）。
5. **日期不一致并列显示**：V-1304（压力容器 2 级）与 GL-2103（压力管道 2 级）台账「下次检验日期」被人为改写，`dateConflict` 保留台账值与计算值两者，`resolved` 取台账值，warning 具体到行号，分组按台账日期。
6. **类别不识别不硬套**：X-0301 类别写「电梯附属装置」，不在六类范围，进 `undetermined` 并 warning；自造字母码（PV/QZ 等）同样不识别。
7. **4 级监控 / 5 级停用**：V-1306（4 级）进 `monitored`，台账载明的下次检验日期（监控期限）在 90 天外，按该日期计入正常分组，不按常规周期推算（`calcNext` 为空）；V-1307（5 级）进 `stopped` 并同时进 `undetermined`。
8. **年度检查**：按「上次年度检查日期」+ 12 个自然月判到期，只对压力容器/压力管道；台账无该列（如旧格式）时 `annualCheck` 为 null 并 warning。
9. **整改项已完成不计**：`sample-issues.xlsx` 中 V-1303 标「已完成」不计入遗留；状态为空的记「未填写」，**不当作已完成**。
10. **合计行与系统列名**：SAP 变体末行「合计」被跳过并 warning，`功能位置/设备/设备描述/设备品种/设备代码/使用登记证编号/检验机构/检验类型/年度检查日期/工厂区段` 等系统列名均可识别。

```bash
node scripts/make-sample.js --out examples            # 默认 seed=1

```
