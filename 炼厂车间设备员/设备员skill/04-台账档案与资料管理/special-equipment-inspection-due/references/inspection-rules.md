# 定检周期规则、年度检查口径与表述规范

> **本表为默认参考口径，以现行有效法规、安全技术规范（TSG 21、TSG D7005 及锅炉、起重机械、场内机动车辆相应规范）与检验机构出具的检验报告载明为准。**
> 厂内特种设备管理制度（依据《中国石化设备管理规定》《炼化企业设备管理技术规定》制定）另有规定的，**以厂内规定为准**。脚本查表所得仅用于校验台账，不构成对检验周期的最终认定。

## 一、岗位边界

- **车间设备员可做**：台账到期提醒与定检计划汇总、使用单位年度检查的组织与记录、报检资料准备、遗留整改项跟踪、检验报告归档核对。
- **由特种设备管理员归口**：报检手续、检验机构委托与受理、使用登记变更。
- **由检验机构归口**：检验结论、安全状况等级、监控使用期限、改造监督检验。
- **安全阀**：校验周期以厂内规定与校验报告为准，脚本不代入；校验台账、送校批次与不合格整改用 `valve-instrument-calibration-ledger`，本技能只按台账载明的下次检验日期提示。

## 二、定期检验周期查表（脚本按「设备类别 + 安全状况等级 / 检验类型」取值）

### 1. 压力容器

| 安全状况等级 | 默认检验周期 | 说明 |
|---|---|---|
| 1 级、2 级 | 按 TSG 21 常规周期（6 年） | 一般每 6 年一次全面检验 |
| 3 级 | 按 TSG 21 常规周期（3 年） | 一般每 3 年一次全面检验 |
| 4 级 | **不推算** | 属监控使用，检验周期由检验机构在报告中确定，监控使用期限届满须重新检验 |
| 5 级 | **不推算** | 应立即停止使用，不得继续运行 |
| 缺失 / 不定级 | **不推算** | 归入待核实，**绝不按 6 年（最长）处理** |

### 2. 压力管道（工业管道）

| 情形 | 默认检验周期 |
|---|---|
| 安全状况等级 1~2 级 | 按 TSG D7005 常规周期（6 年） |
| 安全状况等级 3 级 | 按 TSG D7005 常规周期（3 年） |
| 安全状况等级 4~5 级 | **不推算**，按停用或检验机构意见处置 |
| 安全状况等级缺失 | **不推算**，归入待核实 |

**GC1 / GC2 只是管道分级，不决定检验周期。** 规格型号列里的 GC 级别只作展示；曾按 GC 级别直接给 6 年的做法会把 3 级管道算成最长周期，已删除。

### 3. 锅炉

| 检验类型 | 默认周期 |
|---|---|
| 外部检验 | 1 年 |
| 内部检验 | 2 年 |
| 水压试验 | 6 年 |

检验类型**优先取台账独立「检验类型」列**，没有时从规格型号 / 设备名称文本找。**未注明检验类型时不推算**：三者周期不同，取任一都是猜测，一律归入待核实，提示在「检验类型」列补注。

### 4. 安全阀

**脚本不代入默认周期。** 安全阀校验周期以厂内安全附件管理制度与校验报告为准；延长校验周期须有厂内审批文件。台账有「下次检验日期」时按该日期提示到期，没有时进待核实并指向 `valve-instrument-calibration-ledger`。

### 5. 起重机械

默认按相应安全技术规范常规周期（2 年）一次定期检验。日常维护保养与自行检查另按厂内制度执行，不在本技能计算范围。

### 6. 场（厂）内专用机动车辆

默认按相应安全技术规范常规周期（1 年）一次定期检验。

## 三、年度检查（使用单位自查，车间设备员主责）

压力容器 / 压力管道的使用单位每年至少进行一次年度检查（TSG 21 / TSG D7005），由车间设备员组织、记录并归档。脚本按台账「上次年度检查日期」+ 12 个自然月判到期：

| 状态 | 判定 |
|---|---|
| 年度检查超期 | 下次年度检查日 < 基准日 |
| 年度检查临期 | 0 ≤ 剩余天数 ≤ `--lead-days`（默认 90） |
| 年度检查周期内 | 剩余天数 > `--lead-days` |
| 年度检查待核实 | 上次年度检查日期缺失或无法解析，**不按定期检验日期代算** |

台账无「上次年度检查日期」列时本节不出数并 warning，建议在台账补此列。年度检查内容与记录格式按厂内特种设备管理制度，本技能不出检查表。

## 四、到期日的取值优先级

1. **台账「下次检验日期」有值 → 以其为准**（检验报告载明）。
2. 台账为空、上次检验日期与周期可确定 → 用规则计算值（按自然月推）。
3. 两者都没有 → 归入待核实，**不编造到期日**。

**两者并存且不一致时**：两个日期在报告中并列显示，出 warning 提示核实，分组（超期/临期/正常）仍按台账日期。计算值的作用是暴露台账可能的录入错误或未报备的延期，**不是用来覆盖检验报告**。

## 五、未判定（undetermined）的触发与禁止

以下情形一律单列，**不得按最长周期、最短周期或同类设备默认值处理**：

| 触发 | 缺什么 |
|---|---|
| 压力容器/压力管道安全状况等级缺失或不定级 | 安全状况等级 |
| 设备类别无法识别为六类之一（含自造字母码） | 设备类别 |
| 设备类别写「储罐」「常压罐」「油罐」且未写明压力容器 | 设备类别（储罐待核实）——常压储罐不是特种设备 |
| 锅炉未注明外部检验/内部检验/水压试验 | 检验类型 |
| 安全阀台账无下次检验日期 | 下次检验日期（周期以厂内规定为准） |
| 上次检验日期缺失或无法解析，且台账无下次检验日期 | 上次检验日期 |
| 压力容器 4 级（监控使用）、5 级（应停用） | 周期依据不适用常规推算 |

## 六、超期表述要求（硬约束）

存在超期设备时，`inspection.md` 与 `报检准备清单.md` 开头由**脚本直接写入**下面这句话，模型**不得删除、改写或弱化**（不用 emoji，用【注意】）：

> 【注意】存在超期未检特种设备，超期使用违反《特种设备安全法》，应立即停用并报检

撰写说明段时：

| 场景 | 应写 | 不得写 |
|---|---|---|
| 超期设备 | 「V-13XX 已超期 XX 天，应立即停用并报检」 | 「尽快安排检验」「近期报检即可」 |
| 延期可能性 | 「如已办理延长手续，请提供审批文件并更新台账」 | 「可申请延期」「问题不大」 |
| 安全状况等级 | 「等级缺失，周期无法确定，需补齐」 | 「按 6 年估算」「参照同类设备」 |
| 储罐 | 「台账写的是储罐，须先核实是否为压力容器，常压储罐不是特种设备」 | 「储罐按压力容器 6 年算」 |
| 年度检查 | 「V-13XX 年度检查已超期 XX 天，请车间组织年度检查并记录」 | 「定检没到期，年度检查可以一起做」 |
| 检验结论 | 「台账载明结论为 XX」 | 「该设备状况良好可继续使用」 |
| 日期不一致 | 「台账 X 与计算值 Y 不一致，以检验报告为准，请核实」 | 「以计算值为准」「台账写错了」 |
| 安全阀 | 「按台账载明日期 X 到期；校验台账与送校请用安全阀校验台账到期管理」 | 「安全阀按 1 年算已超期」 |

## 七、分析段表述规范

撰写 200~400 字，结构固定为五段：

1. **到期概览**：台账设备总数、超期/临期/正常/待核实分布，按类别的主要分布。
2. **超期设备与法律风险**：逐台列出位号、超期天数，明确应立即停用并报检；数量与天数一律引用 `inspection.json`。
3. **临期设备与报检安排**：临期台数、最近到期的几台、建议的报检提前量与停工检修窗口配合（涉及设备交出、盲板抽堵、受限空间、用火作业许可的提前办理）。
4. **年度检查与遗留整改项**：年度检查超期/临期/缺失台数；未闭环项数、已过整改期限的项数；未提供清单时写「未提供整改项清单，本项未统计」。
5. **数据待核实项**：待核实台数与缺失字段（含储罐待核实）、日期不一致项数，点名需要补齐的台账列。

### 硬约束

- **不判定检验结论与安全状况等级**，以检验机构报告为准。
- **不认可任何形式的超期使用**，不出具「可继续使用」「可缓检」的意见。
- **不做延期检验的论证**；延期须有审批文件，由特种设备管理员办理。
- **不替台账补齐缺失字段**，缺什么写什么；不替用户认定储罐是否为压力容器。
- **数字一律引用 `inspection.json`**，不得自行统计。

## 八、下游衔接

- 报检资料准备 → 本技能产出的 `报检准备清单.md`
- 检验报告返回后的台账更新与参数核对 → `equipment-ledger-query`（查）/ `nameplate-ocr-intake`（铭牌与设备代码核对）
- 安全阀校验台账、送校批次与不合格整改 → `valve-instrument-calibration-ledger`
- 检验查出的缺陷需登记 → `defect-intake-grading`（缺陷 A/B/C 三级，提维修通知单）
- 结构或材质改造涉及改造告知、监督检验、使用登记变更 → `moc-change-assistant`
- 停用报检涉及的停工、设备交出与作业许可 → 车间检修计划，本技能不做方案
