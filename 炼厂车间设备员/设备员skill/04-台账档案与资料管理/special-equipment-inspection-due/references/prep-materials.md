# 报检应备资料清单（按设备类别）

> **本清单为默认参考口径，以检验机构受理要求与厂内特种设备管理制度为准。**
> 脚本 `scripts/inspection.js` 内置同一份表（常量 `PREP_MATERIALS`），生成 `报检准备清单.md` 时直接使用；
> 修改本文件后须同步修改脚本常量，否则产出与本文件不一致。

## 一、压力容器

- [ ] 使用登记证（正本/复印件）与设备代码
- [ ] 上一周期检验报告及结论页
- [ ] 设计图样、竣工图与产品质量证明文件（含材质、焊接、热处理记录）
- [ ] 安全附件校验记录（安全阀、压力表、液位计、测温仪表）
- [ ] 运行记录与操作规程、使用单位年度检查报告
- [ ] 停用、置换、清洗与隔离方案（内外部检验需停用时），相关作业许可（受限空间、用火、盲板抽堵）
- [ ] 上周期遗留整改项的整改完成证明

## 二、压力管道

- [ ] 压力管道使用登记证与管道元件/管段编号台账
- [ ] 上一周期检验报告、管道单线图（ISO 图）
- [ ] 安装竣工资料、焊缝无损检测报告与合格证明
- [ ] 测厚记录与腐蚀减薄趋势数据、年度检查记录
- [ ] 支吊架检查记录、防腐保温状况说明
- [ ] 停车吹扫置换方案与用火/受限空间作业许可配合计划
- [ ] 上周期遗留整改项的整改完成证明

## 三、锅炉

- [ ] 锅炉使用登记证与设备代码
- [ ] 上一周期外部检验、内部检验、水压试验报告
- [ ] 水（介）质处理记录与化验报告
- [ ] 安全附件（安全阀、压力表、水位计、超温超压保护）校验与联锁试验记录
- [ ] 司炉工、水处理作业人员特种作业证件（看复审有效期）
- [ ] 运行记录、启停记录与年度维护保养记录
- [ ] 上周期遗留整改项的整改完成证明

## 四、安全阀

- [ ] 安全阀台账（位号、整定压力、口径、型号、所属设备）
- [ ] 上一周期校验报告与铅封记录
- [ ] 整定压力依据（设备设计压力、工艺卡片）
- [ ] 拆装与备用阀替换计划（在线校验需说明方式）
- [ ] 延长校验周期的厂内审批文件（如已办理）
- [ ] 上周期遗留整改项的整改完成证明

## 五、起重机械

- [ ] 起重机械使用登记证与设备铭牌信息
- [ ] 上一周期定期检验报告
- [ ] 日常维护保养记录、月度与年度自行检查记录
- [ ] 钢丝绳、吊钩、制动器、限位装置检查与更换记录
- [ ] 起重机司机（Q2）、起重机指挥（Q1）特种作业证件（看复审有效期）
- [ ] 试验载荷与场地、配合吊装作业许可的准备说明
- [ ] 上周期遗留整改项的整改完成证明

## 六、场内机动车辆

- [ ] 场（厂）内专用机动车辆使用登记证与牌证
- [ ] 上一周期定期检验报告
- [ ] 日常维护保养与检查记录
- [ ] 制动、转向、灯光、警示装置检查记录
- [ ] 驾驶人员特种作业证件（看复审有效期）
- [ ] 上周期遗留整改项的整改完成证明

## 通用要求

- 资料需与台账中的**设备代码、使用登记证编号**一一对应，复印件加盖使用单位公章。
- 需停用检验的设备（压力容器内外部检验、压力管道全面检验、锅炉内部检验），报检前须完成**停工、设备交出、隔离、置换、清洗、检测合格**，并按《中国石化作业许可管理规定》办妥受限空间、用火、盲板抽堵等作业许可（双监护、JSA 交底）。
- 上周期遗留整改项须提供**整改完成证明**，未闭环的应在报检时向检验机构说明。
- 检验报告返回后，须及时更新台账「上次检验日期」「检验结论」「下次检验日期」「安全状况等级」「检验机构」各列，并归档原件；涉及改造的另办改造告知、监督检验与使用登记变更（见 `moc-change-assistant`）。

> 报检手续由特种设备管理员办理，本清单不替代其法定职责，也不构成对设备可否继续使用的判定。
