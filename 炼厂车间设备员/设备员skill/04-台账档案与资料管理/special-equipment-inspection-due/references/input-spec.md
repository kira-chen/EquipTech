# 输入规格：特种设备台账

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一次只读一个台账文件（`--input` 不支持逗号分隔多文件）；按装置分文件的台账请合并后传入，或逐个运行

## 工作表：特种设备台账

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「特种设备台账」「特种设备台账表」「特种设备」「设备台账」均可识别。**找不到该表时脚本直接 `ok:false` 退出**（台账是唯一数据源）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 设备类别 | 是 | 设备品种，中文写法，见下方「设备类别取值」；无法识别 → 该设备进待核实 |
| 位号 | 是 | 厂内设备位号 / SAP 功能位置；为空的行会被跳过并 warning |
| 上次检验日期 | 是 | 见下方「日期字段」；缺失且无下次检验日期 → 进待核实 |
| 设备名称 | 否 | SAP「设备描述」；缺失时报表显示 — |
| 设备编号 | 否 | SAP 8 位设备流水号 / EM 编码，**单列展示，不作位号** |
| 设备代码 | 否 | 特种设备代码（注册代码），用于与检验报告文件名匹配 |
| 使用登记证编号 | 否 | 使用登记证编号 |
| 检验机构 | 否 | 原样带出，写入超期清单 |
| 检验类型 | 否 | 全面检验 / 年度检查 / 耐压试验 / 定期检验；**锅炉的外部检验 / 内部检验 / 水压试验请填此列**，脚本据此查周期 |
| 检验结论 | 否 | 原样带出，**脚本不判定、不解释检验结论** |
| 下次检验日期 | 否 | 检验报告载明的到期日；**有值时以此为准**，与规则计算不一致时列入日期不一致节 |
| 安全状况等级 | 否 | 见下方「安全状况等级取值」；压力容器/压力管道缺此列时周期无法确定 |
| 上次年度检查日期 | 否 | 使用单位年度检查日期；有此列时输出「年度检查到期」一节（压力容器 / 压力管道），无此列时该节不出数并 warning |
| 装置 | 否 | 所属装置或区域（SAP 工厂区段） |
| 规格型号 | 否 | 压力管道的 GC 级别常写在此列（只展示，不决定周期）；锅炉检验类型无独立列时也从此列找 |
| 使用状态 | 否 | 在用/备用/停用，原样带出 |

## 列名别名

脚本别名表 = 局部别名（优先）+ 共享 `SYSTEM_ALIASES`（特种设备平台 / SAP PM / EM 列名，见顶层《中石化口径对照.md》第二节），以下写法均可识别：

| 标准列名 | 可识别的写法（局部） | 共享别名追加（系统导出） |
|---|---|---|
| 设备类别 | 设备类别、类别、设备种类、种类、特种设备类别、设备品种、设备类型 | 对象类型、设备分类、专业类别 |
| 位号 | 位号、设备位号、内部编号、TAG、tag | 位号编码、**功能位置**、功能位置编号、技术标识、技术对象、技术对象标识 |
| 设备编号 | — | 设备编号、**设备**（SAP 流水号）、设备号、设备编码、技术对象编号、EM编码 |
| 设备名称 | 设备名称、名称、设备描述 | 技术对象描述、功能位置描述、描述 |
| 设备代码 | 设备代码、特种设备代码、注册代码、注册号、登记代码、注册编号 | — |
| 使用登记证编号 | 使用登记证编号、使用证号、使用登记证号、登记证号、使用登记证 | — |
| 检验机构 | 检验机构、检验单位、检测机构、检验检测机构 | — |
| 检验类型 | 检验类型、检验类别、检验种类、检验项目、锅炉检验类型 | — |
| 上次检验日期 | 上次检验日期、上次检验、本次检验日期、检验日期、上次定检日期、末次检验日期 | — |
| 检验结论 | 检验结论、结论、检验结果 | — |
| 下次检验日期 | 下次检验日期、下次检验、下次定检日期、到期日期、下次检验时间 | — |
| 安全状况等级 | 安全状况等级、安全状况、等级、安全等级 | — |
| 上次年度检查日期 | 上次年度检查日期、年度检查日期、上次年检日期、年检日期、上次年度检查、年度检查 | — |
| 装置 | 装置、所属装置、装置名称、区域、所在区域 | 工厂区段、单元、生产单元 |
| 规格型号 | 规格型号、型号、规格 | 型号编号、技术参数 |

表头行识别：取前 10 行中命中必需列最多的一行，因此首行是标题、第三行才是表头的平台导出表也能读。「设备编号」不是位号别名：SAP 导出表里「功能位置」是位号、「设备」是流水号，两者分列。

## 设备类别取值（按设备品种中文写法）

| 标准类别 | 可识别的写法（包含匹配） |
|---|---|
| 压力容器 | 压力容器、容器、球罐、换热器容器、气瓶 |
| 压力管道 | 压力管道、管道、工业管道、管线 |
| 锅炉 | 锅炉、蒸汽发生器、余热锅炉、导热油炉 |
| 安全阀 | 安全阀、安全泄放装置、泄放阀、爆破片（只按台账载明的下次检验日期提示，周期以厂内规定为准） |
| 起重机械 | 起重机械、起重机、行车、天车、桥式起重、门式起重、葫芦 |
| 场内机动车辆 | 场内机动车辆、场内车辆、厂内机动车、厂内车辆、叉车、牵引车、场（厂）内专用机动车辆 |
| **储罐（待核实）** | 储罐、常压罐、常压储罐、油罐 且未写明「压力容器 / 球罐」→ 进待核实并 warning：常压储罐不是特种设备，压力储罐请改写为「压力容器」 |

以上之外的写法（电梯、客运索道、以及 PV/PP/BL/SV/QZ/CC 之类自造字母码）**不识别为本技能覆盖范围**，该行进待核实并 warning。

## 安全状况等级取值

| 识别结果 | 可识别的写法 |
|---|---|
| 1~5 级 | `1级`/`一级`/`1`、`2级`/`二级`、`3级`/`三级`、`4级`/`四级`、`5级`/`五级` |
| 不定级 | 不定级、不分级、无等级、不适用、NA、N/A —— 压力容器/压力管道按此归入待核实 |
| 缺失 | 空、`—`、`-`、`/`、`无` |

**安全状况等级缺失时不按任何默认等级推算周期**，该设备归入 `undetermined` 单列一节。压力管道规格型号里的 GC1/GC2 只是管道分级，**不决定检验周期**。

## 日期字段
- 支持：`2026-09-21`、`2026/9/21`、`2026年9月21日`、`20260921`、Excel 日期单元格、Excel 日期序列号
- 无法解析时输出 `null` 并 warning，**绝不按空或按今天处理**
- 到期日计算按自然月推（`C.addMonths`，6 年 = 72 个月，1 年 = 12 个月），落到不存在的日期时回退到当月最后一天

## 整改项清单（可选，`--issues`）

工作表名：整改项 / 遗留整改项 / 整改清单 / 问题清单。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 为空的行跳过并 warning；不在台账中的位号仍保留并标 `inLedger:false` |
| 整改项 | 是 | 问题描述 |
| 要求完成日期 | 否 | 早于基准日的计超期天数 |
| 整改状态 | 否 | 填「已完成/完成/已整改/已闭环/闭环/关闭/是」的项不计入遗留；为空时记「未填写」，**不当作已完成** |
| 责任人 | 否 | |

缺此参数时 `openIssues` 为 `null`，报表写「未提供整改项清单」，**不按台账倒推整改项数量**。

## 检验报告目录（可选，`--reports`）

传入一个目录，脚本按文件名是否包含位号或设备代码判断该设备的报告是否已归档，列出未匹配到的设备。**只核对文件是否存在，不读取报告内容，不解析检验结论。**

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 位号为空的行（warning 提示）
- 使用 `--category` 时不属于该类别的行（warning 提示被排除台数）
