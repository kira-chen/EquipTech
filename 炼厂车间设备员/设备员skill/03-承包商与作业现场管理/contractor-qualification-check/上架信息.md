# 承包商资质核验
**技能名称**：承包商资质核验

**技能简介**：承包商入厂前，按《中国石化承包商安全管理规定》口径核对单位资质、安全协议、人员入厂三级教育、特种作业证有效期与复审、证种与作业类型是否对应，输出三档核验意见。辅助审查，不替代安全环保部门审批。

**技能描述**

面向炼化厂车间设备员，在承包商进装置作业前把资质材料过一遍。上传承包商资质清单（承包商管理平台或 SAP 供应商主数据导出的 Excel 列名可直接识别），告知承包商类别、本次作业类型和起止时间，脚本逐条核对营业执照与安全生产许可证、安全协议是否在期、人员入厂三级教育与体检、特种作业证有效期与复审、起重指挥与司机、压力容器焊工项目代号，以及证种与作业类型是否对应。有效期为空、无法解析或厂内口径未给的一律列为未判定，不按合格处理。输出"建议准入 / 建议补充材料后再审 / 不建议准入"三档意见与不符合项清单，由模型成文并保留固定声明。不核实证书真伪，不读 PDF 与图片原件，不替代安全环保部门审批。

**示例问题**
1. 这家施工队下周来干用火、高处、进罐的活，资质帮我核一下，我们厂入厂教育和体检都是一年有效。　　**附件：** `examples/sample-contractor-qual-2026-10-26.xlsx`
2. 这家机电公司的材料应该齐了，用火加临时用电，看看能不能进，入厂教育按一年算。　　**附件：** `examples/sample-all-valid.xlsx`
3. 要焊压力容器，两个焊工的证帮我核一下项目代号对不对。　　**附件：** `examples/sample-pressure-welding.xlsx`
4. 这是承包商平台导出的表，第一行是标题，底下还有合计行，这家是做机泵维保的，不是施工单位，看看证齐不齐、复审到期没有。　　**附件：** `examples/sample-erp-export.xlsx`
5. 按我们厂的准入清单再对一遍，另外看看这几个人以前来过没有。　　**附件：** `examples/sample-contractor-qual-2026-10-26.xlsx + examples/sample-plant-spec.xlsx + examples/sample-history.xlsx`
