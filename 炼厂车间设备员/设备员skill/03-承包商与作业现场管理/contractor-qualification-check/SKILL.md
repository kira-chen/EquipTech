# 承包商资质核验（contractor-qualification-check）

面向中石化体系炼化厂车间（运行部）设备员，在承包商入厂前核对单位资质、安全协议、人员入厂三级安全教育与持证情况（含特种作业操作证复审）、作业范围匹配性。**有效期判定与范围匹配一律由脚本完成，模型只负责成文；不得放宽判定或替用户认可过期证书。**

车间设备员可做的部分：按清单核对材料是否齐全、是否在有效期内、证种是否对应本次作业，形成核验意见提交车间与安全环保部门。**准入审批、承包商分档考核由安全环保部门归口**，本技能只出"建议准入 / 建议补充材料后再审 / 不建议准入"三档核验意见。

## 适用条件
- 用户说"核对一下承包商资质 / 这些证过期没 / 人员能不能进厂 / 特种作业证查一下 / 复审到期没 / 资质审查"，并提供资质清单或人员证书清单。
- 覆盖三个层面：承包商单位资质（营业执照、安全生产许可证按承包商类别、专业资质等级、安全协议）、作业人员证书（特种作业操作证及其复审、特种设备作业人员证 Q1/Q2、特种设备焊接作业人员证、培训记录）、必备材料（入厂三级安全教育；高处/受限空间作业的体检）。
- 不适用：现场作业过程的监督检查（site-supervision-points）；承包商违章记录与考核（contractor-performance-log）；安全环保部门的正式准入审批与分档考核。

## 前提条件
- 输入：资质清单（`.xlsx`，或同结构 CSV 目录；承包商管理平台/SAP 供应商主数据导出列名可直接识别）。**脚本不读 PDF 与图片**：证书扫描件须先由用户或平台 pdf 技能整理成清单再传入，原件仅用于人工抽查核对。
- 必填信息：承包商名称、拟承担的作业类型（用火/受限空间/高处/吊装/临时用电/压力容器焊接）、作业起止时间。建议提供：承包商类别（施工类/维保类/技术服务类，决定是否必备安全生产许可证）、厂内口径参数（入厂教育有效天数、体检有效天数、特种作业证复审周期）。可选：厂内准入要求清单、历史准入记录。
- 环境：可执行 Node.js ≥ 18，脚本仅用内置模块，无需 npm 安装。**若环境无法执行 node（无 Bash 工具或 `node --version` 失败），明确告知用户并终止，不得手工核对有效期。**

## 数据获取（MCP）

平台接入了业务系统 MCP 服务时，按下表调用工具取数，不再请用户上传导出文件；未接入时按操作步骤请用户提供系统导出文件。工具全部只读，不在业务系统里创建或修改任何单据。

| 服务 | 工具 | 参数 | 交给脚本 |
|---|---|---|---|
| HSE管理平台 | `get_contractors` | `contractor_code`：承包商编码 | `--input`（目录 A） |
| HSE管理平台 | `get_personnel_certificates` | `contractor_code`：承包商编码 | `--input`（目录 A） |
| HSE管理平台 | `get_admission_requirements` | — | `--spec`（目录 B） |

取数后：

1. 工具返回下载链接（60 分钟内有效，过期重新调用）。csv 按原文件名放进新建的空目录，不改文件名，不与其他技能的文件混放；表中目录字母相同的放同一个目录，不同字母分开放，把目录作为“交给脚本”一列的参数值。
2. `get_contractors`：填 `contractor_code` 时返回这一家的「单位资质」，一次只审一家；返回说明里给出承包商类别，作 `--contractor-type`。不知道编码时先不带参数调一次，从「承包商名单」按名称查编码（名单表不交给脚本）。
3. `get_admission_requirements`：可选，需要按准入要求核对时使用。

## 操作步骤
1. **确认承包商与作业类型** —— 承包商名称、作业类型、作业起止时间；作业类型决定需核验哪些证书，**类型不明确时必须追问，不得按最小集合核验**。
2. **运行脚本** —— 技能目录以平台实际加载路径为准（Windows 路径加双引号）：
   ```bash
   node "<技能目录绝对路径>/scripts/qualify.js" --input "<资质清单xlsx>" --contractor "<承包商名称>" --work-type "<作业类型,类型>" --contractor-type <施工类|维保类|技术服务类> --from <YYYY-MM-DD> --to <YYYY-MM-DD> --out "<输入同目录>/资质核验"
   ```
   可选：`--edu-valid-days <入厂教育有效天数>`、`--medical-valid-days <体检有效天数>`、`--review-years <特种作业证复审周期年数>`（三者均为厂内口径，**不给则相关项进未判定，脚本不替用户选默认值**）；`--spec "<厂内准入要求清单xlsx>"`、`--history "<历史准入记录>"`、`--lead-days <临期提醒天数，默认 30>`。未给 `--contractor-type` 时安全生产许可证按提示项处理，不判缺证。
   读取末行 JSON 摘要（同时写入 `<out>/summary.json`）：`ok` 必须为 `true`，`ok:false` 时把 `error` 告知用户并终止；`warnings` 非空时逐条告知用户（缺列/有效期无法解析/证书类型无法识别/作业类型无对应要求等）。脚本用法详见 `scripts/README.md`。
   - 有效期字段为空或无法解析：判定为 `undetermined`（未判定）单列一节，**绝不按有效处理**。
   - 证书类型无法匹配到作业类型要求：warning 并列出，由用户确认是否适用，**不得自行认定"可以替代"**。
   - 特种作业操作证"下次复审"已过 → 按已过期处理（复审逾期即无效）；入厂安全教育、安全协议、体检（高处/受限空间）缺失或无法判定有效期 → 未判定，不判合格也不判缺证。
   - 过期是否阻断看与本次作业是否相关：单位资质、入厂安全教育/培训/体检等通用项、本次作业类型需要的作业类证书过期 → 计入已过期，不建议准入；**与本次作业类型无关的作业类证书过期**（如只做高处作业，某人焊工证过期）→ 不阻断，单列 `irrelevantExpired`，须提醒该人员换证/复审前不得从事对应作业。`--work-type` 有无法识别的类型时无法区分相关性，全部过期证书都阻断并有 warning。
3. **读取 qualify.json** —— 从 `<输出目录>/qualify.json` 获取：`companyQual`（单位资质核验结果）、`personnelQual`（人员证书逐条结果：姓名、证书类型、证号、有效期、下次复审、状态）、`mandatory`（必备材料：入厂教育/安全协议/体检）、`expired`（已过期，计入阻断）、`irrelevantExpired`（与本次作业无关的过期证书，不阻断）、`expiringSoon`（临期）、`scopeMismatch`（作业范围不匹配）、`missing`（应有未提供）、`advisories`（提示项）、`undetermined`、`unrecognized`、`counts`。
4. **撰写核验结论** —— 按 `assets/templates/qualify-template.md` 成文，含：承包商与作业信息、单位资质核验结果、人员证书核验表、作业类型证书要求与必备材料对照、不符合项清单（过期/临期/范围不符/缺失/提示项/与本次作业无关的过期证书）、未判定项、类型待确认项、核验结论建议。**结论建议只写"建议准入 / 建议补充材料后再审 / 不建议准入"三档并说明依据，不得表述为准入决定。**
5. **交付前自检** —— 对照 `references/checklist.md` 逐项检查；通过后交付 `qualify.md` 与 `qualify.json`。**必须保留声明行："本核验为辅助审查，承包商准入须经安全部门按厂内制度审批；证书真伪须通过发证机关渠道核实"，不得删除或改写。**

## 预期结果
- `qualify.md`：资质核验报告，九节：一、核验概览；二、单位资质核验；三、人员证书核验；四、作业类型证书要求与必备材料对照（4.1 证书要求、4.2 入厂教育/安全协议/体检）；五、不符合项清单（5.1 已过期、5.2 临期、5.3 作业范围不符、5.4 应有未提供、5.5 提示项、5.6 与本次作业无关的过期证书）；六、未判定项；七、类型待确认项；八、核验结论（含分析段占位）；九、声明；给了 `--spec`/`--history` 时另有附一、附二两个对照节；末尾"附：数据提示"列 warnings。
- `qualify.json`：逐条核验结果；`summary.json`：脚本末行摘要。
- 交付时向用户说明：核验人数、过期数（含复审逾期）、与本次作业无关的过期证书数（不阻断，提醒不得从事对应作业）、临期数、范围不符数、缺失数、未判定数（含必备材料未判定数）、脚本 warnings（如有）。

## 不适用范围
- 不核实证书真伪（需通过发证机关或政府平台查询）。
- 不替代安全环保部门的准入审批、分档考核与入厂安全教育考核本身。
- 不评价承包商施工能力与历史业绩（违章与考核记录用 contractor-performance-log）。
- 不做合同资质条款的审查与法律意见。
- 不读 PDF / 图片证书原件。
