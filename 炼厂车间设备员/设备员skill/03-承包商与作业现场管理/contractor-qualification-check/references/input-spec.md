# 输入规格：承包商资质核验

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一个文件内含两张工作表：「单位资质」与「人员证书」，**至少提供其中一张**
- 承包商管理平台 / SAP 供应商主数据导出的列名（供应商编码、证照名称、三级安全教育日期、下次复审日期等）可直接识别，见第三节别名表
- **脚本不读证书 PDF / 图片**：扫描件须先整理成清单（可用平台 pdf 技能转文本后由用户填表），原件仅供人工抽查核对

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「单位资质」「单位资质表」「企业资质」「公司资质」均可识别；人员侧「人员证书」「作业人员」「人员资质」「证书清单」均可识别。

## 一、单位资质工作表

| 列名 | 必需 | 说明 |
|---|---|---|
| 资质名称 | 是 | 为空的行会被跳过并 warning |
| 有效期至 | 是 | 见下方「有效期字段」 |
| 证书编号 | 否 | |
| 资质等级 | 否 | 如「贰级」「壹级」「三级」 |
| 发证机关 | 否 | |
| 发证日期 | 否 | 安全协议行可填签订日期 |
| 经营/承包范围 | 否 | 经营范围或资质承包范围原文 |
| 承包商编码 | 否 | SAP 供应商编码 / 承包商管理平台编码，有则写入报告头 |

资质名称按 `references/qualification-rules.md` 归类为：营业执照 / 安全生产许可证 / 专业承包资质 / 安全协议 / ISO 管理体系认证。**无法归类的按原文列出并单列「类型待确认」，不按合格处理。**

- **安全协议**为必备材料：写一行「安全生产管理协议」（或 HSE 协议），有效期至填协议到期日；未提供 → 未判定。
- **安全生产许可证**是否必备由 `--contractor-type` 决定（施工类必备；维保类/技术服务类不要求）；未给参数时按提示项处理。

## 二、人员证书工作表

| 列名 | 必需 | 说明 |
|---|---|---|
| 姓名 | 是 | 为空的行会被跳过并 warning |
| 证书类型 | 是 | 证书全称，见下方「证书类型取值」 |
| 有效期至 | 是 | 见下方「有效期字段」 |
| 身份证号 | 否 | 建议脱敏后提供 |
| 岗位 | 否 | 焊工/架子工/电工/起重工等 |
| 作业类别 | 否 | 准操项目，如「焊接与热切割作业」「登高架设作业」；证书类型无法归类时用本列补位 |
| 项目代号 | 否 | **压力容器/管道焊接必填**，如 `SMAW-FeII-6G`；为空时该项计入未判定 |
| 证书编号 | 否 | |
| 发证机关 | 否 | |
| 发证日期 | 否 | `--review-years` 推算复审时，无复审日期则以此为起点 |
| 复审日期 | 否 | 特种作业操作证上次复审日期 |
| 下次复审 | 否 | 特种作业操作证下次复审日期；**已过 → 按已过期处理**（复审逾期即无效）；无法解析 → 未判定 |
| 体检日期 | 否 | 高处 / 受限空间作业人员必备；有效期按 `--medical-valid-days` 推算，未给参数 → 未判定 |
| 培训日期 | 否 | |
| 入厂教育日期 | 否 | 入厂三级安全教育完成日期，**每名人员必备**；有效期按 `--edu-valid-days` 推算，未给参数 → 未判定。也可以单独一行「入厂安全教育记录」写有效期至 |

每名人员一行一证，同一人多证多行；入厂教育日期、体检日期填在该人任一行即可。

## 五、有效期字段

- 支持：`2027-03-15`、`2027/3/15`、`2027年3月15日`、`20270315`、Excel 日期单元格、Excel 日期序列号
- **为空 → 未判定**，单列并注明缺失字段为「有效期至」，**绝不按有效处理**
- **无法解析为日期 →未判定**，原始取值原样列出。常见无法解析的写法：「长期有效」「永久」「见证书」「待补」「—」「/」
- 有效期必须覆盖整个作业期；作业结束日之前失效的，等同不可用（计入已过期）
- 「下次复审」已过基准日或早于作业结束日 → 计入已过期（复审逾期）；无法解析 → 未判定

## 六、作业类型参数（`--work-type`）

用英文逗号、中文逗号或顿号分隔多个类型，如 `--work-type "用火作业,高处作业,受限空间作业"`。

可识别类型（按《中国石化作业许可管理规定》命名）：用火作业（"动火"可识别，报告写"用火作业"）、高处作业、受限空间作业、吊装作业、临时用电作业、压力容器焊接（近义写法见 `references/qualification-rules.md`）。

## 六之二、厂内口径参数

| 参数 | 含义 | 未给时 |
|---|---|---|
| `--contractor-type` | 施工类 / 维保类 / 技术服务类（近义词：工程、安装 → 施工类；维修、检修、保养 → 维保类；检测、服务、咨询、设计 → 技术服务类） | 安全生产许可证按提示项，不判缺证 |
| `--edu-valid-days` | 入厂安全教育有效天数 | 只有入厂教育日期的人员 → 未判定 |
| `--medical-valid-days` | 体检有效天数 | 只有体检日期的人员（高处/受限空间）→ 未判定 |
| `--review-years` | 特种作业操作证复审周期（年） | 不推算复审，只认「下次复审」列 |

**脚本不替用户设这些默认值**，因各厂规定不同；参数值由用户按厂内制度给出。

- **部分类型无法识别** → warning 要求人工明确，结论降为「建议补充材料后再审」
- **全部类型无法识别** → 脚本报错退出，**绝不按空集或最小集合核验**

## 七、厂内准入要求清单（可选，`--spec`）

工作表名「准入要求」（或「厂内要求」「要求清单」「准入清单」）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 作业类型 | 是 | |
| 所需证书 | 是 | |
| 说明 | 否 | |

只做对照提示与 warning，**不改变脚本自动判定**：厂内附加要求需核验人人工核对。

## 八、历史准入记录（可选，`--history`）

工作表名「历史准入」（或「准入记录」「入厂记录」），列：姓名（必需）、证书类型、有效期至、说明。仅作对照，标注人员本次是否在册。

## 九、会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 单位资质表中资质名称为空的行（warning 提示）
- 人员证书表中姓名为空的行（warning 提示）
