# 资质核验口径与作业类型对应表

> 本文件是脚本 `scripts/qualify.js` 判定逻辑的同源说明。口径依据《中国石化承包商安全管理规定》《中国石化作业许可管理规定》、TSG Z6001-2019《特种设备作业人员考核规则》、《特种作业人员安全技术培训考核管理规定》，**只引制度名与规则方向，不转述具体数值**；周期、有效期等数值以证书记载与厂内制度为准，脚本通过参数接厂内口径，不替用户选默认值。**厂内制度有更严格规定的，一律以厂内制度为准。**

## 一、核验的三个层面

### 1. 单位资质

| 资质类型 | 说明 | 是否必备 | 出处 |
|---|---|---|---|
| 营业执照 | 统一社会信用代码、经营范围须覆盖拟承担作业 | **必备** | 《中国石化承包商安全管理规定》准入条件 |
| 安全生产许可证 | 建筑施工企业安全生产许可证等 | **按承包商类别**：施工类必备；维保类、技术服务类（机封厂家服务、检测公司等）不要求。`--contractor-type` 未给时按**提示项**处理，不判缺证 | 同上，承包商分类管理 |
| 安全协议 | 承包商入厂前与发包单位签订的安全生产管理协议 / HSE 协议 | **必备材料**：未提供 → 未判定（不判合格、不判缺证）；有效期按协议约定，过期按已过期 | 同上，入厂前签订安全协议 |
| 专业承包资质等级 | 如石油化工工程施工总承包、机电工程施工总承包、防腐保温专业承包 | 按作业内容要求 | 合同与厂内准入清单 |
| ISO 管理体系认证 | 仅收 ISO 9001/14001/45001 与明确写"管理体系认证"的证书；泛称"认证证书"不归此类 | 按合同/厂内要求 | — |
| 安全生产标准化等级 | 视厂内准入清单要求；脚本不归类，列为"类型待确认" | 按厂内要求 | — |

必备资质缺失或不可用（已过期、未判定）→ 计入「应有未提供」，结论直接落到**不建议准入**。

### 2. 人员证书

| 证书类型 | 发证机关口径 | 说明 |
|---|---|---|
| 特种作业操作证 | 应急管理部门 | 焊接与热切割、高处作业、低压电工、高压电工、制冷与空调作业。**按复审管理**：清单的"下次复审"已过 → 按已过期处理（复审逾期即无效）；复审周期数值以证书与厂内口径为准，`--review-years` 给出时才自复审日期/发证日期推算 |
| 特种设备作业人员证 | 市场监督管理部门 | TSG Z6001-2019：**Q1 = 起重机指挥，Q2 = 起重机司机**；"特种设备作业人员证（Q2）"归起重机司机证，不得被泛类抢走。特种设备焊接作业人员证单列并核项目代号 |
| 司索工 | — | TSG Z6001-2019 已取消司索工取证项目，只核培训记录或厂内确认，**缺失不判缺证**（提示项） |
| 培训合格证 | 培训机构 / 厂内安全环保部门 | 受限空间作业培训、一般安全培训 |
| 入厂安全教育记录 | 厂内安全环保部门 / 车间 / 班组 | 厂级、车间级、班组级三级安全教育；**必备材料**（见第三层面） |
| 体检证明 | 职业健康体检机构 | 高处、受限空间作业人员必备（见第三层面） |

### 3. 必备材料（《中国石化承包商安全管理规定》《中国石化作业许可管理规定》）

| 必备材料 | 对象 | 判定口径 | 未提供时 |
|---|---|---|---|
| 安全协议 | 单位 | 以"单位资质"表中安全协议行的有效期为准 | **未判定**，不按已签订处理 |
| 入厂安全教育（三级教育） | 每名人员 | 有"入厂安全教育记录"行按其有效期；只有"入厂教育日期"列时按 `--edu-valid-days`（厂内口径）推算；未给参数 → 未判定 | **未判定**，不按已完成处理 |
| 体检 | 高处作业、受限空间作业的每名人员 | 有"体检合格证明"行按其有效期；只有"体检日期"列时按 `--medical-valid-days`（厂内口径）推算；未给参数 → 未判定 | **未判定**，不按合格处理；用火/吊装/临时用电等不要求 |

必备材料未判定 → 结论不低于「建议补充材料后再审」；推算后已过期 → 计入已过期，结论「不建议准入」。**脚本不设默认有效期**，因为入厂教育与体检有效期各厂规定不同。

## 二、作业类型 ↔ 所需证书对应表

脚本按下表逐项核对；**表中没有的作业类型，脚本不生成证书要求，而是 warning 要求人工明确，绝不按空集或最小集合核验**。作业类型命名按《中国石化作业许可管理规定》八大类（用火作业、受限空间作业、高处作业、吊装作业、临时用电作业、动土作业、断路作业、盲板抽堵作业），"动火"作为口语别名可识别但报告统一写"用火作业"。

| 作业类型 | 所需证书 | 判定说明 | 出处 |
|---|---|---|---|
| **用火作业** | 焊接与热切割作业证 | 用火实施人（焊工/切割工）须持特种作业操作证（熔化焊接与热切割作业） | 《特种作业人员安全技术培训考核管理规定》特种作业目录 |
| **高处作业** | 高处作业证（**提示项**） | 特种作业"高处作业"只覆盖登高架设、高处安装维护拆除两个准操项目；**一般高处检修人员不需持证**。脚本无法从清单判断作业内容，故列为提示项：有则核有效期，无则提示确认作业内容；人员体检为必备 | 同上；《中国石化作业许可管理规定》 |
| **受限空间作业** | 受限空间培训合格证 + 监护人资质证明 | 进入人员须有受限空间作业培训合格记录；每个作业点须配备监护人（中石化为双监护：属地监护人 + 作业单位监护人，本技能核的是作业单位监护人），**两项都要，缺一计缺失**；人员体检为必备 | 《中国石化作业许可管理规定》 |
| **吊装作业** | 起重机司机证（Q2）+ 起重指挥证（Q1） | 两个角色分别持证，**缺一计缺失**；司索（挂钩绑扎）人员**无取证项目**，只核培训记录，列提示项 | TSG Z6001-2019 |
| **临时用电作业** | 低压电工作业证 **或** 高压电工作业证 | 按实际作业电压等级确定；**脚本不替用户判断电压等级**，两者任一在有效期内即视为满足，实际适用性由核验人确认 | 特种作业目录 |
| **压力容器焊接** | 特种设备焊接作业人员证（含项目代号） | 须核对项目代号（如 `SMAW-FeII-6G`）是否覆盖实际焊接方法、母材类别与焊接位置；**项目代号为空时计入未判定，不判合格** | TSG Z6002 |

动土、断路、盲板抽堵作业无全国统一持证项目，脚本不内置要求；厂内有附加要求的用 `--spec` 清单对照。

### 项目代号读法（压力容器/压力管道焊接）

以 `SMAW-FeII-6G` 为例：

| 段 | 含义 |
|---|---|
| `SMAW` | 焊接方法（焊条电弧焊）。其他如 GTAW（钨极氩弧焊）、GMAW（熔化极气体保护焊）、SAW（埋弧焊） |
| `FeII` | 母材类别（Fe 为钢，II 为类别号） |
| `6G` | 焊接位置（管全位置固定焊）。1G 平焊、2G 横焊、5G 管水平固定、6G 管 45° 固定 |

**核对要点**：实际作业的焊接方法、母材、位置必须落在持证项目代号覆盖范围内。代号缺失、看不懂、或与实际作业不一致 → 未判定，要求承包商提供证书原件与项目栏照片，不得自行推断"应该能焊"。

## 三、有效期与复审判定口径

| 情形 | 判定 | 说明 |
|---|---|---|
| 有效期 > 基准日 + 临期天数，且 ≥ 作业结束日 | **有效** | |
| 基准日 < 有效期 ≤ 基准日 + 临期天数 | **临期** | 默认临期 30 天，`--lead-days` 可调；仍属有效，但作业期间需跟踪换证 |
| 有效期 < 基准日 | **已过期** | 报告标注超期天数 |
| 基准日 ≤ 有效期 < 作业结束日 | **已过期（作业期内失效）** | 证书须覆盖整个作业期；作业期内会失效的，等同不可用 |
| **下次复审 < 基准日**（特种作业操作证等） | **已过期（复审逾期）** | 复审逾期即无效，即便"有效期至"尚未到；下次复审早于作业结束日同样按已过期 |
| 下次复审在临期窗内 | **临期** | 作业期间须跟踪复审 |
| 下次复审无法解析（如"见证书"） | **未判定** | 不按有效处理 |
| **有效期为空** | **未判定** | **绝不按有效处理**；单列一节，注明缺失字段为「有效期至」 |
| **有效期无法解析为日期**（如「长期有效」「见证书」「待补」） | **未判定** | **绝不按有效处理**；原始取值原样列出，要求承包商补填规范日期 |

基准日为脚本运行当日（北京时间），记录在 `qualify.json` 的 `meta.baseDate`。

### 过期证书是否阻断：看与本次作业是否相关

上表的「已过期」是证书本身的状态（`personnelQual[].state`），是否计入阻断项（`expired`，结论「不建议准入」）还要看与本次作业类型是否相关：

| 过期的材料 | 是否阻断 | 说明 |
|---|---|---|
| 单位资质（营业执照、安许、专业承包资质、安全协议、ISO 等） | **阻断** | 不区分作业类型 |
| 入厂安全教育记录、培训合格证、体检合格证明（含按厂内口径推算过期） | **阻断** | 人员通用项，不区分作业类型 |
| 本次作业类型需要的作业类证书（见第二节对应表） | **阻断** | 如用火作业的焊接与热切割作业证、高处作业的高处作业证 |
| 与本次作业类型无关的作业类证书 | **不阻断** | 计入 `irrelevantExpired`（报告 5.6「与本次作业无关的过期证书」），并提示该人员换证/复审前**不得从事对应作业**；同时仍按第五节列为作业范围不符 |
| 证书类型无法识别 | **阻断** | 无法判断是否与本次作业相关，按严格口径 |

作业类证书 = 第二节对应表中出现的证书（焊接与热切割、高处、低压/高压电工、起重机司机、起重指挥、司索工培训记录、受限空间培训合格证、监护人资质证明、特种设备焊接作业人员证）+ 制冷与空调作业证 + 笼统填写的特种设备作业人员证（本次有吊装作业或压力容器焊接时视为相关）。

`--work-type` 中有无法识别的作业类型时，无法区分证书是否与本次作业相关，**保持严格口径：全部过期证书都阻断**，并发 warning 说明。

`--review-years N`：只对特种作业操作证（焊接与热切割、高处、低压/高压电工、制冷与空调）生效，清单无"下次复审"时按复审日期（无则发证日期）加 N 年（按自然月）推算，报告标"（推算）"。特种设备作业人员证复审周期不同，不推算。

### 禁止事项

- 禁止把「长期有效」「永久」「未注明」当作有效。营业执照可能确实长期有效，但**是否长期有效由核验人依原件确认，脚本不做此推断**。
- 禁止用发证日期加固定年限倒推有效期（不同证种周期不同）；复审推算只在用户显式给 `--review-years` 时进行并标注。
- 禁止以「上次核验时有效」为由跳过本次判定。
- 禁止给入厂教育、体检设默认有效期。

## 四、证书类型无法识别的处理

清单中的证书名称无法匹配到已知类型表时：

1. 该条计入 `unrecognized`（类型待确认），在报告「七、类型待确认项」单列；
2. 产生 warning，说明无法识别；
3. **脚本不认定其可替代任何所需证书** —— 即使名称看起来相近（如「某某省新型作业人员上岗资格证」「建筑施工特种作业操作资格证」不得当作应急管理部门的特种作业操作证）；
4. 由核验人确认是否适用；确认适用的，需在报告中人工补注并说明依据。

同理，作业类型无法识别时，脚本不生成该类型的证书要求，只发 warning 要求人工明确应核验哪些证书。

## 五、作业范围匹配

持有的已识别证书若不对应本次申报的任何作业类型，计入 `scopeMismatch`（作业范围不符），说明"不得用于替代所需证书"。

通用材料不计入范围不符：培训合格证、体检合格证明、入厂安全教育记录、特种设备作业人员证（笼统填写、未细分项目的）。

## 六、结论分档（只有三档）

| 结论 | 触发条件 | 含义 |
|---|---|---|
| **不建议准入** | 存在已过期项（含复审逾期、必备材料推算过期；与本次作业无关的作业类证书过期除外，见第三节），或存在应有未提供项 | 材料明确不满足，须补齐后重新核验 |
| **建议补充材料后再审** | 无过期无缺失，但存在未判定（含必备材料未判定）、类型待确认、范围不符、或作业类型未识别 | 材料不足以支撑判定 |
| **建议准入** | 上述均无 | 核验范围内材料齐备且在有效期内；如有临期项或提示项，注明需跟踪换证/确认作业内容 |

### 表述硬约束

- 结论**只能**写这三档之一。
- **不得表述为准入决定**：禁止写「准予准入」「批准入厂」「同意准入」「审批通过」。核验是辅助审查，准入审批与承包商分档考核由安全环保部门归口。
- **不核实证书真伪**：脚本与报告只依据清单的书面记载判断有效期与范围匹配，真伪须通过发证机关或政府主管部门查询渠道核实。报告必须写明这一点。
- 必须保留固定声明行：

  > 本核验为辅助审查，承包商准入须经安全部门按厂内制度审批；证书真伪须通过发证机关渠道核实

## 七、分析段表述规范

撰写 200~400 字，四段结构：

1. **核验范围**：承包商、承包商类别、作业类型、作业期间、核验的资质与证书条目数、厂内口径参数是否齐。
2. **不符合项与影响**：逐类说明过期（含复审逾期）、缺失、范围不符，指出哪些作业类型因此无法开展；与本次作业无关的过期证书单独一句说明不计入阻断，但该人员不得从事对应作业。
3. **未判定与材料缺口**：哪些项因有效期、项目代号、入厂教育、安全协议、体检缺失而无法判定，需要承包商或安全环保部门补什么。
4. **建议补充与跟进事项**：补材料清单、临期证书换证/复审跟踪、需安全环保部门确认的事项。

| 场景 | 应写 | 不得写 |
|---|---|---|
| 过期证书 | 「孙立民的焊接与热切割作业证已于 X 月 X 日过期，超期 51 天」 | 「证快到期了问题不大」 |
| 复审逾期 | 「孙立民的焊接与热切割作业证下次复审日期已过 30 天，复审逾期按已过期处理」 | 「有效期还没到，先用着」 |
| 无关证书过期 | 「吴长海的低压电工作业证复审逾期，与本次用火、高处、受限空间作业无关，不计入阻断项；换证/复审前不得从事临时用电作业」 | 「过期证与本次无关，不用管」「有一张证过期就不能进厂」 |
| 未判定 | 「郑守业的受限空间培训合格证未填有效期，无法判定，已列为未判定」 | 「按培训记录应该还在有效期内」 |
| 必备材料 | 「冯广顺无入厂三级教育记录，未判定，请安全环保部门确认是否已完成入厂教育」 | 「入厂教育一般进厂当天补做就行」 |
| 类型待确认 | 「该证书类型不在对应表内，请确认是否适用于本次用火作业」 | 「该证等同于焊工证，可以用」 |
| 结论 | 「不建议准入：存在 2 项过期证书与 2 项缺失」 | 「不予准入」「审批不通过」 |
| 真伪 | 「证书真伪须通过发证机关渠道核实」 | 「证书已核实真实有效」 |
