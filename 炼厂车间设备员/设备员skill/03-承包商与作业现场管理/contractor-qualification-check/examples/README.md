# examples 回归测试数据

> 本目录仅开发包含有（`build.sh --with-examples`），发布包不含。
> 全部样例由 `node scripts/make-sample.js --out examples` 再生（默认 `--date 2026-10-26`，证号与具体日期随 seed 变化但结论不变）。样例日期相对生成日排布，预期计数以在生成日附近（约 20 天内）运行为准；时间久了可用 `--date <今天>` 重新生成。
> **样例中的承包商名称、人名、身份证号、证书编号、协议编号（`AQXY-虚构-xxxx`）全部编造，不对应任何真实单位、人员或证件。**

## MCP 取数对照

平台接入 HSE管理平台 MCP 时不上传附件，按 SKILL.md「数据获取（MCP）」取数：`get_contractors`（带 `contractor_code`）的「单位资质.csv」与 `get_personnel_certificates`（同一编码）的「人员证书.csv」放同一目录 A 作 `--input`；需要按准入要求对照时 `get_admission_requirements` 的「准入要求.csv」放目录 B 作 `--spec`。`--contractor-type` 取 `get_contractors` 返回说明里的类别。演示数据每天按剧本重置（证书日期相对当天排布），下表只写每天稳定的结论；作业期取 3 天后至 10 天后。

|---|---|---|---|---|

## 关键验证点

1. **有效期为空不按有效**：主样例中郑守业的受限空间培训合格证有效期为空，进 `undetermined` 单列，`state` 既不是 valid 也不是 expired；受限空间作业因此"无可用持证人"计入 `missing`。
2. **无法解析的有效期不按有效**：平台导出样例中谭书文的有效期写「待补」，同样进 `undetermined`，原始取值原样列出。
3. **类型无法识别不得替代**：主样例中王延青的「安全生产管理人员考核合格证」、平台导出样例中卢明道的「建筑施工特种作业操作资格证」均进 `unrecognized`，脚本不认定其可替代任何所需证书，只发 warning 请人工确认。
4. **项目代号缺失不判合格**：压力容器焊接样例中薛茂林无项目代号，进 `undetermined` 并注明需核对 SMAW-FeII-6G 类代号是否覆盖实际焊接方法、材质与位置。
5. **复审逾期按已过期**：主样例吴长海低压电工证"有效期至"未到，但"下次复审"已过 → `personnelQual` 状态为 `expired`，原因写"复审逾期"；该证不对应本次用火/高处/受限空间作业，进 `irrelevantExpired`（5.6 节）不计入阻断，提示不得从事临时用电作业。加报临时用电作业时则计入 `expired`。
6. **必备材料不默认合格**：安全协议、入厂安全教育、体检（高处/受限空间）缺失或未给厂内有效期参数 → `mandatory[].state = undetermined`，并进「六、未判定项」；主样例冯广顺两项未判定。
7. **安许按承包商类别**：平台导出样例为维保类，无安全生产许可证不计缺证；主样例施工类有安许且有效。
8. **Q1/Q2 与司索**：Q2 归起重机司机证；吊装作业只要求司机证 + 指挥证，司索工列提示项。
9. **结论三档且非决定**：`conclusion` 只会是建议准入 / 建议补充材料后再审 / 不建议准入；md 写明「本结论为核验意见，不是准入决定」。
10. **声明行原文保留**：每份 `qualify.md` 第九节含「本核验为辅助审查，承包商准入须经安全部门按厂内制度审批；证书真伪须通过发证机关渠道核实」，并另行说明不核实证书真伪。
11. **临期默认 30 天**：主样例的 ISO 证书与周敬和的高处作业证均落在 30 天内；加 `--lead-days 60` 会有更多项进入临期，但不影响过期与缺失判定。
12. **系统列名**：平台导出样例的「供应商编码」「证照名称」「三级安全教育日期」「下次复审日期」均通过共享别名命中。

## 再生样例

```bash
node scripts/make-sample.js --out examples                       # 默认 seed=1，date=2026-10-26
node scripts/make-sample.js --out examples --seed 7 --date 2026-11-20   # 证号与日期变化，结论不变
```
