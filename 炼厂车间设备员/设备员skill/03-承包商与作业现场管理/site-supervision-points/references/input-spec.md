# 输入口径说明

本技能的输入来自**命令行参数**，不读取附件表格。作业计划表 / 作业许可台账（xlsx）只作为设备员抽取参数的人工对照物，**脚本不解析、不消费这些文件**；`examples/sample-work-plan.xlsx` 亦然。作业许可（电子作业票）系统导出的「许可证编号 / 作业类别 / 作业级别 / 作业地点 / 属地监护人 / 作业单位监护人」等列，由设备员对应抄到 `--permit`（票号或路径）、`--work-type`、`--level`、`--location`、`--unit` 即可。

## 一、参数定义

| 参数 | 必需 | 取值口径 | 缺失时的处理 |
|---|---|---|---|
| `--work-type` | 是 | 作业类型，多类型用 `,` `、` `/` `+` `;` 分隔 | 缺失报错退出 |
| `--scope` | 是 | 作业内容，自由文本 | 缺失报错退出 |
| `--location` | 是 | 位号或区域，自由文本 | 缺失报错退出 |
| `--medium` | 否 | 介质名称 | 缺失或不在库 → 按最严口径 + warning，**不按无危险** |
| `--duration` | 否 | 预计时长，正数小时 | 缺失 → 巡查轮次输出 `null`（显示「—」），**不按 0** |
| `--headcount` | 否 | 作业人数，正整数 | 缺失 → 显示「—」 |
| `--env` | 否 | 环境条件，自由文本（高温/密闭/带压/邻近运行设备/夜间/露天） | 缺失 → 显示「—」 |
| `--unit` | 否 | 作业单位 | 缺失 → 显示「—」 |
| `--start` `--end` | 否 | ISO 8601 **带时区**，如 `2026-09-21T09:00:00+08:00` | 缺失 → 显示「—」；格式非法报错退出 |
| `--level` | 否 | 作业票级别，以作业票为准：特级/一级/二级用火、高处一~四级、吊装一~三级（可写「一级用火」「高处二级」「吊装三级」，只写「一级」时按识别出的作业类型推断） | 缺失 → 频次按作业类型默认口径并在判定依据注明；无法识别或与识别类型不符 → warning，仅记录不生效，**脚本不自判级别** |
| `--permit` | 否 | 作业票文件路径 | 文件不存在 → warning 且不中断；**脚本不解析票内容** |
| `--out` | 否 | 输出目录 | 默认 `supervision-out/` |

## 二、作业类型别名表

| 用户可能填写 | 识别为 |
|---|---|
| 用火、动火、明火、焊接、气割、切割、打磨、砂轮、电焊、氧焊、烘烤、喷灯 | 用火作业（《中国石化作业许可管理规定》命名，不写「动火」） |
| 受限空间、有限空间、进罐、进塔、进容器、入罐、进入设备内 | 受限空间作业 |
| 高处、登高、高空、脚手架、搭架、架子、吊篮、临边、攀登 | 高处作业 |
| 吊装、起重、吊车、汽车吊、行车、葫芦、吊运、起吊 | 吊装作业 |
| 临时用电、临电、接电、用电作业、电源接引 | 临时用电作业 |
| 动土、开挖、挖掘、破土、开槽、钻探、打桩 | 动土作业 |
| 断路、占路、封路、道路占用 | 断路作业 |
| 盲板、抽堵、加盲板、拆盲板、插盲板 | 盲板抽堵作业 |
| 检修、拆解、解体、抽芯、更换、安装、试压、校验、保运 | 常规检修作业（日常维修，不属八大类，不纳入 S 系列许可通用要点） |

**以上均不命中的原始文本原样列入 `meta.unknownTypes`，不猜测归类。**

## 三、介质别名与危险特性

见 `references/supervision-rules.md` 第五节。介质为空或不在库时按最严口径（易燃易爆 + 有毒有害）处理并 warning。

## 四、会被拒绝的输入

| 情形 | 行为 |
|---|---|
| 缺 `--work-type` / `--scope` / `--location` | `ok:false` + exit 1 |
| 值参数后面缺取值或紧跟另一个 `--flag` | `ok:false`「参数 --xx 缺少取值」 |
| 未知参数 | `ok:false`「未知参数 --xx」 |
| `--duration` 非正数 / `--headcount` 非正整数 | `ok:false` |
| `--start` / `--end` 非 ISO 8601 带时区 | `ok:false`，错误信息含格式示例 |
| `--end` 不晚于 `--start` | `ok:false` |
| `--level` 后缺取值 | `ok:false` |

## 五、不会中断的情形（只 warning）

| 情形 | warning 内容 |
|---|---|
| 作业类型全部不在覆盖范围 | 只输出通用监督框架，标注「待安全专业补充」 |
| 部分作业类型不在覆盖范围 | 已覆盖部分正常出要点，未覆盖部分标注「待安全专业补充」 |
| 多类型组合 | 已合并各类型要点并标注来源类型，加严项见 `escalated` |
| 介质为空或不在危险特性库 | 已按最严口径处理，请核实 MSDS 后复核 |
| `--permit` 指向的文件不存在 | 本次未对照作业票，要点仅按作业类型规则生成 |
| `--level` 无法识别 | 本次按作业类型默认口径，未按级别映射频次 |
| `--level` 与识别出的作业类型不符（如高处作业填「一级用火」） | 级别仅作记录，频次仍按作业类型默认口径 |
