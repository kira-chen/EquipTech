# 交叉作业冲突检测
**技能名称**：交叉作业冲突检测

**技能简介**：把当天同一区域的多张作业票放在一起比对，找出空间上下层、用火与排放、吊装与下方作业、同一监护人等冲突，同位号受限空间加用火的双票作业只作提示，输出冲突清单与协调建议。辅助排查，不替代安全环保部门统筹。

**技能描述**

面向炼化厂车间（运行部）设备员，在作业开始前把当天的作业票清单过一遍，看哪些活会打架。上传作业清单（作业许可系统导出的许可证编号、作业类别、作业地点、属地监护人、作业单位监护人等列名可直接识别），告知车间和日期，技能两两比对：同区域同层或上下层的空间冲突；用火与可燃介质吹扫、吊装与下方作业、盲板抽堵与同系统作业等风险冲突；同一监护人、同一台吊车、同一电源回路被多张票占用的资源冲突，每条带规则号、严重度和建议。罐内、塔内用火这种同位号受限空间加用火的双票作业只列为提示项，不算冲突。区域、标高、介质、时间没填的一律列为无法判定，不按无冲突放行。最终安排由安全环保部门决定。

**示例问题**
1. 明天常减压这八张票帮我排一下，看看有没有交叉作业，哪些要错开。　　**附件：** `sample-operations-2026-09-21.xlsx`
2. 这是作业许可系统导出的今天的台账，有属地监护人和施工队监护人两列，没有电源回路那些栏，能查吗？　　**附件：** `sample-permit-export.xlsx`
3. 有两个活区域栏没填，这是我们装置的区域划分表，按位号对一下再看。　　**附件：** `sample-operations-2026-09-21.xlsx + sample-area-map.xlsx`
4. 用火和吹扫是前后脚接着干的，间隔半小时算不算冲突？介质栏施工队没填会怎么样？　　**附件：** `sample-no-medium.xlsx`
5. 施工队给的是他们自己导出的表，第一行是标题，列名和我们的不一样，还夹着昨天的活，帮我看看。　　**附件：** `sample-contractor-export.xlsx`
