# 输入规格：交叉作业冲突检测

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一次只处理一个作业清单文件；多份清单请先合并到一张「作业清单」表

## 作业清单工作表（必需）

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「作业清单」「作业清单表」「作业票」「作业计划」均可识别。

| 列名 | 必需 | 说明 |
|---|---|---|
| 作业编号 | 是 | 作业票号 / 许可证编号；为空的行会被跳过并 warning |
| 作业类型 | 是 | 作业类别（八大类命名：用火/受限空间/高处/吊装/临时用电/动土/断路/盲板抽堵）或作业内容，用于识别冲突矩阵中的作业类别，见下方「作业类型识别」 |
| 位号 | 否 | 作业对象位号 / 功能位置；用于「同一空间」认定（同位号受限空间 + 用火 → 双票提示项）与区域划分表补区域。本技能不区分 SAP 8 位设备编号与位号，「设备编号」栏按位号读 |
| 区域 | 否 | 作业地点 / 作业区域；**为空时空间关系一律未判定**，绝不按「不在同一区域」处理 |
| 标高 | 否 | **为空时同区域内的上下层关系未判定**；见下方「标高取值」 |
| 开始时间 | 否 | 为空时该作业与其他作业的时段关系一律未判定 |
| 结束时间 | 否 | 同上 |
| 作业单位 | 否 | 施工单位/承包商，仅用于展示 |
| 监护人 | 否 | 资源冲突判定（Z1）。中石化为**双监护**：「属地监护人」「作业单位监护人」两列各自单列，并与本列合并后全部参与 Z1 比对 |
| 属地监护人 | 否 | 作业许可系统导出列；参与 Z1 |
| 作业单位监护人 | 否 | 作业许可系统导出列；参与 Z1 |
| 涉及介质 | 否 | 风险冲突判定；**为空时相关冲突项标未判定**，不得判为无冲突 |
| 使用设备 | 否 | 起重设备等，资源冲突判定（Z2）；只有起重类设备或吊装作业所用设备参与 Z2，普通机具同名不判 |
| 所属系统 | 否 | 盲板抽堵冲突判定（R7） |
| 电源回路 | 否 | 资源冲突判定（Z3）。**作业许可系统导出通常无此列**，缺列属正常：脚本只提示一次「本次不判 Z3」，不算数据问题 |
| 消防覆盖区 | 否 | 资源冲突判定（Z4）。同上，通常缺省，缺列只提示一次 |
| 作业内容描述 | 否 | 与作业类型合并后参与类型识别，可提高识别准确度 |
| 车间 | 否 | 车间范围核对（D007），只认表头正好是「车间 / 所属车间 / 属地车间 / 运行部」（或其后加「名称」）的列；「维护工厂」等 SAP 工厂代码列、「属地单位 / 使用单位」和「车间负责人」「车间监护人」等人员列都不认；「车间监护人」是属地监护人的别名，不当车间列。有本车间行时剔除其他车间的作业并 warning（逐车间写行数），不参与任何冲突判定；车间为空的行按本车间保留并 warning；没有一行是本车间时不筛，warning 与 md 开头写【注意】（多半是传错了文件）；无车间列不筛，md 口径写「输入未含车间列，车间范围以取数条件为准」。结果写 `meta.workshopScope`。区域划分表（`--area-map`）是查找表，不核对 |

## 作业类型识别

脚本把「作业类型 + 作业内容描述」合并后做关键词匹配，**一项作业可同时命中多个类型**（如「进罐用火焊补」同时是受限空间与用火）。

| 类型 | 识别关键词 |
|---|---|
| 用火作业（《中国石化作业许可管理规定》命名，"动火"仅作识别别名） | 用火、动火、明火、焊接、气割、切割、打磨、砂轮、电焊、氧焊、烘烤、喷灯 |
| 受限空间作业 | 受限空间、进罐、进塔、进容器、入罐、有限空间、进入设备内 |
| 高处作业 | 高处作业、登高、高空、脚手架、搭架、架子、上塔、平台作业、吊篮 |
| 吊装作业 | 吊装、起重、吊车、汽车吊、行车、葫芦、吊运、起吊 |
| 盲板抽堵 | 盲板、抽堵、加盲板、拆盲板、插盲板 |
| 动土作业 | 动土、开挖、挖掘、破土、开槽、钻探、打桩 |
| 临时用电 | 临时用电、接电、用电作业、电源接引、临电 |
| 吹扫置换/排放 | 吹扫、置换、排放、泄压、导淋、退料、排凝、放空、脱水 |
| 清洗带水作业 | 清洗、冲洗、水洗、高压水、化学清洗、带水、蒸煮 |
| 断路/管线作业 | 断路、管线拆装、管线作业、管道拆除、动管线 |
| 检修作业 | 检修、拆解、解体、抽芯、更换、安装、试压、校验 |
| 其他作业 | 以上均不匹配 |

**类型识别不准会导致冲突漏判**，作业类型写法不规范时建议在「作业内容描述」中补充具体工序。

## 标高取值

| 写法 | 解析结果 |
|---|---|
| `0`、`12.5`、`+8.0`、`-3` | 按数值（米） |
| `12.5m`、`8米` | 按数值（米） |
| `3层`、`3F` | 按层高折算（默认 4 米/层，`--floor-height` 可调）为 12，**标「推断，待确认」并 warning** |
| `一层`/`二层`/`三层`/`四层`/`五层`/`六层` | 同上按层数 × 层高折算 |
| `地面`、`地坪`、`零米` | 0 |
| `地下` | -3 |
| 空单元格 | **null（未判定）**，同区域内上下层关系标未判定 |
| 其他无法解析的文字（如「很高」） | **null（未判定）** + warning，**绝不按 0 处理** |

标高差 **≥ 2 米** 判为上下层作业（vertical），< 2 米判为同层（same）。

**层高说明**：炼化装置框架层高常见 4~6 米不等，脚本不替用户选层高——默认 4 米只是折算缺省值，折算结果一律标「推断，待确认」；厂内框架层高不同时传 `--floor-height`，或直接在清单里填米数。

## 时间字段
- 支持：`2026-09-21 09:00`、`2026/9/21 9:00`、Excel 日期单元格、Excel 日期序列号
- **有效期不覆盖检测日期的作业（结束时间不晚于检测日 00:00，或开始时间不早于次日 00:00）会被跳过并 warning**（列入 `skipped`）；前一天开、后一天结束的多日作业票检测日全天有效，**不跳过**，照常参与冲突判定；重叠分钟与并行时段只算检测日 [当日 00:00, 次日 00:00) 内的部分
- 起或止时间缺失/无法解析 → 该作业与其他所有作业的时段关系标为 `undetermined`，**不得按不重叠处理**
- 结束时间只写日期、没有时分 → 按当日 24:00（次日 00:00）处理并 warning；不补成当日 00:00，以免检测日当天的作业被跳过
- 结束时间不晚于开始时间 → warning 提示核实，不自动修正

## 时段重叠判定（`--window`）

| 取值 | 含义 |
|---|---|
| `0`（默认） | 严格重叠：两时段必须有正的交集分钟数；首尾相接不计为重叠 |
| `>0` | 两作业时段交集为空但间隔 ≤ N 分钟时，同样视为重叠（前后衔接过近同样存在交叉风险） |

`--window` 取非负整数，其他写法报错终止。

## 区域划分表（可选，`--area-map`）

sheet 名匹配「区域划分」「区域」。用于按位号补全作业清单中为空的区域字段。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | |
| 区域 | 是 | |
| 所属系统 | 否 | 区域表提供时，可一并补全作业的所属系统 |

**位号不在区域划分表中时，区域仍为空，空间关系仍判未判定**，不做任何推断。

## 厂内冲突口径（可选，`--rules`）

模板见 `assets/templates/rules-template.xlsx`。需含「冲突口径」工作表（别名：口径、冲突规则、规则）：

| 列名 | 必需 | 说明 |
|---|---|---|
| 规则号 | 是 | 内置规则号 S1~S3 / R1~R8 / Z1~Z4；不是内置规则号的行被忽略并 warning（**`--rules` 不新增规则**） |
| 严重度 | 否 | 高 / 中 / 低，覆盖该规则的默认严重度；其他取值忽略 |
| 启用 | 否 | 是 / 否；填「否」停用该规则 |
| 建议 | 否 | 覆盖协调建议措辞，**须以「建议」开头**，否则忽略并 warning |

至少一行生效时，报告判定口径写「厂内口径（文件名）覆盖规则 …」；无可用行或无该工作表时回落内置默认矩阵并 warning。未传 `--rules` 时判定口径标注「默认口径，非厂内正式口径」。

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 作业编号为空的行（warning 提示）
- 有效期不覆盖检测日期的作业（warning 提示，列入 `skipped`）
