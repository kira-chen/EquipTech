# 交叉作业冲突矩阵与判定口径

> **本表为默认参考口径（非厂内正式口径）。** 各厂作业许可与交叉作业管理制度不同，厂内有正式规定时用 `--rules` 覆盖规则的严重度/启用/建议（模板 `assets/templates/rules-template.xlsx`），并在交付时注明采用的口径来源。
> **口径来源**：作业类别命名（八大类：用火、受限空间、高处、吊装、临时用电、动土、断路、盲板抽堵）、双监护（属地监护人 + 作业单位监护人）依据《中国石化作业许可管理规定》；交叉作业的相互告知、统一协调要求依据 GB 30871-2022 与中石化作业许可规定，**本表只引用要求名称与分类概念，不转述法规数值**。
> **本检测为辅助排查，交叉作业的最终安排与许可由安全环保部门按厂内制度决定；未列出的冲突不代表不存在。**

## 一、三类冲突与严重度

| 冲突类别 | 规则号 | 判定依据 |
|---|---|---|
| 空间冲突 | S1~S3 | 同区域 + 时段重叠；同区域上下层（标高差）构成落物风险 |
| 风险冲突 | R1~R8 | 作业类型两两组合的风险叠加，按冲突矩阵判定 |
| 提示项（不计冲突） | R2（同位号） | 同位号「受限空间 + 用火」双票作业，属合法常态，只提示核对两票关联、气体分析、双监护 |
| 资源冲突 | Z1~Z4 | 同一监护人（属地监护人、作业单位监护人两列合并比对）/ 起重设备 / 电源回路 / 消防覆盖区被多项同时段作业占用；电源回路、消防覆盖区两列在作业许可系统导出中通常缺省，缺列不判 Z3/Z4 |

| 严重度 | 含义 |
|---|---|
| 高 | 可直接导致人身伤害或火灾爆炸，需在作业前消除或错时 |
| 中 | 存在风险叠加，需增加控制措施后方可同时进行 |
| 低 | 以相互干扰为主，需相互告知与作业面分隔 |
| 提示 | 不构成冲突，只需核对（目前仅 R2 同位号双票作业） |
| **未判定** | 判定所依赖的字段缺失（区域、标高、起止时间、介质、所属系统） |

## 二、判定前置：时段重叠

所有冲突判定的前置条件是两项作业时段重叠。

- 默认 `--window 0`：严格重叠，交集分钟数 > 0 才算重叠，首尾相接不算
- `--window N`：交集为空但间隔 ≤ N 分钟时同样视为重叠
- **任一侧起止时间缺失或无法解析 → 时段关系 `undetermined`**，该组作业列入「无法判定项」，**绝不按不重叠跳过**

## 三、空间关系判定

| 条件 | 判定 |
|---|---|
| 任一方区域字段为空 | **未判定**（缺区域） |
| 两方区域不同 | 不同区域（different） |
| 同区域、任一方标高为空或无法解析 | **未判定**（缺标高） |
| 同区域、标高差 ≥ 2 米 | 同区域上下层（vertical） |
| 同区域、标高差 < 2 米 | 同区域同层（same） |

**硬约束：区域或标高字段为空时一律归入 `undetermined`，绝不按「不在同一区域」处理。** 区域缺失时按「不在同一区域」处理等同于把最危险的组合静默放行，是本技能最不能犯的错误。

## 四、空间冲突规则

| 规则号 | 条件 | 严重度 | 风险 |
|---|---|---|---|
| S1 | 同区域同层 + 时段重叠 | 中 | 作业面重叠，人员与工机具相互干扰 |
| S2 | 同区域上下层 + 上方为高处作业或吊装 + 下方有人作业 | **高** | 落物打击 |
| S3 | 同区域上下层 + 上方无高处/吊装作业 | 低 | 相互干扰 |

## 五、风险冲突矩阵

| 规则号 | 作业组合 | 空间条件 | 严重度 | 风险说明 |
|---|---|---|---|---|
| **R1** | 用火 × 可燃介质排放/吹扫置换 | 同区域（含上下层） | **高** | 排放可燃介质遇火源引燃、闪爆 |
| **R2** | 用火 × 受限空间 | **同位号 → 提示项（不计冲突）**：罐内/塔内用火是「受限空间票 + 用火票」双票作业的合法常态，只核对两票互相关联、气体分析同时满足两票要求、双监护到位、用火级别与票面一致；**同区域同层不同位号 → 高**：邻近用火影响受限空间出入口与通风 | 高 / 提示 | 邻近用火烟气火星进入受限空间，空间内人员撤离受限 |
| **R3** | 用火 × 高处作业（下方用火，上方有可燃物） | 同层，或用火在下方的上下层 | 中 | 火星飞溅引燃上方可燃物或作业人员防护用品 |
| **R4** | 吊装 × 任何下方作业 | 同区域（同层或上下层） | **高** | 吊物坠落、吊臂扫碰 |
| **R5** | 受限空间 × 邻近用火/热工作业 | 同区域上下层（不同位号） | **高** | 烟气与有害气体进入受限空间，空间内人员撤离受限 |
| **R6** | 临时用电 × 带水作业/清洗 | 同区域 | 中 | 电缆接头与配电箱受潮触电 |
| **R7** | 盲板抽堵 × 同系统其他作业 | 同一「所属系统」 | **高** | 抽堵期间隔离状态变化，介质窜入或憋压 |
| **R8** | 动土 × 地下管线区域作业 | 同区域 | 中 | 开挖触及地下管线或影响管线支撑 |

### 规则间的关系

- **R2 与 R5 互补**：同位号由 R2 出提示项（不计冲突），同区域同层不同位号由 R2 判高冲突，同区域上下层不同位号由 R5 覆盖，不重复计数。
- **同位号双票作业不是冲突**：旧版把「同位号受限空间 + 用火」判为高冲突并建议「人员撤出再用火」，这与罐内/塔内用火的实际做法相悖，已改为提示项；需要错时的情形只有邻近用火（不同位号）。
- **R4 与 S2 并存**：吊装的上下层组合同时命中风险冲突 R4 与空间冲突 S2，分别列入两节，属预期行为——一条从落物风险角度、一条从空间关系角度描述同一组作业。
- 一项作业可同时属于多个类型，因此一组作业可能同时命中多条规则，逐条列出，不合并。

## 六、风险冲突的未判定口径

| 场景 | 处理 |
|---|---|
| R1：吹扫置换作业的介质字段为空或不在可燃性库中 | **R1 标未判定**，注明缺「涉及介质」 |
| R2/R3/R4/R6/R8：空间关系未判定（缺区域或标高） | **该条标未判定**，注明缺失的具体字段 |
| R7：两项作业同区域同时段，但任一方「所属系统」为空 | **R7 标未判定**，注明缺「所属系统」 |
| Z1~Z4：资源值相同，但任一方起止时间缺失 | **该资源冲突标未判定**，注明缺「起止时间」 |

**硬约束：介质字段为空而涉及风险冲突判定时，对应冲突项标 `undetermined`，不得因缺数据判定为无冲突。**

介质可燃性分档：

| 档位 | 典型介质 |
|---|---|
| 可燃/易燃 | 氢、硫化氢、液化气、轻烃、石脑油、汽油、瓦斯、干气、丙烯、乙烯、丁烷、丙烷、苯、甲苯、二甲苯、甲醇、原油、柴油、蜡油、航煤、煤油、污油、溶剂 |
| 惰性或不可燃 | 水、蒸汽、氮气、空气、除盐水、循环水、净化风、仪表风、烟气 |
| **无法判定** | 介质为空，或不在以上列表中 |

**介质不在库中时不按不可燃处理**，而是判为未判定并提示核实介质与 MSDS。

## 七、资源冲突规则

| 规则号 | 资源 | 字段 | 严重度 | 风险说明 |
|---|---|---|---|---|
| Z1 | 监护人 | 监护人 | **高** | 同一监护人被排到多项同时段作业，无法同时在岗监护 |
| Z2 | 起重设备 | 使用设备 | **高** | 同一台起重设备被排到多项同时段作业，无法同时到位 |
| Z3 | 电源回路 | 电源回路 | 中 | 同一回路被多项作业占用，停送电操作相互影响 |
| Z4 | 消防设施覆盖区 | 消防覆盖区 | 中 | 共用同一消防设施覆盖区，一处动用后其余作业消防保障被削弱 |

一个字段内用「、，,;；/」分隔的多个值分别参与比对（如监护人栏写「张三、李四」）。

## 七之二、厂内口径覆盖（`--rules`）

`--rules` 文件（模板 `assets/templates/rules-template.xlsx`，「冲突口径」表：规则号 / 严重度 / 启用 / 建议）可以：覆盖某规则的严重度（高/中/低）、停用某规则（启用=否）、替换协调建议措辞（须以「建议」开头）。**不能新增规则、不能把提示项改回冲突、不能放宽未判定口径**。覆盖生效后报告判定口径写明「厂内口径（文件名）覆盖规则 …」；未传时标注「默认口径，非厂内正式口径」。

## 八、协调建议表述规范

脚本对每条冲突给出建议，建议措辞固定为以下几类：

| 规则 | 建议 |
|---|---|
| S1 | 建议错时安排或明确作业面分隔，落实相互告知 |
| S2 | 建议先后作业；确需同时进行时，建议在下方设置硬质防护棚并增加专人监护 |
| S3 | 建议明确上下层作业相互告知，落实警戒与围挡 |
| R1 | 建议错时安排：排放吹扫结束并经气体检测合格后再行用火 |
| R2（邻近） | 建议错时安排；确需同时进行时，建议用火点避开受限空间出入口与通风口并增加属地监护 |
| R2（同位号提示项） | 建议核对受限空间票与用火票互相关联、气体分析同时满足两票要求、双监护到位；不构成冲突，无需错时 |
| R3 | 建议错时安排；确需同时进行时，建议在用火点上方设置阻燃隔离并增加用火监护人 |
| R4 | 建议错时安排：吊装作业期间下方停止一切作业并设置警戒区 |
| R5 | 建议错时安排；确需同时进行时，建议加强受限空间强制通风并连续检测 |
| R6 | 建议错时安排；确需同时进行时，建议临时用电采用防水接头并加装漏电保护 |
| R7 | 建议先后作业：盲板抽堵完成并确认隔离到位后再进行同系统其他作业 |
| R8 | 建议先探明地下管线走向并人工开挖至管线埋深，建议增加管线监护 |
| Z1 | 建议错时安排或另行指派监护人，一名监护人同一时段只对应一项作业 |
| Z2 | 建议错时安排起重设备使用时段，或另行调配设备 |
| Z3 | 建议错时安排，或由电气专业确认分回路供电后再同时作业 |
| Z4 | 建议错时安排，或补充临时消防措施后再同时作业 |

### 硬约束

**建议只能是建议。** 协调建议一律用「建议错时 / 建议增加监护 / 建议先后作业 / 建议补充信息」等建议语气，**不得表述为已批准的安排**。

| 应写 | 不得写 |
|---|---|
| 「建议错时安排，由安全环保部门确认后执行」 | 「已安排错时，9:00 用火、10:00 吹扫」 |
| 「建议先后作业」 | 「批准两项作业同时进行」 |
| 「建议增加专人监护」 | 「已增派监护人，可以同时作业」 |
| 「无法判定，需补充区域字段后重新检测」 | 「未发现冲突，可以正常作业」 |

## 九、分析段表述规范

撰写 200~400 字，结构固定为五段：

1. **总体情况**：检测作业数、各类冲突组数、高严重度冲突数、同时段最大并行作业数。
2. **高严重度冲突与建议措施**：逐条说明高严重度冲突涉及的作业编号、命中规则、风险，以及脚本给出的建议。
3. **一般冲突**：中低严重度冲突的归类说明。
4. **提示项与无法判定项、需补充信息**：同位号双票作业的核对要点（不写成冲突）；哪些作业缺哪个字段导致无法判定，需补充后重新检测。
5. **建议协调安排**：建议提交安全环保部门统筹的事项、建议召开班前交底（JSA/风险分析交底）的内容。

### 用词要求

| 场景 | 应写 | 不得写 |
|---|---|---|
| 冲突描述 | 「ZY-001 用火与 ZY-002 石脑油排放时段重叠 117 分钟，命中 R1」 | 「这两个活肯定要出事」 |
| 同位号双票作业 | 「ZY-005 进罐与 ZY-006 罐内用火为双票作业，列为提示项，建议核对两票关联与双监护」 | 「ZY-005 与 ZY-006 冲突，人员撤出再用火」 |
| 无冲突 | 「按本次录入的信息未检出冲突；未列出的冲突不代表不存在」 | 「经检查无任何冲突，可放心作业」 |
| 未判定 | 「ZY-007 区域字段为空，与其余 6 项作业的空间关系均无法判定」 | 「ZY-007 不在同一区域，无冲突」 |
| 数字 | 引用 conflicts.json 的 counts | 自行统计或估算 |

### 硬约束

- **不批准或否决作业安排**，不替代安全环保部门统筹。
- **不判定某组合「可以接受」**。冲突矩阵命中即列出，是否可接受由安全环保部门决定。
- **不做现场实际空间关系的勘察结论**。区域与标高以清单录入为准。
- **数字一律引用 conflicts.json**，不得自行统计。
- **必须保留声明行**：本检测为辅助排查，交叉作业的最终安排与许可由安全环保部门按厂内制度决定；未列出的冲突不代表不存在。
