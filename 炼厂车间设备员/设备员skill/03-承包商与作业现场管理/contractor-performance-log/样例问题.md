# 承包商表现记录 · 样例问题

> 附件均在 `examples/`（可用 `node scripts/make-sample.js --out examples --seed <n> --to <YYYY-MM-DD>` 重新生成，默认 seed=1、to=2026-09-21，评价区间 2026-07-01 至 2026-09-21）。记录日期随 seed 在区间内变化，但每题的预期结论——承包商数、未判定/未整改/名称待确认的条数与得分——不变；预期计数与验证要点见 `examples/README.md` 对照表（仅开发库含，发布包不含）。样例中承包商名称、人名、编码全部编造。

1. 这三个月常减压车间的承包商表现帮我汇总一下，要报给安全环保部门做季度考核用。　　**附件：** `examples/sample-contractor-records-2026-09-21.xlsx`
2. 这是承包商管理平台导出的检查记录，有供应商编码，同一家公司写了两种名字，帮我按编码合并统计一下。　　**附件：** `examples/sample-contractor-export.xlsx`
3. 我们厂有正式的扣分标准，一般违章扣 3 分不是 2 分，严重、重大违章和质量、进度的扣分也和默认的不一样，按厂里的口径重新算。　　**附件：** `examples/sample-contractor-records-2026-09-21.xlsx + examples/sample-contractor-rules.xlsx`
4. 这份表第一行是标题，底下有合计行，有一条类型写的"其他"，还有一条没填承包商，能读吗？　　**附件：** `examples/sample-contractor-messy.xlsx`
5. 只看安泰机电这一家，顺便把工单台账和承包商名单带上，看看履约情况和是不是在册单位。　　**附件：** `examples/sample-contractor-records-2026-09-21.xlsx + examples/sample-contractor-orders.xlsx + examples/sample-contractor-roster.xlsx`
6. 违章记录按重大、严重、一般分一下，有一条写的"严重违规"，算严重还是重大？　　**附件：** `examples/sample-contractor-export.xlsx`
7. 宏远建安和宏远建安工程有限公司是一家，你直接合起来算行不行？　　**附件：** `examples/sample-contractor-records-2026-09-21.xlsx`（预期：脚本不合并，列入名称待确认，建议回源记录补编码或统一名称后重跑）

## 平台接入业务系统 MCP 时

不上传附件，数据由 MCP 工具获取，演示数据每天按剧本刷新。

M1. 近 90 天各承包商在现场表现怎么样？按单位汇总一下扣分和未整改的事项，我要报给安全环保部门。　　**数据：** MCP HSE管理平台 `get_site_inspections`（`workshop`：常减压车间，不填日期即近 90 天）作 `--input`、`get_contractors`（无参数，承包商名单）作 `--roster`，`--from` 今天前 89 天、`--to` 今天

M2. 示例检维修公司这三个月有哪些违章和没整改完的？　　**数据：** MCP HSE管理平台 `get_site_inspections`（`workshop`：常减压车间，`contractor_code`：C1001）、`get_contractors`（无参数），`--contractor C1001`
