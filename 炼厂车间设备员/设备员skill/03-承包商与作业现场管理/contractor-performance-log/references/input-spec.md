# 输入规格：承包商表现记录

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一次只读一个记录文件：`--input 承包商检查记录.xlsx`

## 检查记录 / 违章记录工作表（必需）

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「检查记录」「违章记录」「现场检查记录」「承包商检查记录」「记录」均可识别。找不到时脚本报错终止（该表是唯一数据源）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 记录日期 | 是 | 用于评价区间过滤。**缺失时该条不计分并进 `undetermined`，不按区间内默认处理** |
| 承包商 | 是 | 无承包商编码时**按字面量分组统计，全称与简称绝不自动合并**；为空时归入「（未填承包商）」并 warning |
| 承包商编码 | 否 | 承包商管理平台 / SAP 供应商编码。**有此列时按编码分组**，同一编码下的不同名称写法视为同一单位（名称以「/」并列展示，warning 提示）；无编码的记录仍按名称分组 |
| 类型 | 是 | 四个维度之一，见下方「类型取值」。缺失或无法归类 → `undetermined` |
| 事项描述 | 是 | 记录的具体事实；与承包商同时为空的行会被跳过并 warning |
| 严重程度 | 否 | 见下方「严重程度取值」。**缺失或无法归类时该条进 `undetermined`，绝不按最低档计分** |
| 项目 | 否 | 作业项目 / 工程名称，展示用 |
| 整改情况 | 否 | 见下方「整改情况取值」；填报为未整改 / 整改中的进 `unrectified` |
| 检查人 | 否 | 展示用，便于追溯。「监护人」是作业票的双监护角色（属地监护人 / 作业单位监护人），不是检查人，不作别名 |
| 车间 | 否 | 车间范围核对（D007）。HSE 管理平台 `get_site_inspections` 导出带此列。只认表头正好是「车间 / 所属车间 / 属地车间 / 运行部」（或其后加「名称」）的列；「维护工厂」等 SAP 工厂代码列、「属地单位 / 使用单位」和「车间负责人」「车间监护人」等人员列都不认。有本车间行时剔除其他车间的记录并 warning（逐车间写行数），不计分、不进任何清单；车间为空的行按本车间保留并 warning；没有一行是本车间时不筛，warning 与 md 开头写【注意】（多半是传错了文件）；无车间列不筛，md 口径写「输入未含车间列，车间范围以取数条件为准」。结果写 `meta.workshopScope` |

## 列名别名

脚本按别名表匹配列头（局部别名 + 共享 `SYSTEM_ALIASES`，局部优先），以下写法均可识别：

| 标准列名 | 可识别的写法 |
|---|---|
| 记录日期 | 记录日期、检查日期、日期、发生日期、检查时间、记录时间、登记日期 |
| 承包商 | 承包商、承包商名称、施工单位、施工队、队伍、作业单位、外来单位、单位名称、乙方、作业单位名称、承修单位 |
| 承包商编码 | 承包商编码、供应商编码、承包商代码、供应商代码、单位编码、供应商 |
| 项目 | 项目、项目名称、作业项目、工程名称、施工项目、作业内容、工程 |
| 类型 | 类型、记录类型、问题类型、违章类型、扣分类型、维度、分类 |
| 事项描述 | 事项描述、描述、问题描述、事项、情况描述、违章内容、内容、事实描述 |
| 严重程度 | 严重程度、程度、违章等级、等级、严重性、级别、问题等级 |
| 整改情况 | 整改情况、整改状态、整改结果、处理情况、整改、闭环情况 |
| 检查人 | 检查人、检查人员、记录人、发现人、检查者、属地检查人（**不含「监护人」**） |
| 许可证编号（展示用，不参与判定） | 许可证编号、作业票编号、作业许可证编号、票号、许可证号 |

表头行识别：取前 10 行中命中必需列最多的一行，因此首行是标题、第三行才是表头的系统导出表也能读。

## 类型取值（四个维度）

| 归类 | 可识别的写法 |
|---|---|
| 安全违章 | 安全违章、安全、违章、违规、HSE、安全问题、三违 |
| 施工质量 | 施工质量、质量、返工、工程质量、质量问题 |
| 进度履约 | 进度履约、进度、履约、工期、延期、进度问题 |
| 现场配合与文明施工 | 现场配合、配合、文明施工、文明、现场管理、协调、配合度 |
| **类型缺失** | 空单元格、—、-、/ |
| **类型无法识别** | 以上都不匹配的其他文字（如「其他」「综合」） |

**类型缺失与无法识别一律进 `undetermined`，绝不按任一维度的最低档计分。**

## 严重程度取值

严重程度的枚举**按维度分列**，脚本先定维度、再在该维度的枚举中匹配：

| 维度 | 归类 | 可识别的写法 |
|---|---|---|
| 安全违章 | 一般违章 | 一般违章、一般、轻微、普通、C类违章、C级 |
| | 严重违章 | 严重违章、严重、**严重违规**、较大、B类违章、B级 |
| | 重大违章 | 重大违章、重大、重大违规、A类违章、A级 |
| 施工质量 | 返工 | 返工、返修、整改返工、重做 |
| | 质量不合格 | 质量不合格、不合格、质量事故、验收不合格（**「不符合」不自动归此档**，进未判定并提示用户明确是返工还是质量不合格） |
| 进度履约 | 延期 | 延期、滞后、误期、未按期、拖期、进度滞后 |
| | 严重延期 | 严重延期、严重滞后、重大延期、严重误期 |
| 现场配合与文明施工 | 文明施工差 | 文明施工差、文明施工、现场脏乱、脏乱、料具乱堆、卫生差 |
| | 不配合 | 不配合、拒不配合、拒绝配合、对抗、不服从 |
| 任意维度 | **程度未填** | 空单元格、—、-、/ |
| 任意维度 | **程度无法识别** | 该维度枚举中都不匹配的其他文字（如「待定级」） |

> **关键口径**：严重程度为空或无法识别 → 该条进 `undetermined`，`deduction` 为 `null`，**绝不按该维度最低档计分**，也不按事项描述推断。

## 整改情况取值

| 归类 | 可识别的写法 |
|---|---|
| 已整改 | 已整改、整改完毕、已完成、已闭环、完成、已处理、已改正、已纠正 |
| 未整改 | 未整改、未完成、未处理、整改中、待整改、未闭环、进行中、未改 |
| 未确认 | 空单元格，或以上都不匹配的其他文字（**按未确认处理，不算未整改也不算已整改**，无法归类时 warning） |

填报为「未整改」一类的记录进 `unrectified` 单列一节。未整改**不额外扣分**，扣分只由维度与严重程度决定。

## 日期字段
- 支持：`2026-09-21`、`2026/9/21`、`2026年9月21日`、`20260921`、Excel 日期单元格、Excel 日期序列号
- 无法解析时输出 `null` 并 warning，**不猜测**；该条记录进 `undetermined` 且不计分

## 评分口径文件（可选，`--rules`）

传入厂内正式的评分口径，覆盖 `evaluation-rules.md` 的默认值。模板见 `assets/templates/rules-template.xlsx`。需含「评分口径」工作表（别名：扣分标准、评分标准、口径）：

| 列名 | 必需 | 说明 |
|---|---|---|
| 类型名称 | 是 | 安全违章 / 施工质量 / 进度履约 / 现场配合（或其别名） |
| 程度名称 | 是 | 该维度下的严重程度（见上表） |
| 扣分 | 是 | 数字，取绝对值；无法解析的行被忽略并 warning |
| 基准分 | 否 | 任一行填写即生效，默认 100 |

可选工作表「分档标准」（列：分档、最低分），最低分留空的一行为最低档，不足两档时回落默认分档并 warning。

类型或程度无法归类、扣分无法解析的行会被忽略并 warning，该项仍按默认口径。口径文件中一条可用行都没有时，整体回落默认口径并 warning。

**传入 `--rules` 且至少命中一行时**，产出标注「厂内口径（文件名）」；否则标注「采用默认口径，非厂内正式口径，结果仅供参考」。

## 承包商名单（可选，`--roster`）

需含「承包商名单」工作表：

| 列名 | 必需 | 说明 |
|---|---|---|
| 承包商名称 | 是 | 全称 |
| 简称 | 否 | 常用简称，纳入名称歧义比对范围 |
| 承包商编码 | 否 | 供应商编码，用于判断按编码分组的记录是否在册 |

名单只用于标注记录中的名称是否在册、并把名单中的简称纳入 `nameAmbiguity` 的比对范围，**不用于自动合并统计**。

名单中已声明的「全称 ↔ 简称」是确定的对应关系，本身不算待确认的歧义：只有当记录里**两种写法都实际出现过**（即源记录确实混用了）时才列入 `nameAmbiguity` 提示；即便如此，脚本依旧分别统计，不合并。

## 工单台账（可选，`--orders`）

需含「工单台账」工作表（列：工单号、承包商、项目、完成情况，可选车间）。输出各承包商的工单数与完成情况，**仅作参考展示，不参与评分**。带车间列时按检查记录同样的规则核对车间范围。

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 承包商与事项描述均为空的行（warning 提示）

## 不会被跳过、但会单列的情况
- **承包商名称疑似重复（全称/简称混用）**：两个名称各自统计，进 `nameAmbiguity` 并 warning，**脚本绝不合并**
- **严重程度为空或无法归类**：进 `undetermined` 不计分，**绝不按最低档**
- **记录类型缺失或无法归类**：进 `undetermined` 不计分
- **记录日期缺失**：进 `undetermined` 不计分，不臆断区间归属
- **记录日期在评价区间外**：进 `outOfRange` 计数，不计入本期统计
- **承包商为空**：归入「（未填承包商）」单列，不参与名称歧义判断；只有编码没有名称时按编码分组并显示「（编码 X）」
- **同一承包商编码下多种名称写法**：按编码合并为一行并 warning，不进 `nameAmbiguity`
