## 共同的边界
四个技能都**不替代安全部门的准入审批、作业许可与考核决定**。资质核验不核实证书真伪；监督要点不替代监护人现场职责；冲突检测不批准作业安排；表现记录不做考核处罚结论。各技能 SKILL.md 中的声明行不得删除。
