# 设备会议汇报稿 · 样例问题

> 附件均在 `examples/`（可用 `node scripts/make-sample.js --out examples --seed <n>` 再生；seed 只改滴速、超期天数、金额等数值，设备数、超期数、需复算指标等结论不变）。预期要点与验证点见 `examples/README.md`（仅开发库含，发布包不含）。

1. 车间设备例会 15 分钟，把这周的巡检和工单情况讲一下，位号要保留。　　**附件：** `examples/sample-status.json + examples/sample-orders.json`
2. 同样的数据给公司机动部领导汇报 8 分钟，只讲结论和要他们定的事，位号别放。　　**附件：** `examples/sample-status.json + examples/sample-orders.json`
3. 把上周的周报指标和隐患情况组织成分厂设备月会的材料，我们分厂叫炼油一部设备科，指标别重算。　　**附件：** `examples/sample-periodic.json + examples/sample-hazard.json`
4. 议题里有能耗管理，但我手上没有能耗数据，材料里怎么处理，别给我编一段。　　**附件：** `examples/sample-status.json + examples/sample-orders.json`
5. 材料要外发，位号全去掉，关键指标那一段多留点时间，另外要做成 PPT。　　**附件：** `examples/sample-periodic.json + examples/sample-orders.json`
6. 这个 JSON 是别的系统导出的，能不能一起用。　　**附件：** `examples/sample-unknown.json + examples/sample-status.json`
7. 需要领导定两件事：机封备件加急采购、检修力量不足要协调，上次会上还有备件定额调整没落实，一起放进材料。　　**附件：** `examples/sample-status.json + examples/sample-orders.json`
8. 我只有一张工单台账 Excel，能直接出汇报稿吗。　　**附件：** 任一 xlsx（技能提示先用 work-order-tracker 生成 orders.json）

## 平台接入业务系统 MCP 时

> 不上传附件，数据由 MCP 工具获取，演示数据每天按剧本刷新。本技能不直接调 MCP：先按上游技能的取数说明跑出上游 JSON（取数都填 workshop=常减压车间），再交给本技能汇总。

M1. 明天常减压车间设备例会 15 分钟，把巡检、工单和隐患情况讲一下，位号保留。　　**数据：** 先运行上游技能：inspection-data-digest（MCP 点检巡检App `get_inspection_records` for_skill=inspection-data-digest、设备资产管理 `get_equipment_ledger` for_skill=inspection-task-dispatch）、work-order-tracker（设备资产管理 `get_work_orders`）、hazard-closure-tracker（HSE管理平台 `get_hazards`），得 status.json、orders.json、hazard.json
M2. 同样的内容给公司设备管理部门汇报 8 分钟，位号别放，要领导定 P-2101A 进料泵是否提前安排检修。　　**数据：** 同 M1 的三个上游 JSON
M3. 把常减压车间近 30 天的设备月报和隐患情况组织成分厂设备月会材料，指标照搬月报，别重算。　　**数据：** 先运行上游技能：equipment-weekly-monthly-report（MCP 设备资产管理 `get_equipment_ledger`、`get_failure_history`、`get_work_orders`、`get_notifications`）得 periodic.json，hazard-closure-tracker（HSE管理平台 `get_hazards`）得 hazard.json
