# 设备员工作交接记录 · 样例问题

> 附件均在 `examples/`（可用 `node scripts/make-sample.js --out examples --seed <n>` 再生；seed 只改电流、滴速、振动等数值，各项计数与结转结论不变）。交接时间统一用带时区的 ISO 8601 时点，预期计数与验证要点见 `examples/README.md` 对照表（仅开发库含，发布包不含）。

1. 我这周末值班，把这两天的设备情况整理成值班交接记录，周一交给张工。　　**附件：** `examples/sample-handover-2026-09-21.xlsx`
2. 接手前先核一下上次值班交接交代的三件事，哪些已经闭环了，没闭环的照原样列出来别给我改期限。　　**附件：** `examples/sample-handover-2026-09-21.xlsx + examples/sample-prev-handover-2026-09-20.xlsx`
3. 我下周休假，这几天就两条记录，也出一份休假交接记录给代管的同事，责任人没填的照实写。　　**附件：** `examples/sample-minimal-2026-09-21.xlsx`
4. 这是 EM 系统导出来的工作记录，第一行是标题，列名是功能位置、设备描述、通知单描述那种，底下还有合计行，能直接出交接记录吗。　　**附件：** `examples/sample-em-export.xlsx`
5. 连着两次交接 P-1105A 那条都没人处理，这次调岗交接还能看到最早是哪次交下来的吗，把上次的 handover.json 也给你。　　**附件：** `examples/sample-handover-2026-09-21.xlsx`，另附上一次运行本技能得到的 `handover.json`（先跑一遍即可）
6. 交接时间我写「今天下午」行不行，不行的话告诉我该怎么写。　　**附件：** `examples/sample-handover-2026-09-21.xlsx`
7. 在修的减压塔顶换热器 E-1205 检修那边没给进度，交接记录里怎么写，别替我编一个。　　**附件：** `examples/sample-handover-2026-09-21.xlsx`
8. 交接记录里没做完的事帮我直接转成待办清单。　　**附件：** 第 2 题运行本技能产出的 `handover.json`（交 worklog-todo-manager）

## 平台接入业务系统 MCP 时

> 不上传附件，数据由 MCP 工具获取，演示数据每天按剧本刷新。

M1. 我今天早上 8:30 交常减压车间的值班，交给吴七，把本班的缺陷和在修设备从系统里取出来整理成值班交接记录。　　**数据：** MCP 设备资产管理 `get_notifications`（workshop=常减压车间，for_skill=shift-handover-record）、`get_work_orders`（workshop=常减压车间，for_skill=shift-handover-record）
M2. 加氢车间的设备员郑八今天下午 5 点开始休假，出一份休假交接记录，只要加氢车间的事。　　**数据：** MCP 设备资产管理 `get_notifications`、`get_work_orders`（workshop=加氢车间，for_skill=shift-handover-record）
M3. 明早 8:30 吴七再交班，把今天的交接记录作上次交接，没闭环的照原样结转，再转成吴七的待办。　　**数据：** 同 M1 再取一次；`--prev` 用 M1 产出的 handover.json；待办交 worklog-todo-manager
