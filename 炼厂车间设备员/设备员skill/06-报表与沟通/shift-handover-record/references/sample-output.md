## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 结转项 | 「上次交下来后本次未处理，原要求完成时间为今日 12:00」 | 「P-35XXA 待补装」（隐去来源与原期限） |
| 期限 | 「未作延期，是否顺延请交接双方现场确认」 | 「顺延至明日 12:00」 |
| 责任人缺失 | 「责任人未落实，需接手人明确」 | 省略该条 / 写「由接手人负责」 |
| 在修无说明 | 「在修状态无说明，需与检修当面确认进度」 | 「检修进行中，预计明日完工」 |
| 异常未闭环 | 「已降负荷观察并通知动设备工程师，尚未闭环」 | 「已处理完毕」 |
| 上次表现 | 只陈述事项状态 | 「上次值班未按时完成，工作不到位」 |
| 交接性质 | 「设备员值班交接」 | 「夜班交接班」（操作班组口径） |
