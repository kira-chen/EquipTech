# 设备员工作交接记录
**技能名称**：设备员工作交接记录

**技能简介**：把值班、休假或调岗期间的设备异常、处理情况、在修设备和未完成事项整理成设备员工作交接记录，上次交接没闭环的事项强制结转、不自动延期，产出的 handover.json 可直接进待办。

**技能描述**

面向炼化厂车间（运行部）设备员，交接的是值班、休假、调岗三类工作交接。把交接期间的值班或工作记录（Excel，支持 SAP PM、EM 导出列名）和在修设备清单交给技能，脚本分出状态变化、异常处理、在修三类，未完成事项逐条列出，责任人、期限没填的写待明确而不是删掉；给了上次交接记录，按位号加内容相似度逐条核对，没闭环的原样结转并标明上次遗留，来源指向最初那次交接，期限不动。在修设备没写状态或超期的自动进重点关注。生成九节交接记录和 handover.json，可交待办管理技能读成待办。交接时间必须是带时区的时点；不评价上次工作质量，不判断哪条可以不交接，记录保留以双方现场确认签字为准的说明。

**示例问题**
1. 我这周末值班，把这两天的设备情况整理成值班交接记录，周一交给张工。　　**附件：** `sample-handover-2026-09-21.xlsx`
2. 接手前先核一下上次值班交接交代的三件事，哪些已经闭环了，没闭环的照原样列出来别给我改期限。　　**附件：** `sample-handover-2026-09-21.xlsx + sample-prev-handover-2026-09-20.xlsx`
3. 我下周休假，这几天就两条记录，也出一份休假交接记录给代管的同事，责任人没填的照实写。　　**附件：** `sample-minimal-2026-09-21.xlsx`
4. 这是 EM 系统导出来的工作记录，第一行是标题，列名是功能位置、设备描述、通知单描述那种，底下还有合计行，能直接出交接记录吗。　　**附件：** `sample-em-export.xlsx`
5. 连着两次交接 P-1105A 那条都没人处理，这次调岗交接还能看到最早是哪次交下来的吗，把上次的 handover.json 也给你。　　**附件：** `sample-handover-2026-09-21.xlsx`，另附上一次运行本技能得到的 `handover.json`（先跑一遍即可）
