# 车间设备日报 · 样例问题

> 附件均在 `examples/`（可用 `node scripts/make-sample.js --out examples --seed <n>` 再生；seed 只改检修完成比例与特护参数数值，各项计数不变）。预期计数与验证要点见 `examples/README.md` 对照表（仅开发库含，发布包不含）。

1. 出今天的设备日报，早会要用，值班是乙班张工，附件是今天的巡检、通知单、工单、作业票和隐患汇总。　　**附件：** `examples/sample-daily-source-2026-09-21.xlsx`
2. 今天只有巡检数据，工单和检修进度还没汇总，先出一份日报，没有的部分照实写没提供。　　**附件：** `examples/sample-inspection-only.xlsx`
3. 这是 SAP 导出的通知单和订单清单，列名是功能位置、订单、系统状态那种，TECO 的算不算闭环，直接出日报。　　**附件：** `examples/sample-sap-export.xlsx`
4. 把巡检汇总、缺陷登记、工单跟踪、泄漏点、隐患五个技能跑出来的 JSON 合成一份常减压车间的设备日报。　　**附件：** `examples/upstream/status.json + examples/upstream/orders.json + examples/upstream/defects.json + examples/upstream/leaks.json + examples/upstream/hazard.json`
5. 检修进度表里完成比例填得乱七八糟，有 150% 有负数还有"快好了"，这样也能出日报吗，别给我算成 0。　　**附件：** `examples/sample-bad-percent.xlsx`
6. 跟昨天对比一下，异常设备、超期工单、超期隐患是多了还是少了，昨天的 daily.json 也给你。　　**附件：** `examples/sample-daily-source-2026-09-21.xlsx`，另附前一日运行本技能得到的 `daily.json`（先跑一遍即可）
7. 巡检表里特护机组那几台是用重要度列标的"A/特护"，日报里能不能单独列一节把振动温度写上。　　**附件：** `examples/sample-daily-source-2026-09-21.xlsx`
8. 隐患台账里等级写的是"B 级"，不是重大/一般，日报里怎么处理，别给我乱映射。　　**附件：** `examples/sample-daily-source-2026-09-21.xlsx`（可把隐患等级改成 B 级验证）

## 平台接入业务系统 MCP 时

> 不上传附件，数据由 MCP 工具获取，演示数据每天按剧本刷新。

M1. 出今天常减压车间的设备日报，缺陷、工单、隐患、作业票都从系统里取，E-1201 抽芯检修今天开了哪些票要写清楚。　　**数据：** MCP 设备资产管理 `get_notifications`（workshop=常减压车间，for_skill=equipment-daily-report）、`get_work_orders`（workshop=常减压车间，for_skill=equipment-daily-report）；HSE管理平台 `get_hazards`（workshop=常减压车间）；作业票系统 `get_permits`（workshop=常减压车间，date=今天）
M2. 今天的巡检汇总也带上，特护机组单独一节，P-2101A 振动的情况要在日报里体现。　　**数据：** 先按 inspection-data-digest 的取数说明调 MCP 点检巡检App `get_inspection_records`（workshop=常减压车间，for_skill=inspection-data-digest）、设备资产管理 `get_equipment_ledger`（workshop=常减压车间，for_skill=inspection-task-dispatch）跑出 status.json；再加上 M1 的四项取数
M3. 加氢车间今天的设备日报，只要本车间的缺陷和工单，别把常减压车间的单子混进来。　　**数据：** MCP 设备资产管理 `get_notifications`、`get_work_orders`（workshop=加氢车间，for_skill=equipment-daily-report，不填 start_date）；HSE管理平台 `get_hazards`（workshop=加氢车间）；作业票系统 `get_permits`（workshop=加氢车间，date=今天）
