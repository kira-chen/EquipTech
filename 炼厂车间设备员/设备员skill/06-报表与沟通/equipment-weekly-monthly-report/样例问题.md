# 设备周报月报 · 样例问题

> 附件均在 `演示case/06-报表与沟通/equipment-weekly-monthly-report/`（可用 `node scripts/make-sample.js --seed <n>` 再生；seed 只改停机/修复时长、备件金额、特护参数数值，各项计数与比率不变）。预期计数与验证要点见 `演示case/06-报表与沟通/equipment-weekly-monthly-report/README.md` 对照表（不进发布包）。

1. 出上周常减压车间的设备周报，完好率、泄漏率、检修计划完成率都算一下，日报 JSON 和周台账都在附件里。　　**附件：** `daily/ + sample-period-source-2026-09-14_2026-09-20.xlsx`
2. 设备台账还没整理出来，先把这周的故障次数和停机时间统计出来，完好率算不了就写算不了，别给我估一个。　　**附件：** `sample-no-ledger.xlsx`
3. 我们厂完好率是按在册台数算的，检修计划完成率还要算上批准顺延的，按我们这张口径表出月报，算不了的指标说清楚。　　**附件：** `sample-period-source-2026-09-14_2026-09-20.xlsx + sample-metrics-rules.xlsx`
4. 这是从 SAP 导出来的技术对象清单、订单清单和通知单清单，列名是功能位置、系统状态、基本结束日期那种，TECO 的单子算不算闭环，直接出周报。　　**附件：** `sample-sap-export.xlsx`
5. 跟上周的周报比一下，哪些指标掉了，上周的 periodic.json 也给你，没有对比基准的指标别按 0 算。　　**附件：** `daily/ + sample-period-source-2026-09-14_2026-09-20.xlsx`，另附上一次运行本技能得到的 `periodic.json`（先跑一遍即可）
6. 我这个月只有日报 JSON，台账还没导，先出个月报，特护机组那一节按日报里的记录汇总。　　**附件：** `daily/`
7. 台账里没有「在用」这一列，只有在册台数，完好率怎么处理，我们要按在用算。　　**附件：** `sample-sap-export.xlsx`（可删除「使用状态」列验证）
8. 检修计划表里写的还是大修、中修、小修，周报要按大检修和日常维修分开算完成率，能自动对上吗。　　**附件：** `sample-period-source-2026-09-14_2026-09-20.xlsx`

## 平台接入业务系统 MCP 时

> 不上传附件，数据由 MCP 工具获取，演示数据每天按剧本刷新。

M1. 出常减压车间近 30 天的设备月报，台账、故障、工单、缺陷都从系统里取，完好率只算本车间的设备。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（workshop=常减压车间）、`get_failure_history`（workshop=常减压车间，start_date=30 天前，for_skill=equipment-weekly-monthly-report）、`get_work_orders`、`get_notifications`（workshop=常减压车间，for_skill=equipment-weekly-monthly-report，不填 start_date）
M2. 加氢车间上周的设备周报，故障和超期工单列清楚，别混进常减压车间的。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（workshop=加氢车间）、`get_failure_history`（workshop=加氢车间，start_date=7 天前，for_skill=equipment-weekly-monthly-report）、`get_work_orders`、`get_notifications`（workshop=加氢车间，for_skill=equipment-weekly-monthly-report）
M3. 常减压车间这个月跟上个月比一下，完好率、工单及时率有没有掉，上个月的也从系统里取，没数据的指标别按 0 比。　　**数据：** 同 M1，上月再取一次（`get_failure_history` 的 start_date=60 天前），先跑出上月 periodic.json 作 `--prev`
