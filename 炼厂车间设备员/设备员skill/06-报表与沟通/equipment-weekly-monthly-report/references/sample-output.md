## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 数据缺口 | 「缺 0X-16、0X-19 两天，指标基于 5 天数据计算，未外推补齐」 | 「全周设备运行平稳」（拿 5 天当 7 天说） |
| 分母缺失 | 「设备完好率本期未计算，台账缺「在用」列」 | 「设备完好率约 95%」「按在册 20 台算完好率」 |
| 需复算 | 「设备完好率按厂内口径需复算，本期未出数」 | 沿用默认算法结果并冠以厂内算法名 |
| 泄漏率 | 「静密封点泄漏率 0.42‰，是否达标以厂内指标为准」 | 「泄漏率达标」 |
| 非计划停工 | 「非计划停工 1 次，是否构成事件按规定另行报送」 | 「发生一般非计划停工事件 1 起」 |
| 指标下降有数据支撑 | 「完好率下降 5 个百分点，台账中 EQ-XXX18、EQ-XXX19 标记为非完好」 | 「完好率下降，维护保养不到位」 |
| 指标下降无原因记录 | 「计划完成率较上周下降，原因待分析」 | 「完成率下降主要因施工队伍组织不力」 |
| 故障频发 | 「P-XXXXB 一周内 3 次故障，累计停机 9 小时，建议列入下周重点跟踪」 | 「P-XXXXB 机封老化严重，需整体更换」（根因诊断） |
| 延期项目 | 「项目4 计划 0X-18、实际 0X-20 完成，延期 2 天」 | 「电气班拖延工期」 |
| 未判定 | 「1 项因缺实际完成日期无法判断是否按期，已单列」 | 直接算作按期或延期 |
| 环比缺一侧 | 「上期该指标未计算，本期无可比基准」 | 按 0 算出一个变化值 |
| 下期 | 「下期重点：跟踪 P-XXXXB 运行状态」 | 「预计下周完好率可回升至 95%」（预测指标） |
