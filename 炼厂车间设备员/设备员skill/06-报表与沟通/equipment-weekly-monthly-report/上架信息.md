# 设备周报月报
**技能名称**：设备周报月报

**技能简介**：把一周或一月的日报 JSON 与台账汇成车间设备周报月报，按常用指标口径算完好率、主要设备完好率、备机完好率、静动密封点泄漏率、分级检修计划完成率、工单及时率、故障停机与非计划停工次数，缺数据不补、口径不一致不硬算。

**技能描述**

面向炼化厂车间（运行部）设备员，用于每周、每月向车间和分厂、公司设备管理部门报送设备周报月报。把区间内的日报 JSON、设备台账、故障记录、检修计划、工单、密封点、停工记录交给技能（支持 SAP PM、EM 导出列名），脚本按统一口径算设备完好率、密封点泄漏率、检修计划完成率、工单及时率、故障停机次数与时长、非计划停工次数，已完成与 TECO 单列为待验收不计闭环，生成十二节报告、指标表和数据缺口说明，分析段由模型按口径撰写。缺哪天日报写明缺哪天，不外推；厂内口径与默认算法不一致又没给参数的指标不出数，标明需复算。不做跨车间排名，不预测下期，不判定非计划停工事件等级。单日日报、会议汇报稿由其他技能处理。

**示例问题**
1. 出上周常减压车间的设备周报，完好率、泄漏率、检修计划完成率都算一下，日报 JSON 和周台账都在附件里。　　**附件：** `examples/daily/ + examples/sample-period-source-2026-09-14_2026-09-20.xlsx`
2. 设备台账还没整理出来，先把这周的故障次数和停机时间统计出来，完好率算不了就写算不了，别给我估一个。　　**附件：** `examples/sample-no-ledger.xlsx`
3. 我们厂完好率是按在册台数算的，检修计划完成率还要算上批准顺延的，按我们这张口径表出月报，算不了的指标说清楚。　　**附件：** `examples/sample-period-source-2026-09-14_2026-09-20.xlsx + examples/sample-metrics-rules.xlsx`
4. 这是从 SAP 导出来的技术对象清单、订单清单和通知单清单，列名是功能位置、系统状态、基本结束日期那种，TECO 的单子算不算闭环，直接出周报。　　**附件：** `examples/sample-sap-export.xlsx`
5. 跟上周的周报比一下，哪些指标掉了，上周的 periodic.json 也给你，没有对比基准的指标别按 0 算。　　**附件：** `examples/daily/ + examples/sample-period-source-2026-09-14_2026-09-20.xlsx`，另附上一次运行本技能得到的 `periodic.json`（先跑一遍即可）
