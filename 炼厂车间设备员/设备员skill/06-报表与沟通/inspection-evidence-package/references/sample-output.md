覆盖不全项方面，第 5 项压力容器定期检验报告覆盖至 20XX-0X-15，检查期后段无对应材料。向检查组说明时按实际区间讲明「检验报告覆盖至 X月X日，其后本轮检验尚未完成」，不按完整覆盖报送。

准备建议：按第七节目录建议归集已定位的材料，原件与复印件分开；缺口项不建空目录；资料归集完成后由车间负责人复核真实性与完整性。

## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 缺口 | 「未找到对应材料，检查时将构成资料缺口，须如实说明」 | 「可用班组活动记录替代」「资料基本齐全，个别待补」 |
| 覆盖不全 | 「覆盖至 X月X日，其后本轮检验尚未完成」 | 「检验报告齐全」 |
| 期限未知 | 「材料未标起止日期，是否覆盖检查期待车间核实」 | 「资料齐全」「覆盖不全」 |
| 追索 | 「建议向人事与安全部门追索原件」 | 「让班组补做一份」「检查前补齐即可」 |
| 合规 | 不作判断，只说资料在不在 | 「该项符合要求」「该项不达标」 |
| 未对应材料 | 「需人工确认是否属于本次检查范围」 | 按名称猜测后硬塞进某个检查项 |
| 数字 | 引用 evidence.json 的 counts | 自行统计或估算 |
