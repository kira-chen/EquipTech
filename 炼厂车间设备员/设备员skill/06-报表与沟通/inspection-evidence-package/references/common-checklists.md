# 常见检查类型的典型检查项与对应资料参考

> **本文是「检查项笼统时用来跟用户确认范围」的参考，不是判定依据。**
> 实际以检查通知/检查表原文为准。本文列的资料名称也不代表车间一定应当有 ——
> 有没有以车间实际为准，**缺了就如实说明，不得照本文补编**。

用法：检查项写得笼统（如「设备管理台账」「基础管理资料」）时，拿本文对应小节的条目去问用户
「是指以下哪几项」，**由用户确认后再比对，不得自行缩小或扩大范围**。

---

## 一、设备专业检查

| 典型检查项 | 通常对应的资料 | 资料类别 |
|---|---|---|
| 设备台账是否建立健全、与现场一致 | 车间设备台账、设备清单 | 设备台账 |
| 日常巡检点检是否按规定执行并有记录 | 巡检记录、点检记录、班检表 | 巡检点检记录 |
| 检修作业是否有完整的检修记录 | 检修记录台账、检修方案、验收单 | 检修与维修记录 |
| 设备缺陷是否登记并闭环整改 | 缺陷登记台账、整改记录 | 缺陷与故障记录 |
| 设备技术档案是否齐全可追溯 | 设备技术档案目录、设备履历 | 设备档案 |
| 备用设备是否按规定盘车维护 | 备用设备维护记录 | 检修与维修记录 |
| 润滑管理是否到位 | 润滑油更换台账、油品分析报告 | （特征词匹配） |
| 转动设备状态监测是否开展 | 振动监测报告、测振记录 | （特征词匹配） |
| 静设备测厚与腐蚀监测是否按计划执行 | 测厚记录、腐蚀监测报告 | 检验检测报告 |
| 设备完好率与运行指标是否统计 | 设备完好率统计表、运行月报 | （按实际命名） |
| 设备设施变更是否履行变更管理（MOC）审批并建台账 | 变更申请审批单、变更台账 | 变更管理（MOC）资料 |
| 特护机组是否逐台建立特护方案并按日巡检 | 特护方案、特护日报、大机组运行记录 | 特护设备（大机组）记录 |
| 润滑管理是否落实五定三过滤 | 润滑五定表、换油台账、油品分析报告 | 润滑管理（五定三过滤）记录 |
| 主要设备是否建立一机一档 | 一机一档目录、设备卡片 | 一机一档 |

## 二、安全生产检查

| 典型检查项 | 通常对应的资料 | 资料类别 |
|---|---|---|
| 设备设施台账是否建立健全 | 设备台账、安全设施台账 | 设备台账 |
| 安全阀等安全附件是否在检验有效期内 | 安全阀校验记录、安全附件台账 | 安全附件与安全设施记录 |
| 可燃有毒气体报警器是否按期校验并完好 | 报警器校验记录、完好率统计 | 安全附件与安全设施记录 |
| 安全联锁是否投用、摘除/旁路是否履行审批、SIS 功能测试是否按期 | 联锁投用台账、联锁旁路审批单、SIS 功能测试记录 | 安全仪表与联锁（SIS）记录 |
| 特殊作业是否办票、双监护是否到位 | 用火作业票（旧称动火票）、受限空间票、高处作业票、吊装票、临时用电票、动土票、断路票、盲板抽堵票 | 作业票（作业许可） |
| 从业人员安全培训是否按计划开展 | 培训记录、考核记录、培训台账 | 培训与资质记录 |
| 特种作业人员是否持证上岗 | 人员资质证书台账、操作证复印件 | 培训与资质记录 |
| 事故应急预案演练是否按计划组织 | 演练方案、演练记录与评估 | 演练与应急记录 |
| 隐患排查治理是否闭环 | 隐患排查台账、整改验收记录 | 隐患排查治理记录 |
| 承包商作业是否纳入管理 | 承包商资质审查、外委施工方案与交底 | （特征词匹配） |

## 三、特种设备监察

> 特种设备资料的法定性最强，缺失影响最直接。**缺了尤其不能拿相近材料充数。**

| 典型检查项 | 通常对应的资料 | 资料类别 |
|---|---|---|
| 特种设备是否办理使用登记 | 使用登记证、使用登记表 | 特种设备管理资料 |
| 压力容器定期检验是否在有效期内 | 特种设备定期检验报告 | 检验检测报告 |
| 压力管道是否按期检验 | 管道定期检验报告、管道档案 | 检验检测报告 |
| 安全附件是否按期校验 | 安全阀校验报告、压力表检定证书 | 安全附件 / 校验检定记录 |
| 作业人员是否持证 | 特种设备作业人员证、复审记录 | 培训与资质记录 |
| 是否建立特种设备台账与技术档案 | 特种设备台账、设备技术档案 | 设备台账 / 设备档案 |
| 年度检验计划是否编制并执行 | 特种设备年度检验计划 | 计划与方案 |
| 维修改造是否履行告知与验收 | 改造告知书、竣工验收资料 | 验收资料 |

## 四、环保检查

| 典型检查项 | 通常对应的资料 | 资料类别 |
|---|---|---|
| 废气排放是否达标、在线监测是否正常 | 在线监测数据、比对监测报告 | 环保监测与治理记录 |
| 废水排放是否受控 | 废水监测记录、排污口台账 | 环保监测与治理记录 |
| 固废危废是否规范贮存转移 | 危废台账、转移联单 | 环保监测与治理记录 |
| 密封点泄漏检测（LDAR）是否按周期开展、泄漏率是否统计 | LDAR 检测报告、密封点台账、泄漏率统计 | 泄漏检测与修复（LDAR）记录 |
| 环保设施是否与主体同步运行 | 环保设施运行记录、停运报备 | 环保监测与治理记录 |
| 噪声治理措施是否落实 | 噪声监测报告 | 环保监测与治理记录 |
| 排污许可证要求是否执行到位 | 排污许可证、执行报告 | （按实际命名） |

## 五、内部审计

| 典型检查项 | 通常对应的资料 | 资料类别 |
|---|---|---|
| 管理制度是否健全、职责是否明确 | 车间管理制度、岗位职责、责任制 | 制度与职责文件 |
| 制度执行是否留痕 | 会议记录、交底记录、检查记录 | 会议与活动记录 |
| 检修费用与计划是否匹配 | 检修计划、检修费用台账 | 计划与方案 |
| 备件领用是否规范、库存是否准确 | 备件出入库台账、盘点记录 | 备件与物资记录 |
| 能耗指标是否统计分析 | 能耗统计表、用能分析报告 | 能耗与计量记录 |
| 外委施工是否履行招标与验收 | 合同、施工方案、竣工验收资料 | 验收资料 |
| 上次审计问题是否整改闭环 | 整改台账、验证记录 | （无对应类别，须人工确认；审计问题整改台账不是隐患排查治理台账） |

## 使用时的三条纪律

1. **本文只用于跟用户确认范围**，确认完仍以检查通知原文为准。
2. **本文列了而车间没有的资料，就是缺口**，如实写「未找到对应材料」，**不得照本文补编，不得建议补做**。
3. **本文没列而检查通知要求的资料，一样要比对**，不得因为本文没提就略过。
