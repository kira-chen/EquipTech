# 迎检资料准备
**技能名称**：迎检资料准备

**技能简介**：按检查通知或检查表逐项从车间台账、记录里找对应的证据材料，列出资料齐全项、缺口项、时间覆盖不全项和归集包目录，缺的如实写未找到，不拿相近材料充数，不建议补做记录。

**技能描述**

面向炼化厂车间（运行部）设备员，用于分厂、公司或外部监管来检查前准备资料。把检查通知或检查表（Word、Excel、文本，PDF 先转文字）和本车间的资料清单交给技能，脚本逐条解析检查项，按 25 类资料词表和位号特征词匹配材料，只认直接命中，泛词不算；给了检查期就判断每份材料时间覆不覆盖。输出八节资料清单、资料清单.xlsx 和 evidence.json：缺材料的检查项醒目列为缺口，覆盖不全的写明实际区间，没有日期的单列期限未知，对不上的材料单列请人工确认，归集包目录按检查项编号组织。不判断检查项达不达标，不建议用其他材料替代，不补录任何记录，末尾保留资料真实性由车间负责的声明。自查表填报和条款对照由其他技能处理。

**示例问题**
1. 下周公司要来设备专业检查，这是检查表，车间的台账资料清单在附件里，帮我把每一项对应的材料找出来，缺什么直说。　　**附件：** `sample-checklist.xlsx + sample-materials.xlsx`
2. 安监处发的安全生产检查通知是文字的，按通知里的六条检查内容把资料对一遍，检查期是三季度。　　**附件：** `sample-notice.md + sample-materials.xlsx`
3. 这次检查要看变更管理、联锁旁路审批、特护机组、润滑五定三过滤、LDAR、一机一档和用火作业票，我们的材料在这份清单里，看看哪些拿得出来。　　**附件：** `sample-checklist-sinopec.xlsx + sample-materials-sinopec.xlsx`
4. 材料才交了一份设备台账，其他的还没整理，先跑一下看差多少，别拿台账去凑别的项。　　**附件：** `sample-checklist.xlsx + sample-materials-sparse.xlsx`
5. 压力容器检验报告只到六月底，检查期是七到九月，这项算齐全还是缺口，清单里怎么写。　　**附件：** `sample-checklist.xlsx + sample-materials.xlsx`
