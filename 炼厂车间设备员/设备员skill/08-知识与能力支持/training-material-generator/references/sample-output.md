## 语言与边界风格要点

| 场景 | 应写 | 不应写 |
|---|---|---|
| 有资料的数值题 | 「答案：……XXX N·m ｜ 出处：XX管理规定.md 第4.1条（第6行）」 | 只写答案不写出处 |
| **无资料的数值考点** | 改为原理概念题，并在「无资料支撑」一节登记 | **「轴承温度不得超过 75℃」这类凭经验的答案** |
| 原理内容 | 「离心泵靠叶轮旋转……　*（通用原理）*」 | 把通用原理写成本厂规定 |
| 干扰项 | 「由个人习惯决定」「与设备状态无关」 | **把 75℃ 改成 85℃ 当干扰项** |
| 题量不够 | 「只能出 12 道，缺口请补资料」 | 编 8 道数值题补到 20 |
| 学时未定 | 「—」「未指定（学时待排）」 | 按 0 或随手写 2 学时 |
| 操作步骤 | 「以厂内正式规程为准，本材料不生成」 | 自己写一套开车步骤 |

**编的数值比没有数值更危险**：没有数值，员工会去查规程；有一个错数值，员工会背下来照着用。
