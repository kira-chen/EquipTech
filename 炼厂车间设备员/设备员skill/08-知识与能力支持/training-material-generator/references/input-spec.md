# 输入规格：培训材料与考题生成

## 一、培训对象（`--audience`，必填）

| 归一值 | 可识别的写法 | 判定顺序 |
|---|---|---|
| 三级安全教育 | 三级安全教育、三级教育、厂级、车间级、班组级 | 1（先判） |
| 四新 | 四新、新工艺、新技术、新设备、新材料 | 2（含「新」字，先于新员工） |
| 复岗 | 复岗、返岗、复工、离岗…返回/回岗 | 3 |
| 新员工 | 新员工、新人、新进、入厂、新上岗、新入职 | 4 |
| 在岗 | 在岗、在职、复训、岗位提升 | 5 |
| 转岗 | 转岗、换岗、调岗 | 6 |

**不在表内的写法直接报错**，不猜、不按默认值归类。培训对象决定内容深度，猜错等于整套材料的深度都错。三级安全教育只生成车间级、班组级的设备专业部分，厂级由公司安全环保部门归口。

## 二、设备范围（`--scope` 与 `--ledger` 至少一项）

### `--scope`：设备类型或主题，逗号分隔

按设备类型识别（顺序：电机 → 压缩机 → 离心泵 → 换热器 → 塔器容器 → 阀门 → 管道 → 通用）。识别不出设备类型的条目作为「用户指定主题」并入提纲最后一个模块。

命中规程类拦截规则的主题（如「编写安全操作规程」「开车步骤」）被剔除并 warning。**全部主题被剔除时报错**，不空转出一份没有内容的材料。

### `--ledger`：设备清单 `.xlsx` / 同结构 CSV 目录

sheet 名匹配：去空白与「表」字后包含匹配，「设备台账」「设备清单」「台账」「技术对象」「功能位置」「设备」「清单」「Sheet1」均可识别（SAP PM IH08 技术对象清单 / 功能位置清单、EM 导出都能命中）；都不命中时取第一个工作表并 warning。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 为空的行跳过并 warning（含 sheet 名与行号） |
| 设备名称 | 否 | 设备类型列缺失时用于推断类型 |
| 设备类型 | 否 | 缺失时按设备名称推断 |
| 区域 | 否 | |

列名别名：

别名表 = 局部别名（优先）+ 共享 `SYSTEM_ALIASES`（SAP PM/EM 导出列名，见顶层《中石化口径对照.md》第二节）：

| 标准列名 | 可识别的写法 |
|---|---|
| 位号 | 位号、设备位号、TAG、tag、功能位置、功能位置编号、技术标识、技术对象、位号编码（**SAP 8 位「设备」「设备编号」不作位号**） |
| 设备名称 | 设备名称、名称、设备描述、技术对象描述、功能位置描述 |
| 设备类型 | 设备类型、类型、设备类别、对象类型、设备分类、专业类别、设备品种 |
| 区域 | 区域、装置区、位置、装置、工厂区段、单元、装置名称、生产单元 |

表头行识别：取前 10 行中命中必需列最多的一行，因此首行是标题、第三行才是表头的导出表也能读。

## 三、技术资料（`--docs`，可选但强烈建议）

支持 `.md` / `.txt` / `.csv`（按行）与 `.docx`（经 `lib/docx-lite.js` 抽取段落与表格）。可给多个路径（逗号分隔），也可给目录（读目录下受支持的文件，不递归）。**PDF 不读**：先用平台 pdf 技能转为 txt/docx 再传入，扫描件需 OCR；扩展名不支持的文件 warning 跳过，不中断。

**不提供资料时只生成通用原理类内容，不产出任何带数值的考题**，并 warning 告知该限制。

### 条款抽取口径

| 输入行 | 处理 |
|---|---|
| `4.2 联轴器对中偏差不大于 0.08mm` | 条款，`clause = "4.2"`，`numeric = true` |
| `第4.2条 ……` | 同上 |
| `点检记录应如实填写` | 条款，`clause = null`，`numeric = false` |
| `# 4 离心泵管理要求` | markdown 标题 → 记作后续条款的 `topicHint`，不单独成条款 |
| `> 本文件为样例……` | **引用块跳过**，说明与免责声明不是条款 |
| 表格分隔行 `\|---\|---\|` | 跳过 |
| 长度 < 4 字的行 | 跳过 |
| 命中 F1~F5 规程类规则的条款 | **排除**并计入 `blockedTopics`，warning 说明 |

每条条款都带出处 `{file, loc, clause}`：`loc` 对 md/txt 是「第N行」，对 docx 是「第N段」或「表N第M行」。

### 数值识别口径

含以下任一形式即判为「含技术数值」：

- **带单位**：N·m、kN、MPa、kPa、bar、mm、mm/s、μm、℃、K/h、kW、kV、V、A、Hz、rpm、r/min、ppm、mg/L、%、倍、级 等
- **周期**：`每 500 小时`、`3 个月一次`、`12 个月`
- **区间与比较**：`0.05~0.10`、`不低于 0.3`、`不大于 75`、`≥ 4.5`

**不判为技术数值**：条款号（`第3.2条`）、编号（`A-1`）、年份（`2026 年`）、题号与选项号。

## 四、其他参数

| 参数 | 必需 | 取值 | 缺失时 |
|---|---|---|---|
| `--duration` | 否 | 正数（学时） | 各模块学时为 `null`，报表显示「—」，**不按 0 也不臆造** |
| `--questions` | 否 | 正整数 | 有学时按学时推，无学时取 20 与素材上限的较小值 |
| `--types` | 否 | 单选 / 多选 / 判断 / 简答，逗号分隔 | 四种全用 |
| `--difficulty` | 否 | 基础 / 中等 / 较难 | 按培训对象的默认难度（新员工、三级安全教育=基础；在岗、转岗、复岗、四新=中等） |
| `--workshop` | 否 | 车间名 | 材料抬头不显示车间 |
| `--no-negative-judge` | 否 | 标志位 | 默认判断题交替出肯定式 / 否定式；加此标志只出肯定式 |
| `--out` | 否 | 输出目录 | 默认系统临时目录 `<os.tmpdir()>/tmg-out`，建议始终传 |

`--types` 中无法识别的题型被忽略并 warning；**全部无法识别时报错**。

## 五、会被跳过的行

- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning）
- 位号为空的行（warning，含行号）
- 资料中的引用块、表格分隔行、markdown 标题、过短行
- 资料中命中规程类拦截规则的条款（warning，计入 `blockedTopics`）

## 六、资料覆盖度评估

`counts` 中给出四个口径，用来判断这次材料的「含金量」：

| 字段 | 含义 |
|---|---|
| `clausesTotal` | 资料中抽到的条款总数 |
| `clausesUsable` | 排除规程类后可用的条款数 |
| `clausesNumeric` | 其中含数值的条款数 —— **这就是数值类考题的天花板** |
| `questionsAvailable` | 三类素材之和，即可出题上限 |

`clausesNumeric` 为 0 时，产出中不会有任何数值题，`noSourceTopics` 会逐类设备登记「无资料支撑」。
