# 培训材料与考题生成（training-material-generator）

面向中石化体系炼化厂车间（运行部）设备员，按本车间实际设备生成培训提纲、讲义要点与考题的**设备专业建议稿**，由车间工艺/安全审核后纳入培训计划。**所有技术数值类考题必须基于所提供资料并标注出处；无资料支撑时只出原理概念类题目，不得编造数值答案；内置通用原理条目（source: builtin）须经车间技术人员审核。**

## 适用条件
- 用户说"做新员工培训材料 / 复岗培训 / 四新培训 / 三级安全教育车间级班组级内容 / 出几道设备题 / 培训讲义 / 考核题库 / 这个月培训讲什么"，并提供车间设备清单或技术资料。
- 产出类型：培训提纲、讲义要点、考题（单选、多选、判断、简答）、实操考核项。
- 车间设备员可做的部分：设备专业培训建议稿、按厂内规程出带出处的题。**不做**（由 XX 归口）：厂级安全教育内容由公司安全环保部门归口；技能鉴定与上岗授权由公司人力资源/安全部门归口；培训计划的审批与考核结论由车间主任/分厂归口。
- 不适用：替代正式培训教材与国家技能鉴定题库；生成无出处的技术数值考题；日常知识问答（用 equipment-knowledge-qa）；操作工异常指引卡（用 operator-anomaly-guide）。

## 前提条件
- 输入：车间设备清单（`.xlsx`/`.csv`，支持 SAP PM 技术对象导出列名：功能位置、设备描述、对象类型、工厂区段）或技术资料（规程、说明书，txt/md/docx）。**PDF 统一前置步骤：PDF 先用平台 pdf 技能转为 txt/docx 再传入，脚本不读 PDF；扫描件需 OCR。** **无任何资料时只能生成通用原理类内容，须明确告知用户该限制。**
- 必填信息：培训对象（新员工 / 在岗 / 转岗 / 复岗 / 四新 / 三级安全教育）、培训主题或设备范围、培训时长或题目数量。可选：培训重点要求、往期培训记录、考核标准。
- 环境：可执行 Node.js ≥ 18，脚本仅用内置模块，无需 npm 安装。**若环境无法执行 node（无 Bash 工具或 `node --version` 失败），明确告知用户并终止，不得基于文字手工成文或自行判定（硬约束 2）。**

## 数据获取（MCP）

平台接入了业务系统 MCP 服务时，按下表调用工具取数，不再请用户上传导出文件；未接入时按操作步骤请用户提供系统导出文件。工具全部只读，不在业务系统里创建或修改任何单据。

| 服务 | 工具 | 参数 | 交给脚本 |
|---|---|---|---|
| 设备资产管理 | `get_equipment_ledger` | `workshop`：车间 | `--ledger` |

取数后：

1. 工具返回下载链接（60 分钟内有效，过期重新调用）。csv 按原文件名放进新建的空目录，不改文件名，不与其他技能的文件混放；把目录作为“交给脚本”一列的参数值。

厂内设备管理规定、说明书等资料来自平台知识库，放进一个目录作 `--docs`。

## 操作步骤
1. **确认培训要素** —— 培训对象、主题与设备范围、题量或学时、难度要求。**培训对象决定深度：新员工侧重认识与安全；在岗侧重故障处理与标准；转岗侧重差异点；复岗侧重离岗期间的变化点与设备当前状态；四新（新工艺/新技术/新设备/新材料）侧重差异与投用前条件确认；三级安全教育只做车间级、班组级的设备专业部分，厂级由公司安全环保部门归口。**
2. **运行脚本** —— 技能目录以平台实际加载路径为准（Windows 路径加双引号）：
   ```bash
   node "<技能目录绝对路径>/scripts/training.js" --scope "<设备范围或主题>" --audience <新员工|在岗|转岗|复岗|四新|三级安全教育> --docs "<资料路径>" --out "<工作目录>/培训材料"
   ```
   可选：`--ledger "<设备清单xlsx>"`（与 `--scope` 同时给时按 scope 过滤清单，只保留 scope 内的设备类型或位号，warning 写明剔除台数）、`--duration <培训学时>`、`--questions <题目数量>`、`--types "<单选,多选,判断,简答>"`、`--difficulty <基础|中等|较难>`、`--workshop "<车间名>"`、`--no-negative-judge`（判断题只出肯定式）。
   读取末行 JSON 摘要（同时写入 `<out>/summary.json`）：`ok` 必须为 `true`，`ok:false` 时把 `error` 告知用户并终止；`warnings` 非空时逐条告知用户（资料无法解析/设备清单为空/题量与资料覆盖不匹配/否定式改写退回肯定式等）。脚本用法详见 `scripts/README.md`。
   - 资料不足以支撑要求的题量：warning 说明可出题数，**绝不用编造的数值题凑数**。
   - 数值题题干里的规定值由脚本遮成 `＿＿`：区间两端（含「0.05-0.10mm」）、负数连同负号（「低于-10℃」）都遮，字母后的「-」按位号保留（P-2101A），「数字-数字」编号尾段（E-1201-3 次、M20-8.8级）不遮。成稿时不得把遮住的数值写回题干。
   - 判断题：肯定式答案「正确」；否定式由脚本在原句加否定词生成（**不改任何数值**，改写前后数字序列必须一致），答案「错误」并在答案表给出正确表述与出处。
3. **读取 training.json** —— 从 `<输出目录>/training.json` 获取：`outline`（培训提纲与学时分配）、`keyPoints`（讲义要点及资料出处，内置原理条目 `origin: builtin`）、`questions`（考题：题干、选项、答案、出处、考点、`negated` 标记）、`practicalItems`（实操考核项）、`noSourceTopics`（无资料支撑的主题）、`counts`（含 `questionsBuiltinPrinciple`、`questionsJudgeTrue`、`questionsJudgeNegated`）。
4. **生成材料** —— 按 `assets/templates/training-template.md` 成文，输出三份：`培训提纲.md`、`讲义要点.md`、`考题与答案.md`。**每道涉及具体数值、标准、周期的题目，答案后必须标注出处（文件与位置）；无出处的一律改为原理概念题。原理类内容标注"通用原理"，内置条目点名需技术人员审核。**
5. **交付前自检** —— 对照 `references/checklist.md` 逐项检查，重点核对：**每道数值类题目是否有出处、否定式判断题是否改动了数值、是否混入了编造的标准值**。通过后交付三份材料与 `training.json`。**必须保留声明行："仅供参考，不替代操作规程与检修规程；设备专业建议稿，由车间工艺/安全审核后使用。本材料由脚本汇总、模型成文，其中内置通用原理条目（source: builtin）须经车间技术人员审核后方可使用；技能鉴定请以国家或企业正式题库为准。"**

## 预期结果
- `培训提纲.md`：五节（一、培训目标；二、模块与学时分配；三、各模块内容；四、实操考核项；五、不在本提纲范围内的内容）+ 附：生成提示。
- `讲义要点.md`：五节（一、资料来源；二、通用原理要点；三、厂内规定要点；四、无资料支撑的内容；五、讲解提示）。
- `考题与答案.md`：五节（一、题量构成；二、考题；三、答案与出处；四、无资料支撑、未出数值题的主题；五、审核提示）。
- `training.json`：结构化内容与出处；`summary.json`：脚本末行摘要。
- 交付时向用户说明：提纲覆盖模块、讲义要点数、考题数（按题型、有无出处、判断题肯定/否定式分类）、内置原理条目数、无资料支撑的主题、脚本 warnings（如有）。

## 不适用范围
- 不生成无出处的技术数值类考题；否定式判断题不改任何数值。
- 不替代国家职业技能鉴定题库与正式培训教材。
- 不做培训效果评估与人员能力认定、不做上岗授权。
- 不生成安全操作规程、开停车步骤、应急预案、作业许可办理流程类内容（以厂内正式规程与《中国石化作业许可管理规定》为准）。
- 不生成厂级安全教育内容（由公司安全环保部门归口）。
