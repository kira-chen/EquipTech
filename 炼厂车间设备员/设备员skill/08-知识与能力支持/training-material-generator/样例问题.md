# 培训材料与考题生成 · 样例问题

> 附件均在 `演示case/08-知识与能力支持/training-material-generator/`（**可再生数据**，`node scripts/make-sample.js --seed <n>` 重新生成，默认 seed=1）。规程样例中的力矩、温度、周期等数值与 SAP 样例的工厂区段随 seed 变化，但每题的预期结论——含数值条款数（8 条）、可出数值题数、设备类型数、SAP 样例 5 台——不变；预期计数见 `演示case/08-知识与能力支持/training-material-generator/README.md` 对照表（不进发布包）。PDF 规程一律先用平台 pdf 技能转为 txt/docx 再作 `--docs` 传入，脚本不读 PDF。

1. 给车间新员工做一套 8 学时的设备培训材料，设备清单在附件里，暂时没有规程。　　**附件：** `sample-equipment-list.xlsx`（`--audience 新员工 --duration 8`，预期四模块按权重分摊学时；无资料，考题全部为原理概念题，一道数值题都没有，warning 告知该限制）
2. 按我们车间的动设备管理规定给在岗人员出 12 道题，数值题要标清楚出自哪一条。　　**附件：** `sample-equipment-list.xlsx + sample-spec.md`（`--audience 在岗 --questions 12`，预期 8 道数值题带「文件 第X.X条（第N行）」出处，题干数值遮成 ＿＿）
3. 出 200 道题。　　**附件：** `sample-equipment-list.xlsx + sample-spec.md`（同题 2，把 `--questions 12` 换成 `--questions 200`，预期 warning「只能出 N 道（数值类/定性规定类/原理概念类）」，md 用【注意】提示缺口，不用编造的数值题凑数）
4. 资料里没写任何数值，还能出考核题吗。　　**附件：** `sample-equipment-list.xlsx + sample-spec-no-number.md`（`--audience 在岗`，预期 `clausesNumeric = 0`，只出定性规定题与原理题，`noSourceTopics` 登记无资料支撑）
5. 我把整本资料给你了，里面有开停车步骤。　　**附件：** `sample-equipment-list.xlsx + sample-spec-with-procedure.md`（`--audience 在岗`，预期开停车步骤条款被 F3 剔除并 warning，泵的数值条款照常可用）
6. 清单是 SAP 里 IH08 导出来的，列名是功能位置、设备描述、对象类型，能直接用吗。　　**附件：** `sample-sap-export.xlsx`（`--audience 新员工`，预期 5 台可读，位号取功能位置，8 位设备流水号不出现在提纲）
7. 休了半年病假回来的员工做复岗培训。　　**附件：** `sample-equipment-list.xlsx`（`--audience 复岗`，预期首模块「离岗期间的变化点」，含变更管理台账、未闭环缺陷隐患、修订的规程与系统）
8. 新上了一台空压机，投用前给岗位做四新培训。　　**附件：** `sample-spec.md`（`--scope 压缩机 --audience 新设备投用`，预期归四新而非新员工，提纲含「新设备 / 新材料的结构与特点」与「投用前条件确认（PSSR）」）
9. 新员工三级安全教育，车间级和班组级的设备部分帮我出一下，厂级的也一起出吧。　　**附件：** `sample-equipment-list.xlsx`（`--audience 班组级安全教育`，预期只生成车间级、班组级模块，提纲声明「厂级安全教育内容由公司安全环保部门归口，本材料不生成」）
10. 判断题别全是"正确"的，出几道错的，但别改规程里的数。　　**附件：** `sample-spec.md`（`--audience 在岗 --types 判断`，预期肯定式 / 否定式交替，否定式答案「错误」并给正确表述与出处，数字序列与原文一致；`--no-negative-judge` 可关闭）
11. 转岗过来的人，先讲跟原岗位不一样的地方。　　**附件：** `sample-equipment-list.xlsx`（`--audience 转岗`，预期首模块「与原岗位的差异点」，第二模块「本车间特有设备」列位号）
12. 清单里没填设备类型列，「循环水泵电机」算泵还是电机。　　**附件：** `sample-no-type.xlsx`（预期按名称推断为电机，类型识别顺序与 operator-anomaly-guide 同源）

## 平台接入业务系统 MCP 时

不上传附件，设备清单由 MCP 工具获取（演示数据每天按剧本刷新），车间设备管理规定等资料来自平台知识库，下载后放进一个目录作 `--docs`（演示知识库含常减压车间动设备管理规定.md、常减压车间静设备管理规定.docx、无数值说明.txt 与一份压缩机说明书 PDF）。

M1. 给常减压车间在岗人员做 4 学时的设备培训，按车间动设备、静设备管理规定出题，数值题标清出处。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（workshop=常减压车间）→ `--ledger`；平台知识库资料目录 → `--docs`；`--audience 在岗 --workshop 常减压车间 --duration 4`（预期：9 道数值题全部带出处、题干数值遮成 ＿＿；「4.6 进料泵切换步骤」被 F3 剔除；压缩机说明书 PDF 逐个 warning 提示先转 txt/docx；电机、阀门、管道等无数值条款的类型登记为无资料支撑）
M2. 加氢车间来了几个新员工，按车间台账做 8 学时的设备培训，规程还没给你。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（workshop=加氢车间）→ `--ledger`，不给 `--docs`；`--audience 新员工 --workshop 加氢车间 --duration 8`（预期：考题全部为原理概念题，一道数值题都没有；提纲「本车间设备认识」按类型列位号，R-5101 加氢精制反应器归塔器容器）
M3. 常减压车间有人休完长假回来，做一套复岗培训。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（workshop=常减压车间）→ `--ledger`；平台知识库资料目录 → `--docs`；`--audience 复岗 --workshop 常减压车间`（预期：首模块「离岗期间的变化点」，含变更管理台账、期间修订的规程与系统；数值题均带出处）
