# 能效计算口径与表述规范（单机口径）

## 〇、口径边界：本技能 vs energy-weekly-report

| | 本技能 equipment-energy-analysis | energy-weekly-report（skill-pack/【炼化】能耗周报与对标/） |
|---|---|---|
| 口径 | **单台设备的能效**（泵效率、炉热效率、电机效率…） | **装置综合能耗**（工艺口径，吨原料综合能耗、单位能耗指标） |
| 对象 | 一台泵、一台风机、一台加热炉 | 一套常减压、一套加氢装置 |
| 基准 | 该设备的设计效率，或同类设备横向对比 | 装置设计值、历史同期、行业对标值 |
| 谁在用 | 车间设备员，看设备本身状态 | 工艺 / 能源管理，看装置运行水平 |
| 边界 | **不出装置级综合能耗数字，也不做装置对标** | 不算单机效率 |

用户问「我们装置这周能耗怎么样」「综合能耗降下来没有」→ 用 `energy-weekly-report`。
用户问「这台泵费不费电」「哪台机组能效偏低」→ 用本技能。

报告头尾两处保留边界行：**「本报告为单台设备的能效口径分析，不算装置综合能耗、不算单位产品能耗（两者归能源管理部门/工艺口径）；车间设备员只做单机能效对标与异常提示，能耗指标考核归能源管理部门；装置级能耗与对标请使用 energy-weekly-report 技能。」**

报告末尾另固定写入通用声明行：「本材料由脚本汇总、模型成文，仅供设备员复核参考，不替代审批、定性、验收与签字；厂内制度与系统数据为准。」

## 一、各设备类型的计算口径

### 离心泵
```
有效功率 Pe (kW) = ρ(kg/m³) × g × Q(m³/h) × H(m) / 3 600 000
效率 η = Pe / 轴功率
```
必需：流量、扬程、介质密度、轴功率（或电机功率 + 电机效率）。
**介质密度必须用实际介质的密度**，不得按水的 1000 kg/m³ 代替 —— 渣油、柴油、液氨差别很大，按水算出来的效率是假的。

### 风机
```
有效功率 Pe (kW) = Q(m³/h) × p全压(Pa) / 3 600 000
效率 η = Pe / 轴功率
```
风量与全压须为同一工况点的数值。

### 压缩机
```
等温功率 Pis (kW) = Q入口(m³/h) × p1(Pa) × ln(p2/p1) / 3 600 000
等温效率 η = Pis / 轴功率
```
压力用**绝压**。出口压力不大于进口压力时压比无意义，归入数据不足。

**多变效率口径（`--polytropic`）**：
```
(n−1)/n = ln(T2/T1) / ln(p2/p1)      T 取绝对温度（℃ + 273.15），p 取绝压
多变效率 η_p = [(k−1)/k] ÷ [(n−1)/n]
```
必需：进口压力、出口压力、进口温度、出口温度、绝热指数 k。缺任一项 → 该台归入数据不足，**不按典型 k=1.4 代替，也不退回等温口径顶替**；出口温度不高于进口温度时多变指数无法求取，同样归数据不足。多变效率不依赖轴功率。JSON `efficiencyKind` 记录 `isothermal` / `polytropic`，md 抬头与「【注意】」行标明口径，两种口径的结果不得混排对比。

### 电机
```
效率 η = 输出功率 / 输入功率
```
若只有负载率而无实测输出功率，需查该型号的效率-负载率曲线，**曲线属于设备资料，不得凭经验假定**；没有曲线时归入数据不足。

### 加热炉
```
热效率 η = 有效热负荷 / (燃料量 × 低位发热值)
```
两侧单位口径须一致。正平衡法需要进出口温度与流量算有效热负荷，反平衡法需要排烟温度与烟气组分；**两种方法不能混算**，输入给的是哪一侧就按哪一侧。

### 换热器
```
传热系数 K = 换热量 Q / (换热面积 A × 对数平均温差 ΔTm)
```
换热器给 K 值，**不折算成 0~100% 的效率**。K 的高低需与该换热器的设计 K 值或投用初期的 K 值比，脏污系数变化是常见方向，但**不得据此断言已结垢**。

## 二、对标规则

| 基准来源 | 何时采用 | 判定 |
|---|---|---|
| 设计效率 | 设计参数表里有该设备的设计效率 | 效率 < 设计效率 × `--threshold`（默认 0.9）→ 能效偏低 |
| 组内中位数 | 无设计效率，但同组可算设备 ≥2 台 | 效率 < 组内中位数 × `--threshold` → 能效偏低 |
| 无 | 既无设计效率，组内也无同类设备 | `notComparable`，**不判偏低** |
| — | 统计期内运行时间为 0 h | `notRunning`，**不判正常或偏低**，不参与组内对比 |

**绝不做的事**：拿「离心泵一般 70~80%」「加热炉一般 90%」这类通用典型效率值当基准。这些数字随比转速、流量等级、介质、炉型变化极大，用它判定单台设备偏低，结论站不住，还会误导检修安排。无基准就直说无基准。

## 三、四类不给结论的情况

### 1. 计算参数不全（最关键）
缺任何一个必需参数 → 效率 `null`（显示 —），归入 `insufficientData`，列出缺哪些参数。
**绝不用典型值代替缺失参数**：不按水的密度算油泵，不按 0.95 假定电机效率，不按额定功率代替实测轴功率。用假参数算出来的效率看着像个数，实际是编的。

### 2. 结果超出物理合理范围
算得效率 > 100% 或 ≤ 0 → 归入 `implausible`，**原样保留不截断**，warning 提示核实数据。
效率超 100% 只可能是数据问题：流量计单位是 t/h 被当成 m³/h、功率表读的是电流、扬程用的是压力表读数没折算、取数时点不一致。
**不得把 130% 截断成 100% 后当作「效率很高」呈现** —— 那会把一个数据质量问题伪装成设备状态结论。

### 3. 无可比基准
既无设计效率又无同类设备 → 不判偏低，报告里写明「无可比基准，未做偏低判定」。

### 4. 统计期内未运行
运行时间为 0 h（或 ≤ 0）的设备，统计期内没有运行，「近 30 天均值」里的流量、功率不代表运行工况，算出的效率不能说明能效好坏。效率照列供核对，`lowJudgement = notRunning`，判定列标「统计期内未运行（不判定）」，**不判正常也不判偏低**，不进能效偏低清单，也不参与组内排名与中位数，warning 提示核实是否备用或停运。运行时间列为空的不按 0 h 处理，照常判定。

## 四、能效偏低的表述规范

**只提示需核实的方向，不断言原因。** 脚本输出的是 `checkPoints`，不是 `cause`。

| 需核实的方向 | 怎么写 | 不能写 |
|---|---|---|
| 运行工况偏离 | 「需核实运行点是否偏离设计点（流量/扬程/负荷率）」 | 「因为小流量运行导致效率低」 |
| 过流部件磨损 | 「需检查叶轮、口环、机封的磨损与间隙」 | 「叶轮已磨损，需更换」 |
| 管网阻力变化 | 「需核实管网阻力是否变化（阀门开度、过滤器堵塞）」 | 「管线堵了」 |
| 仪表取数 | 「需核实流量计、功率表的校验状态」 | 「仪表不准」 |
| 换热器 K 值下降 | 「K 值低于投用初期，需核实污垢与流程分配」 | 「已结垢，需清洗」 |

确认原因需要现场检查、工况核对与仪表校验，报告只负责把范围缩小，不下结论。

## 五、费用差额的表述规范

```
功率差额 = 实测轴功率 − 有效功率 / 基准效率
费用差额 = 功率差额 × 运行时间 × 单价
```

保留声明行：**「费用差额为按当前运行条件、以设计效率或组内中位数为参照的静态测算，未考虑工况变化、负荷率、检修投入与工艺约束，不等于可实现的节能收益。」**

| 应写 | 不应写 |
|---|---|
| 「按当前运行条件测算，年费用差额约 X 万元」 | 「改造后每年可节约 X 万元」 |
| 「该差额是与基准效率的静态比较」 | 「节能潜力 X 万元」 |
| 「是否可实现需结合工况与技术方案评估」 | 「投资回收期约 N 年」 |

缺运行时间或缺单价时不测算，**不用典型运行小时、不按典型电价代替**。

### 电价口径（分时电价）

中石化炼化厂多执行分时电价（峰/平/谷），单价由厂内能源/财务口径提供，**脚本不内置任何电价数值**：

| 单价表写法 | 脚本行为 |
|---|---|
| 一行「电」单价 | 按单一电价测算，warning 提示"厂内执行分时电价时请改提供加权平均电价（时段列填「加权」）或按时段分列运行小时" |
| 峰/平/谷多行，无加权行 | **不做费用差额测算**，warning 说明"脚本不自行取峰、平或谷电价" |
| 峰/平/谷多行 + 一行时段为「加权/平均/综合」 | 只认加权行，`priceKind` 标「分时电价加权平均」 |
| 非电介质（蒸汽等） | 按该介质单价测算并标注 |

报告 5.3 节下方固定写入「【注意】电价说明：……」提示行。

## 六、分析段写法（energy.md 第六节，250~400 字）

结构：总体情况 → 能效偏低设备与可能方向 → 同类设备差异 → 数据不足与异常值 → 建议核实事项。

- 所有效率数值、偏差、排名、费用差额**一律引用 `energy.json`**，不得自行计算或估算。
- 能效偏低只写需核实的方向，不断言原因，不做故障诊断。
- 无设计参数时明确说明「本次只做同类设备横向对比」，不得暗示与某个行业水平比较。
- 异常值单独说明是数据问题而非设备结论。
- 建议限于：核对运行工况与负荷率、安排性能复测、检查过流部件、核实仪表校验状态、补齐缺失参数后重算。
- **不得出具**：节能改造方案、技术经济评价、投资回收期、装置级综合能耗结论。
