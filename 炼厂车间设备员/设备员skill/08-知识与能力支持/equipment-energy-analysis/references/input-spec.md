# 输入规格：设备能效分析与对标

## 运行数据（必需）

sheet 名匹配「运行数据」「运行参数」「能效数据」「运行记录」。**一行一台设备**（一个统计区间内的代表工况或平均工况）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 为空的行跳过并 warning；重复位号原样保留不合并并 warning |
| 设备名称 | 否 | |
| 设备类型 | 否 | 填了则按行内类型算；无法识别时 warning 并回退 `--equip-type` |
| 分组 | 否 | 同类设备横向对比的分组；缺省按设备类型分组 |
| 运行时间 | 否 | 小时；仅用于费用差额测算，缺失时不测算、**不用典型运行小时代替** |

其余列按设备类型取用，见下表。

## 各设备类型必需参数清单（最关键）

**缺任何一项，该设备效率输出 `null` 并归入 `insufficientData`，脚本绝不用典型值代替缺失参数。**

| 设备类型 | 计算口径 | 必需参数 | 单位 |
|---|---|---|---|
| 离心泵 | 有效功率 Pe = ρgQH/3600000；效率 η = Pe / 轴功率 | 流量 Q、扬程 H、介质密度 ρ、轴功率（或电机功率 + 电机效率） | m³/h、m、kg/m³、kW |
| 风机 | 有效功率 Pe = Q×p/3600000；效率 η = Pe / 轴功率 | 流量（风量）Q、全压 p、轴功率（或电机功率 + 电机效率） | m³/h、Pa、kW |
| 压缩机（默认等温） | 等温功率 Pis = Q×p1×ln(p2/p1)/3600000；效率 η = Pis / 轴功率 | 入口体积流量 Q、进口压力 p1（绝压）、出口压力 p2（绝压）、轴功率（或电机功率 + 电机效率） | m³/h、MPa、MPa、kW |
| 压缩机（`--polytropic` 多变） | (n−1)/n = ln(T2/T1)/ln(p2/p1)；η_p = [(k−1)/k] ÷ [(n−1)/n] | 进口压力、出口压力（绝压）、进口温度、出口温度（℃）、绝热指数 k | MPa、MPa、℃、℃、— |
| 电机 | 效率 η = 输出功率 / 输入功率 | 输出功率、输入功率 | kW、kW |
| 加热炉 | 热效率 η = 有效热负荷 / （燃料量 × 低位发热值） | 有效热负荷、燃料量、低位发热值 | 热量与燃料量口径须一致 |
| 换热器 | 传热系数 K = 换热量 / (换热面积 × 对数平均温差) | 换热量、换热面积、对数平均温差 | kW、m²、K |

### 几点口径说明

- **轴功率取数**：优先直接读「轴功率」列；没有轴功率时用「电机功率 × 电机效率」折算。**只有电机功率而没有电机效率时不折算**（不按典型电机效率 0.93/0.95 代替），该设备归入数据不足。电机效率支持 `0.95` 与 `95` 两种写法。
- **压缩机**：默认等温效率口径，压力须为**绝压**。出口压力不大于进口压力时压比无意义，归入数据不足。加 `--polytropic` 切换为多变效率口径：缺进口温度、出口温度或绝热指数任一项 → 该台数据不足，**不按典型 k=1.4、不退回等温口径顶替**；出口温度不高于进口温度 → 多变指数无法求取，同样数据不足。JSON `efficiencyKind` 记 `isothermal` / `polytropic`。
- **加热炉**：燃料量与低位发热值相乘得燃料总热量，与有效热负荷**单位口径须一致**（例如燃料量 t/h × 低位发热值 MJ/t，有效热负荷 MJ/h）。脚本不做单位换算，只按输入数值相除。
- **换热器**：只给传热系数 K，**不折算成 0~100% 的效率**，因此不套用效率的物理合理范围判定，也不进入能效偏低排名。
- **单位能耗**：泵/风机/压缩机按 轴功率 / 流量（kW/(m³/h)）；加热炉按 燃料量 / 有效热负荷；电机按 输入功率 / 输出功率。任一项缺失或为 0 时为 `null`。

## 设计参数（可选）

sheet 名匹配「设计参数」「铭牌参数」「设计值」；也可用 `--design` 指向单独的 xlsx。

| 列名 | 必需 | 说明 |
|---|---|---|
| 位号 | 是 | 与运行数据按位号配对 |
| 额定流量 / 额定扬程 / 额定功率 | 否 | 参考信息 |
| 设计效率 | 否 | 支持 `0.82` 与 `82` 两种写法；不在 0~100% 范围的按缺设计效率处理并 warning |

**未提供设计参数表时**：脚本只做同类设备横向对比，不做与设计值的偏差分析，**不引用通用典型效率值作为基准**；概览中「与设计值偏差分析」一栏显示「—（未提供设计参数，仅做同类横向对比）」而不是 0。

## 分组（可选）

sheet 名匹配「分组」「对比组」「同类分组」；也可用 `--group` 指向单独的 xlsx。列：位号、分组。未提供时按运行数据里的「分组」列，仍无则按设备类型分组。

## 单价（可选）

sheet 名匹配「单价」「价格」「能源单价」；也可用 `--price` 指向单独的 xlsx。列：能源介质、单价、计价单位、时段（可选：峰/平/谷/加权）。优先取「电」。

| 写法 | 脚本行为 |
|---|---|
| 一行电价 | 按单一电价测算，warning 提示厂内执行分时电价时应提供加权平均电价 |
| 峰/平/谷多行，无「加权/平均/综合」行 | 不测算费用差额，warning「脚本不自行取峰、平或谷电价」 |
| 峰/平/谷多行 + 一行时段为「加权」 | 只认加权行 |

**未提供单价时**：不做费用差额测算，**不按典型电价代替**；脚本不内置任何电价数值。

| 输出功率 / 输入功率 | 输出功率、轴端输出功率 / 输入功率、电输入功率、有功输入 |

## 其他参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--equip-type` | 无（必填） | 离心泵 / 风机 / 压缩机 / 电机 / 加热炉 / 换热器；无法识别时报错 |
| `--threshold` | 0.9 | 能效偏低判定比例：效率低于基准 × 该比例即判偏低；须在 0~1 之间 |
| `--design` `--group` `--price` | 无 | 外部表路径；文件不存在时报错 |
| `--polytropic` | 关 | 压缩机按多变效率口径；对其他设备类型无影响 |
| `--out` | `<os.tmpdir()>/eea-out` | 输出目录，建议始终传 |

## 会被跳过 / 不参与计算的行

| 情况 | 处理 |
|---|---|
| 全空行 | 跳过 |
| 首列以 合计 / 小计 / 总计 开头 | 跳过并 warning |
| 位号为空 | 跳过并 warning |
| 数值无法解析（「未记录」「/」等） | 该项记 `null` 并 warning，**不按 0**；导致参数不全的归入数据不足 |
| 位号重复 | 原样保留不合并并 warning |

## 四类不给结论的情况

| 情况 | 处理 |
|---|---|
| 计算所需参数不全 | 效率 `null`，归入 `insufficientData`，列出缺哪些参数，**不用典型值代替** |
| 算得效率超出 0~100%（或 ≤0） | 归入 `implausible`，**原样保留不截断**，warning 提示核实原始数据的单位、量程、取数时点 |
| 既无设计效率、组内又无同类设备（<2 台可算） | `lowJudgement = notComparable`，不判偏低，**不引用通用典型效率值作为基准** |
| 统计期内运行时间为 0 h | `lowJudgement = notRunning`，效率照列供核对，不判正常或偏低，不参与组内排名与中位数，warning 提示 |
