# 设备专业知识问答
**技能名称**：设备专业知识问答

**技能简介**：车间设备员提设备专业问题时，先分清是原理、本厂规定还是具体数值；有厂内规程就照录原文标出处，没有就只讲通用原理并标注，数值一律指路去查规程，不给记忆中的数。

**技能描述**

面向炼化厂车间（运行部）设备员与新员工，回答设备专业问题。把问题和厂内资料（txt/md/docx，PDF 先转文字）交给技能，脚本先把问题归为原理概念、本厂规定或数值标准三类，再在你指定的资料目录内检索原文。有资料支撑的照录原文并标注文件名和第几段；资料没写的原理问题按通用原理回答，整段标注非本厂规定，不超过三百字且不出现任何数字或单位；涉及力矩、间隙、限值、周期等具体数值的问题一律不作答，只说明该数通常记在哪类文件里；本厂规定类没资料时明确答不了，不用通用做法搪塞。产出带来源标注与声明行，仅供参考，不替代操作规程与检修规程。找文件用技术文件查找技能，当前异常判断用异常分诊技能。

**示例问题**
1. 新来的操作工问我离心泵为什么会汽蚀，帮我按通用原理解释一下，不要带任何具体数值，我讲给他听。　　**附件：** 无（不提供资料也可运行）
2. 附件是我们车间 P-1101A 的检修规程和管理规定，机械密封压盖螺栓的紧固力矩规程里是怎么写的，帮我把原文和出处找出来。　　**附件：** `sample-docs/`（P-1101A机泵检修规程.md、车间设备管理规定.docx 等）
3. 我们车间机泵润滑油统一用什么牌号，是厂里有规定的，帮我从附件资料里查原文，查不到就直说。　　**附件：** `sample-docs/车间设备管理规定.docx`
4. 机械密封是什么原理，压盖螺栓力矩应该上多大？原理部分讲清楚，数值部分你告诉我该查哪份文件就行。　　**附件：** `sample-docs/`
5. 附件里有一份装配图 PDF 和一份培训教材，什么是水锤？资料里有没有写，没写的话你按通用原理说，并告诉我 PDF 要怎么处理才能被检索。　　**附件：** `sample-docs/`（含 P-1101A装配图.pdf、设备基础知识培训教材.md）
