# 设备专业知识问答 · 样例问题

> 附件均在 `sample-docs/`（**可再生样例**，用 `node scripts/make-sample.js --seed <n>` 重新生成；默认 seed=1）。seed 只改厂家、型号、力矩值、周期等表面数值，文件构成（可检索文字资料 3 份、伪 PDF 1 份、SAP 列名台账 1 份）与每题的预期分类结论不变。预期计数与验证要点见 `演示case/08-知识与能力支持/equipment-knowledge-qa/README.md` 对照表（不进发布包）。PDF 一律先用平台 pdf 技能转为 txt/docx 再放进资料目录，脚本不读 PDF。

1. 新来的操作工问我离心泵为什么会汽蚀，帮我按通用原理解释一下，不要带任何具体数值。　　**附件：** 无（`--question "为什么会发生汽蚀"`，预期 principle / G2，通用原理段 ≤300 字且无数字）
2. 附件是我们车间的检修规程与管理规定，机械密封压盖螺栓紧固力矩规程里是怎么写的，把原文和出处找出来。　　**附件：** `sample-docs/`（预期 numeric / N5，照录 `P-1101A机泵检修规程.md` 原文并标第 N 段，仍带"不提供记忆中的数值"声明）
3. 机械密封压盖螺栓上多大力矩？我手头没有资料。　　**附件：** 无（预期 numeric，拦截并指路：《炼化企业设备维护检修规程》对应设备分册回装条款、制造厂随机说明书）
4. 我们车间机泵润滑油统一用什么牌号，厂里是有规定的，从附件里查原文。　　**附件：** `sample-docs/车间设备管理规定.docx`（预期 plant，命中第八条原文带出处）
5. 我们厂机泵备用件是怎么规定的？　　**附件：** 无（预期 plant，明确"未提供厂内资料，无法回答本厂规定"，不用通用做法搪塞）
6. 什么是水锤？附件资料里有没有写。　　**附件：** `sample-docs/`（预期 principle / G1，命中 0 段 → 先说"资料未涉及"再按通用原理作答）
7. 机械密封是什么原理，压盖螺栓力矩应该上多大？　　**附件：** `sample-docs/`（预期 numeric + mixedPrinciple，原理部分与数值部分分节）
8. 附件里有一张装配图 PDF，帮我看看图上标的密封腔尺寸。　　**附件：** `sample-docs/P-1101A装配图.pdf`（预期：PDF 只做文件定位，warning 提示先用平台 pdf 技能转 txt/docx，不得声称读到图上内容）
9. 我们厂设备缺陷分几级、A 级缺陷要报到哪一级？　　**附件：** `sample-docs/车间设备管理规定.docx`（预期 plant，照录第四条 A/B/C 三级与"上报公司设备管理部门"原文）
10. 帮我看看这个。　　**附件：** 任一（预期 undetermined / U1，回问是原理、数值还是本厂规定，不默认放行）
