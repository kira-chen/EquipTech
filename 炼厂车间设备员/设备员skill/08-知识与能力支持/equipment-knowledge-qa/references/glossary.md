# 炼化设备常用术语与缩略语对照

> **本文件只解释术语含义，不含任何数值、限值、周期、公差。** 需要具体取值时一律查厂内规程或设备说明书——见 `qa-rules.md` 第三节。
> 术语解释属**通用原理**，非本厂规定；引用本文件内容作答时须带「通用原理，非本厂规定」标注。

## 一、动设备

| 术语 | 含义 |
|---|---|
| 汽蚀 | 泵入口液体压力降至该温度下饱和蒸汽压以下时局部汽化生成气泡，气泡随液流进入高压区溃灭，冲击致叶轮材料剥落的现象 |
| 汽蚀余量 NPSH | 泵吸入口处液体所具有的、高于饱和蒸汽压的富余能量头；分装置汽蚀余量 NPSHa 与必需汽蚀余量 NPSHr |
| 抽空 | 泵内液体被气体置换，泵失去输送能力，表现为出口压力与流量骤降 |
| 机械密封 | 靠垂直于轴线的动环与静环端面贴合并相对滑动实现密封的装置，泄漏通道短、泄漏量小 |
| 动环 / 静环 | 机械密封的一对摩擦副，动环随轴旋转，静环固定于压盖，两者端面构成密封面 |
| 端面比压 | 机械密封动静环端面单位面积上的接触压力，由弹簧力与介质压力共同形成 |
| 填料密封 | 靠填料函内压紧的填料与轴表面接触实现密封，结构简单、便于现场更换，存在持续微量泄漏 |
| 冲洗方案 Plan | API 标准对机械密封冲洗、急冷、隔离方式的编号体系；各 Plan 号对应一种管路布置（自冲洗、外冲洗、无压隔离、带压隔离等），**具体采用哪个 Plan 号查设备说明书与技术协议** |
| 对中 | 调整驱动机与被驱动机两轴线使其重合的作业，分径向偏差（平行度）与轴向偏差（角度） |
| 联轴器 | 连接主动轴与从动轴传递扭矩的部件，常见膜片式、齿式、弹性柱销式 |
| 叶轮 | 离心泵向液体做功的旋转部件，靠离心力提高液体压能与动能 |
| 口环 / 密封环 | 叶轮与泵壳之间的可更换耐磨环，用于减小高低压腔之间的内泄漏 |
| 平衡盘 / 平衡鼓 | 多级离心泵中用于平衡轴向力的部件 |
| 串轴 | 转子沿轴向的窜动 |
| 轴套 | 套在轴上保护轴表面、承受密封件磨损的可更换件 |
| 干运转 | 泵在无液体或液体不足条件下运行，会迅速损坏机械密封与轴承 |
| 喘振 | 离心压缩机在小流量工况下流量与压力周期性大幅波动的不稳定现象 |
| 防喘振线 | 压缩机性能曲线上区分稳定运行区与喘振区的分界 |
| 盘车 | 停机状态下人工或机械转动转子，用于检查转动灵活性与防止转子弯曲 |
| 顶轴油 | 大型机组启停时在轴瓦与轴颈间建立油膜、减少启动磨损的高压油 |
| 巴氏合金 | 用于滑动轴承的低熔点减磨合金，俗称白合金 |
| 滚动轴承 / 滑动轴承 | 前者靠滚动体传力，后者靠油膜承载 |
| 点检 | 按固定路线、固定项目、固定周期对设备状态进行的定性与定量检查 |

## 二、静设备

| 术语 | 含义 |
|---|---|
| 换热器 | 实现两种介质间热量传递的设备，按结构分管壳式、板式、空冷器等 |
| 管程 / 壳程 | 管壳式换热器中介质走管内的通道为管程，走管子外侧壳体内的通道为壳程 |
| 管束 | 换热管与管板、折流板组成的可抽出组件 |
| 折流板 | 壳程内改变介质流向、提高传热系数并支撑换热管的挡板 |
| 浮头 | 管束一端可自由伸缩的结构，用于消除管壳热膨胀差产生的温差应力 |
| 结垢 | 介质中溶解盐类、悬浮颗粒、腐蚀产物或结焦物在换热面沉积，形成热阻致传热下降 |
| 抽芯 | 将换热器管束从壳体中抽出以便清洗检查的作业 |
| 压力容器 | 盛装气体或液体、承载一定压力的密闭设备，按法规实行设计、制造、使用、检验全过程监管 |
| 安全阀 | 当设备内压力超过设定值时自动开启泄压、压力回落后自动关闭的安全附件 |
| 爆破片 | 一次性泄压装置，达到动作压力时破裂泄放，不可复位 |
| 液位计 | 指示容器内液体高度的仪表，分玻璃板式、磁翻板式、差压式、雷达式等 |
| 塔盘 | 精馏塔内实现气液接触传质的构件，常见浮阀、筛板、泡罩 |
| 填料塔 | 以规整或散堆填料替代塔盘实现气液接触的塔型 |
| 液泛 | 塔内气相上升速度过大致液相无法正常下流、塔内积液并使压降骤增的异常工况 |
| 偏流 | 介质在换热面或填料层中分布不均，部分通道流量偏大 |
| 应力腐蚀开裂 SCC | 材料在拉应力与特定腐蚀介质共同作用下产生的开裂 |
| 氢鼓包 / 氢致开裂 | 湿硫化氢环境中氢原子渗入钢材内部聚集致鼓包或开裂 |
| 冲刷腐蚀 | 高速流体或携带固体颗粒的流体对金属表面的机械冲刷与电化学腐蚀共同作用 |
| 露点腐蚀 | 烟气或工艺气冷却至酸露点以下时酸液凝结造成的腐蚀 |
| 减薄 | 因腐蚀或冲刷造成的壁厚损失 |
| 定期检验 | 按法规要求对在用压力容器、压力管道进行的周期性检验 |
| 无损检测 NDT | 不损伤被检件的检测方法总称，含射线 RT、超声 UT、磁粉 MT、渗透 PT、涡流 ET |
| 测厚 | 用超声等手段测量设备或管道剩余壁厚 |

## 三、电气与仪表

| 术语 | 含义 |
|---|---|
| 绝缘电阻 | 电气设备带电部分与地之间的电阻，反映绝缘状况 |
| 接地 | 将设备金属外壳与大地可靠连接，防止触电与静电积聚 |
| 变频器 VFD | 改变供电频率实现电机调速的装置 |
| 软启动 | 通过降压或限流方式减小电机启动电流冲击的启动方式 |
| 联锁 | 当某一参数越限时自动触发停机、切断、切换等保护动作的逻辑 |
| 报警 / 联锁定值 | 触发报警或联锁动作的参数设定值（**具体取值查厂内定值表，本文件不列**） |
| DCS | 集散控制系统，实现工艺参数的集中监视与分散控制 |
| SIS | 安全仪表系统，独立于 DCS 承担安全联锁保护功能 |
| 变送器 | 将温度、压力、液位、流量等物理量转换为标准电信号的仪表 |
| 调节阀 | 接受控制信号改变开度以调节流量的执行器 |
| 气开 / 气关 | 调节阀在信号气源中断时的失效位置，气开阀失气关闭，气关阀失气开启 |
| 阀门定位器 | 提高调节阀定位精度与响应速度的附件 |
| 校验 / 检定 | 对仪表示值准确度的检查与调整，检定为法制计量行为 |
| 四线制 / 两线制 | 变送器供电与信号传输的接线方式 |
| 本安 / 隔爆 | 两类电气防爆型式：本安限制能量，隔爆靠外壳承受内部爆炸并阻止传爆 |

## 四、管理与作业

| 术语 | 含义 |
|---|---|
| 位号 TAG | 装置内设备、管线、仪表的唯一编号 |
| 台账 | 记录设备基础信息、运行与检维修履历的登记册 |
| 受控文件 | 经审批发布、有版本标识、更新有程序的正式文件 |
| 操作法 | 岗位操作的规范性文件，含开停工步骤与工艺卡片 |
| 检修规程 | 规定设备解体、检查、修复、回装、验收方法与要求的文件 |
| 技术协议 | 订货时买卖双方约定设备技术要求与随机资料的文件 |
| 预防性维修 PM | 按周期或状态提前实施的维修，区别于故障后的纠正性维修 |
| 预测性维修 PdM | 基于状态监测数据预判劣化趋势后安排的维修 |
| 状态监测 | 对振动、温度、油液、声发射等参数的持续或周期性监测 |
| 缺陷 | 设备偏离正常技术状态、但尚未丧失功能的问题 |
| 故障 | 设备丧失规定功能的状态 |
| 作业票（作业许可证） | 对用火、受限空间、高处、吊装、临时用电、动土、断路、盲板抽堵八类作业实行审批的许可文件（《中国石化作业许可管理规定》，中石化口径写"用火"不写"动火"） |
| 挂牌上锁 LOTO | 检修前对能量源实施隔离、上锁、挂牌，防止意外启动 |
| 盲板抽堵 | 用盲板对管道进行物理隔离或恢复连通的作业 |
| 置换 | 用惰性气体或水蒸汽将设备内可燃、有毒介质排除的作业 |
| 交出 | 生产岗位将设备按规定条件（停运、泄压、置换合格、隔离到位）移交检修的过程 |
| 验收 | 检修完成后按规程对修复质量与功能进行的检查确认 |
| 试运 | 检修回装后的空负荷与负荷运转检查 |
| 特种设备 | 按法规纳入监管的锅炉、压力容器、压力管道、起重机械等 |
| 完整性管理 | 以风险为基础对静设备全生命周期劣化进行识别、评估与控制的管理体系 |
| RBI | 基于风险的检验，按失效可能性与后果确定检验策略 |
| FMEA | 失效模式与影响分析 |
| MTBF / MTTR | 平均故障间隔时间 / 平均修复时间 |

## 六、使用本文件的两条纪律

1. **本文件不含任何技术数值、限值、公差、周期，这是故意的。** 任何「一般是多少」「通常控制在多少」的问题，本文件都答不了，也不该由本文件来答——转 `qa-rules.md` 第三节的数值类口径。
2. **本文件的解释是通用原理**。本厂对同一术语可能有更具体的界定（比如本厂把「点检」和「巡检」分得比这里更细），以厂内文件为准。回答时带上「通用原理，非本厂规定」标注。
