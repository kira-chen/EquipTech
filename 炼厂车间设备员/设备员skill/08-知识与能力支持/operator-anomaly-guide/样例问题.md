# 操作工异常识别指引卡 · 样例问题

> 附件均在 `examples/`（可用 `node scripts/make-sample.js --out examples --seed <n>` 再生，默认 seed=1；区域随 seed 变化，设备类型、覆盖结论与拦截结论不变）。预期计数与验证要点见 `examples/README.md` 对照表（仅开发库含，发布包不含）。

1. 附件是我们车间从 SAP 导出的功能位置清单，帮我按设备类型给外操做一张异常识别指引卡，发现异常先报内操和班长，紧急情况打厂调度。　　**附件：** `examples/sample-sap-export.xlsx`
2. 这是常减压车间的设备台账，里面有加热炉，你按清单出一版指引卡，加热炉那部分不会写的就标出来让工艺补。　　**附件：** `examples/sample-equipment-list.xlsx`
3. 我想在处置动作里加几条：打开泵盖检查、更换机封、检查接线盒外观、通知班长，你看哪些能写进卡里，哪些不能。　　**附件：** `examples/sample-equipment-list.xlsx`
4. 我们厂 HSE 规定外操巡检不准用手摸设备判温度，把摸的内容全部去掉，温度振动按巡检仪读数来。　　**附件：** `examples/sample-sap-export.xlsx`
5. 这份清单没有设备类型那一列，只有位号和名称，能不能按名称自动分类出一版指引卡，报给班长。　　**附件：** `examples/sample-no-type.xlsx`
6. 紧急电话我还没跟安全那边确认，先出一版不带紧急电话的，位置留着我回头填。　　**附件：** `examples/sample-equipment-list.xlsx`
7. 只给离心泵和电机两类做一张卡就行，不用台账，报给班长和车间设备员，出来后告诉我哪些地方要送工艺和安全审核。　　**附件：** 无
8. 外操问发现异常时能不能自己切备泵，指引卡里这条怎么写才不越权。　　**附件：** `examples/sample-sap-export.xlsx`

## 平台接入业务系统 MCP 时

不上传附件，数据由 MCP 工具获取，演示数据每天按剧本刷新。上报对象、紧急上报方式仍须用户按厂内实际流程给出。

M1. 按常减压车间的设备台账给外操做一张异常识别指引卡，发现异常先报内操和班长，紧急情况打厂调度。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（workshop=常减压车间）→ `--ledger`，`--workshop 常减压车间 --report-to "内操、班长" --emergency 厂调度`（预期：按台账设备类型分节，P-2101A/B 在离心泵节、E-1201 在换热器节；常压炉与变送器、界位计归「通用」并标待安全专业补充；区域取「装置」列）
M2. 常减压车间 HSE 规定外操不准用手摸设备，按台账重出一版，把摸的内容全部去掉。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（workshop=常减压车间）→ `--ledger`，加 `--no-touch`（预期：无「摸」小节，异常特征去掉烫手/手感类，warning 写明去掉条数；未给紧急上报方式时标「待车间补充」）
M3. 加氢车间的指引卡里我想加几条处置动作：打开泵盖检查、解除联锁、切换备泵、通知班长，哪些能写。　　**数据：** MCP 设备资产管理 `get_equipment_ledger`（workshop=加氢车间）→ `--ledger`，`--workshop 加氢车间 --report-to 班长 --actions "打开泵盖检查,解除联锁,切换备泵,通知班长"`（预期：「打开泵盖检查」S1、「解除联锁」S6 被拦截改为停止操作并上报；切换备泵、通知班长放行；R-5101 加氢精制反应器归塔器容器节）
