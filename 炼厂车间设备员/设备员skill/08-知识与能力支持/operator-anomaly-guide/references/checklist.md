# 交付自检清单

## 职责边界（核心）
- [ ] **指引卡中没有任何拆检、调整、更换、堵漏、动火、带电作业的动作**
- [ ] 被拦截的动作已单列，说明规则号与原因
- [ ] 「切换备用设备」「降低负荷」带「经值班领导/内操同意后执行」，「关闭就地阀门」「清理泄漏物」带「仅限操作规程明确授权」，且每节下方的【注意】限定行未被删
- [ ] 「检查接线盒外观」类观察描述未被误拦；「拆/接/短接接线」「用火补焊」已拦
- [ ] 每个设备类型节末尾保留「以上动作之外的处置不属于操作工职责」提示

## 判据
- [ ] **异常特征全部是定性描述，没有需要仪器测量的数值**
- [ ] 参照物是「平时」而非绝对值
- [ ] 涉及「摸」的动作带了安全提示（手背试温 / 注意触电 / 勿接触运转部件），且每条前有「仅在操作规程允许且确认安全时」限定语
- [ ] 厂内规程禁止手摸的，已用 `--no-touch`，指引卡无「摸」小节、异常特征无「烫手/手感」

## 结构
- [ ] **紧急撤离条件排在所有设备类型之前**
- [ ] 上报路径来自用户提供，未自行设定
- [ ] 紧急上报方式未提供时标注「待车间补充」，**未填入任何假设的号码**
- [ ] 报告要素清单齐全，并提示「说现象，不用说原因」
