# XX车间 设备异常识别与上报指引

发给：岗位操作工　｜　发现异常报告给：**班长，内操，车间设备员张（分机 8XXX）**
编制：车间设备员（设备专业建议稿）　｜　审核：车间工艺 / 安全　｜　生成时间：2026-XX-XX XX:XX:XX（北京时间）

> **这张卡解决四件事：看什么、什么算异常、先做什么、找谁报。**
> 不要求你判断原因，也不要求你动手修。**看到不对，停下来，报上去。**

> 【注意】本材料仅供参考，不替代操作规程与检修规程；为设备专业建议稿，由车间工艺/安全审核后纳入岗位操作法或 HSE 作业指导书，并与厂内操作规程、应急预案一致后发放；遇紧急情况以应急预案为准。

## 一、什么情况立即撤离并报警

**以下任一情况，不要犹豫，先撤离到上风向安全区，再报告：**

- 大量泄漏、成股喷出或形成气云
- 着火、冒烟或闻到强烈可燃气味
- 设备异常声响急剧增大或有部件飞出迹象
- 可燃 / 有毒气体报警器报警
- 人员出现头晕、恶心、刺激症状
- 设备或管线明显变形、鼓包、开裂

紧急上报方式：**厂内报警 XXX，调度 8XXX**

## 二、离心泵

**本车间该类设备**：P-XXXXA（回流泵A）、P-XXXXB（回流泵B）、P-XXXXC（渣油泵A）

**日常观察要点**

- **看**：
  - 机封或填料处有无滴漏、成股流出
  - 压力表、电流表指示是否明显偏离平时
- **听**：
  - 有无明显异响、金属摩擦声、周期性敲击声
- **摸**：
  - 仅在操作规程允许且确认安全（无带电、无高温烫伤、无运转部件）时：轴承箱是否明显比平时烫手（手背试温，勿长时间接触）

**什么情况算异常**

- 声音明显变大或出现新的异响
- 温度烫手到无法持续接触
- 有可见滴漏或成股流出

**发现异常先做什么**

- 停止操作并上报
- 切换至备用设备（按操作规程，经值班领导/内操同意后执行）
- 降低负荷（按操作规程，经值班领导/内操同意后执行）
- 就地观察并记录现象
- 通知班长 / 内操 / 车间设备员 / 调度

> 【注意】切换备用设备、降低负荷须经值班领导/内操同意后按操作规程执行；关闭就地阀门、清理泄漏物仅限操作规程明确授权的情形。
> 以上动作之外的处置（拆检、调整、更换、堵漏、用火等）**不属于操作工职责**，请勿自行实施。

## 三、报告要说清的信息

报告给 **班长，内操，车间设备员张** 时，把下面几项说清楚：

- 报告人岗位与姓名
- 设备位号与名称
- 发现时间
- 看到/听到/摸到/闻到的具体现象
- 当前设备是否还在运行
- 是否已采取的动作（如已通知谁）
- 现场是否有人员、是否设置警戒

> 说现象，不用说原因。「泵响得比平时大很多，轴承那里烫手」比「轴承坏了」更有用。

## 语言风格要点

| 场景 | 应写 | 不应写 |
|---|---|---|
| 异常判据 | 「声音明显变大」「烫手到无法持续接触」 | 「振动超过 4.5mm/s」「温度超过 75℃」 |
| 处置动作 | 「停止操作并上报」 | 「打开泵盖检查轴承」 |
| 参照物 | 「比平时明显……」 | 给绝对数值 |
| 摸的动作 | 「仅在操作规程允许且确认安全时：……手背试温，勿长时间接触」；规程禁止手摸时用 `--no-touch` | 「摸轴承箱温度」 |
| 切换备用/降负荷 | 「经值班领导/内操同意后按操作规程执行」 | 「发现异常立即切备泵」 |
| 报告内容 | 「说现象，不用说原因」 | 要求操作工判断故障部位 |
| 句子长度 | 短句，一行一件事 | 长段落、专业术语堆叠 |

指引卡的读者是刚上岗的操作工，不是设备员。**能用大白话说清的，不要用专业术语。**
