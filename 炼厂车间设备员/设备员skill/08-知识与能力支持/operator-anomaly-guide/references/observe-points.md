# 各设备类型的看听摸闻要点

> 以下为**默认参考口径**。厂内操作规程有规定的以规程为准，指引卡发放前须经车间审核并与规程一致。

所有要点遵循两条原则：**用定性描述，不用需仪器测量的数值**；**参照物是「平时」**。

## 「摸」类观察点的口径

- 默认：脚本在每条「摸」类观察点前加限定语「仅在操作规程允许且确认安全（无带电、无高温烫伤、无运转部件）时」，`guide.json` 的 `meta.touchQualifier` 记录该限定语。
- `--no-touch`：厂内规程禁止操作工手摸设备判温判振时使用。脚本去掉全部「摸」类观察点，并去掉依赖手摸的异常特征（含「烫手」「手感」「无法持续接触」「异常发烫」字样），`counts.touchPointsRemoved` / `counts.touchSignsRemoved` 记录条数，每节加一行【注意】「本卡不含手摸类观察点；温度、振动是否异常以巡检仪/测温枪读数或车间设备员点检为准」，报告要素里不再要求「摸到」。
- 不启用时两个计数为 `null`（不是 0），表示未做去除。

中石化炼化厂操作工巡检多已配智能巡检仪/点检仪，温度与振动有测点读数的，建议加 `--no-touch`，由仪器读数与 `inspection-data-digest` 汇总判断。

## 离心泵

| 感官 | 要点 |
|---|---|
| 看 | 机封或填料处有无滴漏、成股流出；压力表、电流表指示是否明显偏离平时；联轴器护罩是否完好；地脚螺栓有无松动迹象；油位是否在视镜范围内 |
| 听 | 有无明显异响、金属摩擦声、周期性敲击声；声音较平时是否明显变大 |
| 摸 | 轴承箱是否明显比平时烫手（**手背试温，勿长时间接触**）；振动是否明显比平时大 |
| 闻 | 有无异常焦糊味、油味、介质味 |

**异常特征**：声音明显变大或出现新的异响 / 温度烫手到无法持续接触 / 振动手感明显增强 / 有可见滴漏或成股流出 / 压力电流指示明显偏离平时 / 机体有明显抖动

## 压缩机（含风机）

| 感官 | 要点 |
|---|---|
| 看 | 各级压力、温度指示是否明显偏离平时；油位、油压是否正常；有无可见泄漏；冷却水是否畅通 |
| 听 | 有无异常敲击声、气流啸叫声、喘振声 |
| 摸 | 机体振动是否明显增强 |
| 闻 | 有无焦糊味、油味、可燃气味 |

**异常特征**：出现喘振（周期性压力波动与噪声）/ 声音明显变化 / 振动明显增强 / 油压明显下降 / 可见泄漏

## 换热器

| 感官 | 要点 |
|---|---|
| 看 | 法兰、封头、管口有无渗漏；保温层有无湿痕、油迹；进出口温度指示是否明显偏离平时 |
| 听 | 有无异常流动声、冲击声 |
| 摸 | 保温外表有无异常发烫（**注意烫伤**） |
| 闻 | 有无介质味 |

**异常特征**：法兰或管口可见渗漏 / 保温层有湿痕或油迹 / 进出口温差明显变化

## 塔器容器

| 感官 | 要点 |
|---|---|
| 看 | 人孔、法兰、接管处有无渗漏；液位指示是否正常；保温与防腐层是否破损；基础与支撑有无异常 |
| 听 | 有无异常声响 |
| 闻 | 有无介质味 |

**异常特征**：可见渗漏或滴漏 / 液位异常波动或指示失灵 / 保温层有湿痕油迹 / 安全阀起跳或有泄漏声

## 电机

| 感官 | 要点 |
|---|---|
| 看 | 接线盒是否完好、有无烧灼痕迹；电流表指示是否明显偏离平时；风扇罩是否完好、通风是否受阻 |
| 听 | 有无异常嗡嗡声、摩擦声、放电声 |
| 摸 | 外壳是否明显比平时烫手（**注意触电风险，勿湿手接触**） |
| 闻 | 有无焦糊味、绝缘漆味 |

**异常特征**：有焦糊味或冒烟（**立即上报**）/ 异常声响 / 电流明显偏离平时 / 外壳异常发烫

## 阀门

| 感官 | 要点 |
|---|---|
| 看 | 填料函、阀体、法兰有无渗漏；阀位指示与实际是否一致；执行机构气源、电源是否正常 |
| 听 | 有无内漏的气流声 |

**异常特征**：填料或阀体可见渗漏 / 阀门动作卡涩或不动作 / 阀位与指示不符

## 管道

| 感官 | 要点 |
|---|---|
| 看 | 焊缝、法兰、支吊架有无渗漏与变形；保温层有无破损湿痕；支吊架有无脱落 |
| 听 | 有无异常振动声、冲击声 |

**异常特征**：可见渗漏 / 管道异常振动 / 支吊架脱落或明显变形 / 保温层有湿痕油迹

## 通用（类型不覆盖时）

| 感官 | 要点 |
|---|---|
| 看 | 有无可见泄漏；仪表指示是否明显偏离平时；有无异常变形、松动、破损 |
| 听 | 有无异响，声音较平时是否明显变化 |
| 摸 | 有无异常发烫或振动（**注意安全，勿接触运转部件与带电体**） |
| 闻 | 有无异常气味 |

**异常特征**：出现与平时明显不同的现象 / 可见泄漏 / 异常声响或振动 / 异常气味或冒烟

通用框架仅为兜底，具体要点须由安全与工艺专业补充。
