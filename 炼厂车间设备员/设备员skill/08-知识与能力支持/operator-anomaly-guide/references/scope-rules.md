# 操作工职责边界

> 本技能最重要的约束：**指引卡里出现的每一个处置动作，都必须是操作工职责范围内的。** 写错一条，一线人员照做出事，责任在编制方。

## 一、为什么要机器校验

编写指引卡时很容易顺手写上「打开泵盖看看轴承」这类话。写的人觉得是常识，看的人是刚上岗的操作工。结果就是无票拆检、带电作业、带压堵漏。

因此脚本对每一条处置动作做模式匹配，命中超范围模式的**一律拦截并替换为「停止操作并立即上报」**，同时在报告中单列被拦截的动作与原因。

## 二、超范围动作规则表

| 规则号 | 类别 | 识别模式 | 原因 |
|---|---|---|---|
| S1 | 拆检类 | 拆卸、拆开、拆下、解体、分解、打开泵盖/机壳/端盖/人孔/法兰 | 属维修作业，操作工不得实施 |
| S2 | 调整类 | 调整联轴器/对中/间隙/轴承/密封/弹簧、对中、找正、紧固地脚螺栓 | 需专业工具与技术标准 |
| S3 | 更换类 | 更换/换上/换新 机械密封、机封、填料、轴承、叶轮、口环、垫片、阀门、阀芯、滤芯、皮带、联轴器、部件、零件、备件 | 属检修作业 |
| S4 | 用火类 | 焊接、用火（动火）、切割、打磨 | 须办理用火作业许可（《中国石化作业许可管理规定》八大类之一） |
| S5 | 电气类 | 带电检查/操作、**拆/接/短接/甩开/改/紧固 接线**、短接、甩开联锁保护 | 须由电气专业按票作业。**只拦动手动作**：「检查接线盒外观」「接线盒有无烧灼痕迹」「检查接线是否松动」属观察，不拦 |
| S6 | 联锁屏蔽 | 强行/手动 复位、解除、屏蔽 联锁/报警/保护 | 须走变更与审批流程 |
| S7 | 决策类 | 自行判断/处理/决定 是否能否 继续/停机/运行 | 停机与继续运行由值班领导或工艺决定 |
| S8 | 堵漏类 | 补焊、堵漏、包扎泄漏、带压堵漏 | 须专业队伍按方案实施 |
| S9 | 受限空间 | 进入受限空间/塔/罐/容器/坑 | 须办票并有监护 |
| S10 | 高处作业 | 登高、攀爬超过 2 米/高处 | 须办票并有防护 |

**注意 S3 不拦「更换润滑油」**：加换油在多数厂属操作工职责（按规程执行），拦掉会过度限制。

## 三、职责内动作白名单

| 动作 | 说明 |
|---|---|
| 停止操作并上报 | 最基本、最安全的动作 |
| 切换至备用设备（按操作规程，经值班领导/内操同意后执行） | 限定语是条目的一部分，脚本原样写入指引卡，并在每节下方单独一行【注意】重申 |
| 降低负荷（按操作规程，经值班领导/内操同意后执行） | 同上 |
| 就地观察并记录现象 | 鼓励，为后续判断提供依据 |
| 通知班长 / 内操 / 车间设备员 / 调度 | 按厂内上报路径；中石化炼化厂外操发现异常一般先报内操与班长 |
| 在安全距离外观察，禁止靠近 | 泄漏、异响加剧时 |
| 按应急预案撤离并报警 | 紧急情况 |
| 设置警戒，禁止无关人员靠近 | |
| 关闭就地阀门 | **仅限操作规程明确授权的阀门** |
| 清理泄漏物 | **仅限低危介质且规程授权** |

带限定条件的四条（切换备用、降负荷、关阀、清理泄漏物），写入指引卡时条件必须一并写上；脚本已在 `sections[].actionNote` 与 md 正文写入「切换备用设备、降低负荷须经值班领导/内操同意后按操作规程执行；关闭就地阀门、清理泄漏物仅限操作规程明确授权的情形」，模型不得删掉。

## 四、异常判据用定性不用数值

操作工手上通常没有测振仪、红外测温仪。**指引卡里不能出现「振动超过 4.5mm/s」「轴承温度超过 75℃」这类需要仪器才能判断的判据。**

应当写：
- 「声音明显变大或出现新的异响」
- 「烫手到无法持续接触」
- 「振动手感明显增强」
- 「可见滴漏或成股流出」
- 「指示明显偏离平时」

参照物是「平时」，这是操作工每天接触设备形成的直觉，比任何数值都可靠。

涉及「摸」的动作必须带安全提示：手背试温、勿长时间接触、注意触电风险、勿湿手接触、勿接触运转部件。此外脚本默认在每条「摸」类观察点前加限定语「仅在操作规程允许且确认安全（无带电、无高温烫伤、无运转部件）时」；厂内规程禁止操作工手摸设备判温判振的，运行时加 `--no-touch`，整类去掉并一并去掉「烫手 / 手感」类异常特征（口径见 `observe-points.md`）。

## 五、紧急撤离条件（所有设备通用，必须置顶）

| 条件 |
|---|
| 大量泄漏、成股喷出或形成气云 |
| 着火、冒烟或闻到强烈可燃气味 |
| 设备异常声响急剧增大或有部件飞出迹象 |
| 可燃 / 有毒气体报警器报警 |
| 人员出现头晕、恶心、刺激症状 |
| 设备或管线明显变形、鼓包、开裂 |

这一节在指引卡中**必须排在所有设备类型之前**。命悬一线的时候，没人会翻到第三页。

## 六、上报路径不得自行设定

`--report-to` 是必填参数。脚本不会给出「报告给班长」这类默认值，因为各厂上报对象与流程不同，写错了会延误。

紧急上报方式（`--emergency`）未提供时，指引卡中该项留「待车间补充」并 warning，**不填入任何假设的电话号码**。

## 七、设备类型识别顺序

类型识别是顺序敏感的：**电机必须先于泵与风机判定**。

「鼓风机电机」若被「风机」先命中，就会套用压缩机的观察要点，漏掉「接线盒有无烧灼痕迹」「有无绝缘漆味」这些电气专属项，而这些恰恰是电机异常最早的可见征兆。

当前顺序：电机 → 压缩机 → 离心泵 → 换热器 → 塔器容器 → 阀门 → 管道 → 通用。

**同源说明**：`scripts/lib/scope.js` 的 `TYPE_PATTERNS` 与 `training-material-generator/scripts/lib/tm.js` 的 `TYPE_PATTERNS` 逐字相同，两技能各带一份副本、不互相 require（技能包要求每个技能自包含）。修改任一方的设备类型词表时须同步另一方，否则同一台「鼓风机电机」在指引卡与培训讲义里会归到不同类型。共享抽取由主代理后续处理。

## 八、材料性质与审核归口

本技能产出是**设备专业建议稿**：车间设备员编制，由车间工艺/安全审核后纳入岗位操作法或 HSE 作业指导书。脚本写入的声明行为培训/指引类统一口径：「本材料仅供参考，不替代操作规程与检修规程；为设备专业建议稿，由车间工艺/安全审核后纳入岗位操作法或 HSE 作业指导书，并与厂内操作规程、应急预案一致后发放；遇紧急情况以应急预案为准。」卡头与卡尾各一处，不得删改。

## 九、不在覆盖范围的设备类型

只输出通用观察框架并标注「待安全专业补充」，**不凭通用知识编写具体观察要点**。

加热炉、工业炉、特种设备等有专门操作规程的设备，其观察要点应由安全与工艺专业提供。
