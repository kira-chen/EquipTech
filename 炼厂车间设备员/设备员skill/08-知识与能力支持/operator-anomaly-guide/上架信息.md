# 操作工异常识别指引卡
**技能名称**：操作工异常识别指引卡

**技能简介**：车间设备员按设备类型给岗位操作工编一张"看什么、什么算异常、先做什么、找谁报"的指引卡，脚本自动拦截拆检、调整、用火、接线等超出操作工职责的动作；产出为设备专业建议稿，经车间工艺/安全审核后纳入岗位操作法或 HSE 作业指导书。

**技能描述**

面向炼化厂车间（运行部）设备员。上传车间设备清单或口头说明设备范围，再给出厂内实际的上报对象与紧急电话，技能按离心泵、压缩机、换热器、塔器容器、电机、阀门、管道七类设备生成看、听、摸、闻观察要点，异常特征全用"比平时明显变大"这类定性描述，不给需要仪器判断的数值。紧急撤离条件固定排最前；切换备用设备、降低负荷自带经值班领导同意后执行的限定；不允许手摸的可一键去掉摸类观察点。你自拟的处置动作逐条过职责边界校验，打开泵盖、更换机封、拆接线等一律拦截改为停止操作并上报。不覆盖的设备只出通用框架并标待补充。产出为设备专业建议稿，须经车间工艺、安全审核后纳入岗位操作法，不替代操作规程与应急预案。

**示例问题**
1. 附件是我们车间从 SAP 导出的功能位置清单，帮我按设备类型给外操做一张异常识别指引卡，发现异常先报内操和班长，紧急情况打厂调度。　　**附件：** `examples/sample-sap-export.xlsx`
2. 这是常减压车间的设备台账，里面有加热炉，你按清单出一版指引卡，加热炉那部分不会写的就标出来让工艺补。　　**附件：** `examples/sample-equipment-list.xlsx`
3. 我想在处置动作里加几条：打开泵盖检查、更换机封、检查接线盒外观、通知班长，你看哪些能写进卡里，哪些不能。　　**附件：** `examples/sample-equipment-list.xlsx`
4. 我们厂 HSE 规定外操巡检不准用手摸设备判温度，把摸的内容全部去掉，温度振动按巡检仪读数来。　　**附件：** `examples/sample-sap-export.xlsx`
5. 这份清单没有设备类型那一列，只有位号和名称，能不能按名称自动分类出一版指引卡，报给班长。　　**附件：** `examples/sample-no-type.xlsx`
