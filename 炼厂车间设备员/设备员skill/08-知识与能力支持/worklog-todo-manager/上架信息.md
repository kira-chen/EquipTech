# 工作日志与待办管理
**技能名称**：工作日志与待办管理

**技能简介**：把工单、隐患、定检、校验、润滑、缺陷各技能的产出、值班交接记录里的未完成事项和自记待办汇成一份个人待办清单与工作日志，按到期和优先级排序；昨天没干完的原样结转不延期，没写期限的不代填，疑似重复的只提示不合并。

**技能描述**

面向炼化厂车间（运行部）设备员。把各技能的 JSON 产出（工单、隐患、定检、校验、缺陷、交接记录等）和自己记的待办表或文字交给脚本，自动识别来源类型，按基准日分成已逾期、今日到期、近期、前瞻期外、无到期日五档；优先级按口径表对齐，重大隐患、定检超期、安全阀校验一律最高。上一日 todo.json 传进来后未完成项全部结转，保留原始到期日并标结转自几月几日，不自动延期也不丢弃；来源没给到期日的单列不代填；同一位号出现在多个来源的列为疑似重复供确认，不自动合并。产出待办清单与工作日志，今日完成事项只认你提供的，不推断。业务系统里的工单待办以系统为准；不做团队任务分派与绩效统计。

**示例问题**
1. 把工单、隐患、定检、校验、润滑、缺陷这几份产出和我自己记的待办汇总一下，我今天要干什么。　　**附件：** `sample-orders.json + sample-hazard.json + sample-inspection.json + sample-calibration.json + sample-lube.json + sample-defects.json + sample-todo-sheet.xlsx + sample-todo-text.txt`
2. 昨天值班交接记录里没干完的事也排进来，和工单、缺陷放一起看，有重的别给我合掉。　　**附件：** `sample-handover.json + sample-orders.json + sample-defects.json`
3. 这张跟进表是从 SAP 导出来的，紧急程度写的是 1 到 4，还有几条写的 A 级和 II 级，能按统一口径排吗。　　**附件：** `sample-todo-sap-style.xlsx`
4. 昨天没干完的别丢了，接着往下排；今天做完了 P-1102A 加油和晨会，一起记进日志。　　**附件：** `sample-orders.json`，另附上一日运行本技能得到的 `todo.json`（加 `--prev` 与 `--done`，先跑一遍即可）
5. 这个 JSON 是别的系统导的，能一起读吗；另外只看未来 3 天的。　　**附件：** `sample-unknown.json + sample-orders.json`（加 `--horizon 3`）
