# 交付自检清单

运行脚本后、交付前逐项核对。

## 脚本执行
- [ ] 末行 JSON 的 `ok` 为 `true`；为 `false` 时已把 `error` 原文告知用户并终止
- [ ] `warnings` 已逐条告知用户，未隐去任何一条
- [ ] `compliance.json`、`compliance.md`、`对照表.xlsx` 均已生成

## 条款来源（不得凭记忆）
- [ ] **条款文本由用户提供**，`--rules` 指向的是用户给的文件
- [ ] **未凭记忆写出任何条款编号**（「TSG 21 第 4.2.3 条」这类一律不许）
- [ ] **未凭印象复述、补全、纠正条款原文**
- [ ] 用户只给了标准名称没给文本时，已回问索要文本，**未自行列举条款**
- [ ] 报告中已写明条款来源文件名与「用户提供」字样
- [ ] 企业制度（集团/公司/厂内）同样由用户提供原文，未凭记忆引用《中国石化设备管理规定》等制度的条款内容
- [ ] 用户给的是 PDF 时，已先用平台 pdf 技能转为 txt/docx 再传入（扫描件先 OCR），未让脚本直接读 PDF

## 表述红线（最关键）
- [ ] **全文未出现「符合」「不符合」作为判定结论**
- [ ] 全文未出现「达标 / 不达标」「合规 / 违规 / 违法」「合格 / 不合格」「满足要求 / 不满足要求」作为判定结论
- [ ] 每条条款的状态都是「已见对应材料 / 未见对应材料 / 材料不完整 / 需进一步确认」四者之一
- [ ] 交付时的**口头说明**同样只用这四个词，未在对话里说「这几条符合、那几条不符合」
- [ ] 未给出任何整体性结论（「总体符合要求」「基本合规」「问题不大」）
- [ ] md 开头的四档口径提示保留完整，未删除或弱化

> 产出中允许出现这些词的位置只有三种：技能标题、明确的禁用/免责语句、用户条款原文被逐字搬运的行。除此之外都算违规。

## 未见对应材料
- [ ] **状态写的是「未见对应材料」**，未改成「缺失」「不符合」「待整改」等说法
- [ ] `noEvidence` 项名下没有挂任何材料，**未用相近材料充数**
- [ ] 说明里写的是「在所提供材料中未见」，**未推断原因，未判定后果**
- [ ] 已提示用户核实是否另有归档，而不是断言材料不存在

## 需进一步确认（笼统条款）
- [ ] 笼统条款单列在第四节，**未自行解释条款含义**
- [ ] **未猜测笼统条款指向哪份资料**，未据此改判为已见/未见
- [ ] 每条都写明了笼统在哪（`vagueReason`）
- [ ] 已告知用户该找谁明确条款含义（标准归口部门、法务、上级设备管理部门）

## 材料不完整
- [ ] 「材料不完整」的判定**来自用户填报的「完整性说明」**，未自行推断
- [ ] 名下部分材料齐备、部分不完整的，**仍判材料不完整**，未被齐备的那份掩盖
- [ ] 不完整的具体情形已如实写出（缺页、缺章、仅覆盖部分等）

## 已见对应材料
- [ ] 已注明「材料内容是否满足条款要求需人工核对」，**未把「见到材料」等同于「内容达到要求」**

## 未对应材料
- [ ] 未对应到任何条款的资料单列，**未按名称猜测强行对应到某条条款**

## 不越界
- [ ] **未提供法律意见与法律责任分析**
- [ ] 未分析违反条款的后果（处罚、罚款、责令停产、追究责任）
- [ ] 未判断条款是否适用于本车间
- [ ] 未引用、比附用户未提供的其他法条
- [ ] 未评估法律风险等级
- [ ] 未替代监管检查、内部审计与法务审查的正式判定

## 声明行
- [ ] **末尾声明行逐字保留**：「本对照为辅助自查，仅反映所提供材料与条款的对应情况，不构成合规达标结论与法律意见；正式判定以监管部门、内审或法务意见为准」
- [ ] 声明行未被改写、未被移到不显眼位置、未被删除
- [ ] 声明行后的补充句逐字保留：「最终符合性结论由自查责任人按厂内审核表口径填写，本技能不代填」；未替自查责任人预填任何结论
- [ ] 产出 md 未出现 emoji，醒目提示用「【注意】」

## 分析段
- [ ] 已替换 `<!-- ANALYSIS_START -->` 与 `<!-- ANALYSIS_END -->` 之间的占位文字
- [ ] 字数 200~400
- [ ] 四段结构齐全：材料对应情况概述、未见对应材料的条款及核实方向、材料不完整条款的补充核对方向、需进一步确认条款的明确途径
- [ ] 数字全部引用 `compliance.json` 的 `counts`，未自行统计
- [ ] 分析段同样未出现任何禁用的结论性表述

## 交付说明
- [ ] 已向用户说明：条款总数、已见对应材料数、未见对应材料数、材料不完整数、需进一步确认数
- [ ] 已说明条款来源（用户提供的哪个文件）
- [ ] 已说明脚本 warnings（如有）
- [ ] 已说明本对照不构成达标结论，正式判定以监管部门、内审或法务意见为准；厂内审核表的最终结论由自查责任人填写
