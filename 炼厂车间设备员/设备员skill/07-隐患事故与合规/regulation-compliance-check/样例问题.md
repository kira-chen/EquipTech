# 法规制度符合性自查 · 样例问题

> 附件均在 `演示case/07-隐患事故与合规/regulation-compliance-check/`（**虚构数据**，可用 `node scripts/make-sample.js --seed <n>` 重新生成，默认 seed=1）。样例中的标准名称、条款编号与条款原文**全部虚构**（形如 `XX/T 9xxx—2026（本样例虚构标准）`、`Q/XX-虚构-00N（本样例虚构企业制度）`），不对应任何真实法规、标准或制度，仅用于验证解析与对照逻辑。seed 改变虚构文号与措辞，但每题的预期结论——四档各几条、未对应材料几份——不变；预期计数与验证要点见 `演示case/07-隐患事故与合规/regulation-compliance-check/README.md` 对照表（不进发布包）。运行参数统一 `--workshop 常减压车间 --date 2026-09-21`。

2. 公司下发的这几条制度条款写得比较原则，比如"应当加强管理、确保有效开展"，这种能不能对照出来？对不出来的单独列给我。　　**附件：** `sample-rules-vague.xlsx + sample-materials.xlsx`
3. 我们车间现在手头只有一份设备台账，其他材料还在整理，先按这份条款清单对一遍，把未见材料的条款列出来，我好分头去找。　　**附件：** `sample-rules.xlsx + sample-materials-sparse.xlsx`
4. 这是从标准里摘出来的文字版条款（第X条格式的 md 文件），能不能直接读？对完给我对照表。　　**附件：** `sample-rules.md + sample-materials.xlsx`
5. 上次对照有两条没材料，这次把厂里和公司的制度文件也算上再对一遍，看能不能补上，并标明哪些材料是来自厂内制度的。　　**附件：** `sample-rules.xlsx + sample-materials.xlsx + sample-internal.xlsx`
6. 我们材料挺全的，制度、台账、巡检记录都有，对一下这三条，顺便确认一下报告里不要写"符合"这种话，我要直接交给设备主任。　　**附件：** `sample-rules-small.xlsx + sample-materials-complete.xlsx`
7. 条款清单里有两条写的是"公司设备管理规定"的条款，不是国标，这种企业制度跟法规是不是一样对？对照表里来源列要能看出来。　　**附件：** `sample-rules.xlsx + sample-materials.xlsx`
8. 资料清单里"设备技术档案"我填了"缺页"，"安全阀校验记录"只有一季度的，这两条对出来应该算什么状态？别把它们算成材料齐全。　　**附件：** `sample-rules.xlsx + sample-materials.xlsx`
9. 我只有一份 TSG 规程的 PDF 扫描件，没有条款清单，能直接对吗？告诉我该怎么准备。　　**附件：** 无（预期回答：先用平台 pdf 技能转为 txt/docx，扫描件先 OCR，脚本不读 PDF；不凭记忆列条款）
10. 不给你条款文本，就按"公司设备管理规定"这个名字帮我列一下要求行不行？　　**附件：** 无（预期回答：回问索要条款文本或清单，不凭记忆列举条款编号与要求）

## 平台接入业务系统 MCP 时

> 不上传附件：条款清单、资料清单与厂内制度清单来自平台知识库，本车间台账与记录由 MCP 工具从业务系统取；演示数据每天按剧本刷新，题目只依赖知识库里固定的条款和系统导出的资料种类。

M1. 用知识库里的《法规制度条款清单-设备管理》给常减压车间做一次设备管理自查，台账和各类记录直接从系统里取，看哪些条款还没有对应材料，隐患排查那条别拿通知单凑数。　　**数据：** 平台知识库「KB-法规制度条款清单-设备管理.xlsx」（`--rules`）；MCP 设备资产管理 `get_equipment_ledger`、`get_special_equipment`、`get_safety_valves`、`get_failure_history`、`get_notifications`（均 workshop=常减压车间），点检巡检App `get_inspection_records`（workshop=常减压车间），HSE管理平台 `get_hazards`（workshop=常减压车间）、`get_personnel_certificates`，作业票系统 `get_permits`（workshop=常减压车间），9 份 csv 放同一目录作 `--materials`
M2. 知识库里有一份特种设备使用管理的条款（Word 版），只对一下加氢车间的特种设备台账和安全阀校验台账，看定期检验这条有没有材料。　　**数据：** 平台知识库「KB-法规条款-特种设备使用管理.docx」（`--rules`）；MCP 设备资产管理 `get_special_equipment`、`get_safety_valves`（workshop=加氢车间），2 份 csv 放同一目录作 `--materials`
M3. 知识库里有常减压车间整理好的资料清单和厂内制度清单，按《法规制度条款清单-设备管理》对一遍，资料清单里自己填了不完整的要单列出来。　　**数据：** 数据来自平台知识库：「KB-法规制度条款清单-设备管理.xlsx」（`--rules`）、「资料清单-常减压车间.xlsx」（`--materials`）、「厂内制度清单.xlsx」（`--internal`），不调业务系统工具
