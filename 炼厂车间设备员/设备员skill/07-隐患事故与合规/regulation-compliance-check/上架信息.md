# 技能：法规制度符合性自查
**技能名称**：法规制度符合性自查

**技能简介**：把用户提供的法规标准或企业制度条款与本车间设备管理资料逐条对照，输出"已见材料 / 未见材料 / 材料不完整 / 需确认"四档对照表与缺口清单，不下达标结论。

**技能描述**

面向炼化厂车间设备员，用于迎检前自查、年度设备管理自查或新制度下发后的落实梳理。用户提供条款原文（TSG、GB 或集团、公司、厂内设备管理制度的条款清单，xlsx、docx、md 均可，PDF 先转成文字）与本车间资料清单，脚本逐条比对：条款指向哪类材料、车间有没有、用户自报是否齐全；条款笼统的单列"需进一步确认"，不自行解释，也不拿相近材料充数。产出 md 与 xlsx 对照表，附每条出处与跟进方向。全文只用"已见材料 / 未见材料 / 材料不完整 / 需确认"四档状态，不出现"符合 / 不符合"，不提供法律意见，最终符合性结论由自查责任人按厂内审核表口径填写；不凭记忆引用任何条款，用户只给标准名称时会回问索要文本。

**示例问题**
1. 这是我们车间设备管理自查用的条款清单和资料清单，帮我逐条对一下，看哪些条款还没有对应材料、哪些材料不齐。　　**附件：** `examples/sample-rules.xlsx + examples/sample-materials.xlsx`
2. 公司下发的这几条制度条款写得比较原则，比如"应当加强管理、确保有效开展"，这种能不能对照出来？对不出来的单独列给我。　　**附件：** `examples/sample-rules-vague.xlsx + examples/sample-materials.xlsx`
3. 我们车间现在手头只有一份设备台账，其他材料还在整理，先按这份条款清单对一遍，把未见材料的条款列出来，我好分头去找。　　**附件：** `examples/sample-rules.xlsx + examples/sample-materials-sparse.xlsx`
4. 这是从标准里摘出来的文字版条款（第X条格式的 md 文件），能不能直接读？对完给我对照表。　　**附件：** `examples/sample-rules.md + examples/sample-materials.xlsx`
5. 上次对照有两条没材料，这次把厂里和公司的制度文件也算上再对一遍，看能不能补上，并标明哪些材料是来自厂内制度的。　　**附件：** `examples/sample-rules.xlsx + examples/sample-materials.xlsx + examples/sample-internal.xlsx`
