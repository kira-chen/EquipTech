# 输入规格：隐患整改闭环跟踪

## 支持格式
- `.xlsx`（推荐）或同结构 CSV 目录（文件名 = sheet 名，UTF-8 或 GBK）
- 一次只读一个台账文件：`--input 隐患台账.xlsx`

## 隐患台账工作表（必需）

sheet 名匹配规则：去空白与「表」字后做包含匹配，因此「隐患台账」「隐患排查治理台账」「隐患清单」「隐患」均可识别。找不到时脚本报错终止（台账是唯一数据源）。

| 列名 | 必需 | 说明 |
|---|---|---|
| 隐患编号 | 是 | 与描述同时为空的行会被跳过并 warning；仅编号为空时按描述跟踪并 warning |
| 隐患描述 | 是 | 隐患具体内容 |
| 整改状态 | 是 | 见下方「整改状态取值」 |
| 等级 | 否 | 见下方「等级取值」。**只认「重大/一般」字样；缺失、无法归类或填的是管理层级写法（一级/A 级/厂级）时不映射，台账无期限则进 `undetermined`** |
| 来源 | 否 | 日常巡检 / 车间自查 / 公司（分厂）安全部门检查 / 政府督查 / 集团督查 / HSE 审核 / 第三方诊断 / 事故后整改；原文保留并按来源分布统计 |
| 发现日期 | 否 | 仅当 `--rules` 给出厂内天数时，用于推算一般隐患期限；否则只作展示与闭环时长计算 |
| 责任人 | 否 | 五定「定责任人」依据；督办清单按此分组；为空或填「待定 / 未定 / 无 / 暂无 / — / /」等占位写法时归入「（未填责任人）」组 |
| 责任单位 | 否 | 用于按责任单位分布统计；**不参与车间范围核对**（可能是部门、班组或承包商）。台账没有责任单位类列、只有「车间」列时，责任单位取车间列的值 |
| 要求整改期限 | 否 | 即整改方案期限，五定「定期限」依据；为空 → `undetermined`（无统一天数，不推算） |
| 整改措施 | 否 | 五定「定整改方案」依据 |
| 整改资金 | 否 | 五定「定资金」依据；不需要资金请填「不需要」，留空或填「—」「/」「无」「待定」等占位写法按未落实；台账无此列 warning 一次 |
| 应急措施 | 否 | 五定「定应急措施」依据；留空或填「—」「/」「无」「待定」等占位写法按未落实；台账无此列 warning 一次 |
| 验收情况 | 否 | 见下方「验收取值」 |
| 验收人 | 否 | 非空即视为有验收记录 |
| 验收日期 | 否 | 非空即视为有验收记录；用于计算闭环时长 |
| 整改完成日期 | 否 | 无验收日期时用于计算闭环时长 |
| 车间 | 否 | 所属车间（表头为「车间」「所属车间」「属地车间」「运行部」或其后加「名称」，如「车间名称」；「车间负责人」等人员列不算），用于按 `--workshop` 核对车间范围，规则见下方「车间范围核对」 |

## 等级取值

统一口径为 **重大隐患 / 一般隐患**（《中国石化安全隐患管理规定》）：

| 归类 | 可识别的写法 |
|---|---|
| 重大隐患 | 重大、重大隐患、重大级 |
| 一般隐患 | 一般、一般隐患、普通 |
| **等级缺失** | 空单元格、—、-、/ |
| **等级无法识别（含管理层级写法）** | 一级/二级/三级、A 级/B 级/C 级、公司级/厂级/车间级、以及其他文字（如「特急级」「待定级」） |

「一级/A 级/厂级」在多数厂是管理层级（由谁挂牌督办），不是严重度，**脚本不直接映射**；warning 提示「疑似管理层级写法」。厂内确有对应关系时用 `--rules` 的「等级映射」表声明（见下）。

等级无法识别的项：台账有「要求整改期限」仍按期限判超期/临期（期限判定不依赖等级），但不计入重大隐患、不触发重大隐患提示；台账无期限 → `undetermined`，**绝不按一般隐患或任何默认天数处理**（详见 `hazard-rules.md`）。

## 整改状态取值

| 归类 | 可识别的写法 |
|---|---|
| 已整改 | 已整改、已完成、整改完毕、已闭环、已销号、完成、整改完成、已处理 |
| 整改中 | 整改中、进行中、实施中、在改、部分完成、整改进行、处理中 |

> 判定顺序：以「已整改 / 已完成 / 整改完成 / 已处理 / 已闭环 / 已销号」开头的先归已整改（如「已整改未销号」，未销号、未验收交给验收判定）；再认否定写法（「整改未完成」「尚未整改完」「没处理」等，否定词与动词之间不超过 3 个字且不含「已」；「不」只认紧贴动词，「不符合项整改完成」不算否定）归未整改；然后认整改中，最后认已整改。只按「含完成」判已整改会把「未完成」「部分完成」误当已整改，藏掉超期项。
| 未整改 | 未整改、未开始、待整改、未处理、未实施 |
| **状态无法识别** | 以上都不匹配的其他文字（如「待定」） |
| **状态未填** | 空单元格 |

状态无法识别与未填 → `undetermined`，并注明是状态字段缺失。

## 验收取值

| 归类 | 可识别的写法 |
|---|---|
| 已验收 | 已验收、验收合格、合格、通过、验收通过、符合、是、已销号、已确认 |
| 未验收 | 未验收、不合格、未通过、否、待验收、未复查 |
| 无法归类 | 其他文字 → **按无验收记录处理（就严）并 warning** |

**有验收记录** = 验收情况判为合格 **或**（验收情况不是「不合格 / 未通过 / 待验收」等否定写法 **且** 验收人或验收日期非空）。验收情况明确为否定写法时，即使填了验收人、验收日期也不算验收通过（就严）。

> **关键口径**：整改状态为「已整改」但无验收记录 → `unverified`，**绝不计入已闭环**，闭环率分子不含该项。

## 日期字段
- 支持：`2026-09-21`、`2026/9/21`、`2026年9月21日`、`20260921`、Excel 日期单元格、Excel 日期序列号
- 无法解析时输出 `null` 并 warning，**不猜测**；该字段参与的判定相应进 `undetermined`

## 厂内口径文件（可选，`--rules`）

一个 xlsx，可含以下一张或两张工作表；命中任一张即在报告标注「厂内口径（文件名）」。两张都没有 → warning 并按默认口径。

### 「整改时限」表（厂内有统一天数时才提供）

| 列名 | 必需 | 说明 |
|---|---|---|
| 等级名称 | 是 | 重大隐患 / 一般隐患 |
| 时限天数（别名：整改时限、时限、天数） | 是 | 支持「15天」「2周」「3个月」「1年」或纯数字（按天），由 `parsePeriod` 解析 |

等级无法归类或时限无法解析的行会被忽略并 warning，该等级仍按默认口径（无统一天数）。

### 「等级映射」表（厂内用 A/B/C 级、一级/二级、厂级等写法时提供）

| 列名 | 必需 | 说明 |
|---|---|---|
| 原始等级（别名：厂内等级、台账等级） | 是 | 台账里的写法，如「A级」「厂级」 |
| 归类（别名：对应等级、映射为、严重度） | 是 | 只接受含「重大」或「一般」字样的值 |

归类不是重大/一般的行忽略并 warning。映射只在本次运行生效，脚本不记忆。示例见演示样例 `sample-hazard-rules.xlsx`。

## 上期 hazard.json（可选，`--prev`）

传入上期本脚本产出的 `hazard.json`，输出隐患总数、超期数、闭环率的环比。缺失时对比章节输出「未提供上期 hazard.json」。

上期 hazard.json 的车间与 `--workshop` 核对（D007）：上期产出的 `meta.workshop` 与 `--workshop` 不一致时不做上期对比（同未提供上期），warning 与报告开头【注意】提示；一致时照常使用；上期产出没有 `meta.workshop` 时照常使用，口径处写「上期 hazard.json 未注明车间，无法核对，已照常使用」。核对结果写进 `meta.prevWorkshop`（status：matched / excluded / unknown / noWorkshop）。

## 车间范围核对

隐患台账带车间列时（表头为「车间」「所属车间」「属地车间」「运行部」或其后加「名称」，如「车间名称」；「车间负责人」等人员列不算），脚本按 `--workshop` 逐表核对，结果写进 `hazard.json` 的 `meta.workshopScope`（每张表一项），口径写进报告：

- 有本车间的行：剔除其他车间的行，warning 写明剔除行数与车间名；车间名比对去空白、忽略末尾「车间/运行部」（「常减压」与「常减压车间」视为同一车间）
- 车间列为空的行按本车间保留，warning 写明行数
- 没有一行是本车间：不筛，warning 以【注意】开头，报告标题下写【注意】提示（多半是传错了文件）
- 没有车间列：不筛，报告口径处写「输入未含车间列，车间范围以取数条件为准」。系统导出多数不带车间列，取数时仍必须带 `workshop`
- 「维护工厂」「计划工厂」是 SAP 工厂代码，「使用单位」「责任单位」「作业单位」可能是公司、部门或承包商，都不当车间列

## 会被跳过的行
- 全空行
- 首列以 合计 / 小计 / 总计 / 共计 / 总数 开头的行（warning 提示）
- 隐患编号与描述均为空的行（warning 提示）
- 带车间列时其他车间的行（warning 提示剔除行数与车间名）

## 不会被跳过、但会单列的情况
- 隐患编号重复：**两条均保留并各自判定**，warning 注明两处行号
- 整改状态非「已整改」却已填验收记录：进「状态与验收矛盾」一节，warning 提示，**脚本不作取舍**
