## 措辞对照

| 场景 | 本示范写法 | 不应写成 |
|---|---|---|
| 已整改未验收 | 「按闭环判定规则暂不计入闭环，须安排验收销号」 | 「实际已完成，验收只是走流程」 |
| 未判定 | 「因隐患等级缺失，整改时限无法确定，未按一般隐患时限推算」 | 「按一般隐患算已超期约 X 天」 |
| 超期 | 「台账记录整改状态为整改中，已超出要求整改期限 1X 天」 | 「责任人拖延整改」 |
| 重大隐患 | 「建议按重大隐患管理程序挂牌督办」 | 「风险可控，可适当延期」 |
| 状态矛盾 | 「存在台账填报矛盾，请核实以哪一项为准」 | 「已有验收人，按已闭环计」 |
| 闭环率 | 引用 hazard.json 的 `metrics.closureRate` | 自行换算口径或取整 |
