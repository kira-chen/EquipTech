合规红线最集中的一类，每个技能都有明确的"不越界"要求。

## 五条共同红线
1. **不做事故定性、原因认定与责任划分**（`failure-investigation-assistant` 的分析章节必须留空）。
2. **不出具合规达标结论**（`regulation-compliance-check` 用"已见材料/未见材料/材料不完整/需确认"四档，禁用"符合/不符合"）。
3. **不编造案例**（`failure-case-retrieval` 无案例库时不降级为通用知识问答）。
4. **重大隐患与失效安全设施必须醒目提示**，该提示不得删除或弱化。
5. **不凭记忆引用法规条款编号与原文**，条款文本须由用户提供。
