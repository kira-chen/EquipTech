# 故障案例检索
**技能名称**：故障案例检索

**技能简介**：拿当前故障现象去本厂案例库、SAP 通知单导出或兄弟厂案例汇编里找类似案例，按现象、设备类型、故障部位和 SAP 损坏代码打分排序，逐条标出匹配依据与不同点；没有案例库就明确说用不了，不编案例。

**技能描述**

面向炼化厂车间（运行部）设备员。设备出了状况想知道以前遇到过没有、当时怎么处理的，把案例库（Excel/CSV、Word 表格、md 表格或 SAP PM 通知单导出，PDF 先转文本）和现象描述交给技能，脚本按现象相似度、设备类型、故障部位加权打分，可选按 SAP 损坏代码把同代码案例排前，返回命中案例的现象、当时判定原因、处置方式、效果与出处，每条附哪些特征相似、哪些条件不同。机型按离心压缩机、往复压缩机、汽轮机等细分不混用。相似度不达标的单列为仅供参考，不往命中里凑；没给案例库或库里没有可检索记录，技能直接终止说明，不用通用知识编案例。不做原因判定与事故定性，原因初判和重复故障识别由其他技能处理。

**示例问题**
1. P-1101A 机封一直滴漏，一分钟五六滴，泵底有油渍，案例库里有没有类似的，当时是怎么处理的。　　**附件：** `sample-case-library.xlsx`
2. 这是从 SAP 导出来的 M2 故障通知单清单，损坏代码 LEAK01，帮我查同代码的案例，位号和设备编号分开列。　　**附件：** `sample-sap-notification-export.xlsx`
3. 兄弟厂给的案例汇编是 Word 表格，机封滴漏这种能直接在里面查吗。　　**附件：** `sample-case-library.docx`
4. 裂解气压缩机干气密封泄漏量上升、密封气压差往下掉，案例库里大机组有没有类似的，别把往复机的混进来。　　**附件：** `sample-case-library.xlsx`
5. 往复压缩机干气密封泄漏报警，案例库查一下；要是没有就直说，别拿别的设备的案例凑数。　　**附件：** `sample-pump-only.xlsx`
