## 平台接入业务系统 MCP 时

> 不上传附件，案例库由 MCP 工具从设备资产管理系统的故障历史导出；演示数据每天按剧本刷新，题目只依赖剧本里固定的位号和故障现象。

M1. P-2101A 进料泵驱动端振动大、轴承箱有异响，你从系统里把本厂离心泵的历史故障调出来，看看以前有没有类似的，当时怎么处理的。　　**数据：** MCP 设备资产管理 `get_failure_history`（equip_type=离心泵，for_skill=failure-case-retrieval）；运行时加 `--part 轴承`
M2. E-1201 柴油-原油换热器冷却水回水含油，壳程压力跟着管程压力变，怀疑管束内漏，查一下本厂换热器有没有类似的故障案例。　　**数据：** MCP 设备资产管理 `get_failure_history`（equip_type=换热器，for_skill=failure-case-retrieval）；运行时加 `--part 管束`
M3. C-3101A 往复压缩机一级排气温度高、排气阀有异响，往复压缩机以前出过这种问题吗，别把离心机的案例混进来。　　**数据：** MCP 设备资产管理 `get_failure_history`（equip_type=往复压缩机，for_skill=failure-case-retrieval）；运行时加 `--part 气阀`
