# 技能：故障调查辅助
**技能名称**：故障调查辅助

**技能简介**：设备故障后，把 DCS 导出、报警记录、操作与巡检记录、值班记录、SAP 工单历史归集成一条带出处的时间线，按设备事故调查报告的常规章节搭好框架，原因、责任、防范措施三节留给调查组填写。

**技能描述**

面向炼化厂车间（运行部）设备员，在设备故障后为调查组准备材料。上传故障相关记录（DCS 历史与报警、操作、巡检、值班记录，检修历史可用 SAP PM 工单导出），告知位号、发生时间与现象，技能按你确认的时间窗口把各来源记录排成一条时间线，每条带来源文件与行号；DCS 与手工记录时间对不上的全部保留并标出差异，不取其一；参数缺口只标注区间，不插值。产出按事故调查报告常规章节组织的十节框架，原因分析、责任分析、防范措施恒为空；记录里"导致""操作不当""事故"等归因、定性、追责表述逐条标出并给改写建议，不改原文。事故等级、是否非计划停工和报送时限由调查组按厂内规定认定，技能不判定。不编报事故快报。

**示例问题**
1. 常减压 P-3201A 今天上午 10:40 泵体异响、振动升高后切泵了，附件是 DCS 参数、报警、操作、巡检和值班记录，帮我按调查报告的框架把材料归集一下，时间线要能对回原始记录。　　**附件：** `sample-failure-records-2026-09-21.xlsx + sample-maintenance-history.xlsx`
2. 检修历史我是从 SAP 的 IW38 导出来的，列名是订单、订单类型、功能位置、短文本这些，不想改表头，能直接用吗？帮我把近半年这台泵的工单一起归进去。　　**附件：** `sample-failure-records-2026-09-21.xlsx + sample-sap-pm-orders.xlsx`
3. 现在手上只有报警记录，其他材料还在调，先帮我起个调查报告框架，缺什么材料列个清单我去要。　　**附件：** `sample-alarms-only.xlsx`
4. 班组交上来的操作记录里写了"轴承温度升高导致振动增大""操作工王某操作不当"，调查组还没开会定性，这些话能不能直接进时间线？帮我过一遍。　　**附件：** `sample-causal-wording.xlsx`
5. 仪表那边导的 DCS 历史表第一行是标题、列名是时刻/测点/数值，底下还有合计行，帮我看看能不能读，另外把回溯窗口改成故障前 12 小时、后 6 小时。　　**附件：** `sample-dcs-export.xlsx`
